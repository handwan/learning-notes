    聚类与降维¶

    前四篇都有标签：给定 (x, y)，学一个预测函数。

    这篇没有标签：

    • 聚类：把相似的点分成组
    • 降维：把高维数据压到低维，保留主要结构

    无监督学习没有“正确答案”，所以评估比监督学习更难。

    1. 聚类是什么¶

    给定 n 个点，没有标签，把点分成 k 组，使组内相似、组间不同。

    用途：

    • 客户/用户分群
    • 异常检测
    • 数据压缩/去重
    • 可视化
    • 给监督模型做特征

    注意：

    • 簇的编号是任意的；cluster 0 和 cluster 1 换个名字不影响结果
    • “聚类算法总能给出簇”，不代表数据里真的有簇
    • 没有标签时，不能直接算准确率

    2. K-means¶

    算法¶

    1. 选 k 个初始中心
    2. 每个点分到最近的中心
    3. 每个簇的中心更新为成员均值
    4. 重复 2–3，直到中心不再变化

    目标函数（inertia）：

    \[ J=\sum_{i=1}^{n}\lVert\mathbf{x}_i-\boldsymbol{\mu}_{c_i}\rVert_2^2 \]

    初始化¶

    随机选初始中心容易落到局部最优。常用 k-means++：

    • 第一个中心随机选
    • 后续中心按“离已有中心越远，概率越大”选
    • 再做多次重启，取 inertia 最小的一次

    300 个点、3 个高斯簇，标准化后跑 \(k=2,\dots,6\)。

    K-means：代码与结果¶

    核心是下面的重启循环，k-means++ 和轮廓系数的实现放在前面：

    import numpy as np

def kmeans_pp(X, k, rng, max_iter=100):
    n = len(X)
    centers = [X[rng.integers(n)]]
    for _ in range(1, k):
        d2 = np.min(((X[:, None, :] - np.array(centers)[None, :, :]) ** 2).sum(2), axis=1)
        probs = d2 / d2.sum()
        centers.append(X[rng.choice(n, p=probs)])
    C = np.array(centers)

    for _ in range(max_iter):
        D = ((X[:, None, :] - C[None, :, :]) ** 2).sum(2)
        labels = D.argmin(1)
        newC = C.copy()
        for j in range(k):
            if (labels == j).any():
                newC[j] = X[labels == j].mean(0)
            else:
                newC[j] = X[rng.integers(n)]
        if np.allclose(newC, C):
            break
        C = newC

    D = ((X[:, None, :] - C[None, :, :]) ** 2).sum(2)
    labels = D.argmin(1)
    inertia = D[np.arange(n), labels].sum()
    return labels, C, inertia

def silhouette(X, labels):
    n = len(X)
    D = np.sqrt(((X[:, None, :] - X[None, :, :]) ** 2).sum(2))
    ss = []
    for i in range(n):
        same = labels == labels[i]
        same[i] = False
        if same.sum() == 0:
            ss.append(0.0)
            continue
        a = D[i, same].mean()
        b = min(D[i, labels == c].mean() for c in np.unique(labels) if c != labels[i])
        ss.append((b - a) / max(a, b))
    return float(np.mean(ss))

    数据生成折在下面；先展开再跑：

    数据生成（先展开） 
    rng = np.random.default_rng(12)
centers = np.array([[-2, 0], [2, 0], [0, 3]])
X = np.vstack([rng.normal(c, 0.6, (100, 2)) for c in centers])
X = (X - X.mean(0)) / X.std(0)

    for k in range(2, 7):
    best = None
    for s in range(10):
        labels, C, inertia = kmeans_pp(X, k, np.random.default_rng(100 + s))
        if best is None or inertia < best[0]:
            best = (inertia, labels, C)
    inertia, labels, C = best
    print(k, round(inertia, 2), round(silhouette(X, labels), 3))

    运行结果：

    k inertia 轮廓系数
    2 333.05 0.483
    3 79.18 0.697
    4 65.96 0.589
    5 56.00 0.477
    6 46.07 0.367

    inertia 在 \(k=3\) 后下降变慢（肘部），轮廓系数也在 \(k=3\) 最高。选 3。

    怎么选 k¶

    • 肘部法：inertia 随 k 下降，找下降变慢的拐点
    • 轮廓系数：\(\dfrac{b-a}{\max(a,b)}\)，\(a\) 是到同簇的平均距离，\(b\) 是到最近其他簇的平均距离；越大越好
    • 业务约束：分群数量要能解释、能运营
    • 稳定性：换种子/重采样后簇是否还一致

    不要只看 inertia：它随 \(k\) 单调下降，\(k=n\) 时 \(J=0\)，没有意义。

    3. 层次聚类¶

    凝聚式¶

    1. 每个点是一个簇
    2. 找距离最近的两个簇合并
    3. 重复，直到只剩一个簇
    4. 用树状图（dendrogram）看合并高度，决定切在哪

    簇间距离（linkage）：

    linkage 距离定义
    single 两组间最近点
    complete 两组间最远点
    average 两组间所有点对的平均
    ward 合并后方差增加最小

    层次聚类：代码与结果¶

    12 个点、两个真实组，single linkage：

    import numpy as np

rng = np.random.default_rng(14)
X = np.vstack([rng.normal([-2, 0], 0.35, (6, 2)),
               rng.normal([2, 0], 0.35, (6, 2))])
n = len(X)

def agglomerate(X, stop):
    clusters = [[i] for i in range(len(X))]
    heights = []
    while len(clusters) > stop:
        best = None
        for i in range(len(clusters)):
            for j in range(i + 1, len(clusters)):
                d = min(np.linalg.norm(X[a] - X[b])
                        for a in clusters[i] for b in clusters[j])
                if best is None or d < best[0]:
                    best = (d, i, j)
        d, i, j = best
        clusters[i] += clusters[j]
        clusters.pop(j)
        heights.append(d)
    return clusters, heights

_, heights = agglomerate(X, 1)
print("first", [round(h, 3) for h in heights[:3]])
print("last ", [round(h, 3) for h in heights[-3:]])

clusters, _ = agglomerate(X, 2)
print("sizes", [len(c) for c in clusters])

    运行结果：

    first [0.096, 0.101, 0.12]
last  [0.856, 1.046, 2.329]
sizes [6, 6]

    前几次合并高度在 0.1 左右（簇内），最后一次 2.329（两个簇之间），差距明显；切在 2.329 之前得到 6/6 两组。

    特点¶

    • 不需要预先指定 k
    • 树状图能看多尺度结构
    • 时间复杂度高（朴素 \(O(n^3)\)，优化后 \(O(n^2\log n)\)），内存 \(O(n^2)\)
    • 对噪声和 linkage 选择敏感；single linkage 容易“链式”合并

    4. PCA¶

    目标¶

    找一组正交方向，使数据投影后的方差最大：

    \[ \max_{\lVert\mathbf{v}\rVert_2=1}\operatorname{Var}(X\mathbf{v}) \]

    步骤：

    1. 中心化/标准化
    2. 算协方差矩阵 \(C=\dfrac{1}{n-1}X^\top X\)
    3. 对 C 做特征分解，按特征值从大到小排
    4. 取前 \(k\) 个特征向量，投影：\(Z=XV_k\)

    特征值就是每个主成分的方差；特征值 / 总和 是解释方差比例。

    也可以用 SVD：\(X=USV^\top\)，主成分方向就是 \(V\) 的列。

    PCA：代码与结果¶

    500 个样本、10 个特征，背后只有 3 个潜在因子：

    import numpy as np

rng = np.random.default_rng(13)
n = 500
Z = rng.normal(size=(n, 3))
A = rng.normal(size=(3, 10))
X = Z @ A + rng.normal(0, 0.1, (n, 10))
X = (X - X.mean(0)) / X.std(0)

C = np.cov(X, rowvar=False)
vals, vecs = np.linalg.eigh(C)
order = np.argsort(vals)[::-1]
vals, vecs = vals[order], vecs[:, order]
explained = vals / vals.sum()

print("explained", [round(float(v), 4) for v in explained[:5]])
for k in [1, 2, 3, 4, 5]:
    P = X @ vecs[:, :k]
    R = P @ vecs[:, :k].T
    print(k, round(float(np.mean((X - R) ** 2)), 4))

    运行结果：

    主成分数 解释方差 累计 重构 MSE
    1 0.5077 0.5077 0.4923
    2 0.3004 0.8081 0.1919
    3 0.1859 0.9940 0.0060
    4 0.0027 0.9967 0.0033
    5 0.0008 0.9975 0.0025

    3 个主成分解释了 99.4% 的方差，重构 MSE 从 0.49 降到 0.006；再多加主成分收益很小。

    怎么选主成分¶

    • 累计解释方差到 90%/95%
    • 看碎石图（scree plot）的拐点
    • 下游任务效果：降维后模型是否变好
    • 可解释性：主成分是否能解释

    局限¶

    • 线性：非线性结构用 kernel PCA/UMAP
    • 按方差排序：方差小的方向可能有判别信息
    • 对尺度敏感：先标准化
    • 对异常值敏感
    • 主成分是原特征的线性组合，解释起来不一定直观

    5. 怎么判断聚类有没有意义¶

    聚类没有标签，不能直接算准确率。常用：

    方法 看什么
    轮廓系数 簇内紧、簇间远；[-1,1]，越大越好
    Davies-Bouldin 簇内/簇间比值；越小越好
    Calinski-Harabasz 簇间/簇内方差比；越大越好
    稳定性 换种子/重采样后 ARI 是否高
    外部指标 有标签时用 ARI/NMI
    业务检查 看簇中心/代表样本，是否能解释

    绝对值不可靠¶

    上面的实验里，随机 2D 数据做 k-means，轮廓系数也能到 0.327：

    # 接着上一段：kmeans_pp、silhouette 已定义
rng_random = np.random.default_rng(15)
R = rng_random.normal(size=(300, 2))
labels, C, inertia = kmeans_pp(R, 3, np.random.default_rng(1))
print("random", round(silhouette(R, labels), 3))

    所以：

    • 轮廓系数没有统一阈值：0.3 在随机数据上也可能出现，0.7 只是经验上较明显
    • 不同数据集的轮廓系数不能直接比
    • 最好和随机基线/置换检验比
    • 结合稳定性和业务解释

    6. 其他方法¶

    方法 特点
    DBSCAN 密度聚类，任意形状，能标噪声；要调 eps/min_samples
    GMM 软聚类，椭圆簇；EM 训练；BIC/AIC 选成分数
    t-SNE 可视化；保留局部邻域；距离/密度不可直接解释
    UMAP 可视化/降维；比 t-SNE 快；参数敏感

    注意：t-SNE/UMAP 的坐标不要拿来做聚类或监督特征，它们主要用来“看”。

    7. 什么时候用¶

    适合：

    • 探索性分析：有没有分群、异常、低维结构
    • 用户/客户分群
    • 异常检测（离簇远/密度低）
    • 压缩、去重、可视化
    • 给监督模型做特征（要小心泄漏）

    不适合：

    • 当成有监督预测的替代
    • 把簇编号当真实标签
    • 用聚类证明因果
    • 在训练集+测试集上一起拟合 PCA/聚类，再评估监督模型

    8. 常见坑¶

    • 不标准化，量纲大的特征主导距离
    • 只看 inertia 选 k；它随 k 单调下降
    • 轮廓系数和随机基线比，绝对值不当阈值
    • K-means 用在非球形/大小差异大的簇
    • 层次聚类 single linkage 链式合并
    • PCA 不标准化/不处理异常值
    • 把 PCA 主成分解释成因果/业务含义
    • t-SNE/UMAP 坐标拿来做聚类
    • 在全集上拟合 PCA/聚类，造成监督评估泄漏
    • 把簇编号跨运行比较（编号是任意的）

    9. 要点回顾¶

    1. 聚类无标签，簇编号任意；算法总能给簇，不代表有结构
    2. K-means：最近中心分配 + 均值更新；k-means++、多次重启
    3. 选 k：肘部 + 轮廓系数 + 稳定性 + 业务
    4. 层次聚类：linkage 决定形状；树状图切高度；\(O(n^2)\) 内存
    5. PCA：最大方差方向；解释方差/重构误差选主成分；先标准化
    6. 评估：内部指标要和随机基线/稳定性一起看
    7. 可视化降维（t-SNE/UMAP）不要当特征/聚类依据
