# 最小线性模型

[第 1 篇](01-张量与自动微分.md) 有了张量和 autograd；这一篇把它们拼成一个完整的训练循环。

线性回归是最小可训练模型，softmax 回归是最小分类模型。两者共用同一套骨架：

```text
前向 → 损失 → 反向 → 更新
```

线性模型的概念在 [ML Basics 第 2 篇](../ml-basics/02-线性模型.md) 讲过；这里主要是从零写循环，并和闭式解对拍。

## 1. 线性回归

### 线性回归：数据与模型

先造一份带噪声的线性数据：

$$
y = X\mathbf{w} + b + \varepsilon
$$

??? note "代码：线性回归：数据与模型"
    ```python
    import torch

    torch.manual_seed(0)
    n, d = 200, 3
    X = torch.randn(n, d)
    w_true = torch.tensor([2.0, -1.0, 0.5])
    b_true = 0.7
    y = X @ w_true + b_true + 0.1 * torch.randn(n)
    ```

真实参数是 `[2, -1, 0.5]`，截距 `0.7`，噪声标准差 `0.1`。

模型：

$$
\hat{y} = X\mathbf{w} + b
$$

损失用 MSE：

$$
L(\mathbf{w},b)
= \frac{1}{n}\sum_{i=1}^{n}(\hat{y}_i-y_i)^2
$$

### 闭式解

对 $\mathbf{w}$ 求导并令其为 0：

$$
\nabla_{\mathbf{w}}L
= \frac{2}{n}X^\top(\hat{\mathbf{y}}-\mathbf{y})=0
\;\Longrightarrow\;
\mathbf{w}=(X^\top X)^{-1}X^\top\mathbf{y}
$$

把 `b` 当成多出来的一列 1，就能一起解：

??? note "代码：闭式解"
    ```python
    Xb = torch.cat([X, torch.ones(n, 1)], dim=1)
    w_closed = torch.linalg.lstsq(Xb, y).solution

    with torch.no_grad():
        mse_closed = ((Xb @ w_closed - y) ** 2).mean().item()

    print("closed", [round(v, 4) for v in w_closed.tolist()], round(mse_closed, 6))
    ```

输出：

```text
closed [1.9937, -1.0026, 0.4951, 0.7004] 0.011381
```

最后一个数是截距。MSE 约 `0.0114`，接近噪声方差 `0.01`。

实际代码用 `torch.linalg.lstsq`，不显式求逆，数值更稳。

### 从零写训练循环

不用闭式解，用梯度下降：

$$
\mathbf{w} \leftarrow \mathbf{w}
-\eta\,\frac{2}{n}X^\top(\hat{\mathbf{y}}-\mathbf{y})
$$

??? note "代码：从零写训练循环"
    ```python
    w = torch.zeros(d, requires_grad=True)
    b = torch.zeros(1, requires_grad=True)
    lr = 0.1

    for step in range(500):
        pred = X @ w + b
        loss = ((pred - y) ** 2).mean()

        loss.backward()

        with torch.no_grad():
            w -= lr * w.grad
            b -= lr * b.grad

        w.grad.zero_()
        b.grad.zero_()

    with torch.no_grad():
        mse_gd = ((X @ w + b - y) ** 2).mean().item()

    print("gd    ", [round(v, 4) for v in w.detach().tolist()],
          round(b.item(), 4), round(mse_gd, 6))
    ```

输出：

```text
gd     [1.9937, -1.0026, 0.4951] 0.7004 0.011381
```

逐行看：

- `pred = X @ w + b`：前向，建计算图
- `loss = ((pred - y) ** 2).mean()`：标量损失
- `loss.backward()`：反向，把梯度写进 `w.grad` 和 `b.grad`
- `with torch.no_grad(): ...`：更新参数时不需要建图
- `w.grad.zero_()`：清空梯度；不清会累加

### 和闭式解对比

| 方法 | w | b | MSE |
|---|---|---|---|
| 闭式解 | `[1.9937, -1.0026, 0.4951]` | `0.7004` | `0.011381` |
| 梯度下降 | `[1.9937, -1.0026, 0.4951]` | `0.7004` | `0.011381` |

500 步后参数和 MSE 基本一致。闭式解是精确解；梯度下降是迭代逼近，步数足够时也会到同一个点。

闭式解不是万能的：

- 特征多、样本多时，矩阵求逆很贵
- `XᵀX` 可能不可逆
- 模型一旦非线性，就没有闭式解

所以梯度下降才是通用方法。

## 2. 从回归到分类：softmax 回归

### Softmax 回归：数据与模型

造三个二维高斯簇，做三分类：

??? note "代码：Softmax 回归：数据与模型"
    ```python
    import torch
    import torch.nn.functional as F

    torch.manual_seed(1)
    n_per = 100
    means = torch.tensor([[-2., -1.], [2., -1.], [0., 2.]])
    X = torch.cat([means[i] + torch.randn(n_per, 2) for i in range(3)])
    y = torch.repeat_interleave(torch.arange(3), n_per)

    perm = torch.randperm(len(y))
    X, y = X[perm], y[perm]

    ntr = 240
    Xtr, ytr = X[:ntr], y[:ntr]
    Xte, yte = X[ntr:], y[ntr:]

    # 只用训练集统计量，避免泄漏
    mu, sd = Xtr.mean(0), Xtr.std(0)
    Xtr = (Xtr - mu) / sd
    Xte = (Xte - mu) / sd
    ```

模型先算每个类别的分数，再归一化成概率：

$$
\mathbf{z} = XW + \mathbf{b},
\qquad
p_k = \frac{e^{z_k}}{\sum_{j=1}^{K}e^{z_j}}
$$

损失用交叉熵：

$$
L = -\log p_y
$$

### 训练循环

??? note "代码：训练循环"
    ```python
    W = torch.zeros(2, 3, requires_grad=True)
    b = torch.zeros(3, requires_grad=True)
    lr = 0.1

    for epoch in range(200):
        logits = Xtr @ W + b
        loss = F.cross_entropy(logits, ytr)

        loss.backward()

        with torch.no_grad():
            W -= lr * W.grad
            b -= lr * b.grad

        W.grad.zero_()
        b.grad.zero_()

    with torch.no_grad():
        final_loss = F.cross_entropy(Xtr @ W + b, ytr).item()
        train_acc = ((Xtr @ W + b).argmax(1) == ytr).float().mean().item()
        test_acc = ((Xte @ W + b).argmax(1) == yte).float().mean().item()

    print("loss", round(final_loss, 4))
    print("train_acc", round(train_acc, 4), "test_acc", round(test_acc, 4))
    print("W", [[round(v, 4) for v in row] for row in W.detach().tolist()])
    ```

输出：

```text
loss 0.2156
train_acc 0.9333 test_acc 0.9
W [[-1.6542, 1.6755, -0.0213], [-0.8946, -0.9322, 1.8269]]
```

几个点：

- `W` 的形状是 `(d, K)`：2 个特征、3 个类别
- `logits` 是原始分数，不是概率
- `F.cross_entropy` 直接接收 logits，内部做 `log_softmax + NLL`
- 预测用 `argmax(1)`，取分数最大的类别
- 训练集准确率 `0.9333`，测试集 `0.9`；簇有重叠，不会百分百

### 为什么不用手动 softmax

如果先算：

```python
p = torch.softmax(logits, dim=1)
loss = -torch.log(p[range(n), y]).mean()
```

数值上也能跑，但 `softmax` 后再 `log` 容易在极端 logits 下丢精度。`F.cross_entropy` 把两步合在一起，内部用 log-sum-exp，更稳。

[第 4 篇](04-损失函数与数值稳定.md) 会展开数值稳定性。

## 3. 训练循环的骨架

不管线性回归、MLP 还是 Transformer，训练循环都是这五步：

??? note "代码：训练循环的骨架"
    ```python
    pred = model(x)
    loss = loss_fn(pred, y)

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    ```

| 步骤 | 做什么 |
|---|---|
| 前向 | 建计算图，得到预测和 loss |
| `zero_grad()` | 清掉上一步累积的梯度 |
| `backward()` | 反向传播，写参数的 `.grad` |
| `step()` | 按梯度和优化器规则更新参数 |
| 下一轮 | 重新前向，建新的计算图 |

手写版和库版的对应关系：

| 手写 | 库 |
|---|---|
| `X @ w + b` | `nn.Linear(d, 1)` |
| `((pred - y) ** 2).mean()` | `nn.MSELoss()` |
| `with torch.no_grad(): w -= lr * w.grad` | `optim.SGD(model.parameters(), lr)` |
| `w.grad.zero_()` | `optimizer.zero_grad()` |

后面训练大模型时，只是把 `model` 换成更大的网络，把优化器换成 AdamW，把全量数据换成 mini-batch；骨架不变。

评估时：

```python
model.eval()
with torch.no_grad():
    ...
```

`model.eval()` 关掉 dropout/BN 的训练行为；`no_grad()` 不建图。

## 4. 常见坑

1. **忘记 `zero_grad()`**
   梯度会累加，下一次更新会混进上一步的梯度。

2. **loss 不是标量**
   直接对向量 `backward()` 会报错；先 `mean()`/`sum()`。

3. **把概率传给 `cross_entropy`**
   `F.cross_entropy` 要 logits；先 `softmax` 再传，等于做了两次归一化。

4. **`W` 的方向搞反**
   这里用 `X @ W`，`W` 是 `(d, K)`；`nn.Linear` 内部存的是 `(K, d)`，做的是 `X @ W.T`。

5. **标准化用了全量数据**
   均值/方差只能从训练集算，再应用到验证/测试集；否则泄漏。

6. **学习率太大或太小**
   太大会震荡/发散，太小 500 步也到不了。先试 `1e-2`、`1e-1`，看 loss 曲线。

7. **dtype / device 不一致**
   数据 `float64`、模型 `float32`，或者一个在 CPU 一个在 GPU，都会报错。

8. **训练/评估模式没切**
   有 dropout/BN 时，`model.train()` 和 `model.eval()` 的行为不同。

9. **没有固定随机种子**
   数据、初始化、切分都会变；复现实验先 `torch.manual_seed(...)`。

10. **拿闭式解和未收敛的 GD 比**
    步数不够时参数差很远，不代表 GD 错；看 loss 是否还在降。

## 5. 要点回顾

1. **线性回归 = 线性模型 + MSE**；闭式解是精确解，梯度下降是通用迭代法
2. 训练循环五步：前向 → loss → `zero_grad` → `backward` → `step`
3. `.grad` 会累加；每步更新前必须清空
4. **softmax 回归 = 线性 logits + 交叉熵**；`F.cross_entropy` 接收 logits
5. `W` 的方向：手写 `X @ W` 是 `(d, K)`，`nn.Linear` 内部是 `(K, d)`
6. 标准化、切分、随机种子都要在训练前处理好
7. 评估用 `model.eval()` + `torch.no_grad()`
