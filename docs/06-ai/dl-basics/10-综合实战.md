# 综合实战：从零训练一个小网络

前 9 篇拆开讲了张量、线性模型、MLP、损失、反传、优化器、归一化、CNN/RNN、Transformer。

这一篇把它们串成一条完整流水线：

```text
数据 → 切分 → 标准化 → DataLoader → 模型 → 损失 → 优化器
→ 训练 → 验证 → 早停 → 测试 → 保存 → 重新加载
```

任务用 two-moons 二分类：两条交错的半圆，加噪声。线性模型只能切一条直线，MLP 可以弯。

## 1. 数据、切分与 DataLoader

??? note "代码：数据与切分"
    ```python
    import math
    import random
    import torch
    from torch.utils.data import TensorDataset, DataLoader

    def set_seed(seed=42):
        random.seed(seed)
        torch.manual_seed(seed)

    def make_moons(n, noise=0.2):
        n0 = n // 2
        n1 = n - n0

        t0 = torch.rand(n0) * math.pi
        x0 = torch.stack([torch.cos(t0), torch.sin(t0)], dim=1)

        t1 = torch.rand(n1) * math.pi
        x1 = torch.stack([1 - torch.cos(t1), 0.5 - torch.sin(t1)], dim=1)

        X = torch.cat([x0, x1], dim=0)
        y = torch.cat([torch.zeros(n0), torch.ones(n1)]).long()
        X = X + noise * torch.randn_like(X)

        perm = torch.randperm(n)
        return X[perm], y[perm]

    set_seed(42)
    X, y = make_moons(1000, noise=0.2)

    Xtr, ytr = X[:600], y[:600]
    Xva, yva = X[600:800], y[600:800]
    Xte, yte = X[800:], y[800:]

    # 标准化统计量只能来自训练集
    mu, sd = Xtr.mean(0), Xtr.std(0)
    Xtr = (Xtr - mu) / sd
    Xva = (Xva - mu) / sd
    Xte = (Xte - mu) / sd

    train_loader = DataLoader(
        TensorDataset(Xtr, ytr),
        batch_size=64,
        shuffle=True,
        generator=torch.Generator().manual_seed(42),
    )
    val_loader = DataLoader(TensorDataset(Xva, yva), batch_size=200)
    test_loader = DataLoader(TensorDataset(Xte, yte), batch_size=200)

    print("sizes", len(Xtr), len(Xva), len(Xte))
    ```

输出：

```text
sizes 600 200 200
```

切分：

| 集合 | 数量 | 用途 |
|---|---:|---|
| 训练 | 600 | 学参数 |
| 验证 | 200 | 早停、选超参数 |
| 测试 | 200 | 最后评估一次 |

标准化：

$$
x'=\frac{x-\mu_{\mathrm{train}}}{\sigma_{\mathrm{train}}}
$$

均值/方差只从训练集算，再应用到验证/测试。否则测试集信息泄漏进训练。

### 自定义 Dataset 与 DataLoader

`TensorDataset` 只适合“已经是张量、形状固定”的数据。真实项目常见图片路径、文本、变长序列，这时要自己写 `Dataset`：

??? note "代码：自定义 Dataset"
    ```python
    from torch.utils.data import Dataset, DataLoader

    class MoonsDataset(Dataset):
        def __init__(self, X, y):
            self.X = X
            self.y = y

        def __len__(self):
            return len(self.X)

        def __getitem__(self, i):
            return self.X[i], self.y[i]

    train_ds = MoonsDataset(Xtr, ytr)
    custom_loader = DataLoader(
        train_ds,
        batch_size=64,
        shuffle=True,
        num_workers=0,
        pin_memory=torch.cuda.is_available(),
        generator=torch.Generator().manual_seed(42),
    )

    xb, yb = next(iter(custom_loader))
    print("batch", tuple(xb.shape), tuple(yb.shape))
    ```

输出：

```text
batch (64, 2) (64,)
```

常用参数：

| 参数 | 作用 |
|---|---|
| `batch_size` | 每个 batch 的样本数 |
| `shuffle` | 每轮打乱；训练开，评估关 |
| `num_workers` | 子进程读数据；0 表示主进程 |
| `pin_memory` | 锁页内存，GPU 传输更快；CUDA 才有意义 |
| `drop_last` | 丢掉最后一个不足 batch 的样本；BN/固定形状时有用 |
| `collate_fn` | 把 `__getitem__` 的样本拼成 batch；变长序列常用 |
| `sampler` | 自定义采样，如类别不平衡、分布式 |

变长序列不能直接默认拼接，要自己 pad：

??? note "代码：变长序列的 collate_fn"
    ```python
    def pad_collate(batch):
        xs, ys = zip(*batch)
        lengths = torch.tensor([len(x) for x in xs])
        xpad = torch.nn.utils.rnn.pad_sequence(xs, batch_first=True)
        return xpad, torch.stack(ys), lengths
    ```

`lengths` 后面要用来构造 padding mask；否则 padding 位置会参与 attention/loss。`pad_sequence` 默认 `batch_first=False`，这里显式设成 `True`。

几个实践点：

- `__getitem__` 返回张量，不要返回 numpy/list；默认 `collate_fn` 只负责拼接
- 重 I/O 放 `Dataset` 或 worker，不要在训练循环里读文件
- `num_workers > 0` 时每个 worker 有独立随机状态；复现要配 `worker_init_fn`
- Windows / notebook 的 spawn 模式需要 `if __name__ == "__main__":` 保护
- 最后一批只有 1 个样本时，BatchNorm 会报错；用 `drop_last=True` 或换 LayerNorm
- 类别不平衡用 `WeightedRandomSampler`，不要只靠 `shuffle`

## 2. 模型与训练

??? note "代码：模型与训练"
    ```python
    import torch
    import torch.nn as nn

    # 接着上一段：Xtr/ytr/Xva/yva/Xte/yte、loader 已定义
    class MLP(nn.Module):
        def __init__(self):
            super().__init__()
            self.net = nn.Sequential(
                nn.Linear(2, 64), nn.ReLU(),
                nn.Linear(64, 64), nn.ReLU(),
                nn.Linear(64, 2),
            )

        def forward(self, x):
            return self.net(x)

    def evaluate(model, loader, loss_fn):
        model.eval()
        total_loss = 0.0
        correct = 0
        total = 0
        preds, labels = [], []

        with torch.no_grad():
            for xb, yb in loader:
                logits = model(xb)
                loss = loss_fn(logits, yb)
                total_loss += loss.item() * len(yb)

                pred = logits.argmax(1)
                correct += (pred == yb).sum().item()
                total += len(yb)
                preds.append(pred)
                labels.append(yb)

        return (
            total_loss / total,
            correct / total,
            torch.cat(preds),
            torch.cat(labels),
        )

    set_seed(42)
    model = MLP()
    loss_fn = nn.CrossEntropyLoss()
    opt = torch.optim.AdamW(model.parameters(), lr=0.01, weight_decay=1e-4)

    best_val = float("inf")
    best_state = None
    best_epoch = 0
    bad = 0
    patience = 20

    for epoch in range(1, 201):
        model.train()
        for xb, yb in train_loader:
            opt.zero_grad()
            loss = loss_fn(model(xb), yb)
            loss.backward()
            opt.step()

        val_loss, val_acc, _, _ = evaluate(model, val_loader, loss_fn)

        if val_loss < best_val - 1e-4:
            best_val = val_loss
            best_epoch = epoch
            best_state = {k: v.clone() for k, v in model.state_dict().items()}
            bad = 0
        else:
            bad += 1
            if bad >= patience:
                break

    model.load_state_dict(best_state)

    train_loss, train_acc, _, _ = evaluate(model, train_loader, loss_fn)
    val_loss, val_acc, _, _ = evaluate(model, val_loader, loss_fn)
    test_loss, test_acc, pred, true = evaluate(model, test_loader, loss_fn)

    print("best_epoch", best_epoch, "stopped", epoch)
    print("train", round(train_loss, 4), round(train_acc, 4))
    print("val  ", round(val_loss, 4), round(val_acc, 4))
    print("test ", round(test_loss, 4), round(test_acc, 4))

    print("confusion")
    for t in [0, 1]:
        print("true", t,
              "pred0", int(((pred == 0) & (true == t)).sum()),
              "pred1", int(((pred == 1) & (true == t)).sum()))
    ```

输出：

```text
best_epoch 10 stopped 30
train 0.0737 0.9717
val   0.1221 0.9550
test  0.1127 0.9700
confusion
true 0 pred0 91 pred1 1
true 1 pred0 5 pred1 103
```

几件事：

- 最优 epoch 是 10；之后验证 loss 不降，连续 20 轮就早停
- 保存的是**验证集最优**的参数，不是最后一轮
- 测试集只在最后用一次
- 测试准确率 `0.97`，但仍有 1 个假阳、5 个假阴

混淆矩阵：

| | 预测 0 | 预测 1 |
|---|---:|---:|
| 实际 0 | 91 | 1 |
| 实际 1 | 5 | 103 |

如果假阴的代价高，`0.97` 还不够；要按业务调阈值或损失权重。

同一划分上，线性模型大约 `0.85`；MLP 到 `0.97`，差距来自非线性边界。

## 3. 设备放置

上面的数字是在 CPU 上跑出来的。要用 GPU，训练前把模型和优化器放到 device：

```python
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# 训练前：先移动模型
model = model.to(device)
# 再创建优化器：opt = torch.optim.AdamW(model.parameters(), lr=0.01, weight_decay=1e-4)
```

本节后面的检查直接把第 2 节训练好的 `model` 移到 device；真实训练要在创建优化器之前移动。

训练和评估循环里，每个 batch 也要移到同一个 device：

```python
# 片段：训练/评估循环里
# xb = xb.to(device)
# yb = yb.to(device)
# logits = model(xb)
```

检查当前机器：

??? note "代码：设备放置"
    ```python
    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    model = model.to(device)

    xb, yb = next(iter(train_loader))
    xb, yb = xb.to(device), yb.to(device)
    logits = model(xb)

    print("device", device)
    print("batch", xb.device)
    print("logits", logits.device)
    ```

在这台机器上：

```text
device cuda
batch cuda:0
logits cuda:0
```

CPU 上会显示 `cpu`。

几条规则：

- 模型和数据必须在同一个 device；否则报 `Expected all tensors to be on the same device`
- 先移动模型，再创建优化器；优化器持有参数引用，顺序反了容易出问题
- 验证/测试循环同样要移动 batch；不要只移动训练集
- `DataLoader(pin_memory=True)` 只在 CUDA 上有意义，配合 `.to(device, non_blocking=True)`
- 保存的 `state_dict` 里张量可能还在 GPU；加载时用 `torch.load(..., map_location="cpu")`，再按需要 `.to(device)`
- `torch.cuda.empty_cache()` 只释放缓存，不解决模型/激活本身过大
- GPU 上固定 seed 不一定完全可复现；需要时开 `torch.use_deterministic_algorithms(True)`，并接受性能损失

## 4. 保存与重新加载

??? note "代码：保存与重新加载"
    ```python
    import torch

    # 接着上一段：model、mu、sd、test_loader、evaluate、loss_fn 已定义
    torch.save(
        {
            "model": model.state_dict(),
            "mean": mu,
            "std": sd,
        },
        "moon_mlp.pt",
    )

    ckpt = torch.load("moon_mlp.pt", map_location="cpu", weights_only=True)
    model2 = MLP()
    model2.load_state_dict(ckpt["model"])
    model2.eval()

    _, acc2, _, _ = evaluate(model2, test_loader, loss_fn)
    print("reload", round(acc2, 4))
    ```

输出：

```text
reload 0.97
```

保存三样东西：

- `model.state_dict()`：参数
- `mean` / `std`：预处理统计量
- 配置（学习率、宽度、seed 等）建议一起存

只存模型、不存标准化参数，推理时输入尺度对不上，结果会错。

`map_location="cpu"` 让 GPU 上保存的 checkpoint 也能在没有 GPU 的机器上加载；加载后再 `model2.to(device)`，并把 batch 也移到同一 device。

## 5. 项目结构

真实项目不要把所有东西塞一个脚本：

| 文件 | 职责 |
|---|---|
| `data.py` | 生成/读取数据、切分、标准化、Dataset/DataLoader |
| `model.py` | MLP / 网络结构 |
| `train.py` | 训练循环、早停、保存 |
| `eval.py` | 加载 checkpoint、测试、混淆矩阵 |
| `config.yaml` | 学习率、batch、epoch、seed |

小实验可以一个文件；要复现、要协作，就拆开。

## 6. 复现清单

1. **固定 seed**：Python、NumPy、PyTorch、DataLoader
2. **保存配置**：模型宽度、lr、batch、epoch、patience
3. **保存预处理**：均值、方差、词表、类别映射
4. **保存最优 checkpoint**：按验证集选，不按测试集
5. **记录环境**：Python、PyTorch、CUDA 版本
6. **记录数据版本**：生成参数、文件 hash、切分索引
7. **测试集只用一次**：不要反复调参
8. **保留 baseline**：线性/树模型，确认复杂模型真的更好
9. **记录 device**：CPU/GPU、CUDA 版本、是否混合精度
10. **加载时指定 `map_location`**：GPU 上保存的 checkpoint 要能回到 CPU 或另一块 GPU

## 7. 调试顺序

训练不收敛时，按这个顺序查：

1. **先过拟合一个小 batch**
   取 8 个样本，能不能到 100% 训练准确率？不能，先查标签、损失、梯度。

2. **看 loss 是否有限**
   `NaN` / `inf` 先查学习率、logits、`log(0)`。

3. **看梯度范数**
   全 0 可能死 ReLU/断图；爆炸就 clipping、降 lr。

4. **看数据**
   标签对不对、标准化有没有泄漏、训练/验证分布是否一致。

5. **看 baseline**
   线性模型都很差，可能是特征/标签问题，不是网络问题。

6. **看评估**
   `model.eval()`、`no_grad()`、batch 加权、混淆矩阵。

## 8. 常见坑

1. **先标准化再切分**
   测试集统计量进入训练，分数虚高。

2. **验证/测试集 shuffle**
   评估不需要 shuffle；训练集才 shuffle。

3. **用测试集早停**
   测试集变成验证集，最后没有干净评估。

4. **保存最后一轮**
   最后不一定最好；按验证 loss 保存。

5. **只保存模型，不保存预处理**
   推理时输入尺度不一致，预测漂移。

6. **忘记 `model.eval()`**
   dropout/BN 还在训练模式，评估不可信。

7. **只看准确率**
   类别不平衡时，准确率会骗人；看混淆矩阵、F1、PR-AUC。

8. **batch loss 直接平均**
   最后一个 batch 可能更小；按样本数加权。

9. **没有 baseline**
   不知道 MLP 的提升是不是来自模型，还是数据本身简单。

10. **测试集反复用**
    调一次参看一次测试集，测试集就被“训练”了。

11. **不固定 seed**
    结果不可复现，调参靠运气。

12. **一上来调大模型**
    先小数据、小网络、单 batch 跑通，再放大。

13. **模型和数据不在同一 device**
    报 `Expected all tensors to be on the same device`；前向前把 batch 和模型都 `.to(device)`。

14. **加载 GPU checkpoint 没写 `map_location`**
    没有 GPU 的机器会直接报错；用 `torch.load(..., map_location="cpu")`。

15. **`__getitem__` 返回 numpy/list**
    默认 `collate_fn` 期望张量；用 `torch.as_tensor` 转一下。

16. **变长序列没有 `collate_fn`**
    默认拼接会失败；要 pad，并用 `lengths` 构造 mask。

17. **`num_workers > 0` 的随机性**
    每个 worker 有独立随机状态；复现要配 `worker_init_fn`，Windows/notebook 还要 `if __name__ == "__main__":`。

## 9. 要点回顾

1. 完整流水线：切分 → 标准化 → DataLoader → 模型 → 损失 → 优化器 → 早停 → 测试 → 保存
2. 标准化统计量只来自训练集；测试集只用一次
3. 早停看验证 loss，保存验证最优的 `state_dict`
4. 评估要 `model.eval()` + `no_grad()`，loss 按样本数加权
5. 混淆矩阵比单一准确率更有信息
6. checkpoint 要带预处理参数和配置
7. 固定 seed、保留 baseline、先过拟合一个小 batch
8. 模型和数据放在同一 device；加载 checkpoint 用 `map_location`
9. 自定义 Dataset 实现 `__len__` / `__getitem__`；变长序列用 `collate_fn`，`num_workers` / `pin_memory` 按环境调

这套训练/验证/保存的流水线可以直接套到[第 11 篇](11-从零实现Transformer.md)的 Transformer 上。
