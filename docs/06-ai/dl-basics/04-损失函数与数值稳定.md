# 损失函数与数值稳定

损失函数回答“错得有多离谱”；数值稳定回答“这个错误还算得出来吗”。

很多训练里的 `NaN` / `inf`，不是模型结构错，而是 `exp` 溢出、`log(0)` 这类数值问题。这篇把常见的损失和稳定写法放在一起。

## 1. 回归损失

### MSE

$$
L_{\mathrm{MSE}}
= \frac{1}{n}\sum_{i=1}^{n}(\hat{y}_i-y_i)^2
$$

特点：

- 对大误差惩罚重
- 梯度是 $2(\hat{y}-y)/n$，好优化
- 对异常值敏感
- 单位是原单位的平方，汇报时常开根号成 RMSE

### MAE

$$
L_{\mathrm{MAE}}
= \frac{1}{n}\sum_{i=1}^{n}|\hat{y}_i-y_i|
$$

特点：

- 对异常值更稳
- 梯度是符号函数，0 点不可导
- 误差小时收敛可能不如 MSE 平滑

### Huber

$$
L_\delta(e)=
\begin{cases}
\dfrac{1}{2}e^2, & |e|\le\delta\\[4pt]
\delta\left(|e|-\dfrac{1}{2}\delta\right), & |e|>\delta
\end{cases}
$$

小误差像 MSE，大误差像 MAE。多一个超参数 $\delta$，适合有异常值但又想要平滑梯度的场景。

| 损失 | 异常值 | 梯度 | 常见场景 |
|---|---|---|---|
| MSE | 敏感 | 平滑 | 默认回归 |
| MAE | 稳健 | 0 点不可导 | 异常值多 |
| Huber | 较稳健 | 平滑 | 兼顾两者 |

## 2. 分类损失

### logits 是什么

分类模型最后一层通常输出 **logits**：未归一化的分数。

```text
logits = [2.0, 1.0, 0.1]
```

logits 不是概率，不需要先 softmax 再交给损失函数。`F.cross_entropy` 接收 logits，内部做 `log_softmax + NLL`。

### 二分类：BCE

模型输出一个 logit $z$，先过 sigmoid：

$$
p=\sigma(z)=\frac{1}{1+e^{-z}}
$$

损失：

$$
L_{\mathrm{BCE}}
= -\frac{1}{n}\sum_{i=1}^{n}
\left[y_i\log p_i+(1-y_i)\log(1-p_i)\right]
$$

问题：$p$ 接近 0 时 $\log p\to-\infty$；$p$ 接近 1 时 $\log(1-p)\to-\infty$。两项都可能爆。

稳定写法是把 logit 直接交给：

```python
F.binary_cross_entropy_with_logits(logits, targets)
```

它内部用等价形式，不会先算出 0/1 再取 log。

### 多分类：交叉熵

softmax：

$$
p_k=\frac{e^{z_k}}{\sum_{j=1}^{K}e^{z_j}}
$$

损失：

$$
L_{\mathrm{CE}}=-\log p_y
= -z_y+\log\sum_{j=1}^{K}e^{z_j}
$$

梯度很干净：

$$
\frac{\partial L}{\partial \mathbf{z}}
= \mathbf{p}-\operatorname{onehot}(y)
$$

PyTorch 直接用：

```python
F.cross_entropy(logits, y)
```

`logits` 形状 `(N, K)`，`y` 是 `int64` 类别下标，形状 `(N,)`。

| 任务 | 输出层 | 损失 | API |
|---|---|---|---|
| 回归 | 无 | MSE / MAE / Huber | `mse_loss` / `l1_loss` / `huber_loss` |
| 二分类 | 1 个 logit | BCEWithLogits | `binary_cross_entropy_with_logits` |
| 多分类 | K 个 logits | 交叉熵 | `cross_entropy` |

## 3. 数值稳定

### 问题从哪来

float32 的指数范围有限：

- `exp(88)` 左右就接近上溢
- `exp(-100)` 很快下溢到 0
- `log(0)` 是 $-\infty$
- `inf / inf` 是 `NaN`

手写 softmax 很容易踩：

```python
p = torch.exp(z) / torch.exp(z).sum()
```

如果 `z` 里有 `1000`，`exp(1000)` 直接 `inf`，再除就 `nan`。

### log-sum-exp

不做任何近似，只做恒等变换：

$$
\log\sum_{j=1}^{K}e^{z_j}
= m+\log\sum_{j=1}^{K}e^{z_j-m},
\qquad m=\max_j z_j
$$

减去最大值后，指数最大是 $e^0=1$，不会上溢；很小的项下溢到 0 也不影响结果。

softmax 同理：

$$
\frac{e^{z_i-m}}{\sum_j e^{z_j-m}}
= \frac{e^{z_i}}{\sum_j e^{z_j}}
$$

分子分母同乘 $e^{-m}$，值不变。

### 稳定交叉熵

```python
m = z.max()
lse = m + torch.log(torch.exp(z - m).sum())
loss = -z[y] + lse
```

或者直接用：

```python
torch.log_softmax(z, dim=0)
F.cross_entropy(logits, y)
torch.logsumexp(z, dim=0)
```

### 跑一组大 logits

??? note "代码：跑一组大 logits"
    ```python
    import torch
    import torch.nn.functional as F

    z = torch.tensor([1000.0, 0.0, -1000.0])
    y = torch.tensor(0)

    naive_exp = torch.exp(z)
    p = naive_exp / naive_exp.sum()
    print("exp", naive_exp)
    print("naive p", p)
    print("naive ce", -torch.log(p[y]))

    m = z.max()
    lse = m + torch.log(torch.exp(z - m).sum())
    print("lse", lse)
    print("stable ce", -z[y] + lse)
    print("F.cross_entropy", F.cross_entropy(z.unsqueeze(0), y.unsqueeze(0)))
    print("torch softmax", torch.softmax(z, dim=0))
    print("log_softmax", torch.log_softmax(z, dim=0))
    ```

输出：

```text
exp tensor([inf, 1., 0.])
naive p tensor([nan, 0., 0.])
naive ce tensor(nan)
lse tensor(1000.)
stable ce tensor(0.)
F.cross_entropy tensor(0.)
torch softmax tensor([1., 0., 0.])
log_softmax tensor([    0., -1000., -2000.])
```

读法：

- 手写 `exp` 溢出，概率变成 `nan`
- 稳定版和 `F.cross_entropy` 都得到 `0`
- `torch.softmax` / `log_softmax` 内部已经做了 max 减法

### 再看 BCE

??? note "代码：再看 BCE"
    ```python
    import torch
    import torch.nn.functional as F

    z = torch.tensor([-1000.0, 1000.0])
    y = torch.tensor([1.0, 0.0])

    p = torch.sigmoid(z)
    naive = -(y * torch.log(p) + (1 - y) * torch.log(1 - p)).mean()
    stable = F.binary_cross_entropy_with_logits(z, y)

    print("sigmoid", p)
    print("naive bce", naive)
    print("stable bce", stable)
    ```

输出：

```text
sigmoid tensor([0., 1.])
naive bce tensor(inf)
stable bce tensor(1000.)
```

`sigmoid(-1000)` 下溢成 0，`log(0)` 变成 $-\infty$；稳定版直接算 logit，得到有限值 `1000`。

### 普通 logits 下两者一致

数值稳定不是改变结果，只是避免溢出：

??? note "代码：普通 logits 下两者一致"
    ```python
    import torch
    import torch.nn.functional as F

    z = torch.tensor([2.0, 1.0, 0.1])
    y = torch.tensor(0)

    print("naive", -torch.log(torch.softmax(z, 0)[y]))
    print("stable", F.cross_entropy(z.unsqueeze(0), y.unsqueeze(0)))
    ```

输出：

```text
naive tensor(0.4170)
stable tensor(0.4170)
```

## 4. 常见坑

1. **先 softmax 再交叉熵**
   `F.cross_entropy` 接收 logits；先 softmax 会重复归一化，数值也更差。

2. **先 sigmoid 再 BCE**
   `sigmoid` 在极端 logit 下会变成 0/1，`log(0)` 直接 `inf`；用 `binary_cross_entropy_with_logits`。

3. **手写 `exp` 不减去 max**
   大 logits 上溢成 `inf`，再除就是 `nan`。

4. **用 `clip` 救 `log(0)`**
   `p.clamp(min=1e-7)` 能避免 `inf`，但会改梯度；优先用稳定的损失 API。

5. **float16 下算 loss**
   float16 范围更小，更容易上溢/下溢；loss/logsumexp 通常在 float32 里算。

6. **`reduction` 用错**
   `mean` 和 `sum` 会让学习率等价关系变化；默认 `mean` 最常见。

7. **标签形状/类型不对**
   多分类 `y` 是 `int64` 下标，不是 one-hot；二分类 `y` 是 float，形状要和 logits 一致。

8. **忽略 padding / ignore_index**
   变长序列、padding 位置要 mask 掉，否则 loss 被无效 token 拉偏。

9. **类别不平衡只用普通 CE**
   CE 按样本平均，多数类主导；考虑 `weight=`、重采样或 focal loss。

10. **只看 loss 不看 logits**
   出现 `NaN` 时先打印 logits、loss、梯度，定位是上溢、下溢还是标签越界。

## 5. 要点回顾

1. 回归默认 MSE；异常值多考虑 MAE / Huber
2. 二分类用 logit + `BCEWithLogitsLoss`；多分类用 logits + 交叉熵（softmax/sigmoid 在损失内部）
3. `F.cross_entropy` / `BCEWithLogitsLoss` 接收 **logits**，不要先做 softmax/sigmoid
4. softmax 和交叉熵都要用 **log-sum-exp** 稳定写法
5. 减去最大值不改变 softmax/CE 的结果，只避免上溢
6. `log(0)` 会出 `-inf`；`clip` 是补丁，稳定的损失函数才是正解
7. float16 更容易溢出；loss 计算通常放 float32
