# 初始化、归一化与正则化

这三件事分别管：

- **初始化**：训练开始时的起点
- **归一化**：让每层输入/输出的尺度稳定
- **正则化**：限制模型，别让模型死记训练集

它们不是互相替代的；深层网络经常要一起用。

## 1. 初始化

### 为什么不能全零

如果一层里所有隐藏单元权重相同，它们的输出、梯度也相同，更新后还是相同。网络永远学不到不同的特征。

全零更极端：ReLU 输出全 0，隐藏层梯度全 0，只有输出层 bias 在动。

所以初始化至少要**打破对称**。

### 方差怎么传

考虑一层线性变换：

$$
y_j=\sum_{i=1}^{fan_{in}}W_{ij}x_i
$$

如果 $x_i$ 独立、方差为 $\sigma_x^2$，$W_{ij}$ 独立、方差为 $\sigma_W^2$，那么：

$$
\operatorname{Var}(y_j)=fan_{in}\cdot\sigma_W^2\cdot\sigma_x^2
$$

想让输出方差和输入差不多，就要：

$$
\sigma_W^2\approx\frac{1}{fan_{in}}
$$

但 ReLU 会把一半激活压成 0，实际方差再缩一半，所以 ReLU 需要更大的初始化方差。

### Xavier / He

**Xavier / Glorot**（适合 tanh、sigmoid）：

$$
\operatorname{Var}(W_{ij})
=\frac{2}{fan_{in}+fan_{out}}
$$

**He / Kaiming**（适合 ReLU）：

$$
\operatorname{Var}(W_{ij})
=\frac{2}{fan_{in}}
$$

PyTorch 里：

??? note "代码：Xavier / He"
    ```python
    import torch.nn as nn

    # 片段：layer 已定义
    nn.init.xavier_uniform_(layer.weight)
    nn.init.kaiming_normal_(layer.weight, nonlinearity="relu")
    nn.init.zeros_(layer.bias)
    ```

`nn.Linear` 默认用 Kaiming uniform，对普通 MLP 通常够用；自定义深层网络、RNN、Transformer 时才需要更仔细。

| 初始化 | 方差 | 适合 |
|---|---|---|
| Xavier / Glorot | $2/(fan_{in}+fan_{out})$ | tanh / sigmoid |
| He / Kaiming | $2/fan_{in}$ | ReLU |
| 正交初始化 | 正交矩阵 | RNN、深层网络 |
| 全零 / 全相同 | 0 | ❌ 对称性破不了 |

## 2. 归一化

### BatchNorm

对一个 batch 的每个特征做归一化：

$$
\mu_B=\frac{1}{B}\sum_{i=1}^{B}x_i,
\qquad
\sigma_B^2=\frac{1}{B}\sum_{i=1}^{B}(x_i-\mu_B)^2
$$

$$
\hat{x}_i=\frac{x_i-\mu_B}{\sqrt{\sigma_B^2+\epsilon}},
\qquad
y_i=\gamma\hat{x}_i+\beta
$$

特点：

- 训练时用当前 batch 的均值/方差
- 评估时用训练阶段累计的 running mean/var
- 对 batch size 敏感；batch 太小统计不稳
- CNN 常用，放在卷积/线性层之后、激活之前

PyTorch 的 `BatchNorm` 有两个“momentum”：

- 优化器的 momentum：梯度累积
- BN 的 momentum：running stats 更新

它们不是一回事。

### LayerNorm

对**每个 token/位置**的特征维做归一化：

$$
\mu=\frac{1}{D}\sum_{j=1}^{D}x_j,
\qquad
\sigma^2=\frac{1}{D}\sum_{j=1}^{D}(x_j-\mu)^2
$$

$$
y_j=\gamma\frac{x_j-\mu}{\sqrt{\sigma^2+\epsilon}}+\beta
$$

特点：

- 不依赖 batch
- 训练/评估行为一致
- 适合变长序列、Transformer、RNN
- 归一化维度是特征维，不是 batch 维
- 输入是 `(B, T, D)` 时，每个 `(b, t)` 单独归一化，不跨时间步

### RMSNorm

只除均方根，不减均值：

$$
\operatorname{RMS}(x)
=\sqrt{\frac{1}{D}\sum_{j=1}^{D}x_j^2+\epsilon}
$$

$$
y=\frac{x}{\operatorname{RMS}(x)}\gamma
$$

特点：

- 比 LayerNorm 少一次均值计算
- 不减均值，保留更多方向信息
- LLaMA 等模型使用

### 对比

| 方法 | 归一化维度 | 依赖 batch | 训练/评估 | 常见位置 |
|---|---|---|---|---|
| BatchNorm | batch + 空间维 | 是 | 不一样 | CNN |
| LayerNorm | 每个 token/位置的特征维 | 否 | 一致 | Transformer / RNN |
| RMSNorm | 每个 token/位置的特征维 | 否 | 一致 | LLM |

放置位置没有绝对标准，但要固定：

- CNN：`Conv → BN → ReLU`
- Transformer：常见 pre-LN，即 `LN → Attention/FFN → 残差`
- 不要同一套模型里一半 pre、一半 post

## 3. 正则化

### weight decay / L2

在损失里加参数惩罚：

$$
L_{\mathrm{total}}
=L+\frac{\lambda}{2}\lVert\theta\rVert_2^2
$$

解耦形式（AdamW）见[第 6 篇](06-优化器与学习率.md)。

注意：

- 一般只作用在权重矩阵，不加 bias、LayerNorm/BatchNorm 的 $\gamma/\beta$
- Adam 的 L2 和 AdamW 的 weight decay 不一样
- $\lambda$ 用验证集选，不是越大越好

### dropout

训练时随机把一部分激活置零：

$$
m_i\sim\operatorname{Bernoulli}(1-p),
\qquad
h_i'=\frac{m_i h_i}{1-p}
$$

评估时不再 dropout，直接输出 $h_i$。

PyTorch 的 `nn.Dropout(p)` 已经做了 inverted scaling，训练/评估自动切换。

注意：

- 输出层一般不用 dropout
- `model.train()` / `model.eval()` 要切对
- dropout 太强会欠拟合

### 其他手段

| 方法 | 做什么 | 注意 |
|---|---|---|
| early stopping | 验证 loss 回升就停 | 需要可靠验证集 |
| data augmentation | 随机变换输入 | 领域相关，别破坏标签 |
| label smoothing | 软标签 | 可能影响概率校准 |
| 输入噪声 | 加小噪声 | 小数据有用，太大伤性能 |
| 梯度裁剪 | 限制梯度范数 | 防爆，不是正则的替代 |

正则化的顺序：**先让模型有过拟合的迹象，再加正则**；一上来全加上，容易欠拟合。

## 4. 实验：深层 MLP 加/不加归一化

数据还是圆形边界；模型是 8 层 MLP，每层 64，ReLU；SGD + momentum 0.9，学习率 0.05，200 个 epoch。

??? note "代码：实验：深层 MLP 加/不加归一化"
    ```python
    import torch
    import torch.nn as nn
    import torch.nn.functional as F

    torch.manual_seed(0)
    n = 600
    X = torch.randn(n, 2)
    y = ((X ** 2).sum(1) < 1.0).long()
    perm = torch.randperm(n)
    Xtr, ytr = X[perm][:450], y[perm][:450]
    Xte, yte = X[perm][450:], y[perm][450:]

    def make_mlp(norm=None, depth=8, width=64):
        layers = []
        in_dim = 2
        for _ in range(depth):
            layers.append(nn.Linear(in_dim, width))
            if norm == "bn":
                layers.append(nn.BatchNorm1d(width))
            elif norm == "ln":
                layers.append(nn.LayerNorm(width))
            layers.append(nn.ReLU())
            in_dim = width
        layers.append(nn.Linear(width, 2))
        return nn.Sequential(*layers)

    def train(norm, epochs=200, lr=0.05):
        torch.manual_seed(1)
        model = make_mlp(norm)
        opt = torch.optim.SGD(model.parameters(), lr=lr, momentum=0.9)

        for _ in range(epochs):
            opt.zero_grad()
            loss = F.cross_entropy(model(Xtr), ytr)
            loss.backward()
            opt.step()

        model.eval()
        with torch.no_grad():
            final_loss = F.cross_entropy(model(Xtr), ytr).item()
            tr = (model(Xtr).argmax(1) == ytr).float().mean().item()
            te = (model(Xte).argmax(1) == yte).float().mean().item()

        return tr, te, final_loss

    for norm in [None, "bn", "ln"]:
        tr, te, loss = train(norm)
        print(f"{str(norm):4s} train={tr:.4f} test={te:.4f} loss={loss:.4f}")
    ```

输出：

```text
None train=0.5933 test=0.5867 loss=0.6729
bn   train=1.0000 test=0.9600 loss=0.0001
ln   train=1.0000 test=0.9600 loss=0.0002
```

读法：

- 不加归一化：训练/测试都停在多数类，深层网络没学起来
- 加 BatchNorm 或 LayerNorm：训练集到 1.0，测试集 0.96
- 这个任务上 BN 和 LN 都能救，但不是所有结构都这样
- 把 200 轮加到 300 轮，无归一化也能到 0.94；归一化让优化更快、对学习率更稳

这个实验只说明“在这个深度/学习率下归一化有用”，不说明 BN 永远优于 LN，也不说明 LN 能替代残差连接。

## 5. 常见坑

1. **全零初始化**
   隐藏单元完全对称，永远学不出不同特征。

2. **BatchNorm 用 batch size=1**
   均值/方差没有统计意义；小 batch 用 GroupNorm/LayerNorm。

3. **评估时忘了 `model.eval()`**
   BN 会继续用当前 batch 统计，dropout 还会随机丢；评估结果不可信。

4. **BN 位置不固定**
   同一个模型里 `Conv→BN→ReLU` 和 `Conv→ReLU→BN` 混用，行为不一致。

5. **LayerNorm 轴搞错**
   LN 默认归一化最后一维；CNN 特征图要明确 `normalized_shape`。

6. **weight decay 加到 bias / norm 参数**
   常见做法是只衰减权重矩阵；至少要知道自己加在哪。

7. **Adam 的 L2 当 AdamW**
   Adam 的 weight decay 进梯度，会被自适应分母缩放；复现论文先看清。

8. **dropout 放在输出层**
   输出 logits 被随机置零，loss 会抖；输出层一般不用。

9. **归一化和学习率一起改**
   加 BN 后能用更大 lr；只加 BN 不调 lr，可能看似没效果。

10. **正则化叠太多**
    weight decay + dropout + 强增强一起上，训练集都欠拟合；先看验证曲线。

11. **归一化统计泄漏**
    用自己的数据统计做归一化时，均值/方差只能来自训练集；BN 的 running stats 也一样。

12. **以为归一化能解决一切**
    深层网络还需要合理初始化、残差、学习率；归一化只是其中一环。

## 6. 要点回顾

1. 初始化要打破对称，并尽量保持方差；Xavier 适合 tanh/sigmoid，He 适合 ReLU
2. BatchNorm 用 batch 统计，训练/评估不同，依赖 batch size
3. LayerNorm 按 token/位置归一化特征，不依赖 batch；RMSNorm 只除均方根
4. 归一化位置要固定；CNN 常用 Conv→BN→ReLU，Transformer 常用 pre-LN
5. 正则化不只是 L2：dropout、early stopping、数据增强、label smoothing 都算
6. weight decay 一般不作用在 bias 和 norm 参数上
7. 先过拟合，再加正则；不要一上来叠满
