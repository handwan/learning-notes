# 学习问题的框架

先看一个最小问题：

> 有 100 个样本 $(x_i,y_i)$，想找一个函数 $f(x)$ 预测 $y$。
>
> 怎么定义“预测得好”？怎么找这个函数？

监督学习的大部分内容，都是在这个问题上加东西：换模型、换损失、换优化器、换数据。

## 1. 四件套

| 组件 | 回答什么 | 例子 |
|---|---|---|
| 模型 | 候选函数长什么样 | 线性 $wx+b$、MLP、Transformer |
| 损失 | 怎么衡量预测错 | MSE、交叉熵 |
| 优化 | 怎么找参数 | 闭式解、梯度下降、Adam |
| 数据 | 从哪学、怎么评估 | 训练/验证/测试、采样 |

把四件套写成一句话：

**学习**：在模型允许的函数里，找一组参数，使训练数据上的损失最小。这里的“参数”是广义的；kNN、树等非参数模型没有固定维度的参数，但同样是在用训练数据降低误差。

这就是**经验风险最小化**：

$$
R_{\mathrm{emp}}(\theta)
= \frac{1}{n}\sum_{i=1}^{n} L\bigl(f_\theta(x_i), y_i\bigr)
$$

但真正关心的是**真实风险**：

$$
R(\theta)
= \mathbb{E}_{(x,y)\sim P}\bigl[L(f_\theta(x), y)\bigr]
$$

训练集只是 $P$ 的一个样本。训练损失小，不代表真实风险小；这中间的差距就是泛化。

## 2. 最小例子：y = 2x + 1

模型：

$$
\hat{y} = wx + b
$$

损失：

$$
\mathrm{MSE}(w,b)
= \frac{1}{n}\sum_{i=1}^{n}\bigl(\hat{y}_i-y_i\bigr)^2
$$

### 闭式解

对 $w$、$b$ 求偏导并令其为 0：

$$
\frac{\partial\,\mathrm{MSE}}{\partial b}
= \frac{2}{n}\sum_{i=1}^{n}(wx_i+b-y_i)=0
\quad\Longrightarrow\quad
b=\bar{y}-w\bar{x}
$$

$$
\frac{\partial\,\mathrm{MSE}}{\partial w}
= \frac{2}{n}\sum_{i=1}^{n}(wx_i+b-y_i)x_i=0
\quad\Longrightarrow\quad
w=
\frac{\sum_{i=1}^{n}(x_i-\bar{x})(y_i-\bar{y})}
{\sum_{i=1}^{n}(x_i-\bar{x})^2}
$$

也就是：

$$
w=\frac{\operatorname{Cov}(x,y)}{\operatorname{Var}(x)},
\qquad
b=\bar{y}-w\bar{x}
$$

### 梯度下降

$$
w \leftarrow w-\eta\,\frac{2}{n}\sum_{i=1}^{n}(\hat{y}_i-y_i)x_i,
\qquad
b \leftarrow b-\eta\,\frac{2}{n}\sum_{i=1}^{n}(\hat{y}_i-y_i)
$$

其中 $\eta$ 是学习率（代码里的 `lr`）。

### 跑一遍

```python
import numpy as np

rng = np.random.default_rng(0)
n = 100
x = rng.uniform(-1, 1, n)
y = 2 * x + 1 + rng.normal(0, 0.1, n)

# 闭式解
w = np.cov(x, y, bias=True)[0, 1] / np.var(x)
b = y.mean() - w * x.mean()

# 梯度下降
w_gd, b_gd = 0.0, 0.0
lr = 0.1
for _ in range(200):
    err = (w_gd * x + b_gd) - y
    w_gd -= lr * 2 * np.mean(err * x)
    b_gd -= lr * 2 * np.mean(err)

def mse(w, b):
    return np.mean((w * x + b - y) ** 2)

print("closed form", w, b, mse(w, b))
print("gradient   ", w_gd, b_gd, mse(w_gd, b_gd))
```

> `np.cov(..., bias=True)` 和 `np.var` 都用 $n$ 做分母，和 MSE 的 $1/n$ 对齐。

固定种子 0、200 步、学习率 0.1，运行结果：

| 方法 | w | b | MSE |
|---|---:|---:|---:|
| 闭式解 | 1.993464 | 0.992718 | 0.009401 |
| 梯度下降 | 1.993463 | 0.992718 | 0.009401 |

两者参数差约 $10^{-6}$，MSE 到小数点后 6 位相同。

原因：MSE 对 $(w,b)$ 是凸二次函数，只有一个最小值；学习率足够小，梯度下降会收敛到它。

### 如果学习率太大

把学习率改成 $10$，更新会来回震荡甚至发散。线性回归的梯度是
$\frac{2}{n}\sum_{i=1}^{n}(\hat{y}_i-y_i)x_i$，特征尺度越大，梯度越大；所以：

- 特征先标准化
- 学习率从 $10^{-3}$、$10^{-2}$ 这种量级试
- 看 loss 曲线，不只看最后一步

## 3. 从线性到非线性

如果真实关系是 $y=x^2$，线性模型会欠拟合。两种做法：

1. **加特征**：把 $x^2$ 作为输入，在特征空间 $(x,x^2)$ 里仍是线性的；对原始 $x$ 是非线性的
2. **换模型**：MLP、树模型、核方法

关键点：**框架没变**，只换了假设空间。

深度学习里：

| 组件 | 线性回归 | 神经网络 |
|---|---|---|
| 模型 | `wx + b` | 多层非线性变换 |
| 损失 | MSE | MSE / 交叉熵 |
| 优化 | 闭式解或 GD | 反向传播 + SGD/Adam |
| 数据 | 小样本 | 大数据、minibatch |

神经网络没有闭式解，损失也通常非凸；所以更依赖初始化、学习率、归一化和数据。

## 4. 数据这一侧

经验风险小，不等于真实风险小。三个常见问题：

### 切分

```text
训练集：学参数
验证集：选超参数、早停
测试集：最后评估一次
```

不要用测试集调参；调过之后，它就不再是“没见过”的数据。

### 泄漏

- 用未来数据预测过去
- 归一化时用了全量数据（包括测试集）
- 目标编码/统计特征跨训练测试计算
- 分组数据（同一用户/同一设备）被随机切到两边

### 分布偏移

训练集和线上分布不一致：

- 时间变化（季节性、热点）
- 用户群体变化
- 数据采集方式变化

监控线上指标，不要只看离线验证。

## 5. 损失和指标不是一回事

| 任务 | 损失（优化） | 指标（关心） |
|---|---|---|
| 回归 | MSE | MAE、$R^2$、业务误差 |
| 分类 | 交叉熵 | 准确率、F1、AUC |
| 排序 | pairwise/listwise loss | NDCG、MRR |

用梯度优化时，损失要可导、好优化；树模型可以用不纯度/MSE 这类可直接计算的目标。指标要能解释业务。两者可以不一致，比如类别不平衡时，准确率高但 F1 很差。

## 6. 常见混淆

- **训练误差 vs 泛化误差**：训练集上的 MSE 不是模型好坏的全部
- **损失 vs 指标**：优化的是损失，汇报的是指标
- **参数 vs 超参数**：`w/b` 是参数；学习率、层数、正则化系数是超参数
- **闭式解 vs 梯度下降**：线性回归有闭式解；深度学习一般没有
- **欠拟合 vs 过拟合**：前者模型太简单，后者模型太复杂或数据太少
- **特征缩放**：不做标准化，学习率和正则化都会失真

## 7. 检查清单

拿到一个学习问题，先问：

1. **模型**：它能表达你要的关系吗？
2. **损失**：它和业务目标一致吗？
3. **优化**：能收敛吗？学习率、特征尺度、初始化是否合理？
4. **数据**：切分对吗？有泄漏吗？线上分布会变吗？
5. **指标**：你看的是损失，还是真正关心的指标？

## 8. 要点回顾

1. **学习问题 = 模型 + 损失 + 优化 + 数据**
2. **经验风险最小化**是训练；**泛化**才是目标
3. 线性回归有**闭式解**；梯度下降是更通用的方法
4. 非线性模型不改变框架，只改变**假设空间**
5. 损失和指标要分开；数据切分和泄漏优先检查
