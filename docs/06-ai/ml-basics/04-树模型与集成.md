# 树模型与集成

树模型是表格数据的主力：

- 不需要标准化
- 能处理非线性、特征交互；缺失值支持取决于实现（XGBoost/LightGBM 等）
- 小树可解释
- 随机森林 / GBDT 在表格数据上经常最强

这篇讲三件事：决策树、随机森林、GBDT，最后用偏差-方差解释它们为什么有效。

前三篇讲的是线性模型和评估；这一篇换假设空间：用树做非线性。四件套不变，变的是模型。

## 1. 决策树

决策树做的是**递归划分**：

1. 选一个特征和一个阈值
2. 把数据分成左右两部分
3. 对每边递归
4. 到停止条件，叶子给多数类（分类）或均值（回归）

### 划分标准

分类不纯度：

$$
\operatorname{Gini}(D)=1-\sum_{k=1}^{K}p_k^2,
\qquad
H(D)=-\sum_{k=1}^{K}p_k\log p_k
$$

回归不纯度：

$$
\operatorname{MSE}(D)
=\frac{1}{|D|}\sum_{i\in D}(y_i-\bar{y}_D)^2
$$

每次选“划分后加权不纯度最小”的特征和阈值。

### 停止条件

- `max_depth`：最大深度
- `min_samples_split` / `min_samples_leaf`：节点/叶子最少样本
- `min_impurity_decrease`：不纯度下降不够就不分
- 叶子已经纯：全是同一类

### 剪枝

- **预剪枝**：提前停止（深度、样本数、不纯度）
- **后剪枝**：先长深，再把收益不大的子树合并/剪掉

### 代码：CART + 深度对比

二分类版本，`gini` 和叶子多数投票。先看树的实现：

```python
import numpy as np

def gini(y):
    if len(y) == 0:
        return 0.0
    p = np.bincount(y, minlength=2) / len(y)
    return 1.0 - (p ** 2).sum()

def build(X, y, depth=0, max_depth=4, min_samples=5,
          max_features=None, rng=None):
    if depth >= max_depth or len(y) < min_samples or len(np.unique(y)) == 1:
        return ("leaf", int(np.bincount(y, minlength=2).argmax()))

    n, d = X.shape
    feats = np.arange(d) if max_features is None else rng.choice(d, max_features, replace=False)
    best = None

    for j in feats:
        vals = np.unique(X[:, j])
        for t in (vals[:-1] + vals[1:]) / 2:
            left = X[:, j] <= t
            if left.sum() == 0 or (~left).sum() == 0:
                continue
            score = (left.sum() * gini(y[left]) +
                     (~left).sum() * gini(y[~left])) / n
            if best is None or score < best[0]:
                best = (score, j, t)

    if best is None:
        return ("leaf", int(np.bincount(y, minlength=2).argmax()))

    _, j, t = best
    left = X[:, j] <= t
    return ("node", j, t,
            build(X[left], y[left], depth + 1, max_depth, min_samples, max_features, rng),
            build(X[~left], y[~left], depth + 1, max_depth, min_samples, max_features, rng))

def pred_one(node, x):
    if node[0] == "leaf":
        return node[1]
    _, j, t, l, r = node
    return pred_one(l if x[j] <= t else r, x)

def pred(tree, X):
    return np.array([pred_one(tree, x) for x in X])
```

## 2. 随机森林

单棵树方差大：训练数据稍微一变，树结构可能完全不同。

随机森林用两次随机化降方差：

1. **Bagging**：有放回抽样，训练多棵树
2. **特征子采样**：每次划分只看随机一部分特征

预测时投票（分类）或平均（回归）。

### 为什么有效

- 深树：低偏差、高方差
- 多棵树平均：方差降低，偏差基本不变
- 树之间越不相关，平均降方差越明显；特征子采样就是为了降低相关性

### OOB

每棵树的 bootstrap 大约有 $1-(1-1/n)^n\approx36.8\%$ 的样本没被抽到。这些 OOB 样本可以当验证集，不用额外切分。

### 代码：100 棵树

```python
# 接着上一段：X, y, tr, te, build, pred 已定义
def forest(X, y, n_trees=100, depth=6, max_features=1, seed=0):
    r = np.random.default_rng(seed)
    trees = []
    for _ in range(n_trees):
        idx = r.integers(0, len(y), len(y))
        trees.append(build(X[idx], y[idx], max_depth=depth,
                           max_features=max_features, rng=r))
    return trees

trees = forest(X[tr], y[tr])
votes = np.array([pred(t, X[te]) for t in trees])
print("forest", (np.round(votes.mean(0)) == y[te]).mean())
```

运行结果：

```text
forest 0.93
```

单棵深度 6 的树是 `0.90`，100 棵森林是 `0.93`；提升不算夸张，但更稳。

### 特征重要性

- **不纯度重要性**：每次划分带来的不纯度下降，按特征累加
- 缺点：偏向高基数/连续特征；相关特征会分摊重要性
- **排列重要性**：打乱某个特征，看验证误差涨多少；更接近“模型依赖”
- **SHAP**：局部解释，能看每个样本的特征贡献；计算更贵

重要性不是因果：它只说明模型用了这个特征，不说明它导致结果。

## 3. GBDT

GBDT 是加法模型：

$F_0$ 取常数（如均值），之后每轮：

$$
F_m=F_{m-1}+\eta\,h_m
$$

其中 $\eta$ 是学习率（代码里的 `lr`）。每一轮用一棵小树 $h_m$ 拟合当前残差（平方损失下是负梯度），再加到模型上。

- `lr`：学习率，越小越稳，但需要更多树
- $h_m$：弱学习器，通常是深度 3–8 的树
- 轮数：用验证集/早停选

### 代码：stump + GBDT

用深度 1 的树（stump）演示，数据是 `sin(2πx)`。先看 stump 的实现：

```python
import numpy as np

def fit_stump(X, y):
    best = None
    for j in range(X.shape[1]):
        vals = np.unique(X[:, j])
        for t in (vals[:-1] + vals[1:]) / 2:
            left = X[:, j] <= t
            if left.sum() == 0 or (~left).sum() == 0:
                continue
            lm, rm = y[left].mean(), y[~left].mean()
            sse = ((y[left] - lm) ** 2).sum() + ((y[~left] - rm) ** 2).sum()
            if best is None or sse < best[0]:
                best = (sse, j, t, lm, rm)
    if best is None:
        return (0, 0, 0, y.mean(), y.mean())
    return best[1:]

def stump_pred(stump, X):
    j, t, lm, rm = stump
    return np.where(X[:, j] <= t, lm, rm)
```

数据生成和单树 baseline 折在下面；先展开再跑：

boosting 循环：

```python
f_tr = np.full(len(tr), y[tr].mean())
f_te = np.full(len(te), y[tr].mean())
lr = 0.1
for _ in range(100):
    r = y[tr] - f_tr
    s = fit_stump(X[tr], r)
    f_tr += lr * stump_pred(s, X[tr])
    f_te += lr * stump_pred(s, X[te])

print("gbdt", np.mean((f_tr - y[tr]) ** 2),
      np.mean((f_te - y[te]) ** 2))
```

运行结果：

| 模型 | 训练 MSE | 测试 MSE |
|---|---:|---:|
| 单个 stump | 0.3906 | 0.3566 |
| 100 个 stump + lr=0.1 | 0.1294 | 0.0989 |

从 0.36 降到 0.10，说明加法模型在逐步降低偏差。

### 分类任务

平方损失用残差；分类用对数损失时，拟合的是**负梯度**：

$$
p=\sigma(F),\qquad r_i=y_i-p_i
$$

这也是 GBDT 能做逻辑回归的原因。多分类用 softmax 的负梯度。

### 常见实现

- **XGBoost**：正则化目标、二阶梯度、直方图/近似分裂
- **LightGBM**：leaf-wise 生长、直方图、类别特征
- **CatBoost**：类别特征、ordered boosting

实现细节不同，核心都是“加法模型 + 弱树 + 梯度”。

## 4. 偏差-方差视角

| 模型 | Bias | Variance | 说明 |
|---|---|---|---|
| 浅树 | 高 | 低 | 欠拟合 |
| 深树 | 低 | 高 | 容易过拟合 |
| 随机森林 | 低 | 中/低 | 平均降方差 |
| GBDT | 低 | 中 | 逐步降 bias |

- 森林主要降**方差**，不怎么能降 bias
- Boosting 主要降**偏差**，但轮数太多/学习率太大会过拟合
- 树模型不能外推：训练范围外的值，叶子还是给最近的均值/类别

## 5. 什么时候用

适合：

- 表格数据、混合类型（数值 + 类别）
- 特征交互多、非线性明显
- 中小规模数据，训练/推理要快
- 需要特征重要性/可解释性（小树、SHAP）

不适合：

- 原始图像、文本、音频
- 需要外推的回归
- 超高维稀疏特征（文本 TF-IDF 有时线性模型更好）
- 在线极低延迟且模型很大（需要压缩/蒸馏）

实践顺序：

```text
线性/逻辑回归 baseline
→ 随机森林/GBDT
→ 需要更强表达再上神经网络
```

## 6. 常见坑

- 不切验证集，深度/轮数拍脑袋
- 单棵深树过拟合，误以为“树越深越好”
- 森林 `max_features` 太大，树之间太相关，降方差有限
- GBDT 学习率太大/轮数太多，训练集拟合但验证变差
- 用不纯度重要性解释因果
- 相关特征分摊重要性，误以为“都不重要”
- 训练集和测试集分布不同，树不能外推
- 目标编码在全量数据上计算，泄漏标签
- 缺失值处理不一致（不同库默认策略不同）

## 7. 要点回顾

1. **决策树**：递归划分，分类用 Gini/熵，回归用 MSE
2. **深树**低 bias 高 variance；深度用验证集选
3. **随机森林**：bagging + 特征子采样，主要降方差
4. **GBDT**：加法模型 + 残差/负梯度，主要降 bias
5. **特征重要性**不是因果；相关特征会分摊
6. **树不能外推**；表格数据优先树/GBDT，非结构化数据用神经网络
