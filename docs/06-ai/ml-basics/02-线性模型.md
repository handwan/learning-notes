# 线性模型

线性模型不是“过时的方法”。它是：

- 最快的基线
- 最容易被解释的模型
- 表格数据上很强的基线；更强的通常来自 GBDT/集成模型

这篇讲三件事：线性回归、逻辑回归、正则化。三者共用同一个框架：模型 + 损失 + 优化 + 数据。

第 1 篇用一维例子推过闭式解和梯度下降；这里换成多特征、矩阵形式，结论相同。

## 1. 线性回归

### 模型与损失

模型：

$$
\hat{y}=w_1x_1+w_2x_2+\cdots+w_dx_d+b
=\mathbf{x}^\top\mathbf{w}+b
$$

损失用 MSE：

$$
L(\mathbf{w},b)
=\frac{1}{n}\sum_{i=1}^{n}(\hat{y}_i-y_i)^2
$$

目标：

$$
\min_{\mathbf{w}}\;\frac{1}{n}
\lVert X\mathbf{w}-\mathbf{y}\rVert_2^2
$$

### 闭式解

第 1 篇已经推过标量形式；写成矩阵就是：

$$
\mathbf{w}=(X^\top X)^{-1}X^\top\mathbf{y}
$$

这就是最小二乘解。`X` 里加一列全 1，就把截距 `b` 一起解了。

注意：

- `XᵀX` 可能不可逆（共线、特征多于样本）→ 用伪逆/`lstsq`/正则化
- 特征尺度差太多时，`XᵀX` 条件数很差，解不稳定
- 闭式解是 $O(d^3+nd^2)$，特征很多时不划算

### 梯度下降

$$
\mathbf{w}\leftarrow\mathbf{w}
-\eta\,\frac{2}{n}X^\top(X\mathbf{w}-\mathbf{y})
$$

其中 $\eta$ 是学习率（代码里的 `lr`）。

### 线性回归：代码与结果

```python
import numpy as np

rng = np.random.default_rng(1)
n = 200
x1 = rng.normal(0, 1, n)
x2 = rng.normal(0, 1, n)
y = 3 * x1 - 2 * x2 + 1 + rng.normal(0, 0.5, n)
X = np.column_stack([x1, x2, np.ones(n)])

# 闭式解
w_closed, *_ = np.linalg.lstsq(X, y, rcond=None)

# 梯度下降
w_gd = np.zeros(3)
lr = 0.1
for _ in range(2000):
    err = X @ w_gd - y
    w_gd -= lr * 2 / n * (X.T @ err)

def mse(w):
    return np.mean((X @ w - y) ** 2)

print("closed", w_closed, mse(w_closed))
print("gd    ", w_gd, mse(w_gd))
```

固定种子 1，运行结果：

| 方法 | w₁ | w₂ | b | 训练 MSE |
|---|---:|---:|---:|---:|
| 闭式解 | 3.0582 | -2.1136 | 1.0103 | 0.2461 |
| 梯度下降 | 3.0582 | -2.1136 | 1.0103 | 0.2461 |

真实参数是 `3, -2, 1`，噪声标准差 0.5；估计值接近，训练 MSE 约等于噪声方差。

### 特征缩放与多重共线性

- **特征缩放**：梯度下降对尺度敏感；标准化后收敛更稳，正则化也更公平
- **多重共线性**：两个特征高度相关时，`XᵀX` 接近奇异，系数会变得很大且不稳定；预测可能没问题，但解释系数要小心
- **外推**：线性模型在训练范围外没有依据，不要拿它外推很远

### R²

$$
R^2=1-\frac{\mathrm{SSE}}{\mathrm{SST}},
\qquad
\mathrm{SST}=\sum_{i=1}^{n}(y_i-\bar{y})^2
$$

- $R^2=1$：完美拟合
- $R^2=0$：和“永远预测均值”一样
- $R^2<0$：在测试集上可能比均值还差

$R^2$ 和 MSE 可以互相换算，但 $R^2$ 更直观；不要只看 $R^2$，还要看残差和业务误差。

## 2. 逻辑回归

### 从回归到分类

逻辑回归名字里有“回归”，但做的是分类。它先算一个线性分数：

$$
z=\mathbf{x}^\top\mathbf{w}+b
$$

再用 sigmoid 变成概率：

$$
p=\sigma(z)=\frac{1}{1+e^{-z}}
$$

决策规则：

$p\ge 0.5$ 判为正类，$p<0.5$ 判为负类。

等价于 $z\ge 0$，所以决策边界是线性的。

### 损失

不用 MSE，用对数损失（交叉熵）：

$$
L(\mathbf{w},b)
=-\frac{1}{n}\sum_{i=1}^{n}
\left[y_i\log p_i+(1-y_i)\log(1-p_i)\right]
$$

梯度很干净：

$$
\frac{\partial L}{\partial \mathbf{w}}
=\frac{1}{n}X^\top(\mathbf{p}-\mathbf{y})
$$

为什么不用 MSE：sigmoid + MSE 对 $w$ 不是凸的，梯度里会带 $\sigma'(z)$，饱和区梯度很小；交叉熵配 sigmoid 是凸的，梯度也不会被 $\sigma'$ 压扁。

### 逻辑回归：代码与结果

```python
import numpy as np

rng = np.random.default_rng(2)
n = 200
X0 = rng.normal([-1, -1], 1.0, (n, 2))
X1 = rng.normal([1, 1], 1.0, (n, 2))
X = np.vstack([X0, X1])
y = np.array([0] * n + [1] * n)

mu, sd = X.mean(0), X.std(0)
X = (X - mu) / sd
X = np.column_stack([X, np.ones(2 * n)])

def sigmoid(z):
    out = np.empty_like(z)
    pos = z >= 0
    out[pos] = 1 / (1 + np.exp(-z[pos]))
    out[~pos] = np.exp(z[~pos]) / (1 + np.exp(z[~pos]))
    return out

w = np.zeros(3)
lr = 0.1
for _ in range(2000):
    p = sigmoid(X @ w)
    w -= lr * (X.T @ (p - y)) / n

p = sigmoid(X @ w)
pred = (p >= 0.5).astype(int)
print("w", w)
print("train_acc", (pred == y).mean())
```

固定种子 2，运行结果：

```text
w = [2.3957, 2.8915, 0.0104]
train_acc = 0.9125
```

> 这里的 `w` 是在标准化后的特征上；原始尺度的系数是 `w/sd`，截距也要跟着变。

训练集混淆矩阵：

| | 预测正 | 预测负 |
|---|---:|---:|
| 实际正 | 184 | 16 |
| 实际负 | 19 | 181 |

- 训练集准确率：$\frac{184+181}{400}=0.9125$
- 精确率：$\frac{184}{184+19}\approx0.906$
- 召回率：$\frac{184}{184+16}=0.92$

> 这里没有切分训练/测试，标准化也用全量数据，只用于演示训练拟合。真实评估要先切分，scaler 只在训练集上拟合；见下一篇。

### 阈值与类别不平衡

0.5 只是默认值；阈值要按业务代价调：宁可错杀就降阈值提高召回，宁可漏掉就升阈值提高精确率。

正类只占 1% 时，全预测负类也有 99% 准确率。处理方式包括重采样、类别权重、调阈值、换指标（PR-AUC/F1）；完整实验见[第 3 篇](03-评估、泛化与正则化.md)。

### 多分类：softmax

二分类用 sigmoid；多分类用 softmax：

$$
z_k=\mathbf{x}^\top\mathbf{w}_k,
\qquad
p_k=\frac{\exp(z_k)}{\sum_{j=1}^{K}\exp(z_j)},
\qquad
L=-\log p_y
$$

- 每个类别一组权重 `w_k`
- 输出 `K` 个概率，和为 1
- 损失还是交叉熵；梯度形式不变：`Xᵀ(p - onehot(y)) / n`
- $K=2$ 时，两类权重有冗余；固定一类为基准后，softmax 等价于 sigmoid

常见坑：

- 直接对 logits 做 `exp` 会上溢 → 先减最大值：`z - max(z)`
- 类别不平衡时，softmax + 交叉熵仍会偏向多数类；要加权或重采样

## 3. 正则化

线性模型很容易过拟合，尤其是特征多、样本少、特征相关时。正则化在损失里加惩罚：

### L2 / Ridge

设特征矩阵为 $X$，截距为 $b$，惩罚只作用在特征系数 $\mathbf{w}$ 上。这一节把截距单独拿出来；上一节的增广矩阵写法是同一件事。

$$
L(\mathbf{w},b)
=\lVert X\mathbf{w}+\mathbf{1}b-\mathbf{y}\rVert_2^2
+\lambda\lVert\mathbf{w}\rVert_2^2
$$

把截距并入设计矩阵 $X_a=[X,\mathbf{1}]$，参数记为 $\tilde{\mathbf{w}}=(\mathbf{w},b)$：

$$
\tilde{\mathbf{w}}
=(X_a^\top X_a+\lambda D)^{-1}X_a^\top\mathbf{y},
\qquad
D=\operatorname{diag}(0,1,\dots,1)
$$

- $\lambda$ 越大，系数越向 0 收缩
- 不正则化截距：$D$ 的第一个对角元是 0；如果设计矩阵不含截距列，$D=I$
- 特征要标准化，否则惩罚不公平

### L1 / Lasso

$$
L(\mathbf{w},b)
=\lVert X\mathbf{w}+\mathbf{1}b-\mathbf{y}\rVert_2^2
+\lambda\lVert\mathbf{w}\rVert_1
$$

- 倾向把不重要的系数压到 0，得到稀疏解
- 可以做特征选择
- 和 L2 一样，不正则化截距
- 没有闭式解，常用坐标下降

### 多项式过拟合实验

用 15 个训练点拟合 `sin(2πx)`，多项式阶数 9，噪声 0.2：

```python
import numpy as np

rng = np.random.default_rng(4)
ntr, nte = 15, 500
xtr = rng.uniform(-1, 1, ntr)
xte = rng.uniform(-1, 1, nte)
ytr = np.sin(2 * np.pi * xtr) + rng.normal(0, 0.2, ntr)
yte = np.sin(2 * np.pi * xte) + rng.normal(0, 0.2, nte)

def design(x, deg=9):
    return np.column_stack([x ** k for k in range(deg + 1)])

Xtr, Xte = design(xtr), design(xte)
I = np.eye(10)
I[0, 0] = 0  # 不正则化截距

for lam in [0, 1e-4, 1e-2, 1e-1, 1]:
    if lam == 0:
        w, *_ = np.linalg.lstsq(Xtr, ytr, rcond=None)
    else:
        w = np.linalg.solve(Xtr.T @ Xtr + lam * I, Xtr.T @ ytr)
    print(lam,
          np.mean((Xtr @ w - ytr) ** 2),
          np.mean((Xte @ w - yte) ** 2),
          np.linalg.norm(w))
```

运行结果：

| $\lambda$ | 训练 MSE | 测试 MSE | $\lVert\mathbf{w}\rVert_2$ |
|---:|---:|---:|---:|
| 0 | 0.0019 | 300.8208 | 771.7 |
| 1e-4 | 0.0102 | 0.7669 | 31.5 |
| 1e-2 | 0.1072 | 0.1701 | 7.7 |
| 1e-1 | 0.2013 | 0.3697 | 2.3 |
| 1 | 0.2778 | 0.4192 | 0.6 |

- $\lambda=0$：训练误差极低，测试误差爆炸，典型过拟合
- $\lambda=10^{-2}$：测试误差最低
- $\lambda=1$：训练/测试都变差，欠拟合

> 这里用的是平方误差和 $\lVert X\mathbf{w}-\mathbf{y}\rVert_2^2$，不是 MSE；如果损失写 MSE，闭式解里的 $\lambda$ 要乘 $n$。

> 这个实验为了看多项式过拟合，没有对多项式特征做标准化；真实使用先标准化再调 $\lambda$。

### 怎么选 λ

- 用验证集/交叉验证，不要用测试集
- 先标准化特征
- $\lambda$ 从小到大扫（对数刻度）
- 看验证误差的 U 形曲线

## 4. 什么时候用

适合：

- 表格数据、特征有业务含义
- 样本少、需要可解释
- 作为强基线：先跑逻辑回归/线性回归，再决定要不要上复杂模型
- 需要快速迭代、低延迟

不适合：

- 原始图像、文本、音频
- 强非线性、复杂交互
- 需要端到端表示学习

但即使上树模型/神经网络，线性模型仍值得作为 baseline 对照。

## 5. 常见坑

- 标准化用了全量数据（包括测试集）→ 泄漏
- 正则化时没有标准化特征 → 惩罚不公平
- 正则化了截距 → 截距被无谓压小
- 多重共线性 → 系数符号/大小不可解释
- 类别不平衡时只看准确率
- 阈值固定 0.5，不按业务调
- 用 $R^2$ 代替业务指标
- 在训练范围外外推
- 只跑一次划分，不看方差

## 6. 要点回顾

1. **线性回归**：MSE + 闭式解或梯度下降；$\mathbf{w}=(X^\top X)^{-1}X^\top\mathbf{y}$
2. **逻辑回归**：sigmoid + 交叉熵；梯度 `Xᵀ(p-y)/n`；决策边界线性
3. **正则化**：L2 收缩系数，L1 产生稀疏；$\lambda$ 用验证集选
4. **特征缩放**：梯度下降和正则化都依赖尺度
5. **指标**：损失用于优化，准确率/精确率/召回率/F1 用于业务
6. **基线**：线性模型先跑，再决定要不要上复杂模型
