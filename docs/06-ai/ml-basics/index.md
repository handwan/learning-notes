## 一条主线

假设要根据“学习时长”和“睡眠时长”判断一个学生能否通过考试：

| 篇 | 在这个例子里做什么 |
|---|---|
| 01 | 定义 $f(x)=w_1x_1+w_2x_2+b$；MSE 是损失，梯度下降是优化；先讲回归 |
| 02 | 换成逻辑回归 $p=\sigma(f(x))$，交叉熵是损失，得到线性决策边界 |
| 03 | 切分、交叉验证、看混淆矩阵；如果泄漏，准确率会虚高 |
| 04 | 如果规则是“时长 > 6 且 睡眠 > 7”的矩形，换树；森林/GBDT 更稳 |
| 05 | 如果没有“是否通过”的标签，用聚类分组，或用 PCA 看结构 |
| 06 | 处理缺失的时长/睡眠、把城市类别编码、标准化数值；用 Pipeline 防止泄漏 |

## 读完能做什么

- 拿到一份表格数据，能选基线、做切分、解释指标
- 能把原始表格变成模型可用的特征，并保证预处理不泄漏
- 能判断“模型不好”是欠拟合、过拟合还是数据泄漏
- 能看懂论文里的 baseline / ablation / generalization 在说什么

## 自测 10 问

先不看答案，能答出 7 个以上再往下读。

1. 训练损失下降、验证损失不降，说明什么？
2. 为什么先切分，再标准化？
3. L1 和 L2 正则化有什么区别？
4. 随机森林主要降 bias 还是 variance？为什么？
5. GBDT 每一轮拟合的是什么？
6. 类别不平衡时，为什么准确率会骗人？应该看什么？
7. 交叉验证比单次验证集好在哪？
8. K-means 的 k 怎么选？为什么不能只看 inertia？
9. PCA 为什么要先标准化？前几个主成分代表什么？
10. 树模型为什么不能外推？

??? note "参考答案"
    1. 可能过拟合，也可能训练/验证分布不同；看两者差距、学习曲线，再决定加数据、加正则还是降容量。
    2. 标准化的均值/方差也是从数据里学的；用全量数据会泄漏测试集信息，让评估虚高。
    3. L2 把系数整体收缩、更平滑；L1 倾向把不重要的系数压到 0，可做特征选择；强度都由 $\lambda$ 控制。
    4. 主要降 variance。bagging 平均多棵树的预测，偏差基本不变；树之间越不相关，降方差越明显。
    5. 拟合当前模型的负梯度；平方损失下就是残差，然后加一棵小树。
    6. 全预测多数类就能有很高准确率；应看精确率、召回率、F1、PR-AUC，并按业务代价调阈值。
    7. 多折平均降低单次切分的偶然性，还能报告均值和方差；嵌套 CV 还能避免调参带来的选择偏差。
    8. 肘部法、轮廓系数、稳定性和业务约束一起看；inertia 随 k 单调下降，k=n 时为 0，单独看没有意义。
    9. 方差受量纲影响，不标准化会让大尺度特征主导；前几个主成分是方差最大的正交方向。
    10. 树的预测落在叶子的均值/多数类上，超出训练范围后仍停在边缘叶子，不会沿趋势延伸。
