# 构建与安装流程

编译安装三步：配置 → 编译 → 安装。

```bash
cmake -S . -B build-debug -DCMAKE_BUILD_TYPE=Debug
cmake --build build-debug -j$(nproc)
sudo cmake --install build-debug
```

## 1. 配置：`cmake -S . -B build-debug -DCMAKE_BUILD_TYPE=Debug`

作用：读 `CMakeLists.txt`，检测环境，生成构建文件（`Makefile`/`Ninja`）到 `build-debug/`。这一步不编译。

| 参数 | 含义 |
|---|---|
| `cmake` | 调用 CMake 程序 |
| `-S .` | Source dir = `.`（当前目录，里面是 `CMakeLists.txt`） |
| `-B build-debug` | Build dir = `build-debug`（不存在会自动创建） |
| `-DCMAKE_BUILD_TYPE=Debug` | 定义 CMake 变量（`-D` = define），这里设定构建类型 `Debug` |

**背后做了什么**：

1. 找 `CMakeLists.txt`，执行里面的逻辑（`project()`、找依赖、`find_package()`…）
2. 检测编译器（`g++`）、C++ 标准、系统
3. 把 `CMakeCache.txt`（缓存）、`Makefile`、`cmake_install.cmake` 等写进 `build-debug/`

如果这步报错（如缺库、语法错），都在这里暴露，编译还没开始。

## 2. 编译：`cmake --build build-debug -j$(nproc)`

作用：让构建系统编译（跑底层 `make`/`ninja`）。

| 参数 | 含义 |
|---|---|
| `cmake --build` | 通用"构建"命令（与生成器无关） |
| `build-debug` | 在哪个构建目录里构建 |
| `-j$(nproc)` | 并行编译，`$(nproc)` 是 CPU 核数（shell 展开成数字）；也可写 `-j8` |

**背后**：读取配置中生成的 `Makefile`，按依赖编译源码 → 产出 `.o`、最后链出 `libmylib.so`（在 `build-debug/` 里）。

## 3. 安装：`sudo cmake --install build-debug`

作用：把编译好的产物（库、头文件、cmake 配置）复制到安装目录。

| 参数 | 含义 |
|---|---|
| `sudo` | 提权（安装目标是 `/usr/local/...`，写 `/usr` 要 root） |
| `cmake --install` | 执行 CMake 里的 `install(...)` 规则 |
| `build-debug` | 用哪个构建目录的产物来装 |

**背后**：执行 `CMakeLists.txt` 里定义的所有 `install(...)`：

- 头文件 → `include/`
- 库 → `lib/debug/`
- cmake 配置 → `share/mylib/cmake/`
- RPATH 设置 → `lib/debug`

## 三个阶段的关系

```
CMakeLists.txt
     │  ① cmake -S -B   （配置：生成构建文件 + 缓存）
     ▼
build-debug/  （Makefile / CMakeCache.txt / 产物）
     │  ② cmake --build （编译：Makefile→.o→.so）
     ▼
build-debug/libmylib.so
     │  ③ cmake --install（安装：复制到 /usr/local/...）
     ▼
/usr/local/.../lib/debug/libmylib.so
```

## 常见的等价

| 现代 | 老写法等价 |
|---|---|
| `cmake -S . -B build` | `mkdir build && cd build && cmake ..` |
| `cmake --build build` | `cd build && make` |
| `cmake --install build` | `cd build && make install` |

## 一句话

① 配置（生成构建系统）→ ② 编译（出库）→ ③ 安装（放到系统）。

`-S`/`-B` 分开源码与构建目录；`--build`/`--install` 与生成器无关；`$(nproc)` = CPU 核数（并行）；`sudo` = 装到系统目录要权限。
