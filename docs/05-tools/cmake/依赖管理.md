# 依赖管理

## 1. find_package（找已安装的依赖）

```cmake
find_package(fmt REQUIRED)                      # 必须找到
find_package(Qt5 COMPONENTS Core Gui REQUIRED)  # 找组件
find_package(OpenSSL QUIET)                     # 找不到不报错
```

找到后，用它提供的 **imported target**：

```cmake
target_link_libraries(app PRIVATE fmt::fmt Qt5::Core OpenSSL::SSL)
```

### 两种模式

| 模式 | 查找文件 | 说明 |
|------|----------|------|
| **MODULE** | `FindXXX.cmake` | CMake 自带或项目提供（如 `FindThreads.cmake`） |
| **CONFIG** | `XXXConfig.cmake` / `xxx-config.cmake` | 库安装时自带（现代库都提供） |

CMake 先找 MODULE 再找 CONFIG，可强制：`find_package(fmt CONFIG REQUIRED)`。

### 搜索路径

用 `CMAKE_PREFIX_PATH` 指定前缀：

```bash
cmake -S . -B build -DCMAKE_PREFIX_PATH=/opt/mylib
```

## 2. imported target（依赖的载体）

`find_package` 找到库后，会定义 imported target，携带它的 include/链接信息：

```cmake
# 库里导出的文件底层长这样
add_library(fmt::fmt STATIC IMPORTED)
set_target_properties(fmt::fmt PROPERTIES
    IMPORTED_LOCATION "/usr/local/lib/libfmt.a"
    INTERFACE_INCLUDE_DIRECTORIES "/usr/local/include"
)
```

你**只需 `target_link_libraries(app PRIVATE fmt::fmt)`**，不用管路径。

## 3. 手动找（没有 config 的老库）

```cmake
find_path(MYLIB_INCLUDE_DIR mylib.h)
find_library(MYLIB_LIBRARY NAMES mylib)
```

现代做法：**包装成 imported target**，别到处传变量。

## 4. FetchContent（下载并构建依赖）

不用预装，直接从源码拉取并编译：

```cmake
include(FetchContent)
FetchContent_Declare(
    fmt
    GIT_REPOSITORY https://github.com/fmtlib/fmt.git
    GIT_TAG 10.2.1
)
FetchContent_MakeAvailable(fmt)      # 拉取 + add_subdirectory

target_link_libraries(app PRIVATE fmt::fmt)
```

适合：依赖少、要固定版本、不想让用户手动装。

## 5. add_subdirectory（把依赖当子项目）

依赖源码在本地（submodule / vendored）：

```cmake
add_subdirectory(third_party/fmt)     # fmt 的 CMakeLists 被包含进来
target_link_libraries(app PRIVATE fmt::fmt)
```

## 6. pkg-config（兼容老库）

```cmake
find_package(PkgConfig REQUIRED)
pkg_check_modules(GTK3 REQUIRED gtk+-3.0)
target_link_libraries(app PRIVATE ${GTK3_LIBRARIES})
target_include_directories(app PRIVATE ${GTK3_INCLUDE_DIRS})
```

## 7. 三种方式怎么选

| 方式 | 场景 |
|------|------|
| `find_package` | 依赖已安装（系统 / 独立安装）—— **首选** |
| `FetchContent` | 想固定版本、自动拉取源码 |
| `add_subdirectory` | 依赖源码在仓库内（submodule / vendored） |

## 8. 一句话

> 依赖一律用 **imported target** 传递；`find_package` 找已装的，`FetchContent` 拉源码，别手拼路径和 `-l`。
