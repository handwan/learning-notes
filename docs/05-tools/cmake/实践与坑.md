# 实践与坑

## 1. 现代 vs 旧写法对照

| 旧写法 ❌ | 现代 ✅ |
|-----------|---------|
| `include_directories(include)` | `target_include_directories(t PUBLIC include)` |
| `link_directories(lib)` + `-lxxx` | 用 imported target（`fmt::fmt`） |
| `link_libraries(foo)` | `target_link_libraries(t PRIVATE foo)` |
| `set(CMAKE_CXX_FLAGS "...")` | `target_compile_options(t ...)` |
| `add_definitions(-DX)` | `target_compile_definitions(t PRIVATE X)` |
| `file(GLOB ...)` 收源文件 | **显式列源文件** |
| 手写安装路径 | `${CMAKE_INSTALL_LIBDIR}`（GNUInstallDirs） |
| 绝对路径写进导出 | `$<BUILD_INTERFACE>` / `$<INSTALL_INTERFACE>` |

## 2. 常见坑

### ① 用 GLOB 收源文件

```cmake
file(GLOB SRCS "src/*.cpp")     # ❌ 新增文件不会自动重新 configure
```

**显式列**：`add_executable(app a.cpp b.cpp c.cpp)`。或加 `CONFIGURE_DEPENDS`（仍不推荐）。

### ② 该 PUBLIC 写成 PRIVATE

```cmake
# mylib 公共头文件 #include <fmt/format.h>
target_link_libraries(mylib PRIVATE fmt::fmt)   # ❌
```

→ 使用者编译时报"找不到 fmt 头文件"或链接 `undefined reference`。**公共头暴露的依赖必须 PUBLIC**。

### ③ 忘记 CMAKE_BUILD_TYPE

单配置生成器（Makefile/Ninja）默认**无优化**：

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release   # 显式指定
```

或在 CMakeLists 里设默认值：

```cmake
if(NOT CMAKE_BUILD_TYPE)
    set(CMAKE_BUILD_TYPE Release)
endif()
```

### ④ 源码内构建（in-source）

```bash
cmake .          # ❌ 生成一堆文件在源码里
```

**永远**用 `cmake -S . -B build`。

### ⑤ 变量作用域

`add_subdirectory` 子目录会继承父变量，但**子目录里 set 的东西不外传**（除非 `PARENT_SCOPE` / `CACHE`）。

### ⑥ 导出时写死绝对路径

```cmake
target_include_directories(mylib PUBLIC ${CMAKE_CURRENT_SOURCE_DIR}/include)  # ❌ 导出后失效
```

用 `$<BUILD_INTERFACE:...>` / `$<INSTALL_INTERFACE:...>`。

### ⑦ target 名冲突

不同库都叫 `utils` 会冲突。用**命名空间 / 前缀**：`MyLib::utils`。

## 3. 写 CMake 的原则（背下来）

1. **目标驱动**：只用 `target_*`，不碰全局命令
2. **依赖用 imported target 传递**，别手拼路径和 `-l`
3. **公共头文件暴露的依赖 → PUBLIC**；内部实现 → PRIVATE
4. 一个库对外只暴露**一个 export set、一个 targets 文件、一个命名空间**
5. `find_package` / `FetchContent` 找依赖，别 `link_directories`
6. **显式列源文件**，别 `GLOB`
7. `cmake_minimum_required(VERSION 3.16+)`
8. **源码外构建**，显式 `CMAKE_BUILD_TYPE`

## 4. 一句话

> 现代 CMake = "target 自带一切并自动传播"；踩坑多在**作用域、PUBLIC/PRIVATE、导出路径**这三处。
