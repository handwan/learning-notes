# 基础

## 1. CMake 是什么

**CMake 是"构建系统生成器"（build system generator），不是构建系统本身。**

- 你写 `CMakeLists.txt`（描述怎么构建）
- CMake 生成对应平台的构建文件：Linux 上生成 Makefile/Ninja，Windows 上生成 VS 工程
- 再由 Make/Ninja/MSBuild **真正编译**

好处：**一份 CMakeLists，跨平台、跨 IDE、跨编译器**。

```
CMakeLists.txt ──cmake──→ Makefile / build.ninja ──make/ninja──→ 可执行文件
                 (生成)         (构建系统)              (真正编译)
```

## 2. 构建流程

```bash
# ① configure + generate：读 CMakeLists，生成构建文件
cmake -S . -B build                              # -S 源码目录  -B 构建目录
cmake -S . -B build -G Ninja                     # 指定生成器（默认 Unix Makefiles）
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release   # -D 传变量

# ② build：调用底层构建系统编译
cmake --build build                              # 自动选 make/ninja
cmake --build build -j8                          # 并行

# ③ install（可选）
cmake --install build --prefix /usr/local
```

**out-of-source build**（源码外构建）：产物都放 `build/`，不污染源码——**永远这么做**。

**实用**：加 `-DCMAKE_EXPORT_COMPILE_COMMANDS=ON` 会生成 `compile_commands.json`（每个源文件的编译命令），供 **clangd / clang-tidy / 各种工具**使用。

> 三步的**详细解释**（每个参数、背后做了什么）见 [构建与安装流程](构建与安装流程.md)。

## 3. CMakeLists.txt 语法

```cmake
# 注释用 #

# ① 最低版本（必须）建议写第一行
cmake_minimum_required(VERSION 3.16)

# ② 项目定义
project(MyApp VERSION 1.0.0 LANGUAGES CXX)

# ③ 命令：命令名(参数 参数 ...)
message(STATUS "Building ${PROJECT_NAME}")

# ④ 生成可执行文件
add_executable(app main.cpp)
```

**要点**：

- 命令**大小写不敏感**（`add_executable` == `ADD_EXECUTABLE`），约定**全小写**
- 变量用 `${VAR}` 引用
- 字符串可加引号
- 列表用分号分隔：`set(SRCS a.cpp b.cpp)` 等价于 `"a.cpp;b.cpp"`

## 4. 变量

```cmake
set(MY_VAR "hello")            # 定义
message(${MY_VAR})             # 引用
unset(MY_VAR)                  # 删除

set(SRCS a.cpp b.cpp)          # 列表
list(APPEND SRCS c.cpp)        # 追加
list(LENGTH SRCS n)            # 取长度
```

### 缓存变量（CACHE）

存进 `CMakeCache.txt`，命令行 `-D` 可覆盖，GUI 里可勾选：

```cmake
set(MY_OPTION ON CACHE BOOL "是否开启某功能")
option(MY_OPTION "是否开启某功能" ON)     # option 是 BOOL 缓存变量的简写
```

### 作用域

- 变量默认**目录作用域**：`add_subdirectory` 子目录**继承**父目录变量
- **函数**内修改不影响外面（除非 `set(... PARENT_SCOPE)`）
- `include()` 在**当前作用域**执行

### 常用预定义变量

| 变量 | 含义 |
|------|------|
| `CMAKE_BUILD_TYPE` | Debug / Release / RelWithDebInfo / MinSizeRel |
| `CMAKE_CXX_COMPILER` | C++ 编译器路径 |
| `CMAKE_SOURCE_DIR` | 顶层源码目录 |
| `CMAKE_CURRENT_SOURCE_DIR` | 当前 CMakeLists 所在目录 |
| `CMAKE_BINARY_DIR` | 顶层构建目录 |
| `PROJECT_NAME` / `PROJECT_VERSION` | `project()` 定义的名字 / 版本 |
| `CMAKE_CXX_STANDARD` | C++ 标准（如 17） |

## 5. 控制流

```cmake
if(WIN32)
    message("Windows")
elseif(APPLE)
    message("macOS")
else()
    message("Linux")
endif()

# 常用判断
if(CMAKE_BUILD_TYPE STREQUAL "Debug")   # 字符串比较
if(NOT DEFINED MY_VAR)                  # 是否定义
if(MY_VAR)                              # 真值
if(EXISTS path)                         # 路径存在
if(CMAKE_VERSION VERSION_LESS "3.16")   # 版本比较
```

```cmake
foreach(SRC ${SRCS})
    message(${SRC})
endforeach()

foreach(i RANGE 0 4)      # 0,1,2,3,4
endforeach()

while(cond)
endwhile()
```

## 6. 函数与宏

```cmake
function(my_func arg1 arg2)
    message("${arg1} ${arg2}")
    # 可变参数：ARGV（全部）、ARGN（命名参数之后）
endfunction()

macro(my_macro)
    # 宏是文本替换，不产生新作用域（慎用）
endmacro()
```

**function vs macro**：function 有独立作用域；macro 是文本替换、共享调用者作用域。**优先 function**。

## 7. 常用命令

```cmake
# 文件
file(GLOB SRCS "src/*.cpp")              # ⚠️ 不推荐（不感知新增文件）
configure_file(config.h.in config.h)     # 生成头文件（替换 @VAR@ / ${VAR}）

# 字符串
string(REPLACE ";" " " OUT "${SRCS}")
string(TOUPPER "abc" OUT)

# 引入模块
include(GNUInstallDirs)                  # 标准安装目录变量
include(CMakePackageConfigHelpers)       # 导出助手
```

## 8. 小结

- CMake 是**生成器**：`cmake -S . -B build` → `cmake --build build`
- 永远**源码外构建**（`build/`）
- 语法：命令 + 变量 `${}` + 列表（分号分隔）
- 变量有作用域；缓存变量用 `-D` 传
- `function` 优先于 `macro`
