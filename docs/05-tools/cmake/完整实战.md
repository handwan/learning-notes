# 完整实战

把前面所有知识点串成一条线：**写库 → 安装 → 导出 → 别人 `find_package` 用**。

## 0. 目标

写一个库 `mymath`（提供 `mymath::add`），能被安装，别人能用 `find_package(mymath)` 使用。

## 1. 目录结构

```
mymath/
├── CMakeLists.txt
├── cmake/
│   └── mymath-config.cmake.in
├── include/
│   └── mymath/
│       └── add.h
└── src/
    └── add.cpp
```

## 2. 源码

`include/mymath/add.h`：

```cpp
#pragma once

namespace mymath {

int add(int a, int b);

}
```

`src/add.cpp`：

```cpp
#include "mymath/add.h"

namespace mymath {

int add(int a, int b) {
    return a + b;
}

}
```

## 3. 库的 CMakeLists.txt

```cmake
cmake_minimum_required(VERSION 3.16)
project(mymath VERSION 1.0.0 LANGUAGES CXX)

include(GNUInstallDirs)                 # CMAKE_INSTALL_LIBDIR 等
include(CMakePackageConfigHelpers)      # 导出助手

# ---- target ----
add_library(mymath src/add.cpp)
add_library(mymath::mymath ALIAS mymath)     # 别名，消费侧统一写 mymath::mymath

# 公共头文件：构建时用源码目录，安装后用安装前缀
target_include_directories(mymath PUBLIC
    $<BUILD_INTERFACE:${CMAKE_CURRENT_SOURCE_DIR}/include>
    $<INSTALL_INTERFACE:${CMAKE_INSTALL_INCLUDEDIR}>
)

# C++ 标准（PUBLIC → 使用者自动获得）
target_compile_features(mymath PUBLIC cxx_std_17)

# 依赖：内部用线程 → PRIVATE（不暴露给使用者）
find_package(Threads REQUIRED)
target_link_libraries(mymath PRIVATE Threads::Threads)

# 若公共头文件 include 了第三方库（如 fmt），必须写成 PUBLIC：
# find_package(fmt REQUIRED)
# target_link_libraries(mymath PUBLIC fmt::fmt)

# ---- 安装库 + 头文件 ----
install(TARGETS mymath
    EXPORT mymath-targets
    LIBRARY DESTINATION ${CMAKE_INSTALL_LIBDIR}
    ARCHIVE DESTINATION ${CMAKE_INSTALL_LIBDIR}
    RUNTIME DESTINATION ${CMAKE_INSTALL_BINDIR}
    INCLUDES DESTINATION ${CMAKE_INSTALL_INCLUDEDIR}
)
install(DIRECTORY include/ DESTINATION ${CMAKE_INSTALL_INCLUDEDIR})

# ---- 导出 targets（生成 mymath-targets.cmake）----
install(EXPORT mymath-targets
    FILE mymath-targets.cmake
    NAMESPACE mymath::                                    # 对外名 mymath::mymath
    DESTINATION ${CMAKE_INSTALL_LIBDIR}/cmake/mymath
)

# ---- config + version（让 find_package 找到 + 版本检查）----
write_basic_package_version_file(
    ${CMAKE_CURRENT_BINARY_DIR}/mymath-config-version.cmake
    VERSION ${PROJECT_VERSION}
    COMPATIBILITY SameMajorVersion
)
configure_package_config_file(
    cmake/mymath-config.cmake.in
    ${CMAKE_CURRENT_BINARY_DIR}/mymath-config.cmake
    INSTALL_DESTINATION ${CMAKE_INSTALL_LIBDIR}/cmake/mymath
)
install(FILES
    ${CMAKE_CURRENT_BINARY_DIR}/mymath-config.cmake
    ${CMAKE_CURRENT_BINARY_DIR}/mymath-config-version.cmake
    DESTINATION ${CMAKE_INSTALL_LIBDIR}/cmake/mymath
)
```

## 4. config 模板

`cmake/mymath-config.cmake.in`：

```cmake
@PACKAGE_INIT@

include("${CMAKE_CURRENT_LIST_DIR}/mymath-targets.cmake")

check_required_components(mymath)
```

- `@PACKAGE_INIT@`：`configure_package_config_file` 展开的初始化代码
- `include(...targets.cmake)`：加载导出的 `mymath::mymath`
- `check_required_components`：配合 `find_package(mymath COMPONENTS ...)`

## 5. 构建 + 安装

```bash
cd mymath
cmake -S . -B build -DCMAKE_INSTALL_PREFIX=$HOME/.local
cmake --build build
cmake --install build
```

安装后文件：

```
~/.local/include/mymath/add.h
~/.local/lib/libmymath.a
~/.local/lib/cmake/mymath/mymath-config.cmake
~/.local/lib/cmake/mymath/mymath-config-version.cmake
~/.local/lib/cmake/mymath/mymath-targets.cmake
```

**注意**：`mymath::mymath` 这个 imported target 就定义在 `mymath-targets.cmake` 里——它携带了 include 路径和链接信息。

## 6. 消费项目

```
app/
├── CMakeLists.txt
└── main.cpp
```

`main.cpp`：

```cpp
#include <mymath/add.h>
#include <iostream>

int main() {
    std::cout << mymath::add(1, 2) << '\n';
}
```

`CMakeLists.txt`：

```cmake
cmake_minimum_required(VERSION 3.16)
project(app LANGUAGES CXX)

find_package(mymath 1.0 REQUIRED)      # 版本检查也走通

add_executable(app main.cpp)
target_link_libraries(app PRIVATE mymath::mymath)   # include/依赖全自动
```

**注意**：不需要 `include_directories`、不需要写库路径——`mymath::mymath` 全带上了。

## 7. 构建消费项目

```bash
cd app
cmake -S . -B build -DCMAKE_PREFIX_PATH=$HOME/.local    # 告诉 CMake 去哪找 mymath
cmake --build build
./build/app          # 输出 3
```

## 8. 全过程串讲（对应前面的知识点）

| 步骤 | 用到的知识 | 在哪篇 |
|------|-----------|--------|
| `add_library` + `ALIAS` | target、命名空间 | 核心：Target |
| `$<BUILD_INTERFACE>` / `$<INSTALL_INTERFACE>` | 构建 vs 安装路径 | 生成器表达式 |
| `PUBLIC` / `PRIVATE` | 依赖是否传播 | 核心：Target |
| `install(TARGETS ... EXPORT ...)` | 安装 + 导出集 | 安装与导出 |
| `install(EXPORT ... NAMESPACE ...)` | 生成 targets 文件 | 安装与导出 |
| `configure_package_config_file` | 生成 config | 安装与导出 |
| `find_package(mymath)` | 找库 + imported target | 依赖管理 |
| `target_link_libraries(app PRIVATE mymath::mymath)` | 一键使用 | 核心：Target |
| `CMAKE_PREFIX_PATH` | 搜索路径 | 依赖管理 |

## 9. 一句话

> 写库：**target 挂一切 + `$<BUILD/INSTALL_INTERFACE>` + `install(TARGETS..EXPORT)` + `install(EXPORT)` + config 文件**；用库：**`find_package` + 链接一个带命名空间的 target**，完事。
