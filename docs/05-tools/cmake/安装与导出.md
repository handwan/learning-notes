# 安装与导出

让你写的库能被别人 `find_package(你的库)` 使用。

## 1. install（安装）

```cmake
include(GNUInstallDirs)     # 提供 CMAKE_INSTALL_LIBDIR 等标准路径

install(TARGETS mylib
    EXPORT mylib-targets                          # 加入导出集
    LIBRARY DESTINATION ${CMAKE_INSTALL_LIBDIR}   # 动态库 → lib/
    ARCHIVE DESTINATION ${CMAKE_INSTALL_LIBDIR}   # 静态库
    RUNTIME DESTINATION ${CMAKE_INSTALL_BINDIR}   # 可执行文件 → bin/
    INCLUDES DESTINATION ${CMAKE_INSTALL_INCLUDEDIR}
)

install(DIRECTORY include/ DESTINATION ${CMAKE_INSTALL_INCLUDEDIR})   # 整个目录
install(FILES mylib.h DESTINATION ${CMAKE_INSTALL_INCLUDEDIR})        # 单个文件
```

**GNUInstallDirs** 提供的标准目录：`CMAKE_INSTALL_LIBDIR`（lib 或 lib64）、`CMAKE_INSTALL_BINDIR`（bin）、`CMAKE_INSTALL_INCLUDEDIR`（include）。

## 2. export（导出 targets）

```cmake
install(EXPORT mylib-targets
    FILE mylib-targets.cmake
    NAMESPACE MyLib::                              # 对外名 MyLib::mylib
    DESTINATION ${CMAKE_INSTALL_LIBDIR}/cmake/mylib
)
```

生成 `mylib-targets.cmake`，里面是 imported target 定义，别人 `find_package` 时加载。

## 3. config 文件（让 find_package 找到）

`find_package(MyLib)` 会找 `MyLibConfig.cmake` 或 `mylib-config.cmake`。用 CMake 助手生成：

```cmake
include(CMakePackageConfigHelpers)

# 版本文件：支持 find_package(mylib 1.0 REQUIRED)
write_basic_package_version_file(
    ${CMAKE_CURRENT_BINARY_DIR}/mylib-config-version.cmake
    VERSION ${PROJECT_VERSION}
    COMPATIBILITY SameMajorVersion
)

# config 文件：从模板生成
configure_package_config_file(
    cmake/mylib-config.cmake.in
    ${CMAKE_CURRENT_BINARY_DIR}/mylib-config.cmake
    INSTALL_DESTINATION ${CMAKE_INSTALL_LIBDIR}/cmake/mylib
)

install(FILES
    ${CMAKE_CURRENT_BINARY_DIR}/mylib-config.cmake
    ${CMAKE_CURRENT_BINARY_DIR}/mylib-config-version.cmake
    DESTINATION ${CMAKE_INSTALL_LIBDIR}/cmake/mylib
)
```

`cmake/mylib-config.cmake.in` 模板：

```cmake
@PACKAGE_INIT@
include("${CMAKE_CURRENT_LIST_DIR}/mylib-targets.cmake")
check_required_components(mylib)
```

## 4. 使用者视角

```cmake
find_package(mylib REQUIRED)
add_executable(app main.cpp)
target_link_libraries(app PRIVATE MyLib::mylib)   # 完事
```

## 5. 安装前缀

```bash
cmake --install build --prefix /usr/local
# 或 configure 时：
cmake -S . -B build -DCMAKE_INSTALL_PREFIX=/usr/local
```

## 6. 一句话

> `install(TARGETS ... EXPORT ...)` + `install(EXPORT ... NAMESPACE ...)` + `configure_package_config_file` → 别人 `find_package` 即用。
