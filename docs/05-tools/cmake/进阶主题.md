# 进阶主题

## 1. OBJECT 库

只编译成 `.o` 对象文件、不归档，供多个 target 复用：

```cmake
add_library(common OBJECT src/common.cpp)
target_include_directories(common PUBLIC include)

add_executable(app1 main1.cpp $<TARGET_OBJECTS:common>)
add_executable(app2 main2.cpp $<TARGET_OBJECTS:common>)
```

## 2. 编译器特性检测

```cmake
include(CheckCXXCompilerFlag)
check_cxx_compiler_flag("-march=native" HAS_MARCH_NATIVE)
if(HAS_MARCH_NATIVE)
    target_compile_options(mylib PRIVATE -march=native)
endif()

include(CheckCXXSourceCompiles)
check_cxx_source_compiles(
    "#include <filesystem>\nint main(){ std::filesystem::path p; }"
    HAS_FILESYSTEM
)
```

用于：**跨编译器/跨平台时，探测支持什么再决定加什么选项**。

## 3. Toolchain 文件（交叉编译）

`toolchain-arm.cmake`：

```cmake
set(CMAKE_SYSTEM_NAME Linux)
set(CMAKE_SYSTEM_PROCESSOR aarch64)
set(CMAKE_C_COMPILER aarch64-linux-gnu-gcc)
set(CMAKE_CXX_COMPILER aarch64-linux-gnu-g++)
set(CMAKE_FIND_ROOT_PATH /usr/aarch64-linux-gnu)
set(CMAKE_FIND_ROOT_PATH_MODE_PROGRAM NEVER)
set(CMAKE_FIND_ROOT_PATH_MODE_LIBRARY ONLY)
set(CMAKE_FIND_ROOT_PATH_MODE_INCLUDE ONLY)
```

用法：

```bash
cmake -S . -B build-arm -DCMAKE_TOOLCHAIN_FILE=toolchain-arm.cmake
```

**用途**：给 ARM/嵌入式/异构平台编译（AI 部署常见）。

## 4. CPack（打包）

```cmake
# CPACK_* 变量必须在 include(CPack) 之前设置
set(CPACK_PACKAGE_NAME "mymath")
set(CPACK_PACKAGE_VERSION ${PROJECT_VERSION})
set(CPACK_GENERATOR "DEB;TGZ")     # 可同时多个
include(CPack)
```

```bash
cmake --build build --target package          # 生成安装包
# 或
cpack --config build/CPackConfig.cmake
```

配合 `install(... COMPONENT ...)` 可控制哪些文件进哪个包。

## 5. 其他常用

```cmake
# 编译数据库（clangd / clang-tidy / AI 工具）
set(CMAKE_EXPORT_COMPILE_COMMANDS ON)

# 强制 C++ 标准
set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)
set(CMAKE_CXX_EXTENSIONS OFF)      # 用 -std=c++17 而非 gnu++17

# 调试 CMake 脚本
cmake --trace                       # 打印每条命令
```

## 6. 一句话

> 进阶三件事：**交叉编译（toolchain）**、**打包（CPack）**、**编译期探测与优化（特性检测、OBJECT 库）**。
