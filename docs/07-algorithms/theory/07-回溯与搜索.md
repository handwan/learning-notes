# 回溯与搜索

回溯（backtracking）是**带状态恢复的 DFS**：

```text
选择一个候选
递归进入下一层
撤销这个选择
```

它适合“枚举所有解”或“找一个可行解”，代价通常是指数级；剪枝决定它能不能跑。

## 1. 回溯 vs DFS

| | DFS | 回溯 |
|---|---|---|
| 目的 | 遍历图/树 | 在解空间里搜索 |
| 状态 | 访问标记 | 路径 + 选择 + 约束 |
| 关键动作 | 进入邻居 | 选择、递归、撤销 |
| 剪枝 | 一般不需要 | 核心 |

DFS 是遍历工具；回溯是“在隐式搜索树上做 DFS，并在离开节点时恢复现场”。

## 2. 模板

```text
backtrack(path, choices):
    if 到达终止条件:
       记录 path
       return

    for choice in choices:
        if 不合法: continue
        apply(choice)
        backtrack(path, next_choices)
        undo(choice)
```

四个要素：

1. **路径**：已经做出的选择
2. **选择列表**：当前还能做什么
3. **终止条件**：什么时候记录答案
4. **撤销**：恢复路径、标记、计数器

### 状态要恢复干净

```cpp
path.push_back(x);
used[x] = true;
dfs(...);
used[x] = false;
path.pop_back();
```

任何一个修改忘了撤销，后面的分支都会带着脏状态。

### 传引用，终端再拷贝

```cpp
void dfs(vector<int>& path, vector<vector<int>>& res) {
    if (ok) {
        res.push_back(path);   // 这里才拷贝
        return;
    }
    ...
}
```

递归过程中一直传 `path` 的引用；只在记录答案时复制。否则每层都拷贝，开销很大。

## 3. 子集、组合、排列

### 子集

每个元素选/不选：

```cpp
void dfs(int start, vector<int>& path, vector<vector<int>>& res) {
    res.push_back(path);              // 每个节点都是答案
    for (int i = start; i < n; ++i) {
        path.push_back(a[i]);
        dfs(i + 1, path, res);
        path.pop_back();
    }
}
```

复杂度 `O(2^n)`。

### 组合

从 `n` 个里选 `k` 个：

```cpp
void dfs(int start, vector<int>& path) {
    if ((int)path.size() == k) {
        res.push_back(path);
        return;
    }
    for (int i = start; i < n; ++i) {
        path.push_back(a[i]);
        dfs(i + 1);
        path.pop_back();
    }
}
```

剪枝：剩余元素不够时提前返回。

```text
if (n - i < k - path.size()) break;
```

### 排列

每个元素都要用一次：

```cpp
void dfs(vector<int>& path, vector<bool>& used) {
    if ((int)path.size() == n) {
        res.push_back(path);
        return;
    }
    for (int i = 0; i < n; ++i) {
        if (used[i]) continue;
        used[i] = true;
        path.push_back(a[i]);
        dfs(path, used);
        path.pop_back();
        used[i] = false;
    }
}
```

复杂度 `O(n!)`。

### 有重复元素

先排序，再跳过同一层重复：

**组合/子集**：

```cpp
if (i > start && a[i] == a[i-1]) continue;
```

**排列**：

```cpp
if (used[i]) continue;
if (i > 0 && a[i] == a[i-1] && !used[i-1]) continue;
```

第二个条件的含义：同一层里，相同元素只用第一个；`!used[i-1]` 表示前一个相同元素已经撤销，当前是“同层重复”。

## 4. 剪枝

剪枝是回溯的核心。常见类型：

| 类型 | 例子 |
|---|---|
| **可行性剪枝** | 当前和已经超过 target；棋盘冲突 |
| **最优性剪枝** | 当前代价已经超过已知最优 |
| **重复剪枝** | 排序后跳过同层相同元素 |
| **边界剪枝** | 剩余元素不够凑齐 k 个 |
| **对称剪枝** | 第一行/第一列固定，避免旋转/镜像重复 |
| **顺序剪枝** | 先试约束最强的位置（MRV） |

剪枝必须**保证不丢合法解**。剪错比不剪更糟：程序跑得很快，但答案是错的。

### 分支限界

如果求最优解，可以维护当前最优值，并用下界/上界剪掉不可能更好的分支：

```text
if (当前代价 + 下界 >= 已知最优) return;
```

这就是分支限界（branch and bound）。它和回溯的区别是：回溯找所有解/可行解，分支限界主要做最优化。

## 5. N 皇后

逐行放皇后，列和对角线不能冲突：

```cpp
void dfs(int r) {
    if (r == n) { ans++; return; }
    for (int c = 0; c < n; ++c) {
        if (col[c] || diag1[r + c] || diag2[r - c + n - 1]) continue;
        col[c] = diag1[r + c] = diag2[r - c + n - 1] = true;
        dfs(r + 1);
        col[c] = diag1[r + c] = diag2[r - c + n - 1] = false;
    }
}
```

- `r+c` 标记主对角线
- `r-c+n-1` 标记副对角线（加偏移避免负数）
- 每行只放一个，天然避免行冲突

最坏仍是指数级，但剪枝后实际搜索空间小很多。

## 6. 数独

状态：

- 每行已用数字：`row[9]` 位掩码
- 每列：`col[9]`
- 每个 3×3 宫：`box[9]`
- 空格位置

每填一个数，同时更新三个掩码；递归；撤销。

优化：每次选**候选最少**的空格（MRV），比按固定顺序填快很多。

```text
mask = ~(row[r] | col[c] | box[b]) & 0x1FF
for each bit in mask:
    填数
    dfs()
    撤销
```

## 7. 网格搜索

单词搜索：从每个格子出发，向四个方向走，不能重复用同一格。

```cpp
bool dfs(int r, int c, int idx) {
    if (idx == word.size()) return true;
    if (越界 || board[r][c] != word[idx] || visited[r][c]) return false;

    visited[r][c] = true;
    for (四个方向) {
        if (dfs(nr, nc, idx + 1)) return true;
    }
    visited[r][c] = false;   // 回溯
    return false;
}
```

复杂度最坏 `O(mn · 4^L)`，`L` 是单词长度。

注意：如果只需要判断连通块，不需要撤销 `visited`；如果是枚举路径/单词，必须撤销。

## 8. 括号生成

只有两个选择：加左括号、加右括号。

```text
dfs(path, open, close):
    if path.size() == 2*n:
        记录
        return
    if open < n:        dfs(path+'(', open+1, close)
    if close < open:    dfs(path+')', open, close+1)
```

`close < open` 是合法性剪枝：右括号不能多于左括号。

## 9. 组合总和

给定候选数和目标，找所有组合。元素可重复使用时：

```cpp
void dfs(int start, int remain) {
    if (remain == 0) { res.push_back(path); return; }
    for (int i = start; i < n && a[i] <= remain; ++i) {
        if (i > start && a[i] == a[i-1]) continue;  // 同层去重
        path.push_back(a[i]);
        dfs(i, remain - a[i]);                      // i 而不是 i+1：可重复用
        path.pop_back();
    }
}
```

如果每个元素只能用一次，递归改成 `dfs(i + 1, ...)`。

## 10. 分割回文串

从起点开始枚举切分点：

```text
dfs(start):
    if start == n:
        记录 path
        return
    for end = start .. n-1:
        if s[start..end] 不是回文: continue
        path.push(s[start..end])
        dfs(end+1)
        path.pop()
```

回文判断可以预处理好 `isPal[i][j]`，避免每次重复扫描。

## 11. DFS、BFS、迭代加深

### DFS

- 栈/递归
- 适合枚举、路径、连通性
- 空间 `O(深度)`
- 不一定找到最短路径

### BFS

- 队列
- 无权图最短路
- 空间 `O(宽度)`
- 不适合深度很大的状态空间

### 迭代加深

对深度限制 `d` 反复做 DFS：

```text
for d = 0, 1, 2, ...:
    if dfs(depth_limit = d): return
```

时间仍是指数级，但空间只有 `O(d)`；适合“答案深度不大、宽度很大”的搜索。

### 选择

| 场景 | 方法 |
|---|---|
| 枚举所有解 | DFS/回溯 |
| 无权最短路 | BFS |
| 深度大、宽度小 | DFS |
| 深度小、宽度大 | 迭代加深/BFS |
| 有边权最短路 | Dijkstra（见图算法） |
| 有启发式 | A* |

## 12. 搜索 vs DP

| | 搜索/回溯 | DP |
|---|---|---|
| 是否枚举所有路径 | 是 | 合并重复状态 |
| 状态重叠 | 可能重复算 | 缓存/表格 |
| 适合 | 组合、排列、约束 | 最优值、计数、可行性 |
| 最坏复杂度 | 指数级 | 状态数 × 转移 |

如果搜索树里有大量重复状态，可以加记忆化：

```text
key = (位置, 剩余目标, 其他约束)
```

但状态必须包含所有影响后续决策的信息；否则缓存会给出错误答案。

## 13. 复杂度

| 问题 | 复杂度 |
|---|---|
| 子集 | `O(2^n)` |
| 排列 | `O(n!)` |
| 组合 | `O(C(n,k))` |
| N 皇后 | 最坏指数级，剪枝后远小于 `n!` |
| 数独 | 最坏 `O(9^空格数)` |
| 单词搜索 | `O(mn · 4^L)` |
| 括号生成 | `O(Catalan(n))` |

回溯的复杂度要按**搜索树节点数 × 每个节点的处理代价**算，不是简单看循环层数。

## 14. 常见坑

- **忘记撤销**：`path`、`used`、棋盘、`visited` 修改后没恢复
- **终止条件错**：先记录还是先判断；空集/单元素
- **去重条件错**：组合和排列的跳过条件不一样
- **`start` 用错**：组合用 `i+1`，可重复组合用 `i`
- **剪枝剪错**：把合法解剪掉
- **输出拷贝**：递归里反复拷贝 `path`
- **递归太深**：路径很长时栈溢出
- **状态键不完整**：记忆化漏了约束，缓存错误结果
- **DFS 找最短路**：无权最短路应该用 BFS
- **网格搜索不撤销**：枚举路径时 `visited` 必须恢复

## 15. 要点回顾

1. **回溯 = DFS + 状态恢复 + 剪枝**
2. **模板**：路径、选择列表、终止条件、撤销
3. **子集/组合**用 `start`；**排列**用 `used`
4. **去重**：先排序；组合跳过同层相同，排列加 `!used[i-1]`
5. **剪枝**：可行性、最优性、重复、边界、对称；不能剪掉合法解
6. **N 皇后**：列 + 两条对角线；**数独**：行/列/宫位掩码
7. **DFS/BFS**：枚举用 DFS，无权最短路用 BFS，深度小宽度大用迭代加深
8. **搜索 vs DP**：重复状态多就用记忆化/DP
