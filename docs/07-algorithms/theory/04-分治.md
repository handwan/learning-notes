# 分治

分治（divide and conquer）不是“递归”的同义词。它的固定结构是：

```text
divide   ：把问题拆成若干同类子问题
conquer  ：递归解决子问题
combine  ：把子问题的结果合并成原问题的结果
```

归并排序、快排、二分查找、快速选择、最近点对、最大子数组都能套这个结构。

## 1. 什么时候能用

三个条件：

1. **子问题独立**：子问题之间不共享状态，不会互相影响
2. **结构相同**：子问题能用同一个函数解决
3. **合并可行**：子问题的结果能合成原问题的结果

第三条最容易被忽略。拆得很开心，但合并代价是 `O(n²)`，总复杂度就下不来。

正确性用归纳：基准情况正确；假设子问题结果正确，`combine` 保持结果，则原问题正确。

### 独立性

如果子问题大量重叠，分治会重复计算：

```text
fib(n) = fib(n-1) + fib(n-2)
```

这不是有效的分治，因为 `fib(n-2)` 被算了很多次；应该用 DP/记忆化。

### 结构相同

子问题规模可以不同，但**形式**要一样：

- 归并：左半、右半都是“排序一个数组”
- 最大子数组：左半、右半都是“找最大子数组”
- 最近点对：左半、右半都是“找最近点对”

如果拆完变成完全不同的问题，通常不适合分治。

### 合并

合并可以是：

- 归并排序的 `merge`：`O(n)`
- 最大子数组的“跨中线”扫描：`O(n)`
- 二分查找：没有合并，只有选择一边
- 树遍历：合并子结果可能只是拼接/累加

合并代价直接进入递归式。

## 2. 递归式与复杂度

分治的复杂度通常写成：

```text
T(n) = a·T(n/b) + f(n)
```

- `a` 个子问题
- 每个规模 `n/b`
- 分解 + 合并代价 `f(n)`

常见结果：

| 递归式 | 结果 | 例子 |
|---|---|---|
| `T(n)=2T(n/2)+O(n)` | `O(n log n)` | 归并排序、最大子数组 |
| `T(n)=2T(n/2)+O(1)` | `O(n)` | 平衡二叉树遍历 |
| `T(n)=T(n/2)+O(1)` | `O(log n)` | 二分查找 |
| `T(n)=T(n-1)+O(1)` | `O(n)` | 线性递归 |
| `T(n)=2T(n-1)+O(1)` | `O(2^n)` | 子集枚举 |

主定理的条件和三种情况见 [算法分析](01-算法分析.md)。

### 不平衡的分割

快排、快速选择的分割不一定对半：

- 平均：接近 `T(n)=2T(n/2)+O(n)` 或 `T(n)=T(n/2)+O(n)`
- 最坏：`T(n)=T(n-1)+O(n)` → `O(n²)`

所以“分治”不自动等于 `O(n log n)`；**分割是否平衡**很关键。

## 3. 按什么分

分治的“分”有几种常见方式：

| 分法 | 例子 |
|---|---|
| **按下标** | 归并排序、最大子数组、最近点对 |
| **按值/pivot** | 快速排序、快速选择 |
| **按答案** | 二分答案 |
| **按结构** | 树遍历、表达式分治 |
| **按几何位置** | 最近点对按 x 坐标分 |

二分查找其实是分治的退化形式：只递归一边，没有合并。

## 4. 经典例子

### 归并排序

```text
divide  ：按中点拆成两半
conquer ：分别排序
combine ：合并两个有序数组
```

- 时间 `O(n log n)`
- 空间 `O(n)`
- 稳定
- 适合外部排序

实现细节见[排序与选择](02-排序与选择.md)。

### 快速排序

```text
divide  ：按 pivot 分区
conquer ：分别排序左右
combine ：不需要合并，原地拼起来
```

- 平均 `O(n log n)`
- 最坏 `O(n²)`
- 不稳定
- 分割平衡决定性能

### 最大子数组

按中点分成左、右、跨中线三种情况：

```text
solve(lo, hi):
    if lo == hi: return a[lo]
    mid = (lo + hi) / 2
    left  = solve(lo, mid)
    right = solve(mid+1, hi)
    cross = max_crossing(lo, mid, hi)
    return max(left, right, cross)
```

`max_crossing` 从中线向两边扫，`O(n)`；总复杂度 `O(n log n)`。

> 这题有 `O(n)` 的 Kadane，分治不是最优；它适合练“跨子问题合并”。

### 逆序对

在归并排序的 `merge` 里顺手数：

```text
合并左右两半时：
    如果右边元素更小，说明它比左边剩余的所有元素都小
    逆序对数 += mid - i + 1
```

总复杂度 `O(n log n)`，不增加数量级。

### 快速选择

只递归包含第 k 个元素的那一边：

```text
平均 O(n)
最坏 O(n²)
```

它也是分治，只是每次只解决一个子问题。

### 最近点对

按 x 排序，分成左右两半：

1. 分别求左右最近距离 `d`
2. 合并时只检查中线附近宽度 `2d` 的带子
3. 带内按 y 排序，每个点只比较常数个邻居

总复杂度 `O(n log n)`。

### 幂运算

```cpp
long long power(long long a, long long n) {
    if (n == 0) return 1;
    long long half = power(a, n / 2);
    return n % 2 ? half * half * a : half * half;
}
```

`T(n)=T(n/2)+O(1)` → `O(log n)`。注意乘法溢出。

### 表达式分治

给表达式加括号、不同二叉搜索树数量：

```text
按运算符/根节点分成左右两部分
分别递归左右
合并所有组合
```

如果子区间重复，需要记忆化；否则会重复计算。

## 5. 分治 vs DP vs 贪心 vs 回溯

| 方法 | 子问题关系 | 典型特征 |
|---|---|---|
| **分治** | 不重叠 | 拆开、分别算、合并 |
| **DP** | 重叠 | 状态、转移、记忆化/表格 |
| **贪心** | 只做一个选择 | 局部最优，不回头 |
| **回溯** | 搜索所有选择 | 尝试、撤销、剪枝 |

判断顺序：

1. 子问题重叠吗？重叠 → DP/记忆化
2. 只做一个局部选择就够吗？够 → 贪心
3. 要枚举所有解吗？要 → 回溯
4. 子问题独立且能合并 → 分治

分治和 DP 可以结合：表达式分治 + 记忆化，就是“分治 + 缓存”。

## 6. 实现细节

### 传范围，不要传数组

```cpp
void solve(vector<int>& a, int lo, int hi);
```

不要每次递归都 `vector<int> left(...)` 拷贝；拷贝会把 `O(n log n)` 变成带巨大常数，甚至 `O(n²)`。

### 临时缓冲区复用

归并排序每次合并都需要临时数组。可以在外层开一个 `tmp`，递归里反复用，避免反复分配。

### 基准情况要足够小

```text
if (hi - lo + 1 <= 16) { insertion_sort(a, lo, hi); return; }
```

小数组切插入排序，减少递归和函数调用开销。

### 递归深度

- 平衡分割：深度 `O(log n)`
- 不平衡分割：深度 `O(n)`，可能栈溢出
- 快排可以递归较深的一边用循环，短的一边递归，控制栈深

### 合并别重复计算

最大子数组的 `cross` 必须只扫一遍；如果每次合并都双重循环，复杂度会退化。

## 7. 常见坑

- **基准情况写错**：空区间、单元素、越界
- **分割漏元素**：`[lo, mid]` 和 `[mid+1, hi]` 必须覆盖完整
- **子问题重叠**：斐波那契式递归，应该 DP
- **合并漏情况**：最大子数组忘了跨中线
- **合并重复计数**：逆序对/表达式组合要明确计数范围
- **拷贝开销**：递归里反复拷贝数组
- **不平衡分割**：快排对已排序数组取首元素 pivot
- **递归栈溢出**：深度 `O(n)` 时
- **乘法/计数溢出**：幂、组合数、逆序对
- **小问题用分治**：`n` 很小时，循环/插入排序更快

## 8. 什么时候不用分治

- 子问题大量重叠：用 DP
- 合并代价太高：先算递归式，可能不如线性扫描
- 问题本身有线性/贪心解：最大子数组有 Kadane
- 递归深度不可控：考虑迭代/显式栈
- 常数敏感：小数组、简单循环往往更快

## 9. 要点回顾

1. **分治三步**：divide、conquer、combine；合并代价必须算进复杂度
2. **适用条件**：子问题独立、结构相同、合并可行
3. **递归式**：`T(n)=aT(n/b)+f(n)`；不平衡分割可能退化
4. **经典例子**：归并、快排、二分、快速选择、最大子数组、最近点对
5. **分治 vs DP**：子问题重叠就用 DP；不重叠才适合分治
6. **实现**：传范围、复用缓冲区、小数组切插入、控制递归深度
7. **常见坑**：基准情况、分割覆盖、合并漏情况、拷贝开销、栈溢出
