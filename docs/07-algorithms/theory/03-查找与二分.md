# 查找与二分

查找不只有“在数组里找一个数”。先看数据放在哪：

| 载体 | 前提 | 平均/最坏 |
|---|---|---|
| 顺序表 | 无 | `O(n)` |
| 有序数组 | 有序 + 随机访问 | `O(log n)` |
| 哈希表 | 哈希函数 | 平均 `O(1)`，最坏 `O(n)` |
| 平衡树 | 有序 | `O(log n)` |

顺序查找、折半查找的教材实现见 [查找与排序](../../02-computer-basics/data-structure/09-查找与排序.md)。这篇讲二分真正难的部分：**边界、谓词、答案空间**。

## 1. 二分的本质不是“有序”

二分的本质是：**在单调谓词上找分界点**。

```text
false false false true true true
                ↑
             第一个 true
```

数组有序只是最常见的一种单调性。只要能把问题写成：

```text
ok(x) 随 x 单调变化
```

就可以二分。

## 2. 先选一种区间写法

二分最容易错在区间定义。推荐统一用**左闭右开** `[lo, hi)`：

- `lo` 是候选范围起点
- `hi` 是候选范围终点 + 1
- 循环条件 `lo < hi`
- 结束时 `lo == hi` 就是答案位置

### lower_bound：第一个 >= x

```cpp
int lower_bound(const vector<int>& a, int x) {
    int lo = 0, hi = (int)a.size();   // [0, n)
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] < x) lo = mid + 1;
        else            hi = mid;
    }
    return lo;                         // 第一个 >= x 的位置
}
```

### upper_bound：第一个 > x

```cpp
int upper_bound(const vector<int>& a, int x) {
    int lo = 0, hi = (int)a.size();
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] <= x) lo = mid + 1;
        else             hi = mid;
    }
    return lo;                         // 第一个 > x 的位置
}
```

### 四个常用查询

| 查询 | 写法 |
|---|---|
| 第一个 `>= x` | `lower_bound(a, x)` |
| 第一个 `> x` | `upper_bound(a, x)` |
| 最后一个 `<= x` | `upper_bound(a, x) - 1` |
| 最后一个 `< x` | `lower_bound(a, x) - 1` |

`x` 的出现次数：

```text
upper_bound(a, x) - lower_bound(a, x)
```

### 精确查找

```cpp
int find(const vector<int>& a, int x) {
    int p = lower_bound(a, x);
    if (p < (int)a.size() && a[p] == x) return p;
    return -1;
}
```

不要用 `binary_search` 找位置，它只返回 `bool`。

## 3. 闭区间写法

也可以用 `[lo, hi]`：

```cpp
int lo = 0, hi = n - 1;
while (lo <= hi) {
    int mid = lo + (hi - lo) / 2;
    if (a[mid] == x) return mid;
    else if (a[mid] < x) lo = mid + 1;
    else hi = mid - 1;
}
return -1;
```

闭区间更容易理解，但改动多时容易把 `hi = mid` 和 `hi = mid - 1` 搞混。**一篇笔记里只选一种写法**，不要两套混用。

## 4. 死循环与边界

### 错误 1：`lo = mid`

```cpp
while (lo < hi) {
    int mid = lo + (hi - lo) / 2;
    if (ok(mid)) hi = mid;
    else lo = mid;        // 错：lo 可能永远是 mid
}
```

当 `hi = lo + 1` 时，`mid = lo`；如果 `ok(mid)` 为假，`lo = mid` 不变，死循环。

解决：

- 用 `lo = mid + 1` / `hi = mid` 的半开区间
- 或者取上中位数：`mid = lo + (hi - lo + 1) / 2`

### 错误 2：`mid` 溢出

```cpp
int mid = (lo + hi) / 2;        // lo + hi 可能溢出
int mid = lo + (hi - lo) / 2;   // 安全
```

### 错误 3：区间和答案不匹配

- `lower_bound` 的 `hi` 是 `n`，不是 `n-1`
- 返回位置可能等于 `n`（所有元素都 `< x`），调用方要判越界

### 错误 4：重复元素

普通二分找到一个就返回，不能保证是第一个/最后一个。需要边界就用 `lower_bound`/`upper_bound`。

## 5. 二分答案

很多题不是“在数组里找”，而是“在答案范围里找最小/最大可行值”。

### 最小化

找最小的 `x`，使得 `ok(x)` 为真：

```cpp
int lo = low, hi = high;       // 答案在 [low, high]
while (lo < hi) {
    int mid = lo + (hi - lo) / 2;
    if (ok(mid)) hi = mid;     // 可行，尝试更小
    else         lo = mid + 1; // 不可行，必须更大
}
return lo;
```

### 最大化

找最大的 `x`，使得 `ok(x)` 为真：

```cpp
int lo = low, hi = high;
while (lo < hi) {
    int mid = lo + (hi - lo + 1) / 2;  // 上中位数
    if (ok(mid)) lo = mid;             // 可行，尝试更大
    else         hi = mid - 1;
}
return lo;
```

### 关键：`ok` 必须单调

- 最小化：`ok(x)` 应是 `false ... false true ... true`
- 最大化：`ok(x)` 应是 `true ... true false ... false`

如果 `ok` 不单调，二分答案不成立。

### 边界要包含答案

- 下界：可能的最小值（如速度 `1`）
- 上界：一定可行的最大值（如 `max(piles)`、总和）

上界开太小会返回错误答案；开太大只会多几次迭代，但要注意 `ok` 里的溢出。

### 常见题型

| 题 | `ok(x)` 的含义 |
|---|---|
| 第一个坏版本 | `isBadVersion(x)` |
| 吃香蕉最小速度 | 速度 `x` 能否在 `h` 小时内吃完 |
| 运货船最小容量 | 容量 `x` 能否在 `D` 天运完 |
| 分割数组最大和 | 每段和不超过 `x` 时，段数是否 ≤ `k` |
| 平方根 | `x*x <= n`（注意溢出） |

## 6. 旋转有序数组

### 找最小值

```cpp
int findMin(const vector<int>& a) {
    int lo = 0, hi = (int)a.size() - 1;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] > a[hi]) lo = mid + 1;
        else if (a[mid] < a[hi]) hi = mid;
        else --hi;   // 重复值：无法判断方向，收缩右边界
    }
    return a[lo];
}
```

> 有重复元素时，相等分支用 `--hi` 收缩；最坏 `O(n)`。

思路：右半段如果比 `a[hi]` 大，说明最小值在右边；否则在左边（包含 `mid`）。

### 找目标值

先判断哪一半有序，再决定往哪边走：

```cpp
int search(const vector<int>& a, int target) {
    int lo = 0, hi = (int)a.size() - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] == target) return mid;

        if (a[lo] <= a[mid]) {                 // 左半有序
            if (a[lo] <= target && target < a[mid]) hi = mid - 1;
            else lo = mid + 1;
        } else {                               // 右半有序
            if (a[mid] < target && target <= a[hi]) lo = mid + 1;
            else hi = mid - 1;
        }
    }
    return -1;
}
```

有重复元素时，这版代码不保证正确；需要额外处理（如两端相等时收缩边界），最坏 `O(n)`。

## 7. 峰值与局部性质

峰值元素（相邻不相等）：

```cpp
int findPeak(const vector<int>& a) {
    int lo = 0, hi = (int)a.size() - 1;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] < a[mid + 1]) lo = mid + 1;  // 上坡，峰值在右
        else                     hi = mid;      // 下坡，峰值在左（含 mid）
    }
    return lo;
}
```

这类题用到的不是“全局有序”，而是**局部单调方向**。

## 8. 二维查找

### 情况一：整体按行展开有序

每行有序，且下一行第一个元素大于上一行最后一个：

```cpp
bool searchMatrix(vector<vector<int>>& a, int target) {
    int m = a.size(), n = a[0].size();
    int lo = 0, hi = m * n - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        int v = a[mid / n][mid % n];
        if (v == target) return true;
        if (v < target) lo = mid + 1;
        else hi = mid - 1;
    }
    return false;
}
```

复杂度 `O(log(mn))`。

### 情况二：每行、每列分别有序

从右上角开始：

```text
如果当前值 > target：左移
如果当前值 < target：下移
相等：找到
```

复杂度 `O(m + n)`。

**不要混**：整体展开有序才能 `O(log(mn))`；只有行/列分别有序，不能直接一维二分。

## 9. 实数二分

答案不是整数时，用固定迭代次数，避免 `eps` 选得过小导致死循环：

```cpp
double lo = 0, hi = 1e9;
for (int iter = 0; iter < 100; ++iter) {
    double mid = (lo + hi) / 2;
    if (ok(mid)) hi = mid;
    else         lo = mid;
}
return lo;
```

100 次迭代足以把区间缩到非常小；比 `while (hi - lo > 1e-12)` 更稳。

## 10. 标准库

```cpp
lower_bound(a.begin(), a.end(), x);   // 第一个 >= x
upper_bound(a.begin(), a.end(), x);   // 第一个 > x
equal_range(a.begin(), a.end(), x);   // [lower, upper)
binary_search(a.begin(), a.end(), x); // 只返回 bool
```

要求区间**按 `<` 有序**（或传入等价比较器）；返回的是迭代器，不是下标。

## 11. 常见坑

- `lo = mid` 导致死循环；半开区间用 `lo = mid + 1`
- `mid = (lo + hi) / 2` 溢出；用 `lo + (hi - lo) / 2`
- `lower_bound` 的 `hi` 写成 `n - 1`，漏掉“所有元素都小于 x”的情况
- 找到任意一个相等元素就返回，误以为它是第一个/最后一个
- 二分答案的 `ok` 不单调，或方向写反
- 二分答案的上界太小，答案落在范围外
- `ok` 里的乘法/求和溢出，导致判断错误
- 旋转数组有重复元素，仍按 `O(log n)` 分析
- 二维矩阵只是行/列有序，却按整体有序做一维二分
- `binary_search` 返回 `bool`，拿不到位置
- 实数二分用固定 `eps`，边界选不好会死循环或精度不够

## 12. 要点回顾

1. **二分的本质**：单调谓词上找分界，不是“数组必须有序”
2. **区间写法**：推荐左闭右开 `[lo, hi)`；`lo < hi`，结束时 `lo` 是答案
3. **lower/upper bound**：第一个 `>= x` / 第一个 `> x`；重复元素靠它们找边界
4. **死循环**：不要写 `lo = mid`；用 `lo = mid + 1` 或上中位数
5. **二分答案**：`ok(x)` 必须单调；最小化用 `hi = mid`，最大化用 `lo = mid`
6. **旋转数组**：先判断哪半有序；有重复元素时模板需额外处理，最坏 `O(n)`
7. **二维**：整体展开有序才 `O(log(mn))`；只有行/列有序用右上角走 `O(m+n)`
8. **实数二分**：固定迭代次数，比 `eps` 更稳
