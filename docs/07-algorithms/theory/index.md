# 基础算法

按算法学科组织：分析、设计范式、经典算法族、算法工程。

数组、链表、栈、队列、树、堆、哈希表、并查集等**结构实现**见[数据结构](../../02-computer-basics/data-structure/index.md)。

6. [动态规划](06-动态规划.md)：状态、转移、区间/背包/树形/状压
7. [回溯与搜索](07-回溯与搜索.md)：DFS、剪枝、分支限界
8. [图算法](08-图算法.md)：遍历、连通性、拓扑、最短路、MST
9. [字符串](09-字符串.md)：匹配、KMP、Trie、哈希
10. [数论与随机化](10-数论与随机化.md)：GCD、模运算、快速幂、素数、位运算
