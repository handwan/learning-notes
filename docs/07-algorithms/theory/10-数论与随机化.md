# 数论与随机化

数论处理整数结构：整除、同余、素数、逆元、组合数。随机化处理“用随机性换取简单或更快”的算法。

两者经常一起出现：哈希、素数判定、随机快排、抽样、洗牌。

## 1. 整数与溢出

数论代码最常见的错误不是公式，而是溢出。

- `int` 乘法可能溢出；用 `long long`
- `long long` 乘法仍可能溢出；用 `__int128` 或先取模
- `lcm(a,b)` 不要写 `a*b/gcd`，先除后乘：`a/gcd(a,b)*b`
- 负数的模要归一化：`(x % m + m) % m`

```cpp
long long gcd(long long a, long long b) {
    while (b) {
        a %= b;
        std::swap(a, b);
    }
    return a;
}
```

C++17 可以直接用 `std::gcd`。

> 输入可能为负时，先取绝对值，或直接用 `std::gcd`；`lcm` 也用 `abs(a)/gcd*abs(b)`。

## 2. 扩展欧几里得

求 `ax + by = gcd(a,b)` 的一组整数解：

```cpp
long long exgcd(long long a, long long b, long long& x, long long& y) {
    if (b == 0) { x = 1; y = 0; return a; }
    long long x1, y1;
    long long g = exgcd(b, a % b, x1, y1);
    x = y1;
    y = x1 - (a / b) * y1;
    return g;
}
```

用途：

- 求模逆元（`gcd(a,m)=1`）
- 解线性同余方程
- 解二元一次不定方程

## 3. 模运算与快速幂

```cpp
long long mod_pow(long long a, long long e, long long mod) {
    long long r = 1 % mod;
    a %= mod;
    while (e > 0) {
        if (e & 1) r = (__int128)r * a % mod;
        a = (__int128)a * a % mod;
        e >>= 1;
    }
    return r;
}
```

- 时间 `O(log e)`
- `1 % mod` 处理 `mod=1` 的边界
- 负底数先归一化
- 乘法用 `__int128` 防溢出

## 4. 模逆元

`a` 在模 `m` 下的逆元 `x` 满足：

```text
a·x ≡ 1 (mod m)
```

存在条件：`gcd(a,m)=1`。

### 费马小定理

`m` 是素数，且 `a % m != 0`：

```text
a^(m-2) ≡ a^(-1) (mod m)
```

### 扩展欧几里得

不要求 `m` 是素数，只要求互质：

```text
exgcd(a, m, x, y)
x 就是逆元（可能需要归一化）
```

### 常见坑

- 模数不是素数却用费马
- `gcd(a,m) != 1` 还求逆元
- 逆元结果是负数没归一化

## 5. 素数

### 试除法

```text
for i = 2 .. floor(sqrt(n)):
    if n % i == 0: 合数
```

- `O(sqrt n)`
- 只适合单个数/小数
- `i*i <= n` 注意 `i*i` 溢出，可写 `i <= n / i`

### 埃氏筛

```cpp
vector<bool> is_prime(n + 1, true);
is_prime[0] = is_prime[1] = false;
for (int i = 2; (long long)i * i <= n; ++i) {
    if (!is_prime[i]) continue;
    for (long long j = (long long)i * i; j <= n; j += i)
        is_prime[j] = false;
}
```

- 时间 `O(n log log n)`
- 空间 `O(n)`
- 适合预处理 `1..n` 的素数表

### 线性筛

每个合数只被最小质因子筛一次：

- 时间 `O(n)`
- 空间 `O(n)`
- 可以顺便求最小质因子、欧拉函数

### Miller-Rabin

大数素数判定，概率算法：

- 单轮有极小误判概率
- 多轮降低概率
- 64 位整数可用已知底数集合做确定性判定；不确定就用更多轮

Miller-Rabin 是 **Monte Carlo**：可能把合数判成素数，但不会把素数判成合数（在正确实现下）。

### 分解质因数

试除法：

```text
for p = 2 .. sqrt(n):
    while n % p == 0:
        记录 p
        n /= p
if n > 1: 记录 n
```

- `O(sqrt n)`
- 大数分解用 Pollard Rho（进阶）

## 6. 组合数

模素数 `p`，且 `n < p`：

```text
C(n,k) = n! / (k! (n-k)!)
```

预处理阶乘和逆阶乘：

```cpp
fact[0] = 1;
for (int i = 1; i <= n; ++i) fact[i] = fact[i-1] * i % p;
invfact[n] = mod_pow(fact[n], p - 2, p);
for (int i = n; i > 0; --i) invfact[i-1] = invfact[i] * i % p;

C(n,k) = fact[n] * invfact[k] % p * invfact[n-k] % p;
```

前提：

- `p` 是素数
- `n < p`，否则阶乘会出现 `0`

`n >= p` 时用 Lucas 定理；`p` 不是素数时不能直接费马求逆。

### 组合数溢出

- 不取模时，`C(100,50)` 已经很大
- 取模时，乘法用 `long long`/`__int128`
- 组合数计数题通常要求取模

## 7. 位运算

整数在二进制层面就是一组 0/1。常用操作：

- 取第 `k` 位：`(x >> k) & 1`
- 置 1：`x |= (1LL << k)`
- 清 0：`x &= ~(1LL << k)`
- 翻转：`x ^= (1LL << k)`
- 取最低位的 1：`x & -x`
- 去掉最低位的 1：`x & (x - 1)`
- 判断 2 的幂：`x > 0 && (x & (x - 1)) == 0`
- 枚举子集：`for (sub = mask; sub; sub = (sub - 1) & mask)`

几条注意：

- `x & -x` 取 lowbit，树状数组常用
- `x & (x - 1)` 去掉最低位的 1，可用来数 1 的个数
- 异或：`a ^ a = 0`、`a ^ 0 = a`；一串数里找唯一出现一次的数
- 位掩码表示集合；`1LL << k` 防 `int` 溢出，`k < 63`；64 位用 `1ULL`
- 有符号右移可能做符号扩展，位运算优先用无符号类型
- `__builtin_popcountll(x)` 数 1；`__builtin_ctzll(x)` 数末尾 0；`x == 0` 时 `ctz` 未定义
- 位运算优先级低于比较，`if (x & 1 == 0)` 是错的，要写 `if ((x & 1) == 0)`

位掩码 DP 见[动态规划](06-动态规划.md)。

## 8. 随机数基础

C++ 推荐：

```cpp
mt19937_64 rng(random_device{}());
uniform_int_distribution<long long> dist(l, r);
long long x = dist(rng);
```

不要用：

```cpp
rand() % n
```

原因：

- 低位质量差
- 取模有偏（`RAND_MAX` 不是 `n` 的倍数时）
- 全局状态难复现

### 可复现

- 测试/对拍：固定种子
- 生产：`random_device` 或系统熵
- 安全场景：不要用 `mt19937`，它不是密码学安全的

## 9. 洗牌与抽样

### Fisher-Yates 洗牌

```cpp
for (int i = n - 1; i > 0; --i) {
    int j = dist(0, i);
    swap(a[i], a[j]);
}
```

每个排列等概率。不要写成“每次和整个数组随机交换”，那样分布不均匀。

### 蓄水池抽样

从长度未知的流中均匀抽 `k` 个：

```text
前 k 个直接放入池子
for i = k .. n-1:
    j = random(0, i)
    if j < k: pool[j] = stream[i]
```

每个元素最终留在池中的概率都是 `k/n`。

## 10. 随机化算法

### 随机快排

- 随机选 pivot
- 期望 `O(n log n)`
- 最坏 `O(n²)`
- 对已排序/对抗输入更稳

实现见[排序与选择](02-排序与选择.md)。

### 随机选择

快速选择随机 pivot：

- 期望 `O(n)`
- 最坏 `O(n²)`
- 适合找第 k 大/中位数

见[查找与二分](03-查找与二分.md)。

### 哈希

- 随机哈希种子可以降低被对抗构造碰撞的风险
- 生日悖论：哈希空间不够大时，碰撞比直觉更早出现
- 哈希不是加密，不能用于安全校验

### Monte Carlo vs Las Vegas

| | Monte Carlo | Las Vegas |
|---|---|---|
| 正确性 | 可能错，概率可降 | 总是正确 |
| 时间 | 通常固定/可预测 | 随机 |
| 例子 | Miller-Rabin | 随机快排、随机选择 |

## 11. 随机化的工程问题

- **期望 ≠ 最坏**：随机快排仍可能 `O(n²)`
- **高概率**：失败概率随规模下降，比“期望”更强
- **可复现**：固定种子便于复现 bug；但不要在生产硬编码
- **对抗输入**：随机 pivot/哈希种子能降低被针对的风险
- **随机数质量**：`rand()` 不适合严肃用途
- **安全**：`mt19937` 可预测，不是 CSPRNG

## 12. 常见坑

- `lcm` 先乘后除导致溢出
- 负数取模没归一化
- `gcd(a,m) != 1` 还求逆元
- 模数不是素数却用费马小定理
- 快速幂 `e=0`、`mod=1`、负底数边界
- 筛法 `i*i` 溢出
- Miller-Rabin 轮数/底数不够，误判概率被低估
- 组合数在 `n >= p` 时直接套阶乘逆元
- `rand() % n` 的偏差
- 洗牌方向/范围写错，分布不均匀
- 蓄水池抽样的随机范围写成 `0..n-1`
- 随机化算法按最坏情况分析，忽略期望
- 把哈希当加密

## 13. 要点回顾

1. **gcd** 用欧几里得；`lcm = a/gcd*a`，先除后乘
2. **扩展欧几里得**求 `ax+by=gcd`，也是通用求逆元的方法
3. **快速幂** `O(log e)`；乘法防溢出，处理 `mod=1`
4. **逆元**存在条件 `gcd(a,m)=1`；费马只适用于素数模
5. **素数**：试除 `O(sqrt n)`、埃氏筛 `O(n log log n)`、Miller-Rabin 概率判定
6. **组合数**模素数且 `n < p` 才能用阶乘逆元；否则 Lucas
7. **随机数**用 `mt19937_64` + `uniform_int_distribution`，不要 `rand()%n`
8. **Fisher-Yates** 洗牌；**蓄水池**抽样；随机快排/选择是 Las Vegas
9. **位运算**：`x & -x` 取 lowbit，`x & (x-1)` 去最低位，子集枚举用 `(sub-1) & mask`
