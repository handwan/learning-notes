# 图算法

图算法先解决三个问题：

1. **图怎么建**：邻接表、邻接矩阵、CSR
2. **要解决什么**：遍历/连通、环、拓扑、最短路、最小生成树
3. **边的性质**：有向/无向、加权/无权、负权、是否 DAG

选错算法，通常不是代码写错，而是前提不匹配。

> 邻接表/CSR 的存储细节见 [图结构](../../02-computer-basics/data-structure/06-图结构.md)；MST/最短路的教材实现见 [图算法](../../02-computer-basics/data-structure/07-图算法.md)。

## 1. 建模与表示

| 表示 | 空间 | 适合 |
|---|---|---|
| 邻接矩阵 | `O(V²)` | 稠密图、频繁判断两点是否相邻 |
| 邻接表 | `O(V+E)` | 稀疏图、遍历邻居 |
| CSR | `O(V+E)` | 静态大图、缓存友好 |

建图时先确认：

- 有向还是无向？无向边要加两次
- 是否有重边、自环？
- 顶点编号是 `0..V-1` 还是 `1..V`？
- 边权是否可能为负？
- 图是否可能不连通？

网格、迷宫、状态转移都可以看成**隐式图**：每个格子/状态是点，合法移动是边。

## 2. BFS

BFS 用队列逐层扩展：

```cpp
vector<int> dist(n, -1);
queue<int> q;
dist[s] = 0;
q.push(s);

while (!q.empty()) {
    int u = q.front(); q.pop();
    for (int v : adj[u]) {
        if (dist[v] != -1) continue;
        dist[v] = dist[u] + 1;
        q.push(v);
    }
}
```

### 关键点

- **入队时标记**，不要出队才标记，否则同一节点可能重复入队
- 无权图的最短路就是 BFS 的层数
- 多源 BFS：把所有源点先入队，求“到最近源点的距离”
- 网格 BFS：方向数组 + 边界检查

### 0-1 BFS

边权只有 0 和 1 时，用双端队列：

```text
边权 0：push_front
边权 1：push_back
```

复杂度 `O(V+E)`，比 Dijkstra 的堆更轻。

## 3. DFS

DFS 用递归或显式栈，一条路走到底：

```cpp
void dfs(int u) {
    visited[u] = true;
    for (int v : adj[u]) {
        if (!visited[v]) dfs(v);
    }
}
```

用途：

- 连通块
- 环检测
- 拓扑排序（后序）
- 二分图染色
- 树的遍历/子树信息

递归深度可能到 `O(V)`；深图要改显式栈或增大栈。

## 4. 连通性、环、二分图

### 连通块

无向图：每个未访问点做一次 BFS/DFS，计数加一。

有向图：

- **弱连通**：忽略方向后连通
- **强连通**：任意两点互相可达（Tarjan/Kosaraju）

### 无向图判环

DFS 时记录父亲：

```text
if (visited[v] && v != parent[u]) 找到环
```

重边要特别处理：两条相同的边不算环，或者用边编号而不是父节点。

并查集也可以：

```text
加入边 (u,v) 前，如果 find(u) == find(v)，说明成环
```

### 有向图判环

三色标记：

```text
0 白：未访问
1 灰：当前 DFS 栈中
2 黑：已完成
```

遇到灰色节点，说明有后向边，即环。

### 二分图

用两种颜色染色：

```text
未染色：染 0
邻居：染相反颜色
如果邻居已染色且颜色相同 → 不是二分图
```

等价于：图中没有奇环。

## 5. 拓扑排序与 DAG DP

拓扑排序只适用于 **DAG**（有向无环图）。

### Kahn：入度法

```cpp
queue<int> q;
for (int i = 0; i < n; ++i)
    if (indeg[i] == 0) q.push(i);

while (!q.empty()) {
    int u = q.front(); q.pop();
    order.push_back(u);
    for (int v : adj[u]) {
        if (--indeg[v] == 0) q.push(v);
    }
}
if ((int)order.size() != n) 有环;
```

- 复杂度 `O(V+E)`
- 需要字典序最小：把队列换成小顶堆
- 输出数量小于 `V`：有环

### DFS 后序

DFS 完成一个节点时把它加入结果，最后反转，也能得到拓扑序；同样可以用三色判环。

### DAG 上的 DP

按拓扑序递推：

```text
dist[v] = max(dist[v], dist[u] + w)
```

可以求：

- 最长路径
- 路径计数
- 最少代价
- 依赖关系的最早/最晚时间

**一般图的最长路径是 NP 难**；只有 DAG 能这样线性递推。

## 6. 最短路

### 选型

| 条件 | 算法 | 复杂度 |
|---|---|---|
| 无权 | BFS | `O(V+E)` |
| 边权 0/1 | 0-1 BFS | `O(V+E)` |
| 非负权 | Dijkstra | `O((V+E) log V)` |
| 有负权 | Bellman-Ford | `O(VE)` |
| 有负权 + 全源 | Floyd | `O(V³)` |
| DAG | 拓扑 + 递推 | `O(V+E)` |
| 启发式 | A* | 取决于启发函数 |

### Dijkstra

```cpp
vector<int> dist(n, INF);
priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq;
dist[s] = 0;
pq.push({0, s});

while (!pq.empty()) {
    auto [d, u] = pq.top(); pq.pop();
    if (d != dist[u]) continue;          // 过期条目
    for (auto [v, w] : adj[u]) {
        if (dist[v] > d + w) {
            dist[v] = d + w;
            pq.push({dist[v], v});
        }
    }
}
```

前提：**边权非负**。负边会让“当前最小”不再安全。

### Bellman-Ford

对所有边松弛 `V-1` 轮：

```text
for i = 1 .. V-1:
    for (u, v, w):
        dist[v] = min(dist[v], dist[u] + w)
```

第 `V` 轮还能松弛，说明存在**负环**。

复杂度 `O(VE)`；适合边少、有负权的情况。SPFA 是队列优化，但最坏仍是 `O(VE)`，不能当作稳定线性算法。

### Floyd

全源最短路：

```cpp
for (int k = 0; k < n; ++k)
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < n; ++j)
            dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);
```

- `O(V³)` 时间，`O(V²)` 空间
- 支持负边
- 跑完后 `dist[i][i] < 0` 说明有负环

`k` 必须放最外层，表示“允许经过前 `k` 个中转点”。

### A*

在 Dijkstra 上加入启发函数 `h(u)`：

```text
优先级 = dist[u] + h(u)
```

`h` 必须不高估真实剩余距离（可采纳），否则可能不最优。适合地图/网格寻路。

## 7. 最小生成树

MST 针对**连通无向带权图**，选出一棵树使总边权最小。

### Kruskal

按边权排序，依次加入，不成环就选：

```cpp
sort(edges.begin(), edges.end());
for (auto [w, u, v] : edges) {
    if (find(u) == find(v)) continue;
    unite(u, v);
    ans += w;
    if (++cnt == n - 1) break;
}
```

- 复杂度 `O(E log E)`
- 适合稀疏图
- 需要并查集
- 负权也可以

### Prim

从一个点开始，每次选连接“已选集合”和“未选集合”的最小边：

- 二叉堆：`O(E log V)`
- 邻接矩阵/数组：`O(V²)`，适合稠密图

### 性质

- 切分性质：横跨任意割的最小边一定属于某棵 MST
- MST 不唯一（边权相同）
- 图不连通时得到最小生成森林

## 8. 并查集

并查集维护不相交集合，支持：

```text
find(x)     ：找代表元
unite(a,b)  ：合并两个集合
```

优化：

- **路径压缩**：`parent[x] = find(parent[x])`
- **按秩/大小合并**：把矮树挂到高树下

两者一起，均摊 `O(α(n))`，近似常数。

用途：

- 连通性
- Kruskal
- 无向图判环
- 账户合并、岛屿合并
- 动态连通分量

**不能直接用于有向图**的强连通/可达性。

## 9. 网络流（可选）

最大流/最小割属于进阶图算法：

- Ford-Fulkerson：依赖增广路选择
- Edmonds-Karp：BFS 找增广路，`O(VE²)`
- Dinic：分层图 + 阻塞流，通常更快

应用：

- 二分图匹配
- 任务分配
- 最小割建模
- 有容量限制的网络

基础阶段知道“最大流 = 最小割”和建模方式即可，不必背完所有实现。

## 10. 选型表

| 问题 | 首选 |
|---|---|
| 无权最短路 | BFS |
| 0/1 权最短路 | 0-1 BFS |
| 非负权最短路 | Dijkstra |
| 负权最短路 | Bellman-Ford |
| 全源最短路 | Floyd |
| DAG 最长/最短/计数 | 拓扑 + DP |
| 连通块 | BFS/DFS/并查集 |
| 无向图判环 | DFS 父节点/并查集 |
| 有向图判环 | 三色 DFS/拓扑 |
| 二分图 | 染色 |
| MST | Kruskal（稀疏）/ Prim（稠密） |
| 强连通 | Tarjan/Kosaraju |
| 最大流 | Dinic |

## 11. 常见坑

- BFS 出队才标记 → 重复入队、复杂度退化
- Dijkstra 用于负权边 → 结果错误
- Bellman-Ford 忘记第 `V` 轮判负环
- Floyd 把 `k` 放在内层 → 结果错误
- 拓扑排序不检查输出数量 → 有环也当成功
- 无向图加边只加一次
- 重边/自环没处理
- 顶点编号 `0-based` 和 `1-based` 混用
- 图不连通，只从一个源点跑
- 递归 DFS 深度过大 → 栈溢出
- 边权/距离溢出，`INF + w` 溢出
- 优先队列里过期条目没跳过
- 把 DAG 的最长路算法套到一般图

## 12. 要点回顾

1. **先看边**：有向/无向、权值、负权、是否 DAG
2. **BFS**：无权最短路、多源、0-1 BFS
3. **DFS**：连通块、环、拓扑、染色；注意递归深度
4. **拓扑**：只适用于 DAG；Kahn 看输出数量，DFS 看三色
5. **Dijkstra** 非负权；**Bellman-Ford** 负权/负环；**Floyd** 全源
6. **MST**：Kruskal 排序 + 并查集；Prim 适合稠密图
7. **并查集**：路径压缩 + 按秩合并；无向连通性，不是有向可达
8. **选型**比背实现重要：前提不匹配，代码再对也没用
