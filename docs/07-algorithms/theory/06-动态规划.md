# 动态规划

动态规划（DP）解决的是：**子问题重复出现，且大问题能由子问题组合出来**。

它不只求最优，也能计数、判存在。核心不是“写个数组递推”，而是**定义出一个能唯一描述子问题的状态**。

## 1. 三个前提

1. **最优子结构 / 可组合**：大问题的解能由子问题的解组合
2. **重叠子问题**：不同路径会反复用到同一个子问题
3. **无后效性**：状态确定后，后续只依赖状态，不依赖到达它的路径

如果子问题不重叠，分治就够了；如果每一步只需一个局部选择，贪心可能更简单。

把状态看成点、转移看成有向边，DP 就是**DAG 上的递推**。遍历顺序就是拓扑序；如果状态之间出现环，通常说明状态定义不对，或者需要解方程/迭代。

## 2. 五步设计

```text
1. 定义状态：dp[...] 表示什么
2. 写转移：最后一步有哪些选择
3. 初始化：最小子问题的答案
4. 遍历顺序：保证依赖先算
5. 取答案：dp[n] / max(dp) / dp[0][n-1]
```

再加一步：**空间优化**（滚动数组、倒序/正序）。

### 状态要能唯一描述子问题

同一个 `dp[i]`，不同定义会导致完全不同的转移：

| 定义 | 适合 | 答案 |
|---|---|---|
| `dp[i]` = 前 `i` 个元素的最优值 | 选/不选、前缀 | `dp[n]` |
| `dp[i]` = 以 `i` 结尾的最优值 | 子序列、连续段 | `max(dp)` |
| `dp[i][j]` = 区间 `[i,j]` | 区间合并、回文 | `dp[0][n-1]` |
| `dp[i][w]` = 前 `i` 个、容量 `w` | 背包 | `dp[n][W]` |

如果状态描述不了“当前处于什么情况”，就加维度，不要硬凑。

## 3. 一维 DP

### 爬楼梯

```text
dp[i] = dp[i-1] + dp[i-2]
dp[0] = 1, dp[1] = 1
```

本质是斐波那契；可以滚动成两个变量。

### 打家劫舍

不能选相邻：

```text
dp[i] = max(dp[i-1], dp[i-2] + a[i])
```

`dp[i-1]` 是不选 `i`，`dp[i-2]+a[i]` 是选 `i`。

### 最大子数组和（Kadane）

```text
cur = max(a[i], cur + a[i])
ans = max(ans, cur)
```

`cur` 表示“以 `i` 结尾的最大和”。这是“以 i 结尾”状态，答案不是 `cur` 的最后值，而是历史最大值。

### 最长递增子序列（LIS）

`O(n²)`：

```text
dp[i] = 1 + max(dp[j])   for j < i and a[j] < a[i]
答案 = max(dp)
```

`O(n log n)`：维护 `tails[len]` = 长度为 `len+1` 的递增子序列的最小结尾。

```cpp
int lengthOfLIS(const vector<int>& a) {
    vector<int> tails;
    for (int x : a) {
        auto it = lower_bound(tails.begin(), tails.end(), x);
        if (it == tails.end()) tails.push_back(x);
        else *it = x;
    }
    return tails.size();
}
```

`tails` 不是具体的 LIS，只用来求长度；要还原序列需要额外记录前驱。

### 状态机 DP

有些问题不是“选/不选”，而是“当前处于哪个状态”。典型是股票买卖：

- `hold`：当前持有股票的最大收益
- `cash`：当前不持有股票的最大收益

```cpp
int maxProfit(const vector<int>& p) {
    int hold = -p[0], cash = 0;
    for (int i = 1; i < (int)p.size(); ++i) {
        int next_hold = max(hold, cash - p[i]);   // 买入
        int next_cash = max(cash, hold + p[i]);   // 卖出
        hold = next_hold;
        cash = next_cash;
    }
    return cash;
}
```

状态机 DP 的关键是：

- 状态要覆盖“当前约束”（持有/未持有、冷冻期、交易次数）
- 转移用“前一天的状态”算，不要用当天刚更新的状态
- 初始状态要合法：`hold = -p[0]`，`cash = 0`

有冷冻期/手续费/最多 k 次交易时，加维度或加状态即可。

## 4. 二维序列 DP

### 最长公共子序列（LCS）

```cpp
vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));
for (int i = 1; i <= n; ++i) {
    for (int j = 1; j <= m; ++j) {
        if (a[i-1] == b[j-1]) dp[i][j] = dp[i-1][j-1] + 1;
        else dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
    }
}
```

`dp[i][j]` 是 `a` 前 `i` 个、`b` 前 `j` 个的 LCS 长度。

### 编辑距离

三种操作：

```cpp
dp[i][j] = min({
    dp[i-1][j] + 1,       // 删除
    dp[i][j-1] + 1,       // 插入
    dp[i-1][j-1] + (a[i-1] != b[j-1])  // 替换/匹配
});
```

初始化：`dp[i][0]=i`、`dp[0][j]=j`。

### 回文

`dp[i][j]` 表示 `s[i..j]` 是否回文：

```text
s[i] == s[j] && (j - i < 2 || dp[i+1][j-1])
```

按区间长度从小到大遍历，保证 `dp[i+1][j-1]` 已经算过。

## 5. 网格 DP

### 不同路径

只能向右/向下：

```text
dp[i][j] = dp[i-1][j] + dp[i][j-1]
dp[0][j] = dp[i][0] = 1
```

### 最小路径和

```text
dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]
```

### 最大正方形

`dp[i][j]` 表示以 `(i,j)` 为右下角的最大全 1 正方形边长：

```text
if grid[i][j] == 1:
    dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1
```

答案是最大边长，再平方得面积。

### 计数 DP

最优化 DP 的转移取 `max/min`；计数 DP 的转移取**加法**。

以带障碍的网格路径数为例：

```text
dp[0][0] = 1        // 起点无障碍；起点是障碍则为 0
for i, j:
    if grid[i][j] 是障碍: dp[i][j] = 0
    else:
        dp[i][j] = 从上方来的路径数 + 从左方来的路径数
```

要点：

- 空方案通常初始化为 `1`（如“什么都不选”也是一种方案）
- 转移是累加，不要漏掉某个方向
- 组合和排列的循环顺序不同，容易重复计数
- 计数结果可能很大，通常要取模

## 6. 背包

### 0/1 背包

每个物品最多选一次：

```cpp
vector<int> dp(W + 1, 0);
for (int i = 0; i < n; ++i) {
    for (int w = W; w >= weight[i]; --w) {   // 倒序
        dp[w] = max(dp[w], dp[w - weight[i]] + value[i]);
    }
}
```

倒序保证第 `i` 件物品不会被重复选。

如果要求“恰好装满”：

```text
dp[0] = 0，其他 = -INF
```

如果只要求“不超过容量”：

```text
dp 全部初始化为 0
```

### 完全背包

每件物品可以选无限次：

```cpp
for (int i = 0; i < n; ++i)
    for (int w = weight[i]; w <= W; ++w)   // 正序
        dp[w] = max(dp[w], dp[w - weight[i]] + value[i]);
```

正序让同一件物品可以被再次使用。

### 多重背包

第 `i` 件最多选 `count[i]` 次。可以：

- 拆成 `count[i]` 个 0/1 物品（简单，但慢）
- 二进制拆分：`1, 2, 4, ...` 组合，降到 `O(log count)`
- 单调队列优化（进阶）

### 分组背包

每组最多选一个：

```text
for each group:
    for w from W down to 0:
        for each item in group:
            dp[w] = max(dp[w], dp[w - weight] + value)
```

容量必须倒序，组内枚举物品；否则会选到同组多个。

## 7. 区间 DP

`dp[i][j]` 表示区间 `[i,j]` 的答案，通常按**区间长度**从小到大遍历：

```cpp
for (int i = 0; i < n; ++i) dp[i][i] = base(i);   // 长度为 1 的基准

for (int len = 2; len <= n; ++len) {
    for (int i = 0; i + len - 1 < n; ++i) {
        int j = i + len - 1;
        dp[i][j] = INF;
        for (int k = i; k < j; ++k) {
            dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j] + cost(i, j, k));
        }
    }
}
```

典型：

- 矩阵链乘
- 戳气球（反过来定义“最后戳破”）
- 回文分割
- 石子合并

区间 DP 的关键是：**合并点 `k` 把区间分成两段**，且两段都更短。

## 8. 树形 DP

在树上做后序 DFS，先算子节点，再合并到父节点。

### 打家劫舍 III

每个节点两种状态：

```cpp
void dfs(int u) {
    take[u] = val[u];
    skip[u] = 0;
    for (int v : children[u]) {
        dfs(v);
        take[u] += skip[v];                 // 选 u，不能选子节点
        skip[u] += max(take[v], skip[v]);    // 不选 u，子节点可选可不选
    }
}
```

答案：`max(take[root], skip[root])`。

树形 DP 常见状态：

- 选/不选当前节点
- 当前节点颜色
- 子树内是否已有某状态
- 路径的端点/方向

## 9. 状态压缩 DP

当某一维是“集合”，且规模很小（通常 `n ≤ 20`），可以用二进制整数表示集合：

```text
mask 的第 i 位 = 1：第 i 个元素已选
```

TSP 例子：

```text
dp[mask][i] = 从起点出发，走过 mask，最后停在 i 的最小代价
转移：从 j 走到 i
dp[mask][i] = min(dp[mask ^ (1<<i)][j] + dist[j][i])
```

复杂度 `O(2^n · n²)`，空间 `O(2^n · n)`。

枚举子集：

```cpp
for (int sub = mask; sub; sub = (sub - 1) & mask) {
    // sub 是 mask 的非空子集
}
```

状态压缩适合小规模集合；`n` 到 25 以上通常就不可行。

## 10. 数位 DP

统计 `[0, N]` 中满足某种数位性质的数。

常见状态：

```text
pos     ：当前处理到第几位
tight   ：是否贴着 N 的上界
started ：是否已经出现非零位（处理前导零）
...     ：和、模、上一位数字等
```

转移时枚举当前位 `0..limit`，`limit = tight ? N[pos] : 9`。

前导零和 `tight` 是最容易漏的两个状态。

## 11. 空间优化

### 滚动数组

如果 `dp[i]` 只依赖 `dp[i-1]`，可以只保留两行；如果只依赖上一行同列/左侧，可以压成一维。

0/1 背包压成一维后，容量必须**倒序**；完全背包则**正序**。

### 什么时候不能压

- 需要还原方案，且依赖被覆盖的历史状态
- 依赖多行/多列，不只是一行
- 循环顺序无法保证依赖已算

### 记忆化搜索

自顶向下写递归 + 缓存：

```cpp
int dfs(state) {
    if (memo.count(state)) return memo[state];
    ...
    return memo[state] = ans;
}
```

优点是只算真正用到的状态；缺点是递归栈和哈希开销。

### 方案还原

算出最优值/方案数后，如果要输出具体方案，需要额外记录“选择”：

- LCS：`from[i][j]` 记录来自对角、上方还是左方
- 背包：记录第 `i` 件是否被选
- 路径：记录从上方还是左方来

然后从终态逆推：

```text
i = n, j = m
while 未到起点:
    根据 choice[i][j] 决定走哪边
    回退到前一个状态
    记录当前选择
```

滚动数组只保留值，会覆盖历史；要还原方案，就得额外存 `choice`，或者保留完整表/重新计算。

## 12. 正确性与常见坑

### 检查清单

1. 状态含义能否唯一描述子问题？
2. 转移是否枚举了最后一步的所有选择？
3. 初始化是否覆盖最小子问题？
4. 遍历顺序是否保证依赖先算？
5. 答案取的是 `dp[n]`、`max(dp)` 还是 `dp[0][n-1]`？
6. 是否需要还原方案？

### 常见坑

- **状态少一维**：股票题没区分“持有/未持有”，只用一个 `dp[i]` 会丢信息
- **0/1 背包正序**：同一物品被重复选，变成完全背包
- **完全背包倒序**：每件物品只能用一次
- **初始化错误**：恰好装满和不超过容量是两种初始化
- **遍历顺序错误**：区间 DP 没按长度，二维 DP 没按依赖方向
- **答案取错**：LIS 答案是 `max(dp)`，不是 `dp[n-1]`
- **重复计数**：组合和排列的循环顺序不同
- **溢出**：`INF + cost` 溢出；用 `INF/2` 或 `long long`
- **还原路径**：空间压缩后丢失选择信息
- **递归太深**：记忆化搜索可能栈溢出

## 13. DP vs 其他方法

| 方法 | 子问题 | 选择 | 典型 |
|---|---|---|---|
| **分治** | 不重叠 | 拆开分别算 | 归并、最近点对 |
| **DP** | 重叠 | 枚举所有选择 | 背包、LCS、编辑距离 |
| **贪心** | 通常一个 | 当前最优，不回头 | 区间调度、Huffman |
| **回溯** | 搜索树 | 尝试/撤销 | 排列、组合、N 皇后 |

判断：

- 子问题重叠、需要记住中间结果 → DP
- 能证明“当前选择属于某个最优解” → 贪心
- 子问题独立、可合并 → 分治
- 要枚举所有解 → 回溯

## 14. 要点回顾

1. **DP 三前提**：可组合、重叠子问题、无后效性
2. **五步**：状态、转移、初始化、顺序、答案；再加空间优化
3. **状态定义**：前 i 个 / 以 i 结尾 / 区间 / 背包容量 / 树上选不选
4. **0/1 背包倒序，完全背包正序**；恰好装满用 `-INF`
5. **区间 DP 按长度**；树形 DP 后序；状压 DP 用 bitmask
6. **答案位置**：`dp[n]`、`max(dp)`、`dp[0][n-1]` 要按状态定义取
7. **正确性**：转移枚举所有选择、初始化正确、顺序满足依赖
8. **常见坑**：少维度、顺序错、答案错、溢出、还原路径丢信息
9. **状态机 / 计数**：多状态用 hold/cash；计数转移用加法，空方案初始化为 1
10. **方案还原**：存 choice/parent；滚动数组会覆盖历史
