# 变量命名

## 1. 通用

| 名字 | 含义 | 说明 |
|------|------|------|
| `n`, `m` | 数组/字符串长度、行列数 | `n` 最常用；矩阵题 `m` 行、`n` 列 |
| `i`, `j`, `k` | 循环变量 | 由外到内；`k` 也常当"第三维/中转" |
| `l`, `r` / `left`, `right` | 区间或双指针边界 | `l`/`r` 是缩写，`left`/`right` 更清楚 |
| `mid` | 二分中点 | 写 `mid = lo + (hi - lo) / 2` 防溢出 |
| `ans`, `res` | 最终答案 | `ans` 放标量答案；`res` 放结果集合（如 `vector<vector<int>>`） |
| `cnt` | 计数 | 工程代码里写 `count` |
| `mx`, `mn` | 最大/最小值 | 也可以写 `max_val` 这类全名 |
| `sum`, `prod` | 和 / 积 | |
| `INF`, `MOD` | 无穷大 / 取模常数 | 习惯全大写 |
| `x`, `y`, `z` | 数值、坐标 | |

## 2. 按专题

| 专题 | 惯用名 |
|------|--------|
| 双指针 / 滑动窗口 | `left`, `right`（或 `l`, `r`）；重复检测用 `last[c]`（字符 c 最近出现的位置） |
| 二分 | `lo`, `hi`, `mid`（或 `l`, `r`；`lo`/`hi` 不易和 `1` 混）；记录可行值用 `ans` |
| 图 | `u`, `v`, `w`（边和权）、`g`（邻接表）、`vis`（访问标记）、`dist`（距离） |
| BFS / DFS | `q`（队列）、`stk`/`st`（栈，别写 `stack`，会遮住类型名）、`dirs` 或 `dx`/`dy`（方向数组） |
| 动态规划 | `dp`、`memo`（记忆化）、`pre`/`cur`（滚动数组）、`INF` |
| 哈希 | `seen`（判重集合）、`index_of`/`pos`（值→下标）；`mp` 是常见缩写，但只说明了类型 |
| 字符串 | `s`, `t`（源串/目标串）、`pat`（模式串）、`nxt` 或 `fail`（KMP 失配数组） |
| 链表 / 树 | `head`、`dummy`（哑结点）、`prev`/`cur`/`nxt`、`node`、`dep`（深度）、`sz`（子树大小）、`lc`/`rc`（左右孩子） |
| 位运算 | `mask`（位掩码）、`x`、`bit` |

**一条小原则**：能按用途起名，就别按类型起名——`seen` 说的是"见过哪些"（用途），`mp` 只说了"这是个 map"（类型）；像两数之和这种"值→下标"的表，`index_of[need]` 读起来最像句子。
