# 文件与目录

Linux 的文件系统结构、常用操作、链接、打包压缩与同步。

## 1. 目录树（FHS）

```
/            根目录
├── bin → usr/bin      普通命令（Ubuntu 上是指向 /usr 的软链接）
├── sbin → usr/sbin    管理命令（一般要 root）
├── lib → usr/lib      库文件
├── etc                系统与软件配置（纯文本，改完重载服务）
├── usr                用户空间的软件（bin/lib/include/share）
├── var                会变化的数据：log、缓存、spool、数据库
├── tmp                临时文件（重启可能清空）
├── proc               进程与内核信息的虚拟文件系统（不占磁盘）
├── sys                设备与内核对象的虚拟文件系统
├── dev                设备文件（/dev/sda、/dev/null、/dev/shm）
├── home/<用户>         用户主目录
├── root               root 的主目录
├── opt                第三方大软件（手动安装的）
├── srv                服务数据（用得少）
├── run                运行时状态（PID、socket，重启清空）
├── boot               内核与 GRUB
└── mnt / media        临时挂载点 / 可移动介质
```

**实践**：

- 配置在 `/etc`，日志在 `/var/log`，自己的东西放 `~/`（或 `/opt`）
- `/proc`、`/sys`、`/dev` 是"假文件"（内核接口）；不要当普通文件删除/改名。`/proc/sys`、`/sys` 的部分节点可通过 `sysctl` 或专用接口写
- `/tmp` 与 `/run` 重启会清；要持久化就别放这

## 2. 导航与查看

```bash
pwd                    # 当前路径
cd -                   # 回到上一个目录
ls -lah                # -l 详情 -a 含隐藏 -h 人类可读大小
ls -lt                 # 按修改时间排序（最新在前）
ls -R                  # 递归列出
tree -L 2              # 树状显示（要装 tree）

file somefile          # 看文件类型（不看后缀）
stat somefile          # 详细信息：大小、inode、三个时间
stat -c '%n %s %i %a' somefile   # 自定义格式：名字/大小/inode/权限
```

**路径工具**：

```bash
realpath ./a/../b      # 规范化绝对路径（父目录要存在；-m 不要求存在）
readlink -f link       # 跟随软链接，输出最终目标
basename /a/b/c.txt    # c.txt
dirname /a/b/c.txt     # /a/b
mktemp -d              # 安全创建临时目录（避免可预测文件名）
```

`ls -l` 输出逐段读：

```text
-rw-r--r-- 1 wang wang 1.2K Sep 20 10:30 notes.md
│└┬┘└┬┘└┬┘ │  │    │     │          │
│ │  │  │  │  │    │     │          └ 文件名
│ │  │  │  │  │    │     └ 修改时间
│ │  │  │  │  │    └ 大小
│ │  │  │  │  └ 所属组
│ │  │  │  └ 所有者
│ │  │  └ 硬链接数
│ └──┴── 权限（owner/group/other）
└ 类型：- 普通文件 d 目录 l 链接
```

**三个时间**（`stat` 能看全）：`mtime` 内容修改时间（最常用）、`atime` 访问时间、`ctime` inode 状态变更时间（权限、属主、链接数、内容等变化都会更新，不能用 `touch` 直接设置）。

## 3. 增删改

```bash
mkdir -p a/b/c         # -p：逐级创建，已存在不报错
touch f.txt            # 建空文件 / 更新时间戳
cp -r src/ dst/        # -r 递归；-a 保留属性（备份常用）
mv a.txt b.txt         # 改名；目录就是移动
rm -rf dir/            # -r 递归 -f 不提示（危险，敲前看清）
rmdir emptydir         # 只能删空目录
```

**安全习惯**：

- `rm -rf` 前先 `ls` 一下路径（尤其是变量拼接的路径）
- 用 `mv` 到 `/tmp` 代替直接删；真要删就确认变量非空，并拦住常见的空值、根目录、当前目录：

```bash
case "${dir:-}" in
    ""|"/"|"."|"..") echo "refuse: bad dir" >&2; exit 1 ;;
esac
rm -rf -- "${dir:?}"
```


## 4. 查找：find

```bash
find . -name '*.log'                    # 按名字（区分大小写；-iname 不区分）
find . -type f -name '*.cpp'            # 类型：f 文件 d 目录 l 链接
find . -type f -size +100M              # 大于 100M（-100k、+1G 都行）
find . -type f -mtime -7                # 7 天内修改过（+7 表示 7 天前）
find . -type f -mmin -30                # 30 分钟内修改过
find . -perm /u+x -type f               # 有执行位的文件
find . -maxdepth 2 -name '*.md'         # 限制深度
find . -empty                           # 空文件/空目录

# 找到后执行命令
find . -name '*.tmp' -print -delete                    # 先打印再删
find . -name '*.cpp' -exec wc -l {} +                   # 批量执行（+ 是攒一批，效率高）
find . -name '*.cpp' -print0 | xargs -0 -r grep -l TODO  # 文件名带空格也安全；-r 空输入不执行
```

**要点**：

- `-exec ... {} \;` 是每个文件执行一次；`-exec ... {} +` 是攒一批执行（快）
- 文件名可能含空格 → 用 `-print0` + `xargs -0`（别用裸 `xargs`）
- 文件名搜索可以用 `locate`（查索引，快但可能过期，`updatedb` 更新）

## 5. 硬链接与软链接

```bash
ln target hardlink      # 硬链接（多个名字指向同一个 inode）
ln -s target softlink   # 软链接（符号链接，存的是路径）
```

**相对软链接**：`ln -s target link` 里的 `target` 是按 `link` 所在目录解释的，不是按当前目录；不确定时用绝对路径。

| | 硬链接 | 软链接 |
|--|--------|--------|
| 本质 | 又一个目录项，指向**同一 inode** | 一个特殊文件，内容是**目标路径** |
| 跨文件系统 | ❌ 不行 | ✅ 可以 |
| 指向目录 | ❌ 不行（防环） | ✅ 可以 |
| 目标删除后 | 还能用（数据还在，链接数 -1） | **变"断链"**（用 `ls -l` 看是红的） |
| 创建方式 | `ln` | `ln -s` |

```bash
# 看链接数与 inode：硬链接共享 inode
$ ln a.txt b.txt && ls -li a.txt b.txt
1234567 -rw-r--r-- 2 wang wang 5 ... a.txt      ← 链接数 2，inode 相同
1234567 -rw-r--r-- 2 wang wang 5 ... b.txt
```

**什么时候用软链接**：发布版本切换（`current -> v1.2.3`）、库版本（`libfoo.so.1 -> libfoo.so.1.2.3`）、跨盘引用。**硬链接**多用于备份（rsync 的 `--link-dest`）、节省空间。

## 6. 打包与压缩

```bash
# tar 三件套：c 创建 / x 解压 / t 查看
tar -zcvf a.tar.gz dir/            # gzip 压缩（最常见）
tar -Jcvf a.tar.xz dir/            # xz 压缩（更小更慢）
tar --zstd -cvf a.tar.zst dir/     # zstd（快且小；需要装 zstd 包）
tar -zxvf a.tar.gz                 # 解压到当前目录
tar -zxvf a.tar.gz -C /tmp/dst     # 解压到指定目录
tar -tf a.tar.gz                   # 只看内容不解压
tar -zcvf a.tar.gz --exclude='*.log' dir/    # 排除
tar -zcvf a.tar.gz -C /path/to dir # 从指定目录打包
tar -zxvf a.tar.gz --strip-components=1 -C dst  # 去掉压缩包顶层目录
```

```bash
zip -r a.zip dir/                  # zip 压缩
unzip -l a.zip                     # 列表
unzip a.zip -d out/                # 解压到目录
```

**大文件切分与合并**：

```bash
split -b 1G big.iso part_          # 按大小切（part_aa、part_ab…）
split -l 1000 big.txt part_        # 按行切
cat part_* > big.iso               # 合并回去
```

**解压参数对照**：`-z` gzip（`.tar.gz`/`.tgz`）、`-j` bzip2（`.tar.bz2`）、`-J` xz（`.tar.xz`）、`--zstd` zstd（`.tar.zst`）。**分不清就用 `file` 看一眼**，或者现代 tar 能自动识别：`tar -xf a.tar.xxx`。

## 7. 校验和

下载和传输后核对完整性（发布页一般给 SHA-256 值）；逐字节比对用 `cmp`：

```bash
sha256sum file.iso            # 算 SHA-256
sha256sum -c SHA256SUMS       # 按清单批量校验（每条显示 OK / FAILED）
md5sum file.iso               # 老算法：只适合"变没变"的比对，安全性已破
cmp a.bin b.bin               # 逐字节比（不同时指出第一个差异位置）
```

**惯例**：大文件下载完先核对官方 sha256；跨机器传完再验一遍。

## 8. 同步与传输：rsync

```bash
rsync -avz src/ dst/               # 本地同步（-a 保留属性 -v 详细 -z 压缩）
rsync -avz src/ user@host:/path/   # 同步到远程（走 ssh）
rsync -avz --delete src/ dst/      # dst 里多出来的文件也删掉（让两边完全一致）
rsync -avzn src/ dst/              # -n 试运行：只看会做什么，不动文件
rsync -avz --exclude='*.log' src/ dst/   # 排除日志
rsync -avzP big.iso user@host:/tmp/  # -P：进度 + 断点续传
rsync -avz -e 'ssh -p 2222' src/ user@host:/dst/   # 指定 ssh 端口
```

**最容易踩的坑：末尾斜杠**——

```bash
rsync -avz src/  dst/     # 把 src 里面的内容同步到 dst（dst/src内容...）
rsync -avz src   dst/     # 把 src 目录本身同步到 dst（dst/src/...）
```

**为什么用 rsync 而不是 scp/cp**：增量传输（只传变化的部分）、可续传、`--delete` 能镜像、`-n` 能预演。

## 9. 磁盘占用：df 与 du

```bash
df -h                   # 各文件系统使用量（-h 人类可读）
df -i                   # inode 使用量（inode 满了照样写不进文件！）
du -sh dir/             # 目录总大小
du -h --max-depth=1 .   # 只看一层子目录的大小
du -ah dir/ | sort -rh | head -20      # 找出最大的文件/目录
```

**`df` 和 `du` 对不上是正常的**：被删除但还被进程打开的文件（`lsof | grep deleted`）会占着空间——`du` 不算它，`df` 算。

## 10. 加密（gpg）

```bash
gpg -c file                 # 对称加密（口令），生成 file.gpg
gpg -o file -d file.gpg     # 解密
```

```bash
# 打包 + 加密一条龙（管道）
tar -zcvf - dir/ | gpg -c -o backup.tar.gz.gpg
gpg -d backup.tar.gz.gpg | tar -zxvf -
```

非对称加密（公钥/私钥）：`gpg --full-generate-key` 生成密钥对，`gpg -e -r 对方ID file` 加密，`gpg -d` 解密。

## 11. 要点回顾

1. **目录约定**：配置 `/etc`、日志 `/var/log`、数据自己找人头（`/opt`、`~`）；`/proc`/`/sys`/`/dev` 是内核接口
2. **find 是查找主力**：`-name`/`-type`/`-size`/`-mtime`/`-maxdepth`；危险操作先 `-print` 空跑
3. **硬链接 = 同一 inode 的另一个名字**（不能跨盘/链目录）；**软链接 = 存路径**（可跨盘，会断链）
4. **tar 记组合**：`zcvf` 压、`zxvf` 解、`tf` 看；`-C` 指定目录，`--exclude` 排除
5. **rsync 的斜杠有语义**：`src/` 是内容，`src` 是目录本身；`--delete` 做镜像，`-n` 试运行
6. **`df -i`**：inode 满了也会写不进文件；`du` 与 `df` 对不上时查被删除但打开的文件
7. **gpg 可管道组合**：`tar ... | gpg -c`，备份加密一条命令
8. **校验和**：`sha256sum` 算值、`-c` 对清单、`cmp` 逐字节比——下载/传输后先验
9. **三个时间**：mtime 内容、atime 访问、ctime inode 状态；ctime 不能用 `touch` 直接设置
10. **路径工具**：`realpath`、`readlink -f`、`basename`、`dirname`、`mktemp`
