# 文本处理与管道

Linux 日常常用技能：查看、过滤、替换、统计——大部分工作是一串管道拼出来的。

## 1. 查看文件

```bash
cat f.txt                  # 全部输出（小文件）
cat -n f.txt               # 带行号
less f.txt                 # 分页查看（q 退出，/搜索，G 末尾，gg 开头）
head -n 20 f.txt           # 前 20 行
tail -n 20 f.txt           # 后 20 行
tail -f app.log            # 实时跟踪（看日志）
tail -F app.log            # 跟踪 + 文件被轮转后继续跟（推荐）
```

**`less` 里最常用的键**：`/pattern` 向下搜、`n` 下一个、`G` 到底、`g` 回顶、`F` 进入 tail 模式（Ctrl+C 退出）、`q` 退出。

## 2. grep：过滤

```bash
grep "error" app.log                 # 含 error 的行
grep -i "error" app.log              # 忽略大小写
grep -rn "TODO" src/                 # 递归 + 行号
grep -v "debug" app.log              # 反向：不含 debug 的行
grep -c "error" app.log              # 统计匹配行数
grep -l "error" *.log                # 只列文件名
grep -w "log" f.txt                  # 全词匹配（不匹配 logger）
grep -o "id=[0-9]*" f.txt            # 只输出匹配到的部分
grep -A 3 -B 1 "error" app.log       # 附带后 3 行 / 前 1 行（-C 前后各 N 行）

grep -E "error|warn" app.log          # 扩展正则（等价 egrep）
grep -F "a.b[0]" f.txt                # 固定字符串（不当正则解释）

grep -rn --include='*.cpp' "include" src/    # 只搜某些文件
grep -rn --exclude-dir=build "foo" .         # 排除目录
```

## 3. sed：流编辑

```bash
sed 's/old/new/' f.txt               # 每行第一次替换（只输出到屏幕）
sed 's/old/new/g' f.txt              # 每行全部替换
sed -i 's/old/new/g' f.txt           # 原地修改文件（-i.bak 会先备份）
sed -n '5,10p' f.txt                 # 只打印 5~10 行（-n + p）
sed '/^#/d' f.txt                    # 删除以 # 开头的行
sed '/^$/d' f.txt                    # 删除空行
sed 's/^/    /' f.txt                # 每行行首加 4 空格
sed -E 's/([0-9]+)px/\1pt/g' f.txt   # 扩展正则 + 分组引用 \1
```

**插入、追加、整行替换**：

```bash
sed '/^#/a\    new line' f.txt       # 匹配行后追加
sed '/^#/i\# before' f.txt           # 匹配行前插入
sed '/^#/c\# replaced' f.txt         # 整行替换
```

**要点**：

- `sed` 默认**不改原文件**（输出到 stdout）；要改就 `-i`
- 默认用 **BRE**（基础正则，`+ ? | ()` 要转义）；`-E` 切到 ERE（写起来正常）

## 4. awk：按列处理

```bash
awk '{print $1}' f.txt                        # 第一列（默认按空白切分）
awk -F, '{print $1, $3}' data.csv             # 指定分隔符（逗号）
awk '{print $NF}' f.txt                       # 最后一列（NF = 字段数）
awk 'NR==3' f.txt                             # 第 3 行（NR = 行号）
awk 'NR>=3 && NR<=5' f.txt                    # 3~5 行
awk -F, '$3 > 100' data.csv                    # 条件过滤（第 3 列大于 100）
awk -F, '{sum += $3} END {print sum}' data.csv # 第 3 列求和
awk '{print NR": "$0}' f.txt                  # 带行号输出整行（$0 = 整行）

awk '{sub(/old/, "new"); print}' f.txt        # 每行替换第一个
awk '{gsub(/old/, "new"); print}' f.txt       # 每行全部替换
awk '{printf "%-10s %5d\n", $1, $3}' f.txt   # 格式化输出
```

**内置变量**：`$0` 整行、`$1..$N` 第 N 列、`NF` 列数、`NR` 当前行号、`FS` 输入分隔符、`OFS` 输出分隔符。

用 `-F` 或 `BEGIN{FS=","}` 指定分隔符；`END{}` 在读完所有行后执行（适合汇总）。

`-F,` 只适合简单 CSV；字段里有逗号、引号、换行时，用 Python `csv`、Miller 或 csvkit，别硬用 `awk` 切。

## 5. 其他常用命令

```bash
sort -n nums.txt              # 按数字排序（默认按字典序！）
sort -r                       # 逆序
sort -k2 -t, data.csv         # 按第 2 列排（-t 指定分隔符）
sort -u                       # 排序并去重
sort -h sizes.txt             # 按"人类可读大小"排（1K < 2M < 1G）
sort -V versions.txt          # 版本号排序（1.9 < 1.10）

uniq                          # 去重【相邻】重复行（所以要先 sort）
uniq -c                       # 统计每行出现次数
uniq -d                       # 只显示重复过的行
uniq -u                       # 只显示没重复过的行

wc -l f.txt                   # 行数；-w 词数；-c 字节数

cut -d, -f1,3 data.csv        # 取第 1、3 列（按分隔符）
cut -c1-10 f.txt              # 取每行前 10 个字符

tr 'a-z' 'A-Z' < f.txt        # 小写转大写
tr -d '\n' < f.txt            # 删除换行（全部拼成一行）
tr -s ' ' < f.txt             # 把连续空格压成一个
```

**编解码**：

```bash
base64 f.bin > f.b64          # base64 编码（文本渠道传二进制）
base64 -w0 f.bin > f.b64      # 不换行（GNU；适合放进一行配置）
base64 -d f.b64 > f.bin       # 解码
echo -n 'user:pass' | base64  # API 认证头常用
```

**`sort | uniq -c` 是最经典的组合**——统计词频/排行都靠它（`uniq` 只去相邻重复，不排序结果会错）。

### diff / patch

```bash
diff -u old.txt new.txt > fix.patch       # 生成统一格式补丁
patch -p0 < fix.patch                     # 应用补丁（路径按补丁里的前缀选 -pN）
diff -ruN old/ new/ > tree.patch          # 目录递归比较
patch -p1 < tree.patch                    # 去掉 old/、new/ 前缀后应用
patch --dry-run -p1 < tree.patch          # 先试跑，不落盘
```

`diff` 返回 1 表示“有差异”，不是执行失败；脚本里要单独判断。

### paste / join / column / comm

```bash
paste a.txt b.txt                 # 按行并排（默认 tab）
paste -d, a.txt b.txt             # 用逗号分隔
join -t, -1 1 -2 1 users.csv orders.csv   # 按第 1 列连接（两边先排序）
column -t -s, data.csv            # 对齐成表格
comm -12 <(sort a.txt) <(sort b.txt)      # 两边都有的行（输入必须有序）
```

- `join` / `comm` 都要求输入按连接键排序
- `column` 是 util-linux 工具，最小系统可能没装
- `paste` 不做字段匹配，只是按行拼接

### 换行符：CRLF / LF

```bash
file f.txt                         # 看到 CRLF 就要转换
dos2unix f.txt                     # Windows CRLF -> Unix LF（需装 dos2unix）
unix2dos f.txt                     # Unix LF -> Windows CRLF
sed -i 's/\r$//' f.txt             # 没有 dos2unix 时的替代
```

## 6. 重定向与管道

```bash
cmd > out.txt          # 标准输出覆盖写入
cmd >> out.txt         # 追加
cmd 2> err.txt         # 标准错误写入
cmd > all.txt 2>&1     # 输出和错误都进 all.txt
cmd &> all.txt         # 同上（bash 简写）
cmd > /dev/null        # 丢掉输出（黑洞）
cmd 2>/dev/null        # 只丢错误（常见：屏蔽 warning）
cmd < in.txt           # 从文件读输入

cmd1 | cmd2            # 管道：cmd1 的输出当作 cmd2 的输入
cmd 2>&1 | grep err    # 想让错误进管道，必须先 2>&1
cmd | tee out.txt      # 一边显示一边写文件（tee -a 追加）
```

**注意**：管道默认只传**标准输出**，标准错误还是打到终端——"为什么 grep 抓不到报错"通常是这个原因。

## 7. xargs：把输出变成参数

```bash
find . -name '*.tmp' -print0 | xargs -0 -r rm --   # 文件名含空格也安全；-r 空输入不执行
find . -name '*.cpp' -print0 | xargs -0 -r wc -l  # 文件名含空格时用 -print0 / -0
cat urls.txt | xargs -r -n 1 curl -O       # 每次传 1 个（-n 1）
cat list.txt | xargs -r -I{} echo "处理 {}" # -I{} 占位替换
cat files.txt | xargs -r -P 4 -n 1 gzip    # -P 4：并行 4 个
```

## 8. 正则基础

| 写法 | 含义 | 例子 |
|------|------|------|
| `.` | 任意一个字符 | `a.c` 匹配 abc |
| `*` | 前面元素 0 次或多次 | `ab*c` |
| `+` | 1 次或多次（ERE） | `ab+c` |
| `?` | 0 或 1 次（ERE） | `colou?r` |
| `[]` / `[^]` | 字符集合 / 取反 | `[0-9]`、`[^0-9]` |
| `^` / `$` | 行首 / 行尾 | `^ERROR` |
| `()` | 分组（ERE/Sed 要 `-E`） | `(ab)+` |
| `{n,m}` | 重复次数（ERE） | `[0-9]{2,4}` |
| `\b` | 单词边界（GNU） | `\bword\b` |

**或运算**：BRE 写 `\|`，ERE 写 `|`；例如 `grep 'error\|warn'` 和 `grep -E 'error|warn'`。

**方言差异**：`grep`/`sed` 默认 BRE（`+ ? | ( )` 要加 `\` 或换 `-E`）；`grep -E`、`awk` 用 ERE（直接写）。

## 9. 字符集与中文乱码

```bash
locale                       # 当前语言/字符集环境
echo "$LANG $LC_ALL"         # 常见值：en_US.UTF-8 / zh_CN.UTF-8 / C
file -i f.txt                # 看文件编码（charset=...）
iconv -f GBK -t UTF-8 in.txt -o out.txt     # 编码转换
```

**乱码排查三问**：

1. **文件本身什么编码**？`file -i` 看（`charset=unknown-8bit` 多半是 GBK 或二进制）
2. **终端/系统什么 locale**？`locale` 看——不是 `*.UTF-8` 就可能显示乱码（`export LANG=en_US.UTF-8` 试试）
3. **程序用什么编码读它**？（Python 的 `open(..., encoding=...)`；先 `iconv` 转好再处理）

**实践**：统一 UTF-8（文件、终端、代码都是）；遇到 Windows/老系统的 GBK 文件先 `iconv` 转换，别直接改字节。

## 10. 实战组合

```bash
# 1) Nginx 访问日志：访问量 Top 10 的 IP
awk '{print $1}' access.log | sort | uniq -c | sort -rn | head -10

# 2) 统计日志里各类错误的次数
grep -i error app.log | awk '{print $NF}' | sort | uniq -c | sort -rn | head

# 3) 找出占空间最大的前 20 个文件
du -ah . | sort -rh | head -20

# 4) 代码总行数（排除 build）
find . -name '*.cpp' -not -path './build/*' -print0 | xargs -0 wc -l | tail -1

# 5) 批量改后缀
for f in *.txt; do mv -- "$f" "${f%.txt}.md"; done

# 6) 删除空行 / 去重（保序）
sed '/^$/d' f.txt
awk '!seen[$0]++' f.txt

# 7) CSV 第 3 列求和 + 行数
awk -F, 'NR>1 {sum += $3} END {print sum, NR-1}' data.csv

# 8) 替换多个文件里的字符串（先看会改什么，再真改）
grep -rl 'old_name' .        # 列出受影响文件
grep -rlZ 'old_name' . | xargs -0 -r sed -i.bak 's/old_name/new_name/g'
```

## 11. 要点回顾

1. **查看**：`less`（交互）、`tail -f`（跟日志，轮转场景用 `-F`）
2. **grep**：`-rn` 递归、`-v` 反向、`-c` 计数、`-A/-B/-C` 上下文、`-E` 扩展正则、`--include` 限定文件
3. **sed**：`s/old/new/g` + `-i` 原地改；`sed -n 'a,bp'` 取行范围；`a`/`i`/`c` 追加、插入、整行替换；`-E` 用 ERE
4. **awk**：按列处理（`-F` 分隔符、`$1/$NF`、`NR`、`END{}` 汇总）；`sub`/`gsub` 替换，`printf` 格式化
5. **`sort | uniq -c | sort -rn`**：排行统计的万能组合（uniq 前必须 sort）
6. **重定向**：`2>&1` 把错误并入输出；管道默认只传 stdout；`tee` 分流
7. **文件名带空格**：`find -print0 | xargs -0 -r`；`xargs -P` 可并行
8. **改文件前先确认影响面**：`grep -rl 旧串` 列出文件，再 `sed -i.bak`（留备份）
9. **乱码三问**：`file -i` 看文件编码、`locale` 看环境、程序用什么编码读——统一 UTF-8，老文件先 `iconv` 转
10. **diff / patch**：`diff -u` 生成补丁，`patch -pN` 应用；`diff` 退出码 1 表示有差异
11. **行列与连接**：`paste` 拼行、`join`/`comm` 按键连接（先排序）、`column -t` 对齐
12. **换行符**：`dos2unix` / `unix2dos`；没有工具时 `sed -i 's/\r$//'`
