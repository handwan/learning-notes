# 分布式

分布式不是“上多个节点”，而是接受网络、复制、分区和失败，并明确一致性取舍。

## 篇目

1. [CAP 与一致性](01-CAP与一致性.md)：CAP/PACELC、复制、quorum、读己之写、冲突
2. [复制、分区与热点](02-复制分区与热点.md)：分区键、倾斜、再平衡、跨分片查询
3. [故障、超时与恢复](03-故障超时与恢复.md)：超时、重试、幂等、熔断、补偿
4. [一致性与事务](04-一致性与事务.md)：2PC/TCC/Saga、Outbox/CDC、幂等去重

## 怎么读

- 先看一致性级别和 quorum，不要只背 CAP
- 再看复制/分区/故障，最后看事务模式
