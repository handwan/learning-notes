# 扩展与可用性

系统怎么接流量、扛峰值、控制故障面：入口、缓存、队列、限流与隔离。

## 篇目

1. [入口与负载均衡](01-入口与负载均衡.md)：L4/L7、网关、算法、健康检查、draining
2. [缓存](02-缓存.md)：本地/分布式、TTL、穿透/击穿/雪崩、热 key
3. [消息队列与异步](03-消息队列与异步.md)：投递语义、顺序、积压、重放
4. [限流、降级与隔离](04-限流降级与隔离.md)：令牌桶/滑动窗口、租户隔离、舱壁、过载保护

## 怎么读

- 先看入口，理解流量怎么进来
- 再看缓存/队列/限流，分别解决读、削峰、过载

不先选 Nginx/Redis/Kafka；先看流量和失败模式。
