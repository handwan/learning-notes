# 架构

系统设计里的结构决策：边界、依赖、风格、接口、安全与演进。

## 篇目

1. [架构风格](01-架构风格.md)：单体、模块化单体、微服务、事件驱动、CQRS
2. [边界与依赖](02-边界与依赖.md)：模块边界、数据所有权、同步/异步、依赖倒置
3. [API 与契约](03-API与契约.md)：REST/gRPC/GraphQL、版本化、分页、错误码、幂等键
4. [安全与多租户](04-安全与多租户.md)：认证授权、租户隔离、密钥、加密、审计
5. [演进与技术债](05-演进与技术债.md)：拆分、迁移、回滚、技术债

## 怎么读

- 先看架构风格，知道有哪些选项和代价
- 再看边界与依赖，避免“服务拆了但数据还耦合”
- API、安全、演进按项目需要补
