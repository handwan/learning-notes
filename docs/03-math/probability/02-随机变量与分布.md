# 随机变量与分布

随机变量、离散/连续分布、PDF/CDF，以及 ML 最常用的几个分布（重点：正态分布）。

## 1. 随机变量

**定义**：把样本空间的结果映射成实数。

```python
掷骰子：Ω = {1,2,3,4,5,6}
随机变量 X = 掷出的点数，取值 1~6

掷硬币：X = 1（正面）或 0（反面）
```

随机变量分两类：

- **离散**：取值可数（点数、次数）
- **连续**：取值是区间（身高、温度、时间）

## 2. 分布函数（CDF）

**累计分布函数 CDF**：`F(x) = P(X ≤ x)`，表示"X 不超过 x"的概率。

**概率密度函数 PDF**（连续）/ **概率质量函数 PMF**（离散）：描述"X 在某点附近/某点"的概率。

**关键区别**：

- 离散：`P(X = x)` 有意义（PMF 直接给概率）
- 连续：`P(X = x) = 0`（单点概率为 0），只能看区间（PDF 积分）

## 3. 离散分布

### 伯努利分布（Bernoulli）

**一次实验**，只有成功/失败两种结果。

```python
X ~ Bernoulli(p)     # p = 成功概率
P(X=1) = p, P(X=0) = 1-p

期望 E[X] = p，方差 Var(X) = p(1-p)
```

**场景**：抛一次硬币、一次点击是否转化。

### 二项分布（Binomial）

**n 次独立伯努利实验**，成功 k 次的概率。

```python
X ~ Binomial(n, p)
P(X=k) = C(n,k) · pᵏ · (1-p)ⁿ⁻ᵏ

期望 E[X] = np，方差 Var(X) = np(1-p)
```

**场景**：抛 n 次硬币正面次数、n 个用户中购买人数。

### 泊松分布（Poisson）

**单位时间/空间内**，事件发生 k 次的概率。

```python
X ~ Poisson(λ)      # λ = 平均发生次数
P(X=k) = λᵏ e⁻λ / k!

期望 = 方差 = λ
```

**场景**：一小时进店人数、一页书错别字数。

## 4. 连续分布

### 均匀分布（Uniform）

区间 [a, b] 内每个值等可能。

```python
X ~ U(a, b)
期望 E[X] = (a+b)/2
```

### 正态分布（Gaussian，★最重要）

**钟形曲线**，由均值 μ 和标准差 σ 决定。

```python
X ~ N(μ, σ²)
f(x) = (1/σ√2π) · e^(-(x-μ)²/2σ²)

期望 E[X] = μ，方差 Var(X) = σ²
```

**为什么 ML 里最重要**：

1. **中心极限定理**：大量独立随机变量的和趋近正态——现实中很多数据近似正态
2. 高斯噪声是默认假设（测量误差、传感器噪声）
3. 高斯分布性质好（线性变换仍是高斯）

```python
import numpy as np
np.random.normal(0, 1, 1000)   # 均值0，标准差1，采样1000个
```

### 正态分布的性质（ML 常用）

**1. 线性变换仍是正态**

```python
若 X ~ N(μ, σ²)，则 aX + b ~ N(aμ + b, a²σ²)
```

**标准正态**：`(X - μ) / σ ~ N(0, 1)`（标准化）。

**2. 独立正态的和仍是正态（可加性）**

```python
若 X ~ N(μ₁, σ₁²)，Y ~ N(μ₂, σ₂²)，且独立，则：
X + Y ~ N(μ₁ + μ₂, σ₁² + σ₂²)
```

**3. 独立正态的线性组合仍是正态**

```python
aX + bY ~ N(aμ₁ + bμ₂, a²σ₁² + b²σ₂²)
```

**为什么 ML 常用**：高斯分布的线性变换、求和、组合**结果还是高斯**——这使得它在计算上特别"省心"，采样、初始化、高斯混合模型都依赖这个性质。

### 指数分布（Exponential）

描述**等待时间**（事件发生的间隔）。

```python
X ~ Exp(λ)          # λ = 发生率
f(x) = λe^(-λx)

期望 E[X] = 1/λ
```

**场景**：两次进店间隔时间、设备寿命。

## 5. 常用分布速查表

| 分布 | 参数 | 期望 | 方差 | ML 场景 |
|------|------|------|------|---------|
| 伯努利 | p | p | p(1-p) | 二分类 |
| 二项 | n, p | np | np(1-p) | 多次实验 |
| 泊松 | λ | λ | λ | 单位时间计数 |
| 均匀 | a, b | (a+b)/2 | (b-a)²/12 | 随机初始化 |
| **正态** | μ, σ² | μ | σ² | **默认假设、噪声** |
| 指数 | λ | 1/λ | 1/λ² | 等待时间 |

## numpy 验证

```python
import numpy as np

# 各分布采样
np.random.binomial(n=10, p=0.5, size=5)   # 二项
np.random.poisson(lam=3, size=5)          # 泊松
np.random.uniform(0, 1, 5)                # 均匀
np.random.normal(0, 1, 5)                 # 正态
np.random.exponential(scale=1, size=5)    # 指数

# 可视化（配 matplotlib）
import matplotlib.pyplot as plt
x = np.random.normal(0, 1, 10000)
plt.hist(x, bins=50)      # 钟形直方图
plt.show()
```

## 小结

1. **随机变量** = 结果到实数的映射，分离散/连续
2. **CDF** = P(X≤x)，**PDF/PMF** = 单点概率描述
3. 离散三兄弟：伯努利（一次）→ 二项（n 次）→ 泊松（计数）
4. **正态分布是 ML 最重要的分布**（中心极限 + 默认噪声假设）
