# 概率基础

样本空间、事件、条件概率、全概率公式、贝叶斯公式。贝叶斯是**核心**，ML 处处用。

## 1. 基本概念

- **样本空间 Ω**：一次试验**所有可能结果**的集合。如掷骰子 Ω = {1,2,3,4,5,6}
- **事件**：样本空间的子集。如"掷出偶数" = {2,4,6}
- **概率 P(A)**：0~1 之间的数，衡量事件 A 发生的可能性

## 2. 概率的性质

```
1. 0 ≤ P(A) ≤ 1
2. P(Ω) = 1        （必然事件概率为 1）
3. 互斥事件：P(A ∪ B) = P(A) + P(B)
```

## 3. 条件概率

**定义**：在事件 B 已经发生的前提下，A 发生的概率：

```
P(A|B) = P(A ∩ B) / P(B)
```

**直觉**：B 发生后，"世界"缩小到 B 的范围，看 A∩B 占 B 的比例。

```python
# 例子：52 张牌，摸到红桃(A)的概率是 1/4
# 已知摸到红色(B)，摸到红桃的概率？
P(A|B) = P(红桃且红) / P(红) = (13/52) / (26/52) = 1/2
# 直觉：红色牌有 26 张，其中红桃 13 张，占一半
```

## 4. 全概率公式

**作用**：把复杂事件的概率，拆成若干简单情况的加权和。

```
P(A) = Σ P(A|Bᵢ) · P(Bᵢ)
```

**直觉**：A 可以"通过不同路径"发生（B₁、B₂、...），把每条路径的概率加起来。

```python
# 例子：两箱球，箱1有3红2白，箱2有1红4白
# 随机选箱，再摸球，摸到红球概率？
P(红) = P(红|箱1)·P(箱1) + P(红|箱2)·P(箱2)
      = (3/5)(1/2) + (1/5)(1/2) = 0.4
```

## 5. 贝叶斯公式（核心）

**作用**：**由"果"推"因"**——已知结果 A，反推是哪个原因 B 导致的。

```
P(B|A) = P(A|B) · P(B) / P(A)
```

展开（用全概率）：

```
P(B|A) = P(A|B) · P(B) / Σ P(A|Bᵢ)P(Bᵢ)
```

**直觉**：

- `P(B)`：**先验**（还没看到结果时，对 B 的信念）
- `P(A|B)`：**似然**（B 成立时，看到 A 的可能性）
- `P(B|A)`：**后验**（看到 A 后，对 B 的更新后的信念）

**贝叶斯 = 用新证据（A）更新旧信念（先验）**。

```python
# 经典例子：患病检测
# 某病患病率 1%，检测准确率 99%
# （准确率 = 灵敏度 99% 且 特异度 99%，即假阳性率 1%）
# 检测阳性，真的患病概率？
P(患病) = 0.01                    # 先验
P(阳性|患病) = 0.99               # 似然
P(阳性) = 0.99·0.01 + 0.01·0.99  # 全概率
        = 0.0198

P(患病|阳性) = 0.99·0.01 / 0.0198 ≈ 0.5
# 阳性后，患病概率从 1% 升到 50%（反直觉，但正确）
```

## ML 里的应用

- **朴素贝叶斯分类器**：贝叶斯公式直接用于分类（垃圾邮件、文本分类）
- **贝叶斯推断**：用数据更新模型参数的信念
- **贝叶斯是"概率思维"的核心**：先验 + 证据 → 后验

## 小结

1. **条件概率** `P(A|B)`：B 已发生时 A 的概率
2. **全概率** `P(A) = Σ P(A|Bᵢ)P(Bᵢ)`：把概率拆到各路径
3. **贝叶斯** `P(B|A) = P(A|B)P(B)/P(A)`：由果推因，先验 + 证据 → 后验（ML 核心）
