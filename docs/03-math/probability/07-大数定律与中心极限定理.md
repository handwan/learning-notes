# 大数定律与中心极限定理

理论背景章节。结论值得知道——它们解释了"**为什么样本足够多就可靠**"。

## 1. 大数定律（Law of Large Numbers）

**内容**：样本足够多时，**样本均值趋近于期望**。

```python
# 掷骰子越多，平均值越接近 3.5（期望）
import numpy as np
for n in [10, 100, 10000]:
    avg = np.random.randint(1, 7, n).mean()
    print(n, "次平均：", avg)
# 10     → 波动大
# 10000  → 非常接近 3.5
```

**推论**：频率趋近概率（抛硬币越多，正面比例越接近 0.5）。

## 2. 中心极限定理（Central Limit Theorem）

**内容**：大量**独立同分布**的随机变量之和，其分布**趋近正态分布**（不管原来是什么分布）。

```python
# 哪怕原来服从均匀分布，很多个相加后也变成钟形曲线
import numpy as np
s = np.random.uniform(0, 1, (10000, 100)).sum(axis=1)
# s 的直方图是钟形（近似正态）
```

**意义**：解释了**为什么现实中数据常近似正态**——因为很多现象是大量独立小因素叠加的结果（如测量误差）。

## 3. 怎么看待这两条定理

- 它们是**理论保证**：说明"为什么样本够多就可靠"，不直接参与算法实现
- 实际工作里**不直接计算**；但理解了，才知道"数据驱动"的底气从哪来
- 结论值得记住：**大数定律解释"频率趋近概率"，中心极限解释"正态分布为什么常见"**

## 小结

1. **大数定律**：样本均值趋近期望（频率趋近概率）
2. **中心极限定理**：大量独立同分布之和趋近正态（解释正态的普遍性）
3. ML 里作为理论背景了解，不用深究
