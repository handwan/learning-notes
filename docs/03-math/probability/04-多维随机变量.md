# 多维随机变量

同时看多个随机变量：联合分布、边缘分布、条件分布、独立性。独立性是朴素贝叶斯的基石，条件分布是回归的基石。

## 1. 联合分布（Joint Distribution）

**定义**：两个（或多个）随机变量**一起**的分布。

```python
# 离散：P(X=x, Y=y) = 两者同时取某值的概率
# 连续：联合密度 f(x, y)

# 例子：抛两枚硬币
# X = 第一枚，Y = 第二枚
# P(X=正, Y=正) = 1/4，P(X=正, Y=反) = 1/4 ...
```

**直观理解**：联合分布描述"X 和 Y 的世界全貌"——所有组合各自的概率。

## 2. 边缘分布（Marginal Distribution）

**定义**：从联合分布里，**只看其中一个变量**，把另一个"消除"掉。

```python
# 离散：对另一个变量求和
P(X = x) = Σᵧ P(X=x, Y=y)

# 连续：对另一个变量积分
fₓ(x) = ∫ f(x, y) dy
```

**直觉**："边缘"= 把表格按行/列加起来，只看行（或列）的合计。

```python
# 抛两枚硬币的联合分布（概率表）：
#         Y=正   Y=反   | 边缘（合计）
# X=正    1/4    1/4    |   1/2  ← P(X=正)
# X=反    1/4    1/4    |   1/2  ← P(X=反)
#         --------
# 边缘 P(Y) = 1/2, 1/2
```

## 3. 条件分布（Conditional Distribution）

**定义**：已知一个变量取值，另一个变量的分布。

```python
P(Y=y | X=x) = P(X=x, Y=y) / P(X=x)
```

**直觉**：把世界"固定"在 X=x 这一行，看 Y 在这一行里的分布。

**这是 ML 里"回归/分类"的本质**：
```python
# 机器学习要学的就是 P(Y | X)
# 给定输入 X（特征），输出 Y（标签）的条件分布
```

## 4. 独立性（Independence）★重点

**定义**：两个变量**互不影响**。

```python
X、Y 独立 ⇔ P(X=x, Y=y) = P(X=x) · P(Y=y)
           （联合 = 边缘的乘积）
```

等价地：
```python
P(Y=y | X=x) = P(Y=y)     # 知道 X 不影响 Y 的判断
```

**直觉**：独立 = 知道一个变量的信息，对另一个毫无帮助。

```python
# 抛两枚硬币：独立（第一枚不影响第二枚）
# 身高和体重：不独立（身高高的人通常更重）
```

**为什么 ML 里重要**：**朴素贝叶斯**的核心假设就是"特征之间独立"——虽然现实中很少完全独立，但这个假设让计算从"指数爆炸"简化成"简单相乘"，效果居然还不错。

```python
# 朴素贝叶斯：
P(类别 | 特征) ∝ P(特征1|类别) · P(特征2|类别) · ... · P(类别)
# 特征独立，才能这样直接相乘
```

### 独立 vs 不相关（易混，重点辨析）

这两个概念**不是一回事**：

| | 独立 | 不相关 |
|--|------|--------|
| 定义 | P(X,Y) = P(X)·P(Y) | Cov(X,Y) = 0 |
| 含义 | 完全无关系 | 无**线性**关系 |
| 强弱 | 强 | 弱 |

**关键结论**：

```python
独立  ⇒  不相关          # 一定成立
不相关 ⇏  独立           # 不一定成立！
```

**为什么**：不相关只要求"没有**线性**关系"（协方差为 0），但两个变量仍可能有**非线性**关系（比如 Y = X²）。

```python
# 反例：X 关于 0 对称（如 N(0,1)），Y = X²
# Cov(X, Y) = Cov(X, X²) = E[X³] - E[X]E[X²] = 0  → 不相关
# 但 Y 完全由 X 决定（Y=X²）→ 明显不独立
```

**ML 里为什么重要**：

- 特征工程时，"不相关"只排除了线性冗余，非线性关系还在（要用互信息等方法检测）
- 朴素贝叶斯假设的是**独立**（比不相关更强）

## ML 里的应用总结

| 概念 | ML 用途 |
|------|---------|
| 联合分布 | 生成模型（描述数据全貌） |
| 边缘分布 | 单变量统计 |
| **条件分布 P(Y\|X)** | **回归、分类的本质** |
| **独立性** | **朴素贝叶斯的核心假设** |

## numpy 验证

```python
import numpy as np

# 抛两枚硬币 10000 次，统计联合分布
x = np.random.binomial(1, 0.5, 10000)   # 第一枚
y = np.random.binomial(1, 0.5, 10000)   # 第二枚

# 联合计数
joint = np.zeros((2, 2))
for i in range(10000):
    joint[x[i], y[i]] += 1
joint /= 10000                          # 联合分布

# 边缘分布（对行/列求和）
P_X = joint.sum(axis=1)                 # P(X)
P_Y = joint.sum(axis=0)                 # P(Y)

# 独立验证：联合 ≈ 边缘乘积
joint[0, 0], P_X[0] * P_Y[0]            # 应接近（都是 0.25）
```

## 小结

1. **联合分布** P(X,Y)：两个变量的全貌
2. **边缘分布**：求和/积分"消除"另一个变量，只看一个
3. **条件分布** P(Y|X)：固定一个，看另一个（回归/分类的本质）
4. **独立性**：联合 = 边缘乘积，是朴素贝叶斯的基石
