# 信息论基础

熵、交叉熵、KL 散度。这三个概念是**分类任务损失函数**的理论来源，也是概率论的收尾。

## 1. 熵（Entropy）

**定义**：衡量一个分布的**不确定性/信息量**。

```python
H(X) = -Σ p(x) · log p(x)
```

**直觉**：

- 分布越"确定"（一个事件概率接近 1）→ 熵越小
- 分布越"混乱"（各事件等概率）→ 熵越大

```python
# 抛硬币：
# 均匀硬币（p=0.5）→ H = 1（最不确定）
# 必出正面（p=1）   → H = 0（完全确定，没有信息量）

import math
- (0.5*math.log2(0.5) + 0.5*math.log2(0.5))   # → 1.0
# p=1 时 H=0（约定 0·log0 = 0；注意 math.log2(0.0) 会直接报 ValueError）
```

**性质**：均匀分布的熵最大（最不确定）；确定事件熵为 0。

## 2. 交叉熵（Cross Entropy）★重点

**定义**：用分布 q 去描述真实分布 p 时，所需的平均编码长度。

```python
H(p, q) = -Σ p(x) · log q(x)
# p = 真实分布、q = 预测分布
```

**直觉**：`p` 是真实答案，`q` 是预测。交叉熵衡量"**预测 q 和真实 p 差多远**"——q 猜得越准，交叉熵越小。

```python
# 真实：正面概率 p=1（确实正面）
# 预测1：q=0.9 → 交叉熵 = -1·log(0.9) ≈ 0.105（小，猜得准）
# 预测2：q=0.1 → 交叉熵 = -1·log(0.1) ≈ 2.30（大，猜错了）
```

**关键**：预测越偏离真实，交叉熵越大。所以**最小化交叉熵 = 让预测逼近真实**。

## 3. KL 散度（Kullback-Leibler Divergence）

**定义**：衡量两个分布 p 和 q 的**差异**。

```python
KL(p || q) = Σ p(x) · log( p(x) / q(x) )
```

**性质**：

- `KL(p||q) ≥ 0`，等于 0 当且仅当 p = q
- **不对称**：`KL(p||q) ≠ KL(q||p)`

**直觉**：KL 散度 = "q 偏离 p 的额外代价"。

## 4. 三者关系（重要公式）

```python
交叉熵 = 熵 + KL 散度

H(p, q) = H(p) + KL(p || q)
```

推导：

```python
H(p,q) = -Σ p·log q
       = -Σ p·log p + Σ p·log(p/q)
       = H(p) + KL(p||q)
```

**含义**：

- `H(p)`：真实分布本身的熵（**固定不变**，和预测无关）
- `KL(p||q)`：预测偏离真实的程度（**需要最小化的部分**）

所以：

```python
最小化交叉熵 = 最小化 KL 散度（因为 H(p) 是常数）
```

## 5. ML 应用（核心）

**交叉熵 = 分类任务的损失函数**：

```python
# 二分类：真实标签 y（0或1），预测概率 ŷ
交叉熵损失 = -[ y·log(ŷ) + (1-y)·log(1-ŷ) ]
```

**为什么用交叉熵不用 MSE**（承接第 05 章 MLE）：

```python
# 05 章讲过：伯努利分布假设下的 MLE
# 最大化似然 = 最小化交叉熵
# 所以：逻辑回归（伯努利）→ 交叉熵损失
#      线性回归（高斯）  → MSE 损失
```

**KL 散度应用**：

- 生成模型（VAE）里衡量生成分布 vs 真实分布的差距
- 模型蒸馏：让学生模型输出逼近教师模型

## 6. numpy 验证

```python
import numpy as np

# 交叉熵：二分类
def cross_entropy(y_true, y_pred):
    return -(y_true * np.log(y_pred) + (1-y_true) * np.log(1-y_pred))

cross_entropy(1, 0.9)   # → 0.105（预测准，损失小）
cross_entropy(1, 0.1)   # → 2.30（预测错，损失大）

# KL 散度
def kl_divergence(p, q):
    return np.sum(p * np.log(p / q))

p = np.array([0.5, 0.5])   # 真实
q = np.array([0.8, 0.2])   # 预测
kl_divergence(p, q)        # > 0
```

## 小结

1. **熵** = 不确定性度量
2. **交叉熵** = 用 q 描述 p 的代价，越小预测越准
3. **KL 散度** = 两个分布的差异，不对称
4. **核心公式**：交叉熵 = 熵 + KL 散度
5. **ML**：交叉熵 = 分类损失函数（= 伯努利分布下的 MLE）

到这里，概率论的 ML 主线完成：**贝叶斯 → 分布 → 期望方差 → 条件分布 → MLE → 交叉熵**，整条线通向机器学习。
