# 概率论

重点是「贝叶斯、分布、期望方差、MLE、信息论」。

## 1. 概率基础

样本空间、条件概率、全概率公式、贝叶斯公式。

## 2. 随机变量与分布

离散（伯努利/二项/泊松）、连续（均匀/正态/指数）、PDF/CDF，附常用分布速查表。

## 3. 数字特征

期望、方差、标准差、协方差、相关系数、矩。

## 4. 多维随机变量

联合分布、边缘分布、条件分布、独立性。

## 5. 最大似然估计 MLE

MLE 的思想与求解、最大后验 MAP。

## 6. 信息论基础

熵、交叉熵、KL 散度。

## 7. 大数定律与中心极限定理（了解即可）

理论背景（结论值得知道）。
