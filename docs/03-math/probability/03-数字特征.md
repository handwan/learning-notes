# 数字特征

期望、方差、标准差、协方差、相关系数。数字特征 = 用几个数概括一个分布的"中心"和"离散程度"。

## 1. 期望（Expectation）

**定义**：随机变量的"长期平均值"，也叫均值。

```python
# 离散：
E[X] = Σ x · P(X=x)

# 连续：
E[X] = ∫ x · f(x) dx
```

**直觉**：如果重复做很多次试验，结果的**平均**会趋近期望。

```python
import numpy as np
# 掷骰子的期望 = 3.5
np.mean([1, 2, 3, 4, 5, 6])   # → 3.5
```

**性质**（很重要）：
```python
E[aX + b] = a·E[X] + b        # 线性
E[X + Y] = E[X] + E[Y]        # 和的期望 = 期望的和（无需独立）
```

## 2. 方差 与 标准差

**方差 Var(X)**：衡量数据**离散程度**——偏离期望多远。

```python
Var(X) = E[(X - E[X])²]
       = E[X²] - (E[X])²      # 常用计算式
```

**标准差 σ** = 方差的平方根（和原数据同单位，更直观）。

```python
import numpy as np
np.var([1, 2, 3, 4, 5, 6])   # 方差
np.std([1, 2, 3, 4, 5, 6])   # 标准差
```

**直觉**：方差大 = 数据分散；方差小 = 数据集中。

```python
[5, 5, 5]      → 方差 0（完全集中）
[1, 5, 9]      → 方差大（分散）
```

**性质**：
```python
Var(aX + b) = a²·Var(X)       # 注意：加常数不影响方差
```

## 3. 协方差（Covariance）

**定义**：衡量两个变量**一起怎么变**。

```python
Cov(X, Y) = E[(X - E[X])(Y - E[Y])]
```

**直觉**：

- `Cov > 0`：X 大时 Y 也大（**同向**变化）
- `Cov < 0`：X 大时 Y 反而小（**反向**变化）
- `Cov ≈ 0`：无关

```python
import numpy as np
x = [1, 2, 3, 4, 5]
y = [2, 4, 6, 8, 10]     # y = 2x，完全同向
np.cov(x, y)              # 协方差矩阵，非对角元素是正数
```

### 协方差矩阵（多维推广）

多个变量时，把所有两两协方差排成矩阵：

```python
Cov(X, Y) = E[(X - E[X])(Y - E[Y])]

# n 个变量的协方差矩阵 Σ：
# [ Var(X₁)   Cov(X₁,X₂)  ...  Cov(X₁,Xₙ) ]
# [ Cov(X₂,X₁) Var(X₂)    ...  Cov(X₂,Xₙ) ]
# [   ...         ...      ...    ...      ]
# [ Cov(Xₙ,X₁) ...         ...  Var(Xₙ)   ]
```

**性质**：

- 对角线 = 各变量的方差
- 对称矩阵
- 半正定（第 09 章二次型讲过）

```python
import numpy as np
X = np.array([[1, 2, 3, 4, 5],
              [2, 4, 6, 8, 10]])   # 两行两个变量
np.cov(X)     # 2×2 协方差矩阵
```

**ML 用途**：PCA 就是对协方差矩阵做特征分解，主成分 = 协方差矩阵的特征向量。

## 4. 相关系数（Correlation Coefficient）

**定义**：标准化后的协方差，范围 **[-1, 1]**。

```python
ρ = Cov(X,Y) / (σₓ · σᵧ)
```

- `ρ = 1`：完全正相关
- `ρ = -1`：完全负相关
- `ρ = 0`：不线性相关

**为什么需要相关系数**：协方差受单位影响（大数协方差就大），相关系数**消除了量纲**，可以公平比较。

```python
import numpy as np
x = [1, 2, 3, 4, 5]
y = [2, 4, 6, 8, 10]
np.corrcoef(x, y)[0, 1]   # → 1.0（完全正相关）
```

## 5. 矩（Moment）

矩是分布的"骨架"：

```python
一阶矩 = 期望（中心位置）
二阶矩 = 方差（离散程度）
三阶矩 = 偏度（对称性）
四阶矩 = 峰度（尖峭程度）
```

一般用前两阶（期望、方差）就够，高阶矩了解即可。

## ML 里的应用

1. **期望/方差 → 数据标准化**：`(x - μ) / σ` 把数据归一化（特征缩放）
2. **方差 → 正则化**：损失函数加方差项抑制过拟合
3. **协方差矩阵 → PCA**：协方差矩阵的特征分解 = 主成分方向
4. **相关系数 → 特征选择**：去掉高度相关的冗余特征

## numpy 验证

```python
import numpy as np

x = np.array([1, 2, 3, 4, 5])

x.mean()            # 期望 → 3.0
x.var()             # 方差 → 2.0
x.std()             # 标准差 → 1.414

y = np.array([2, 4, 6, 8, 10])
np.cov(x, y)        # 协方差矩阵
np.corrcoef(x, y)   # 相关系数 → 1.0

# 数据标准化
(x - x.mean()) / x.std()
```

## 小结

1. **期望** = 长期平均值（中心位置）
2. **方差/标准差** = 离散程度
3. **协方差** = 两个变量同向/反向变化
4. **相关系数** = 消除量纲的协方差，范围 [-1, 1]
5. ML 用：标准化、正则化、PCA、特征选择
