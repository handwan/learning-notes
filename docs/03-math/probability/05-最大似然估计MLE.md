# 最大似然估计 MLE

MLE 是概率论通往 ML 的**核心桥梁**：逻辑回归、线性回归的损失函数，本质都是 MLE。

## 1. 核心思想

**已知数据，反推最可能产生这组数据的参数。**

```python
# 问题：有一堆数据，假设它来自某个分布（如正态 N(μ, σ²)）
# 但 μ、σ² 未知，怎么估计？

# MLE 答案：找使"观察到这组数据的概率最大"的参数
θ̂ = argmax P(数据 | θ)
```

**一句话**：参数未知，就选"最可能解释眼前数据"的那个值。

## 2. 似然函数

**定义**：似然函数 = 把参数 θ 当成变量，数据固定时的"出现概率"。

```python
L(θ) = P(数据 | θ) = Πᵢ P(xᵢ | θ)
# Π 表示连乘（假设各数据独立）
```

**注意**：似然函数是关于 **θ** 的函数（数据已知），不是关于数据的。

## 3. 对数似然（为什么要取 log）

连乘 → 取 log 变连加，好求导：

```python
log L(θ) = Σᵢ log P(xᵢ | θ)
# 连乘变连加，且 log 是单调函数，不改变最大值的位置
```

**这是 MLE 的标准操作**：`log` 让"乘积"变"求和"，求导方便。

## 4. 求解：求导 = 0

```python
∂ log L(θ) / ∂θ = 0  →  解出 θ̂
```

## 5. 例子一：掷硬币（二项分布）

抛 n 次，正面 k 次，估计正面概率 p：

```python
L(p) = C(n,k) · pᵏ · (1-p)ⁿ⁻ᵏ

log L(p) = k·log p + (n-k)·log(1-p) + 常数

求导 = 0：
∂logL/∂p = k/p - (n-k)/(1-p) = 0
→  p̂ = k/n      # 就是"频率"！
```

**结论**：硬币正面概率的 MLE 估计 = 正面次数/总次数。符合直觉。

## 6. 例子二：正态分布参数估计（经典推导）

数据 x₁...xₙ 来自 N(μ, σ²)，估计 μ 和 σ²：

```python
# 似然
L(μ, σ²) = Πᵢ (1/σ√2π) · exp(-(xᵢ-μ)² / 2σ²)

# 对数似然
log L = -n·log(σ) - n/2·log(2π) - Σ(xᵢ-μ)² / 2σ²

# 对 μ 求导 = 0：
∂logL/∂μ = Σ(xᵢ-μ)/σ² = 0
→  μ̂ = (1/n) Σ xᵢ          # 样本均值

# 对 σ² 求导 = 0：
→  σ̂² = (1/n) Σ(xᵢ-μ)²      # 样本方差
```

**结论**：正态分布的 MLE 估计 = 样本均值、样本方差。又一次符合直觉。

## 7. 重点：MLE = 最小二乘 = 损失函数（ML 桥梁）

线性回归：假设 `y = wx + b + ε`，其中噪声 `ε ~ N(0, σ²)`。

```python
# 给定 xᵢ，yᵢ 服从 N(wxᵢ+b, σ²)
# 似然：
L(w,b) = Πᵢ (1/σ√2π) exp(-(yᵢ - wxᵢ - b)² / 2σ²)

# 对数似然：
log L = -Σ(yᵢ - wxᵢ - b)² / 2σ² + 常数

# 最大化 log L = 最小化 Σ(yᵢ - wxᵢ - b)²
# 右边就是均方误差 MSE！
```

**结论**：
```
高斯噪声假设下的 MLE = 最小化平方误差 = MSE 损失函数
```

**这就是为什么线性回归用 MSE、逻辑回归用交叉熵**——它们都是 MLE 在不同分布假设下的结果：

| 假设 | MLE 推出的损失函数 |
|------|-------------------|
| 高斯噪声 | 均方误差 MSE（线性回归） |
| 伯努利（二分类） | 交叉熵（逻辑回归） |

## 8. MLE vs MAP vs 贝叶斯估计（对比）

三种参数估计，区别在"把参数当什么"：

| 方法 | 把参数 θ 当什么 | 优化什么 | 学派 |
|------|----------------|---------|------|
| **MLE** 最大似然 | 未知常数 | `argmax P(数据\|θ)` | 频率派 |
| **MAP** 最大后验 | 随机变量（有先验） | `argmax P(数据\|θ)·P(θ)` | 贝叶斯派 |
| 贝叶斯估计 | 随机变量（完整分布） | 算后验分布 P(θ\|数据) | 贝叶斯派 |

**一句话区别**（要点）：

```python
# MLE：只看数据，不看任何先验
θ̂ = argmax P(数据|θ)

# MAP：MLE 再乘一个先验 P(θ)（数据不足时，先验兜底）
θ̂ = argmax P(数据|θ) · P(θ)

# 贝叶斯：不算单个 θ̂，算整个后验分布 P(θ|数据)
```

**例子**（掷硬币，抛 3 次全正面）：

```python
# MLE：p̂ = 3/3 = 1.0（太极端！以后都是正面？）
# MAP：先验假设"硬币一般接近 0.5"，拉回一点 → p̂ ≈ 0.7
# 贝叶斯：给出 p 的完整分布（比如 Beta 分布），能看到不确定性
```

**ML 里的体现**：**正则化 = MAP 的先验**！

```python
# L2 正则化（最优化 04 章）：
# 损失 + λ·Σw²
# 等价于：先验 P(w) ~ 正态分布 N(0, 1/λ) 的 MAP 估计
# 先验说"参数应该小"，数据说"要拟合"——MAP 折中两者
```

## 9. numpy 验证

```python
import numpy as np

# 生成 N(5, 2) 的数据，用 MLE 估计参数
true_mu, true_sigma = 5, 2
x = np.random.normal(true_mu, true_sigma, 10000)

mu_hat = x.mean()              # μ̂ = 样本均值 → ≈ 5
sigma_hat = x.std()            # σ̂ = 样本标准差 → ≈ 2

print(mu_hat, sigma_hat)       # 接近真实值
```

## 小结

1. **MLE** = 找"最可能产生这组数据"的参数
2. **似然函数** L(θ) = P(数据|θ)，取 log 变连加好求导
3. **求导 = 0** 解出参数估计
4. **MLE = 损失函数**：高斯噪声 → MSE；伯努利 → 交叉熵（ML 的核心桥梁）
