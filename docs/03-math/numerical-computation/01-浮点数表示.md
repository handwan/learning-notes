# 浮点数表示

计算机怎么存小数（IEEE 754）。所有数值计算误差的根源。

## 1. IEEE 754 格式

浮点数 = 三部分组成：

```
符号位 | 指数 | 尾数（有效数字）
 1 bit  | 8/11 | 23/52

float  = 1 + 8 + 23 = 32 位
double = 1 + 11 + 52 = 64 位
```

**科学计数法（二进制版）**：

```python
13.5 = 1101.1（二进制）= 1.1011 × 2³
# 存储：符号 0，指数 3，尾数 1011
```

## 2. float vs double

| | float | double |
|--|-------|--------|
| 位数 | 32 | 64 |
| 有效数字 | 约 7 位十进制 | 约 15 位十进制 |
| 范围 | ±3.4×10³⁸ | ±1.7×10³⁰⁸ |
| 用途 | 图形、显存受限 | **默认选择** |

**工程建议**：**默认用 double**（精度够、开销差异小）；显存/带宽受限（GPU、嵌入式）才用 float。

## 3. 0.1 + 0.2 ≠ 0.3 之谜（高频）

```python
0.1 + 0.2 == 0.3     # → False！
0.1 + 0.2            # → 0.30000000000000004
```

**原因**：0.1 在二进制里是**无限循环小数**（就像十进制的 1/3 = 0.3333...），计算机只能存有限位，所以有**舍入误差**。0.1、0.2、0.3 各自都有误差，加起来的误差和 0.3 的误差对不上。

```python
# 十进制 0.1 = 二进制 0.0001100110011001100...（1100 无限循环）
# 只能截断到 52 位尾数 → 舍入 → 不精确
```

**所以**：**浮点数比较不能用 `==`**，要用误差容限：

```cpp
// 正确比较方式：
if (std::fabs(a - b) < 1e-9) { /* 认为相等 */ }
```

## 4. 特殊值

```cpp
double a = 1.0 / 0.0;     // +inf（正无穷）
double b = -1.0 / 0.0;    // -inf
double c = 0.0 / 0.0;     // NaN（Not a Number，未定义结果）
double d = sqrt(-1.0);    // NaN

std::isinf(a);            // 判断无穷
std::isnan(c);            // 判断 NaN
// ⚠️ NaN != NaN 永远为 true（NaN 不等于任何数，包括自己）
```

**场景**：除零、溢出（超出范围变 inf）、无效运算（sqrt 负数）→ 这些都不会报错，静默产生 inf/NaN，是隐藏 bug 的来源。

### NaN 的传播（工程坑）

**NaN 会"传染"**：任何数和 NaN 运算，结果还是 NaN：

```cpp
double x = 0.0 / 0.0;    // NaN
double y = x + 1;        // NaN（传播）
double z = x * 2;        // NaN
sqrt(x);                 // NaN
// 一条 NaN 静默污染整条计算链，最后输出 NaN 也不知道哪里开始错的
```

**工程影响**：AI 推理代码里，一个溢出产生 NaN → 逐层传播 → 最终模型输出全是 NaN，而且**不报错**，排查很费劲。

**排查方法**：

- 定位第一处 NaN：打印中间结果、二分定位
- 用 `-fsanitize=float-divide-by-zero` 等编译选项辅助检测
- 计算后主动检查：`if (std::isnan(result)) { /* 记录日志 */ }`

## 5. numpy 验证

```python
import numpy as np

np.float32(0.1)          # 0.1 存成 float32 的近似值
0.1 + 0.2 == 0.3         # False

np.finfo(np.float32).eps  # float32 的机器精度 ~1.19e-7
np.finfo(np.float64).eps  # float64 的机器精度 ~2.22e-16

np.inf, np.nan           # 特殊值
np.isnan(np.nan)         # True
```

## 6. 小结

1. **IEEE 754**：符号 + 指数 + 尾数（float 32 位 / double 64 位）
2. **浮点比较不能用 ==**（0.1+0.2≠0.3），用容限
3. **特殊值**：inf（溢出/除零）、NaN（无效运算，NaN≠NaN）
4. 默认用 double；GPU/嵌入式才 float
