# 数值计算

计算机有限精度下的计算：误差、经典数值方法、稳定性、量化。

## 1. 浮点数表示

IEEE 754、float vs double、特殊值（inf/NaN）。

## 2. 误差与精度损失

舍入误差、0.1+0.2 之谜、大数吃小数、相减抵消。

## 3. 数值稳定性

条件数、病态问题、稳定 vs 不稳定算法。

## 4. 方程求根

二分法、牛顿法。

## 5. 线性方程组求解

高斯消元、LU 分解、迭代法。

## 6. 插值与拟合

多项式插值、样条、最小二乘拟合。

## 7. 数值积分

梯形法、辛普森法。

## 8. 特征值计算

幂迭代法、QR 算法。

## 9. AI 部署的数值问题

模型量化（FP32 → FP16 → INT8）、混合精度。
