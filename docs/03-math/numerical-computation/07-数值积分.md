# 数值积分

计算机怎么算定积分 ∫f(x)dx。核心思想：**用简单图形近似曲线下的面积**。

## 1. 梯形法（Trapezoidal Rule）

**思想**：把曲线下的面积，用一个个**梯形**近似：

```python
import numpy as np

def trapezoidal(f, a, b, n):
    h = (b - a) / n
    x = np.linspace(a, b, n + 1)
    y = f(x)
    return h * (y[0]/2 + np.sum(y[1:-1]) + y[-1]/2)

# ∫₀¹ x² dx = 1/3 ≈ 0.3333
trapezoidal(lambda x: x**2, 0, 1, 1000)   # → 0.3333
```

**直觉**：每个小区间上，用直线（梯形的顶边）代替曲线。n 越大越准。

## 2. 辛普森法（Simpson's Rule）

**思想**：用**抛物线**（二次曲线）代替直线近似，更准：

```python
def simpson(f, a, b, n):
    if n % 2: n += 1        # n 必须为偶数
    h = (b - a) / n
    x = np.linspace(a, b, n + 1)
    y = f(x)
    return h/3 * (y[0] + y[-1] + 4*np.sum(y[1:-1:2]) + 2*np.sum(y[2:-1:2]))

simpson(lambda x: x**2, 0, 1, 100)   # → 0.3333（更少的 n 就够准）
```

**对比**：辛普森法比梯形法**收敛更快**（同样的 n 更准），是默认选择。

## 3. 误差对比

| 方法 | 每段近似 | 误差阶 |
|------|---------|--------|
| 梯形法 | 直线 | O(h²) |
| 辛普森法 | 抛物线 | O(h⁴) |

h 减半：梯形误差降 4 倍，辛普森降 16 倍——所以辛普森更受欢迎。

## 4. 为什么 ML 需要数值积分

1. **概率论**：连续分布的期望/概率用积分，无解析解时用数值积分
2. **贝叶斯推断**：后验分布的归一化常数（积分）常数值求解
3. 大多时候直接用库（`scipy.integrate.quad`），不用手写

```python
from scipy.integrate import quad
quad(lambda x: x**2, 0, 1)   # → (0.3333, 误差估计)
```

## 5. 小结

1. **数值积分**：用简单图形近似面积
2. **梯形法**：直线近似，O(h²)
3. **辛普森法**：抛物线近似，O(h⁴)，更准，默认选它
4. ML 里概率计算、贝叶斯用，但都用库（scipy.integrate）
