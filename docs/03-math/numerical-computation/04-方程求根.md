# 方程求根

求 f(x) = 0 的解。核心是**二分法**（稳）和**牛顿法**（快）。

## 1. 二分法（Bisection）

**思想**：利用"零点定理"——f(a) 和 f(b) 异号，则 (a,b) 之间必有根。不断对半缩小区间：

```python
def bisection(f, a, b, tol=1e-6):
    if f(a) * f(b) > 0:
        raise ValueError("区间端点必须异号")
    while (b - a) / 2 > tol:
        mid = (a + b) / 2
        if f(mid) == 0:
            return mid
        elif f(a) * f(mid) < 0:   # 根在左半
            b = mid
        else:                      # 根在右半
            a = mid
    return (a + b) / 2

import math
bisection(lambda x: x**2 - 2, 1, 2)   # 求 √2 ≈ 1.4142
```

**特点**：

- ✅ 简单、稳定、一定收敛（只要端点异号）
- ❌ 慢（线性收敛，每次只缩一半）

## 2. 牛顿法（Newton's Method）

**思想**：用切线逼近——在 x 处画切线，切线和 x 轴的交点作为下一个近似：

```python
x_new = x - f(x) / f'(x)
```

```python
def newton(f, df, x0, tol=1e-6, max_iter=100):
    x = x0
    for _ in range(max_iter):
        x_new = x - f(x) / df(x)
        if abs(x_new - x) < tol:
            return x_new
        x = x_new
    return x

newton(lambda x: x**2 - 2, lambda x: 2*x, 1.0)   # 求 √2
```

**特点**：

- ✅ 快（二次收敛，精度翻倍式增长）
- ❌ 依赖初值（初值差可能不收敛）、要算导数、导数接近 0 时出问题

## 3. 对比

| | 二分法 | 牛顿法 |
|--|--------|--------|
| 收敛速度 | 线性（慢） | 二次（快） |
| 可靠性 | 稳（一定收敛） | 依赖初值 |
| 需要导数 | 否 | 是 |
| 用途 | 保险起见 | 初值好时追求快 |

**实践**：先用二分法圈定区间，再用牛顿法加速——两者结合。

## 4. 和 ML 的关系

- 牛顿法在**最优化**里用于找"梯度=0 的点"（之前提过，参数多时 Hessian 求逆太贵）
- 逻辑回归、部分优化器用牛顿法的变体（拟牛顿法 BFGS）

## 5. 小结

1. **二分法**：异号对半缩，稳但慢
2. **牛顿法**：切线逼近，快但依赖初值
3. 求根 → 推广到最优化（找梯度零点）
