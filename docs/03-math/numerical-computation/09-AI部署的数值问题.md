# AI 部署的数值问题

数值计算在 AI 部署（C++ 推理方向）里的应用：模型量化、精度权衡。

## 1. 模型里都是什么精度

```python
训练时：FP32（float，32 位）——主流训练精度
部署时：FP16（16 位）甚至 INT8（8 位整数）——为了快和省显存
```

**为什么部署要降精度**：

| 精度 | 显存 | 速度 | 精度 |
|------|------|------|------|
| FP32 | 4 字节/参数 | 基准 | 基准 |
| FP16 | 2 字节/参数 | 快 2x+ | 略差 |
| INT8 | 1 字节/参数 | 快 4x+ | 要小心校准 |

一个 1 亿参数的模型：FP32 要 400MB，INT8 只要 100MB——显存和带宽直接省 4 倍。

## 2. 量化（Quantization）

**定义**：把 FP32 权重映射到低精度（FP16/INT8）。

```python
# INT8 量化的基本思想：
# 浮点值 x → 整数 q = round(x / scale) + zero_point
# 反量化：x ≈ scale · (q - zero_point)
# scale（步长）和 zero_point 是量化参数

# 例如范围 [-3.0, 3.0] 映射到 [-127, 127]：
# scale = 3.0/127 ≈ 0.0236
# x = 1.5 → q = round(1.5/0.0236) = 64
```

**精度损失来源**：映射是"取整"，每个权重都丢一点精度 → 模型输出有误差。

## 3. 量化带来的问题（数值计算视角）

**① 溢出**：激活值超出表示范围（INT8 最大 127，超了饱和截断）。

**② 精度损失累积**：每层都舍入，深层网络误差累积。

**③ 部分层敏感**：某些层（如 softmax、归一化层）对精度极敏感，量化后效果骤降 → 这些层**保留高精度**（混合精度）。

## 4. 混合精度训练/推理

**做法**：大部分运算用低精度，敏感部分用高精度：

```python
# 混合精度推理的典型配置：
# 卷积/矩阵乘 → INT8/FP16（快）
# softmax / LayerNorm → FP32（保精度）
# 累加器 → FP32（防大数吃小数/溢出）
```

**这正是数值计算知识的用武之地**：知道"哪里会溢出、哪里会丢精度"，才能设计混合精度方案。

## 5. 和 C++ 方向的关系

做 AI 推理部署（TensorRT 等）时，天天打交道的就是：

```
FP32 模型 → 量化校准（找 scale/zero_point）→ INT8 模型 → 验证精度不掉 → 部署
```

- 懂数值计算 → 理解量化为什么掉精度、哪层不能量
- 会 C++ → 写量化 kernel、优化推理速度

**这就是"数值计算"最有价值的应用场景之一**。

## 6. 小结

1. **量化** = FP32 → FP16/INT8，换显存和速度
2. **精度损失来源**：取整舍入、溢出截断、误差累积
3. **混合精度**：敏感层保高精度，其余低精度
4. AI 推理部署 = 数值计算 + C++ 的交叉应用
