# 线性方程组的数值解

解 Ax = b 的数值方法：高斯消元、LU 分解、迭代法。

## 1. 高斯消元（最基础）

线代 03 章讲过原理，这里看**数值实现和坑**：

```python
import numpy as np

def gaussian_elimination(A, b):
    n = len(b)
    # 增广矩阵
    Ab = np.concatenate([A, b.reshape(-1, 1)], axis=1)
    for i in range(n):
        # 选主元（找当前列绝对值最大的行，避免主元为 0 或太小）
        pivot = np.argmax(np.abs(Ab[i:, i])) + i
        Ab[[i, pivot]] = Ab[[pivot, i]]
        # 消元
        for j in range(i+1, n):
            factor = Ab[j, i] / Ab[i, i]
            Ab[j] -= factor * Ab[i]
    # 回代
    x = np.zeros(n)
    for i in range(n-1, -1, -1):
        x[i] = (Ab[i, -1] - Ab[i, i+1:n] @ x[i+1:n]) / Ab[i, i]
    return x

A = np.array([[2.0, 1.0], [1.0, 3.0]])
b = np.array([5.0, 8.0])
gaussian_elimination(A, b)   # → [1.4, 2.2]（2x+y=5, x+3y=8）
```

**关键坑：选主元**。主元太小（接近 0）会导致除法放大误差，所以要"选主元"（换行）。

## 2. LU 分解

**思想**：把 A 分解成下三角 L × 上三角 U，之后解多次方程组就快：

```python
# A = LU
# 解 Ax = b 变成两步：
# 1. 解 Ly = b（前代，O(n²)）
# 2. 解 Ux = y（回代，O(n²)）

# 好处：同一个 A 解多个不同的 b 时，只分解一次，后续都 O(n²)
```

```python
import scipy.linalg as la
# （scipy 有现成的，numpy 没有直接 LU 求解）
P, L, U = la.lu(A)          # P 是置换矩阵（选主元的结果）
```

**用途**：求解器的核心（很多库内部就是 LU/Cholesky 分解）。

## 3. 迭代法（大稀疏矩阵用）

**思想**：高斯消元对大规模稀疏矩阵慢（会"填满"稀疏结构）。迭代法从初值出发，反复逼近：

```python
# 雅可比迭代（Jacobi）：
x⁽ᵏ⁺¹⁾ᵢ = (bᵢ - Σⱼ≠ᵢ aᵢⱼx⁽ᵏ⁾ⱼ) / aᵢᵢ

def jacobi(A, b, x0, max_iter=1000, tol=1e-6):
    x = x0.copy()
    n = len(b)
    for _ in range(max_iter):
        x_new = np.zeros(n)
        for i in range(n):
            s = sum(A[i, j] * x[j] for j in range(n) if j != i)
            x_new[i] = (b[i] - s) / A[i, i]
        if np.linalg.norm(x_new - x) < tol:
            return x_new
        x = x_new
    return x
```

**适用**：大规模、稀疏矩阵（如有限元、图像处理、PageRank）。

## 4. 对比

| 方法 | 适合 | 特点 |
|------|------|------|
| 高斯消元 | 小/中规模稠密矩阵 | 直接法，一次到位 |
| LU 分解 | 同 A 解多个 b | 分解一次复用 |
| 迭代法 | 大规模稀疏矩阵 | 逐步逼近，省内存 |

## 5. 小结

1. **高斯消元**：选主元防误差放大
2. **LU 分解**：A=LU，解多个 b 时快
3. **迭代法**：大规模稀疏矩阵用
4. 日常用 `np.linalg.solve`（内部就是这些方法，已优化）
