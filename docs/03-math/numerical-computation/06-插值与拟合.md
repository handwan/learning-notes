# 插值与拟合

给定一些数据点，怎么"补出"中间的值（插值），或"找出"趋势（拟合）。

## 1. 插值 vs 拟合（先分清）

| | 插值 | 拟合 |
|--|------|------|
| 目的 | 曲线**精确通过**所有数据点 | 曲线**逼近**数据（不要求通过） |
| 适用 | 数据准（无噪声） | 数据有噪声（真实场景） |
| 例子 | 多项式插值、样条 | 最小二乘（线代 08 章） |

## 2. 多项式插值

**思想**：用 n 次多项式通过 n+1 个点。

```python
import numpy as np

# 拉格朗日插值：
def lagrange(x_points, y_points, x):
    result = 0.0
    n = len(x_points)
    for i in range(n):
        term = y_points[i]
        for j in range(n):
            if j != i:
                term *= (x - x_points[j]) / (x_points[i] - x_points[j])
        result += term
    return result

x_points = [0, 1, 2, 3]
y_points = [0, 1, 4, 9]      # y = x²
lagrange(x_points, y_points, 1.5)   # → 2.25（x²在1.5的值）✓
```

**注意**：高次多项式插值会**震荡**（龙格现象）——点越多、次数越高，两端反而翘起来。所以实践里常用**分段低次插值**（如样条）。

## 3. 样条插值（实践常用）

**思想**：不用一个高次多项式，而是**每段用一个低次多项式**（通常是三次），段与段之间光滑连接：

```python
from scipy.interpolate import CubicSpline

x = np.array([0, 1, 2, 3, 4, 5])
y = np.array([0, 1, 0, 1, 0, 1])   # 任意数据
cs = CubicSpline(x, y)
cs(2.5)     # 插值出 2.5 处的值
```

**为什么常用**：三次样条光滑（一阶二阶导连续）、不会震荡，是工程插值的事实标准。

## 4. 拟合（最小二乘）

线代 08 章讲过，这里回顾 + 代码：

```python
import numpy as np

# 数据有噪声，拟合直线 y = ax + b
x = np.array([1, 2, 3, 4, 5])
y = np.array([2.1, 3.9, 6.2, 7.8, 10.1])   # 有噪声

A = np.column_stack([x, np.ones_like(x)])
coeff = np.linalg.lstsq(A, y, rcond=None)[0]   # 最小二乘 → [a, b]
print(coeff)     # → [2.0, 0.0] 附近（y ≈ 2x）
```

## 5. 小结

1. **插值**：曲线精确过点（数据无噪声）
2. **拟合**：曲线逼近数据（数据有噪声，用最小二乘）
3. 多项式插值高次会震荡（龙格现象）→ 用**样条**
4. ML 里"拟合"无处不在（模型就是在拟合数据），插值用的少
