# 数值稳定性

数值稳定性 = 算法会不会把输入的小误差**放大**成输出的大误差。

## 1. 稳定 vs 不稳定算法

```python
# 稳定算法：输入小扰动 → 输出小变化（误差不放大）
# 不稳定算法：输入小扰动 → 输出巨大变化（误差爆炸）
```

**例子：softmax 的朴素实现不稳定**

```python
# 朴素 softmax：
def softmax(x):
    e = np.exp(x)
    return e / e.sum()

x = np.array([1000, 1000, 1000])   # 值太大
# exp(1000) 溢出 → inf → inf/inf = NaN！
```

**稳定写法（减去最大值）**：

```python
def stable_softmax(x):
    m = x.max()                    # 先减最大值
    e = np.exp(x - m)              # 现在指数 ≤ 0，不溢出
    return e / e.sum()

# softmax(x) == softmax(x - 常数)，数学等价但数值稳定
```

**这就是"数值稳定技巧"**：数学上等价，但计算方式不同，误差天差地别。

## 2. 条件数（Condition Number）

**定义**：衡量"输入扰动会被放大多少倍"：

```python
条件数大 → 问题病态（ill-conditioned）→ 输入一点点误差，输出差很多
条件数小 → 问题良态（well-conditioned）
```

**线代的例子**（连线性代数）：

```cpp
// 解 Ax = b，如果 A 接近奇异（det ≈ 0）
// A 的条件数巨大 → b 的一点误差 → x 的巨大误差
// 判断：np.linalg.cond(A)
```

## 3. 稳定性的经典案例

### ① sigmoid 的溢出

```cpp
// σ(x) = 1/(1+e⁻ˣ)
// x 很大（如 1000）→ e⁻¹⁰⁰⁰ ≈ 0 → σ ≈ 1（正常）
// x 很小（如 -1000）→ e¹⁰⁰⁰ 溢出成 inf → 1/(1+inf) = 0
//   （结果 0 恰好是对的，但中间 inf 会报警告；在含 exp 的复合表达式里可能变成 inf-inf = NaN）
// 稳定写法：x ≥ 0 用 σ(x) = 1/(1+e⁻ˣ)；x < 0 用 σ(x) = eˣ/(1+eˣ)（避免中间溢出）
```

### ② 交叉熵的 log(0)

```cpp
// 交叉熵：-log(p)，当 p = 0 时 log(0) = -inf
// 实践：给 p 加极小值，如 -log(p + 1e-12)
```

### ③ 方差的两种算法

```python
# 公式 1：E[x²] - E[x]²（朴素，可能因为"相减抵消"变负）
# 公式 2：Σ(x - mean)²（更稳定）
```

## 4. numpy 验证

```python
import numpy as np

# softmax 溢出
x = np.array([1000, 1000, 1000])
try:
    e = np.exp(x)
    print(e / e.sum())      # → nan（溢出）
except:
    pass
# 稳定版
m = x.max()
e = np.exp(x - m)
print(e / e.sum())          # → [0.33, 0.33, 0.33] ✓

# 条件数
A = np.array([[1, 1], [1, 1.0001]])    # 接近奇异
print(np.linalg.cond(A))               # 条件数巨大 → 病态
```

## 5. 小结

1. **数值稳定**：误差不放大；不稳定算法会让小误差爆炸
2. **经典技巧**：softmax 减最大值、sigmoid 分段、log 加极小值
3. **条件数**：衡量问题本身是否病态（连线性代数 A 接近奇异）
4. ML 里写代码要会用"稳定版公式"，这是基础工程素养
