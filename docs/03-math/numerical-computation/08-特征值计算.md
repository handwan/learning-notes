# 特征值计算

计算机怎么算矩阵的特征值。核心是**幂迭代法**和 **QR 算法**。

## 1. 幂迭代法（Power Iteration）

**目的**：求**最大**特征值（按模）和对应特征向量。

**思想**：反复乘矩阵，向量会"转"到主特征向量方向：

```python
import numpy as np

def power_iteration(A, max_iter=1000, tol=1e-6):
    n = A.shape[0]
    v = np.random.rand(n)            # 随机初始向量
    v = v / np.linalg.norm(v)
    lambda_old = 0
    for _ in range(max_iter):
        w = A @ v                    # 乘矩阵
        v = w / np.linalg.norm(w)    # 归一化
        lam = v @ A @ v              # 瑞利商估算特征值
        if abs(lam - lambda_old) < tol:
            return lam, v
        lambda_old = lam
    return lam, v

A = np.array([[3.0, 0.0], [0.0, 1.0]])   # 特征值 3 和 1
lam, vec = power_iteration(A)
print(lam, vec)    # → 最大特征值 3，对应 [1, 0]
```

**为什么有效**：任意向量 v = c₁e₁ + c₂e₂ + ...，乘 A^k 后 = c₁λ₁ᵏe₁ + c₂λ₂ᵏe₂ + ...，λ₁ 最大 → 其他项相对衰减 → 只剩 e₁ 方向。

## 2. QR 算法

**目的**：求**所有**特征值（不只是最大的）。

**思想**：反复做"QR 分解 + 重乘"，矩阵逐渐收敛到上三角，对角线就是特征值：

```python
def qr_algorithm(A, max_iter=1000, tol=1e-8):
    A_k = A.copy()
    for _ in range(max_iter):
        Q, R = np.linalg.qr(A_k)     # QR 分解
        A_k = R @ Q                  # 重乘
        # 下三角元素趋近 0 时，对角线 = 特征值
        off_diag = np.tril(A_k, -1)
        if np.linalg.norm(off_diag) < tol:
            break
    return np.diag(A_k)              # 对角线就是特征值

A = np.array([[3.0, 1.0], [0.0, 1.0]])
qr_algorithm(A)   # → [3, 1]
```

**本质**：QR 迭代相当于"隐式的幂迭代"，同时收敛出所有特征值。

## 3. 为什么 ML 关心特征值计算

1. **PCA**：主成分 = 协方差矩阵的特征向量（用幂迭代/SVD 算）
2. **SVD**：`np.linalg.svd` 内部就用 QR/幂迭代类算法
3. 大规模矩阵用迭代法（幂迭代），小矩阵用 QR

```python
# 实践：直接调库，不用手写
np.linalg.eig(A)      # 特征值（小矩阵，QR 类算法）
np.linalg.svd(A)      # 奇异值（内部含 QR）
```

## 4. 小结

1. **幂迭代**：反复乘矩阵，收敛到最大特征值（用于 PCA/PageRank）
2. **QR 算法**：QR 分解反复迭代，收敛出所有特征值
3. 实践直接调 `np.linalg.eig/svd`，内部就是这些算法
