# 二次型

二次型是"纯二次项的表达式"，核心是**正定性**——它直接关系到机器学习里"损失函数有没有唯一最小值"，非常重要。

## 1. 二次型是什么

**定义**：形如 `xᵀAx` 的表达式，其中 A 是**对称矩阵**，x 是向量。

```python
# 二维展开：
xᵀAx = [x, y] [[a, b],     [x]
               [b, c]]  ·  [y]
     = a·x² + 2b·xy + c·y²
```

**本质**：一个只含**二次项**的多项式（没有一次项、常数项）。

## 2. 几何意义

二次型 `xᵀAx = 常数` 画出来是**二次曲线/曲面**：

| 类型 | 方程 | 图像 |
|------|------|------|
| 正定 | `x² + y² = 1` | 椭圆（碗状，向上凸） |
| 负定 | `-x² - y² = 1` | 无实解（倒碗） |
| 不定 | `x² - y² = 1` | 双曲线（马鞍面） |

**关键直觉**：二次型对应一个"碗"的形状。正定 = 碗朝上（有唯一最低点），不定 = 马鞍（中间是鞍点）。

## 3. 正定性分类

对称矩阵 A 按 `xᵀAx` 的取值分类：

| 类型 | 条件 | 图像 |
|------|------|------|
| **正定** | `xᵀAx > 0`（对所有 x≠0） | 碗朝上 |
| **半正定** | `xᵀAx ≥ 0` | 碗朝上，但底是平的 |
| **负定** | `xᵀAx < 0` | 碗朝下 |
| **不定** | 有正有负 | 马鞍面 |

```python
A = [[1, 0],
     [0, 1]]      # 正定：x² + y² > 0（除非 x=y=0）

B = [[1, 0],
     [0, -1]]     # 不定：x² - y² 可正可负
```

## 4. 判断正定性的方法

**方法一：特征值（最直观）**

```python
正定   ⇔  所有特征值 > 0
半正定 ⇔  所有特征值 ≥ 0
负定   ⇔  所有特征值 < 0
不定   ⇔  有正有负
```

```python
import numpy as np
A = np.array([[2, 0],
              [0, 3]])
np.linalg.eigvals(A)      # → [2, 3]，全正 → 正定
```

**方法二：顺序主子式（Sylvester 判据）**

```python
正定 ⇔ 所有顺序主子式 > 0

A = [[a, b],
     [b, c]]
# 顺序主子式：a > 0 且 ac - b² > 0
```

## 5. 为什么机器学习关心它（重点）

**1. 损失函数 = 二次型**

很多损失函数（如线性回归的 MSE）是二次型。若它**正定**，则函数是**凸的**，有**唯一全局最小值**，梯度下降能保证收敛到最优解。

```python
损失 = xᵀAx - 2bᵀx + c
若 A 正定 → 凸函数 → 有唯一最小值
```

**2. Hessian 矩阵判断极值**

多元函数在某点的二阶导数矩阵（Hessian）：

```python
Hessian 正定  →  局部最小值
Hessian 负定  →  局部最大值
Hessian 不定  →  鞍点
```

**3. 协方差矩阵**

数据的协方差矩阵是**半正定**的，PCA 就建立在它的特征分解上。

## 6. numpy 验证

```python
import numpy as np

# 判断正定
def is_positive_definite(A):
    return np.all(np.linalg.eigvals(A) > 0)

A = np.array([[2, 0],
              [0, 3]])
is_positive_definite(A)     # True（正定）

B = np.array([[1, 0],
              [0, -1]])
is_positive_definite(B)     # False（不定）

# 二次型的值
x = np.array([1, 1])
x @ A @ x                   # → 5 > 0
x @ B @ x                   # → 0（正负抵消）
```

## 小结

1. **二次型 = xᵀAx**，纯二次项的多项式
2. **正定 = 所有 x≠0 都有 xᵀAx > 0**（碗朝上）
3. **判断：特征值全正 ⇔ 正定**
4. **应用**：损失函数正定 → 凸 → 有唯一最小值；Hessian 正定 → 局部最小值
