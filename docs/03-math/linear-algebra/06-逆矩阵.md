# 逆矩阵

逆矩阵的**几何意义**：逆变换——把矩阵 A 做的变换"撤销"，回到原来的样子。

## 1. 几何意义：逆变换

矩阵 A 代表一个变换，把向量 v 变成 Av。**逆矩阵 A⁻¹ 就是把 Av 再变回 v**：

```python
A     ：v  → Av      （正向变换）
A⁻¹   ：Av → v       （逆向变换，撤销 A）

A⁻¹·A = I           （先做 A 再做 A⁻¹ = 什么都没做）
```

**直观类比**：A 是"顺时针转 90°"，A⁻¹ 就是"逆时针转 90°"。转过去再转回来，等于没转（单位矩阵 I）。

## 2. 定义

```python
A · A⁻¹ = A⁻¹ · A = I
```

I 是单位矩阵（恒等变换，什么都不改变）。

## 3. 可逆的充要条件

以下说法**全部等价**，矩阵满足一个就满足所有：

| 条件 | 说明 |
|------|------|
| `det(A) ≠ 0` | 行列式非零 |
| 满秩 | 秩 = 列数 |
| 列线性无关 | 没有冗余列 |
| 零空间只有 {0} | 只有零向量被压到原点 |

**一句话**：可逆 ⇔ 变换没有"降维"，信息没丢失。

## 4. 为什么 det = 0 不可逆（关键）

行列式为 0 = 变换**降维**了。降维 = 多个不同向量被压到**同一个点**，信息丢失，无法还原。

```python
A = [[1, 1],
     [1, 1]]      # det = 0，降维

# 变换后：
# [1, -1] → [0, 0]
# [2, -2] → [0, 0]
# 两个不同的输入 → 同一个输出 [0, 0]
# 所以无法知道 [0, 0] 原来是谁 → 不可逆
```

**类比**：把 3D 物体压成 2D 照片，照片无法还原回 3D——维度丢了。

## 5. 求逆

### 2×2 公式

```python
A = [[a, b],
     [c, d]]

A⁻¹ = 1/(ad-bc) · [[d, -b],
                   [-c, a]]
# 分母 ad-bc 就是 det(A)，所以 det=0 时无法求逆
```

### numpy

```python
import numpy as np

A = np.array([[1, 2],
              [3, 4]])

A_inv = np.linalg.inv(A)
A @ A_inv      # → 单位矩阵 [[1,0],[0,1]]
```

## 6. 解方程组与逆矩阵

```python
Ax = b
x = A⁻¹ b     # 两边左乘 A⁻¹
```

**但实际求解不用逆矩阵**，而是用第 3 章的高斯消元。原因：

- 消元更快（逆矩阵要先算 A⁻¹ 再乘，多此一举）
- 消元数值更稳定（逆矩阵可能放大误差）

所以：**逆矩阵是"理论概念"，解方程实操用消元**。

## 7. numpy 验证

```python
import numpy as np

# 可逆矩阵
A = np.array([[2, 1],
              [1, 2]])
np.linalg.det(A)        # → 3.0（非零，可逆）
A_inv = np.linalg.inv(A)
A @ A_inv               # → 单位矩阵

# 不可逆矩阵
B = np.array([[1, 2],
              [2, 4]])
np.linalg.det(B)        # → 0.0（降维，不可逆）
# np.linalg.inv(B)      # 会报错 LinAlgError: Singular matrix
```

## 小结

1. **逆矩阵 = 逆变换**，把 A 的变换"撤销"
2. **可逆 ⇔ det ≠ 0 ⇔ 满秩 ⇔ 列线性无关**（全都等价）
3. **det = 0 = 降维 = 信息丢失 = 不可逆**
4. 求逆用 `np.linalg.inv`，但**解方程实际用消元**
