# 矩阵 = 线性变换

这是全书的**核心视角**：矩阵不是一堆数，而是"空间的变换"。理解了它，后面逆矩阵、行列式、特征值全是它的延伸。

## 1. 什么是变换

**变换 = 函数**，输入一个向量，输出另一个向量。

```python
变换 L：向量 → 新向量
```

比如"旋转 90°"：`[1, 0]` 变成 `[0, 1]`。

叫"变换"不叫"函数"，是因为几何上它把**整个空间**一起动，像揉捏平面。

## 2. 线性变换的两个条件

1. **可加性**：`L(v + w) = L(v) + L(w)`
2. **齐次性**：`L(c·v) = c·L(v)`

**几何表现**：网格线变换后**仍平行且等距**（可以转、可以拉伸，但格子还是格子），且**原点不动**。

旋转、缩放、剪切都是线性变换；弯曲则不是。

## 3. 核心洞察：矩阵的列 = 基向量的去向

一个线性变换，只要知道基向量 i、j 去哪了，就完全确定。因为：

```
任意向量 = x·i + y·j
L(x·i + y·j) = x·L(i) + y·L(j)   ← 线性性
```

**i、j 的去向定了，所有向量的去向都定了。**

矩阵就是记录"基向量去哪了"的一张表：

```python
A = [[a, c],
     [b, d]]
# 第一列 [a, b] = i 变换后的去向
# 第二列 [c, d] = j 变换后的去向
```

## 4. 矩阵 × 向量 = 应用变换

```python
[[a, c],   [x]      [a·x + c·y]
 [b, d]] × [y]  =   [b·x + d·y]
```

展开就是 `x·(第一列) + y·(第二列)` = 用**新基向量**重新线性组合出原向量。

**例子**：旋转 90°

```python
# i=[1,0]→[0,1]，j=[0,1]→[-1,0]
R = [[0, -1],
     [1,  0]]

R × [1, 0] → [0, 1]     # 确实转了 90°
```

## 5. 常见线性变换

| 变换 | 矩阵 | 效果 |
|------|------|------|
| 旋转 90° | `[[0,-1],[1,0]]` | 逆时针转 |
| 放大 2 倍 | `[[2,0],[0,2]]` | 整体缩放 |
| 拉伸 x 轴 | `[[2,0],[0,1]]` | 只拉 x 方向 |
| 剪切 | `[[1,1],[0,1]]` | 斜着推 |

## 6. 矩阵 × 矩阵 = 复合变换

先做变换 A，再做变换 B，结果 = **B × A**（从右往左读）：

```python
S @ R      # 先 R 后 S，等价于 S(R(v))
```

**顺序敏感**：`B @ A` 表示"先 A 后 B"，和函数复合 `B(A(v))` 一致，从右往左执行。

## 7. numpy 验证

```python
import numpy as np

R = np.array([[0, -1], [1, 0]])    # 旋转 90°
v = np.array([1, 0])

R @ v        # → [0, 1]，验证旋转

S = np.array([[2, 0], [0, 2]])     # 放大 2 倍
S @ R        # 复合：先旋转后缩放
```

## 小结

1. **线性变换** = 网格线保持平行等距 + 原点不动
2. **矩阵的列 = 基向量 i、j 变换后的去向**（核心）
3. **矩阵乘向量 = 用新基向量重新线性组合**；矩阵乘矩阵 = 复合变换（从右往左）

这章吃透，后面"逆矩阵 = 逆变换""行列式 = 面积缩放比""特征向量 = 方向不变的向量"全是它的延伸。
