# 特征值与特征向量

特征向量是**线性变换中"方向不变"的特殊向量**。它们藏在每个矩阵里，是理解矩阵本质的钥匙，也是 PCA、振动分析、图论等应用的核心。

## 1. 定义

```python
A·v = λ·v
```

- **v**：特征向量（变换后**方向不变**，仍在原来的直线上）
- **λ**：特征值（变换把 v **缩放**了多少倍）

**一句话**：特征向量是"经过 A 变换后，只是被拉伸/压缩、方向不改变"的向量。

## 2. 几何意义

一般向量经过线性变换，方向会转、长度会变。但**特征向量例外**——它们的方向像被"钉住"了，变换只把它们拉长或压短（λ 倍）。

```python
A = [[3, 0],
     [0, 2]]     # 对角矩阵

A·[1, 0] = [3, 0] = 3·[1, 0]     # [1,0] 是特征向量，特征值 3
A·[0, 1] = [0, 2] = 2·[0, 1]     # [0,1] 是特征向量，特征值 2

A·[1, 1] = [3, 2]                # [1,1] 不是特征向量（方向变了）
```

对角矩阵的特征向量就是**基向量本身**——这揭示了"对角化"的本质：**换个基，让变换变成纯缩放**。

## 3. 求解

### 步骤

1. 解特征方程 `det(A - λI) = 0`，得到特征值 λ
2. 对每个 λ，解 `(A - λI)v = 0`，得到特征向量 v

### 例子

```python
A = [[3, 1],
     [0, 2]]

# 1. det(A - λI) = 0
#    (3-λ)(2-λ) = 0
#    λ = 3 或 λ = 2

# 2. λ=3 时，解 (A-3I)v=0 → v=[1,0]
#    λ=2 时，解 (A-2I)v=0 → v=[-1,1]
```

### numpy 一行搞定

```python
import numpy as np
A = np.array([[3, 1],
              [0, 2]])

eigenvalues, eigenvectors = np.linalg.eig(A)
# eigenvalues  = [3, 2]
# eigenvectors = 每列是一个特征向量
```

## 4. 对角化

如果矩阵有 n 个线性无关的特征向量，就能对角化：

```python
A = P · D · P⁻¹
```

- **P**：特征向量拼成的矩阵（换基矩阵）
- **D**：特征值组成的对角矩阵（纯缩放）
- **意义**：A 的变换 = 换到特征向量基(P⁻¹) → 纯缩放(D) → 换回来(P)

### 对角化的用处

```python
A = P·D·P⁻¹
Aⁿ = P·Dⁿ·P⁻¹    # Dⁿ 好算（对角矩阵的 n 次方 = 每个对角元素 n 次方）
```

**应用**：计算矩阵的高次幂、解微分方程、分析系统长期行为。

## 5. 重要性质

| 性质 | 说明 |
|------|------|
| 特征值之和 = 迹 | `λ₁+λ₂ = a+d`（对角线元素和） |
| 特征值之积 = 行列式 | `λ₁·λ₂ = det(A)` |
| 三角矩阵的特征值 | 就是对角线元素 |
| 实对称矩阵 | 特征值全为实数，特征向量正交 |

### 矩阵的迹（trace）

**定义**：对角线元素之和：

```python
A = [[a, b],
     [c, d]]
tr(A) = a + d

import numpy as np
np.trace(A)          # 对角线元素和
```

**关键性质**：

```python
tr(A) = Σ 特征值          # 迹 = 特征值之和
tr(AB) = tr(BA)           # 循环性（可以交换顺序）
tr(A + B) = tr(A) + tr(B) # 线性
```

**ML 用途**：

- 损失函数里用迹表示"平方和"（`||X||² = tr(XᵀX)`）
- 矩阵求导常用（如 `∂tr(AX)/∂X = Aᵀ`）

## 6. 有趣的现象：旋转矩阵

```python
R = [[0, -1],
     [1,  0]]     # 旋转 90°，所有向量方向都变

np.linalg.eig(R)
# 特征值是复数 i 和 -i，没有实数特征向量
```

**几何含义**：旋转把**每个**向量都转了方向，所以没有"方向不变"的实数特征向量。特征值只能是复数——这解释了为什么旋转矩阵的特征值会是复数。

## 7. numpy 验证

```python
import numpy as np

A = np.array([[3, 1],
              [0, 2]])

vals, vecs = np.linalg.eig(A)
print(vals)    # [3. 2.]
print(vecs)    # 每列一个特征向量

# 验证：A·v = λ·v
v = vecs[:, 0]
lam = vals[0]
A @ v          # 应等于 lam * v

# 对角化验证
D = np.diag(vals)
P = vecs
A @ P - P @ D  # 应接近 0
```

## 小结

1. **特征向量 = 方向不变的向量**，特征值 = 缩放倍数
2. **Av = λv**，求法是解 `det(A-λI)=0`
3. **对角化 A = PDP⁻¹** = 换基 → 缩放 → 换回来
4. 特征值之和 = 迹，之积 = 行列式
5. 旋转矩阵没有实数特征向量（特征值是复数）
