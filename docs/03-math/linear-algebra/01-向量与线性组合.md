# 向量与线性组合

一切从"向量"开始。向量、线性组合、张成空间、线性相关/无关，是后面所有概念的基石。

## 1. 向量（Vector）

### 三种视角

- **物理视角**：有方向、有大小（长度）的箭头
- **计算机视角**：一组有序数字，如 `[1, 2]`
- **数学视角**：能相加、能数乘的抽象对象

三者是一个东西：坐标 `[1, 2]` 就代表"从原点向右走 1、向上走 2"的那个箭头。

### 两种基本运算

**加法 = 头尾相接**

```python
[1, 2] + [3, 1] = [4, 3]
# 先走第一个向量，再走第二个向量，终点就是和
```

**数乘 = 缩放**

```python
2 × [1, 2] = [2, 4]     # 拉长 2 倍
-1 × [1, 2] = [-1, -2]  # 反向
```

### 坐标的本质

`[1, 2]` 其实是基向量的数乘之和：

```
[1, 2] = 1 × i + 2 × j      # i = [1, 0]、j = [0, 1]（标准基向量）
```

`[1, 0]` 和 `[0, 1]` 叫**基向量**（i 和 j），任意向量都是它们的线性组合。

## 2. 线性组合（Linear Combination）

**定义**：把若干个向量各自乘一个数，再加起来。

```python
a·v + b·w
# a、b 是标量（系数），v、w 是向量

2·[1,0] + 3·[0,1] = [2, 3]
```

**几何意义**：拿着 v、w 两个"方向"，通过调系数 a、b，就能走到很多位置。坐标系能描述整个平面，靠的就是这个。

## 3. 张成空间（Span）

**定义**：一组向量**所有可能的线性组合**组成的集合。

大白话：系数 a、b 取遍所有实数，这组向量能"扫出"多大范围。

| 情况 | 张成 | 图像 |
|------|------|------|
| 两个向量**不共线** | 整个平面 | 四面八方 |
| 两个向量**共线** | 一条直线 | 再怎么组合还是线 |
| 两个零向量 | 一个点 | 哪都去不了 |

```python
v = [1, 0]; w = [0, 1]    # 不共线 → 张成整个平面
v = [1, 0]; w = [2, 0]    # 共线（w=2v）→ 只张成一条线
```

## 4. 线性相关 / 无关

判断向量组里**有没有冗余**。

- **线性相关**：至少一个向量能由其他向量线性组合表示（多余）
- **线性无关**：每个向量都不能被其他表示（都贡献新维度）

**几何判断**：

| | 相关 | 无关 |
|--|------|------|
| 两个向量 | 共线 | 不共线 |
| 三个向量 | 共面 | 不共面 |

```python
v = [1, 0]
w = [2, 0]      # w = 2·v → {v, w} 相关（共线，有冗余）

a = [1, 0]
b = [3, 5]      # {a, b} 不共线、谁也表示不了谁 → 无关（各贡献一个维度）
```

## 5. numpy 表示

```python
import numpy as np

v = np.array([1, 2])    # 向量 = 一维数组
w = np.array([3, 1])

v + w                    # 加法 → [4, 3]
2 * v                    # 数乘 → [2, 4]
np.linalg.norm(v)        # 长度（模）→ √5

# 判断线性相关：拼成矩阵求秩
A = np.array([[1, 0],
              [2, 0]])   # 两行共线
np.linalg.matrix_rank(A) # → 1，秩 1 说明相关（只张成 1 维）
```

## 小结

1. **向量 = 箭头**，加法是头尾相接，数乘是缩放
2. **线性组合** = 数乘 + 加法拼出结果
3. **张成空间** = 所有组合扫出的范围（线 / 面 / 体）
4. **线性相关 = 有冗余**（共线/共面），**无关 = 每个都贡献新维度**

这四点是理解"向量空间、基、维度、秩"的钥匙。
