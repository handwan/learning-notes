# 线性方程组与消元

线性方程组是线性代数最经典的"落地"问题：给定矩阵 A 和向量 b，求 x 使 **Ax = b**。

## 1. 线性方程组

```python
x + y = 3
x - y = 1
```

用矩阵表示（矩阵 = 线性变换，x 变换后等于 b）：

```
[[1,  1],   [x]     [3]
 [1, -1]] × [y]  =  [1]

   A         x   =   b
```

## 2. 两种几何视角

### 行视角（Row Picture）

每条方程是一条**直线**，方程组的解是这些直线的**交点**。

```
x + y = 3   →  直线 1
x - y = 1   →  直线 2
交点 (2, 1) →  就是解
```

### 列视角（Column Picture，更重要）

把 A 拆成列向量，b 就是这些列的**线性组合**：

```
x · [1, 1] + y · [1, -1] = [3, 1]
    列1          列2         b
```

解 (x, y) 就是"用多少列1、多少列2 拼出 b"。这就是上一章的"线性组合"，所以**解方程 = 找线性组合的系数**。

## 3. 高斯消元（Gaussian Elimination）

核心思想：通过**初等行变换**，把方程消成"阶梯形"，再一步步回代求解。

三种初等行变换：

1. 两行交换
2. 某行乘一个非零数
3. 某行加上另一行的倍数

### 步骤

写成**增广矩阵** `[A | b]`，然后消元：

```python
原方程组：              增广矩阵：
x + y = 3              [1  1 | 3]
x - y = 1              [1 -1 | 1]

# 用第1行消掉第2行的 x：
# 第2行 = 第2行 - 第1行
[1  1 | 3]
[0 -2 | -2]

# 回代：
# -2y = -2  →  y = 1
# x + 1 = 3 →  x = 2
```

### 主元（Pivot）

每行第一个非零元素叫**主元**。消元就是用主元把下面同列的元素"消成 0"。

**主元不能为 0**，若为 0 就和下面换行（这就是"选主元"）。

## 4. 行阶梯形（Row Echelon Form）

消元完成后，矩阵呈"阶梯"形状：

```
[1  1 | 3]
[0 -2 | -2]     ← 阶梯形：每行主元位置逐行右移
```

阶梯形的特征：主元下方的元素全为 0。

## 5. 解的结构（三种情况）

消元完成后，根据结果判断：

| 情况 | 特征 | 例子 |
|------|------|------|
| **唯一解** | 每个变量都有主元 | x=2, y=1 |
| **无解** | 出现 `0 = 非零`（矛盾） | 最后一行 `0 0 | 5` |
| **无穷多解** | 有自由变量（某列没主元） | 变量比方程多 |

### 无解的例子

```python
x + y = 1
x + y = 2        # 矛盾：同一个左边，两个不同的右边

增广矩阵消元后：
[1 1 | 1]
[0 0 | 1]        # 0 = 1，矛盾 → 无解
```

几何意义：两条**平行线**，没有交点。

### 无穷多解的例子

```python
x + y = 2
2x + 2y = 4      # 第二条是第一条的 2 倍，信息重复

消元后：
[1 1 | 2]
[0 0 | 0]        # 最后一行全 0，y 是自由变量

解：x = 2 - y，y 取任意值 → 无穷多解
```

几何意义：两条线**重合**，整条线都是解。

## 6. numpy 求解

```python
import numpy as np

A = np.array([[1, 1],
              [1, -1]])
b = np.array([3, 1])

x = np.linalg.solve(A, b)    # → [2, 1]

np.linalg.matrix_rank(A)     # 秩 = 2，满秩 → 唯一解
```

## 小结

1. **Ax = b**：行视角是求交点，列视角是找线性组合系数
2. **高斯消元**：行变换把矩阵消成阶梯形，主元不能为 0
3. **解有三种**：唯一解 / 无解（0=非零）/ 无穷多解（有自由变量）

理解"解的数量"取决于**秩**和**未知数个数**的关系，就接上了下一章「向量空间与秩」。
