# 内积与正交

内积衡量两个向量的"同向程度"，正交是它的特例（内积为 0）。这套工具引出投影和最小二乘，是机器学习、信号处理的地基。

## 1. 内积（点积）

### 定义

```python
v · w = v₁w₁ + v₂w₂ + ... + vₙwₙ
```

### 几何意义

```python
v · w = ||v|| · ||w|| · cos θ
```

内积的本质是"**两个向量有多同向**"：

| 内积 | 夹角 | 含义 |
|------|------|------|
| `> 0` | < 90° | 方向大致相同 |
| `= 0` | = 90° | 垂直（正交） |
| `< 0` | > 90° | 方向大致相反 |

```python
import numpy as np
v = np.array([1, 0])
w = np.array([0, 1])
v @ w          # → 0（垂直）
np.dot(v, w)   # 同上
```

## 2. 正交

**定义**：两个向量**内积为 0**，几何上就是**垂直**。

```python
[1, 0] · [0, 1] = 0     # 正交（垂直）
```

**为什么重要**：正交的向量"互不干扰"——各自占据独立的方向，像坐标轴一样干净。

## 3. 投影

**定义**：把一个向量 v 投影到另一个向量 w（或子空间）上，得到 v 在 w 方向的"影子"。

```python
proj_w(v) = (v·w / w·w) · w
```

**几何意义**：想象一束垂直的光照下来，v 投在 w 所在直线上的影子。

**公式拆解**（记 ||w|| 为 w 的长度，w·w = ||w||²）：

```python
proj_w(v) = (v·w / w·w) · w
# 展开 w·w = ||w||²，改写成：
#   (v·w / ||w||)  ·  (w / ||w||)
```

即：**投影 = 影子长度（标量）× w 的单位方向**。其中影子长度 = `v·w / ||w||`，单位方向 = `w / ||w||`。

### 投影到子空间

把向量投影到整个子空间（比如一个平面），用于逼近"不在子空间里"的向量——这就是最小二乘的思想。

## 4. 正交基 与 正交矩阵

### 正交基

一组基向量**两两正交**。若再**单位长度**（模为 1），叫**标准正交基**。

```python
i = [1, 0]
j = [0, 1]      # 正交 + 单位长 = 标准正交基
```

**好处**：用标准正交基表示向量，坐标就是内积，计算极简。

### 正交矩阵

矩阵 Q 满足：

```python
Qᵀ Q = I     # 即 Q⁻¹ = Qᵀ
```

**几何意义**：正交矩阵 = **只旋转/镜像、不拉伸**的变换（保长度、保角度）。

```python
# 旋转矩阵就是正交矩阵
R = [[cos θ, -sin θ],
     [sin θ,  cos θ]]
Rᵀ R = I
```

## 5. Gram-Schmidt 正交化

**作用**：把任意线性无关的向量组，变成一组**正交基**。

**思路**：逐个处理，每个向量减去它在前面向量上的投影，剩下的就垂直了：

```python
# 有 v1, v2, v3 ...
u1 = v1
u2 = v2 - proj_u1(v2)         # 去掉 v2 在 u1 上的分量
u3 = v3 - proj_u1(v3) - proj_u2(v3)
# 结果 u1, u2, u3 两两正交
```

```python
import numpy as np
A = np.array([[1, 1],
              [1, 0]])      # 两列不垂直

Q, R = np.linalg.qr(A)      # QR 分解 = Gram-Schmidt
# Q 的列是正交化后的向量
```

## 6. 最小二乘法（Least Squares）

### 问题

方程组 `Ax = b` **无解**时（b 不在 A 的列空间里），找"最接近"的近似解。

### 几何意义

**把 b 投影到 A 的列空间**，投影点就是"最接近 b 的、能解出来的点"。

### 求解

```python
x̂ = (AᵀA)⁻¹ Aᵀ b     # 正规方程
```

### 应用：线性回归

```python
# 有一堆点 (x_i, y_i)，想拟合一条直线 y = ax + b
# 通常无解（点不共线），用最小二乘找"最佳"直线

import numpy as np

x = np.array([1, 2, 3, 4])
y = np.array([2, 4, 5, 4])

A = np.column_stack([x, np.ones_like(x)])   # [x, 1]
coeff = np.linalg.lstsq(A, y, rcond=None)[0]  # → [a, b]
# y = a·x + b 是最佳拟合直线
```

## 7. numpy 验证

```python
import numpy as np

# 内积与正交
v = np.array([1, 0])
w = np.array([0, 1])
print(v @ w)                    # 0，正交

# 投影
def proj(v, w):
    return (v @ w / (w @ w)) * w

proj(np.array([1, 1]), np.array([1, 0]))  # → [1, 0]

# 正交矩阵验证
R = np.array([[0, -1], [1, 0]])
R.T @ R                          # → 单位矩阵

# 最小二乘
A = np.array([[1, 1], [2, 1], [3, 1]])
b = np.array([2, 4, 5])
np.linalg.lstsq(A, b, rcond=None)[0]   # 拟合
```

## 小结

1. **内积 = 同向程度**，`v·w = ||v|| ||w|| cos θ`
2. **正交 = 内积为 0 = 垂直**
3. **投影** = 一个向量在另一个方向上的"影子"
4. **正交矩阵 QᵀQ = I** = 只旋转不拉伸
5. **Gram-Schmidt** = 把任意向量组正交化
6. **最小二乘** = 把 b 投影到列空间，求无解方程组的最佳近似（线性回归的本质）
