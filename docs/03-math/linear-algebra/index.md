# 线性代数

以几何直觉为主线（MIT 18.06 + 3Blue1Brown 思路），核心是「矩阵 = 线性变换」。

## 1. 向量与线性组合

向量、线性组合、张成空间、线性相关/无关。

## 2. 矩阵 = 线性变换

矩阵乘法、线性变换视角（列向量是基向量的去向）。

## 3. 线性方程组与消元

高斯消元、行阶梯形、解的结构。

## 4. 向量空间

基、维度、秩、四个基本子空间（列空间 / 零空间 / 行空间 / 左零空间）。

## 5. 行列式

几何意义：空间缩放体积的比例，行列式的性质。

## 6. 逆矩阵

几何意义：逆变换，可逆的充要条件。

## 7. 特征值与特征向量

方向不变的缩放，相似对角化。

## 8. 内积与正交

投影、正交基、Gram-Schmidt、最小二乘法。

## 9. 二次型

正定性（机器学习中常见）。

## 10. SVD 奇异值分解

降维、PCA 的数学根基。
