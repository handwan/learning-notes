# 向量空间

向量空间、子空间、基、维度、秩，以及四个基本子空间。这章把前面"线性组合/张成/相关无关"串成一个完整体系。

## 1. 向量空间（Vector Space）

**定义**：一组向量，对**加法**和**数乘**封闭（运算后结果还在这个集合里）。

**直观理解**：一个"装向量的世界"。关键性质——里面的向量怎么加、怎么乘，都跑不出这个世界。

- 二维平面 `R²` 是一个向量空间
- 三维空间 `R³` 是一个向量空间

**判断是不是向量空间**：看"封闭性"——任意两个向量相加、任意数乘，结果还在不在集合里。

## 2. 子空间（Subspace）

**定义**：向量空间的子集，本身也构成向量空间。

**直观理解**：整个空间里"穿过原点"的一个平面、一条线，都是子空间。

**判断三条件**：
1. 包含零向量（原点）
2. 对加法封闭
3. 对数乘封闭

```python
# 二维平面里：
# 过原点的一条直线 = 子空间 ✅
# 不过原点的直线   = 不是子空间 ❌（不包含零向量）
```

## 3. 基（Basis）

**定义**：一组向量，满足两个条件：
1. **线性无关**
2. **张成整个空间**

**直观理解**：空间的"坐标轴"。基向量 = 描述这个空间所需的"最小、刚好够用"的一组方向。

```python
# R² 的标准基：
i = [1, 0]
j = [0, 1]
# 无关 + 张成整个平面 → 是基

# 也可以是非标准基：
[1, 1], [1, -1]   # 同样无关、同样张成平面 → 也是基
```

**关键性质**：空间里任意向量，用基表示的方式**唯一**（这是"坐标系"成立的根本）。

## 4. 维度（Dimension）

**定义**：基中向量的个数。

**直观理解**：空间有几根"坐标轴"。

```python
R² 的维度 = 2   # 平面，2 根轴
R³ 的维度 = 3   # 空间，3 根轴
一条直线 = 1 维
一个点   = 0 维
```

**重要结论**：同一个空间的任何基，向量个数都一样（维度是空间的固有属性，不依赖基的选法）。

## 5. 秩（Rank）

**定义**：矩阵**线性无关的列（或行）的个数**。

**本质**：矩阵"真正张成"的空间维度——有多少个"不冗余"的列。

```python
import numpy as np

A = np.array([[1, 2],     # 第2列 = 2×第1列，两列相关
              [2, 4]])
np.linalg.matrix_rank(A)  # → 1（只有 1 个无关列）

B = np.array([[1, 0],
              [0, 1]])
np.linalg.matrix_rank(B)  # → 2（满秩）
```

- **满秩**：秩 = 列数，所有列都线性无关
- **秩亏**：秩 < 列数，有冗余列

## 6. 四个基本子空间（重点）

对于 m×n 矩阵 A，有四个核心子空间：

| 子空间 | 记号 | 是什么 | 维数 | 在哪 |
|--------|------|--------|------|------|
| 列空间 | C(A) | A 的列张成的空间 | r | R^m |
| 行空间 | C(Aᵀ) | A 的行张成的空间 | r | R^n |
| 零空间 | N(A) | Ax=0 的所有解 | n−r | R^n |
| 左零空间 | N(Aᵀ) | Aᵀx=0 的所有解 | m−r | R^m |

### 列空间（Column Space）

A 的**所有列**的线性组合 = 矩阵变换后能到达的所有位置 = 第 3 章说的"列视角"。

```
Ax = b 有解  ⇔  b 在 A 的列空间里
```

### 零空间（Null Space）

满足 **Ax = 0** 的所有解 x。

几何意义：变换后**被压到原点**的所有向量。零空间非平凡（不止 0），说明变换"丢维度"（不可逆）。

### 秩-零化度定理（核心公式）

```
秩 + 零空间维数 = 列数
r + (n - r) = n
```

**含义**：A 的列数 n = "留下的维度"(r) + "被压没的维度"(n−r)。

## 7. numpy 验证

```python
import numpy as np

A = np.array([[1, 2, 3],
              [4, 5, 6]])     # 2×3 矩阵

# 秩
r = np.linalg.matrix_rank(A)  # → 2

# 零空间（用 svd 求：秩之后的行张成零空间）
u, s, vt = np.linalg.svd(A)
null_space = vt[r:]     # r 是上面算出的秩
```

## 小结

1. **向量空间** = 对加法、数乘封闭的集合
2. **基** = 线性无关 + 张成整个空间（空间的"坐标轴"）
3. **维度** = 基的向量个数
4. **秩** = 线性无关的列（行）数
5. **四个基本子空间** + 秩-零化度定理 `r + (n−r) = n`
