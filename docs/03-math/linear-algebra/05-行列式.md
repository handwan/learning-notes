# 行列式

行列式的**几何意义**：线性变换把空间**面积/体积放大了多少倍**。这是它的灵魂，先抓几何意义再看计算。

## 1. 几何意义：缩放因子

行列式 = 变换前后**面积（二维）/体积（三维）的缩放比例**。

```python
A = [[2, 0],
     [0, 2]]      # 放大 2 倍的变换

det(A) = 4       # 面积放大 4 倍（长宽各 2 倍）
```

**直观理解**：线性变换会把网格"拉伸"，行列式就是"一块单位面积，变换后变成了多大"。

- `det = 3`：面积放大 3 倍
- `det = 0.5`：面积缩小一半
- `det = 1`：面积不变（如纯旋转）

## 2. 符号 = 方向

行列式的**正负**表示变换是否"翻转"了空间：

| det | 含义 |
|-----|------|
| `> 0` | 保持方向（i 在 j 的左边） |
| `< 0` | 翻转方向（镜像，i 跑到 j 右边） |

```python
# 镜像变换：i 和 j 交换
A = [[0, 1],
     [1, 0]]
det(A) = -1     # 负号 = 翻转了方向
```

**负号只代表"翻转"，不代表"变小"**。`det = -3` 是"放大 3 倍 + 翻转"。

## 3. det = 0：降维（最重要）

**行列式为 0，意味着变换把空间压缩到了更低维**：

```python
A = [[1, 1],
     [1, 1]]     # 两列相同，线性相关

det(A) = 0
```

几何意义：变换把整个平面"压扁"成一条线（二维 → 一维）。因为两列共线，张成的空间只有一条线。

**结论**：

```
det(A) = 0  ⇔  不可逆  ⇔  列线性相关  ⇔  降维
det(A) ≠ 0  ⇔  可逆    ⇔  列线性无关  ⇔  维度不变
```

## 4. 计算

### 2×2 矩阵

```
det([[a, b],
     [c, d]]) = ad - bc
```

```python
det([[1, 2],
     [3, 4]]) = 1×4 - 2×3 = -2
```

**几何含义**：`ad - bc` 就是 i、j 变换后围成的**平行四边形面积**（带方向）。

### 3×3 矩阵

按行展开（或用 numpy）：

```python
import numpy as np
A = np.array([[1, 2, 3],
              [0, 1, 4],
              [5, 6, 0]])
np.linalg.det(A)   # 直接算，不必手算
```

**手算理解**：3×3 行列式 = 变换后 i、j、k 围成的**平行六面体体积**。

## 5. 行列式的性质

| 性质 | 说明 |
|------|------|
| `det(I) = 1` | 单位矩阵不改变体积 |
| 交换两行 | det 变号 |
| 某行乘 k | det 也乘 k |
| 某行加到另一行 | det 不变（消元不影响行列式！） |
| `det(AB) = det(A)·det(B)` | 复合变换的体积缩放相乘 |
| `det(Aᵀ) = det(A)` | 转置不变 |

**最有用的性质**：`det(AB) = det(A)·det(B)` —— 先放大 2 倍再放大 3 倍，总共放大 6 倍。

## 6. numpy 验证

```python
import numpy as np

A = np.array([[2, 0], [0, 2]])
np.linalg.det(A)    # → 4.0（面积放大 4 倍）

B = np.array([[0, 1], [1, 0]])
np.linalg.det(B)    # → -1.0（翻转）

C = np.array([[1, 1], [1, 1]])
np.linalg.det(C)    # → 0.0（降维，不可逆）

# 性质验证
np.linalg.det(A @ B) == np.linalg.det(A) * np.linalg.det(B)  # True
```

## 小结

1. **行列式 = 变换对面积/体积的缩放倍数**（几何核心）
2. **符号 = 方向**：正保持、负翻转
3. **det = 0 = 降维 = 不可逆**（列线性相关）
4. 计算：2×2 是 `ad - bc`，其余交给 numpy

抓住"缩放因子"这个直觉，行列式的所有公式都好记了。下一章「逆矩阵」，就是"把变换倒回去"。
