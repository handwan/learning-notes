# 梯度下降

梯度下降 = **沿负梯度方向，一步步走到最小值**。ML 训练的核心算法。

## 1. 原理

**核心公式**（就一行）：

```python
x_new = x_old - lr * ∇f(x_old)

# 拆开看：
#   ∇f(x_old)  → 梯度（函数"增长最快"的方向）
#   -∇f        → 负梯度 = "下降最快"的方向
#   lr         → 学习率（learning rate，步长）：控制每次走多远
```

**直觉**：像蒙眼下山——每一步用脚探"哪个方向最陡"，就沿最陡方向往下走一步：

```python
1. 算当前位置的梯度 ∇f(x)（最陡方向）
2. 沿负梯度走一小步（lr 控制步子大小）
3. 重复，直到梯度 ≈ 0（到了平地 = 极值点）
```

## 2. 学习率（lr）——最关键的超参数

```python
lr 太小：收敛慢（走几百步还没到）
lr 太大：来回震荡，甚至发散（一步跨过碗底，越走越远）
lr 合适：较快收敛
```

```
太小：╲___ 慢慢蹭下去
合适：╲__╱ 快速到碗底
太大：╲/╲/╲/ 震荡，可能飞出去
```

**实践**：常用 0.1、0.01、0.001，从小开始试；现代优化器（Adam）会自动调。

## 3. 学习率调度（LR Schedule）

**固定的 lr 往往不最优**：

- 训练前期 lr 大一点 → 走得快
- 训练后期 lr 小一点 → 精细收敛（否则一直在最小值附近震荡）

**常见策略**：

| 策略 | 做法 |
|------|------|
| **Step decay** | 每 N 轮把 lr 乘 0.1 |
| **Cosine annealing** | lr 按余弦曲线从大到小（现在常用） |
| **Warmup** | 最开始 lr 从 0 慢慢升上去（Transformer 标配） |
| **ReduceLROnPlateau** | 验证损失不降了，就降 lr |

**组合**：**warmup + cosine** 是现在大模型训练的常见搭配。

```python
# 伪代码：warmup + cosine
for step in range(total_steps):
    if step < warmup_steps:
        lr = base_lr * step / warmup_steps              # 升温：0 → base_lr
    else:
        lr = cosine_decay(base_lr, min_lr, step)        # 降温：base_lr → min_lr
```

## 4. 梯度问题（消失 / 爆炸 / 裁剪）

### 梯度消失 / 爆炸

多层网络的反向传播是**连乘**（链式法则），每层梯度都要乘进去：

- 每层梯度都 < 1 → 连乘后**指数衰减** → **梯度消失**
- 每层梯度都 > 1 → 连乘后**指数增长** → **梯度爆炸**

**表现**：

- 消失：浅层"学不动"（损失下降极慢）
- 爆炸：损失突然 NaN、参数爆掉

**解决手段**：

| 手段 | 对付 |
|------|------|
| 换激活函数（ReLU 代替 sigmoid） | 消失 |
| 残差连接（ResNet） | 消失 |
| BatchNorm / LayerNorm | 两者 |
| **梯度裁剪（clipping）** | 爆炸 |
| 调小学习率 | 两者 |

### 梯度裁剪（gradient clipping）

**做法**：算完梯度后，若"长度"超过阈值，就**等比缩小**（方向不变）：

```python
g = compute_grad()
if np.linalg.norm(g) > max_norm:
    g = g * (max_norm / np.linalg.norm(g))     # 只缩长度，不改方向
w -= lr * g
```

**用途**：RNN / Transformer 训练的标配（防爆炸）。

## 5. 三种变体（重点）

按"每次用多少数据算梯度"分：

| 变体 | 每步用多少数据 | 特点 |
|------|--------------|------|
| **BGD** 批量梯度下降 | 全部数据 | 稳、准，但慢（大数据集每步都要扫全量） |
| **SGD** 随机梯度下降 | 1 个样本 | 快，但震荡大（单样本噪声大） |
| **Mini-batch** 小批量 | 一小批（如 32/64） | **折中，实际最常用** |

```python
# Mini-batch（伪代码）：
for epoch in range(轮数):
    打乱数据
    for batch in 数据切成小批:
        g = 算这批的平均梯度
        w -= lr * g
```

**SGD 的震荡是"特性不是 bug"**：噪声帮助跳出局部最优（在非凸损失上反而有用）。

## 6. 完整的训练流程

```python
# 用 numpy 从零训练一个线性回归（最小二乘 = 梯度下降版）
import numpy as np

X = np.array([1, 2, 3, 4, 5])
y = np.array([2, 4, 6, 8, 10])     # y = 2x，理想 w = 2

w, b = 0.0, 0.0                     # 初始参数
lr = 0.01

for step in range(1000):
    y_hat = w * X + b               # 预测
    # 损失 L = (y - ŷ)² 的梯度（微积分 03 章推导过）：
    dw = np.mean(-2 * X * (y - y_hat))   # ∂L/∂w
    db = np.mean(-2 * (y - y_hat))       # ∂L/∂b
    w -= lr * dw                    # 梯度下降更新
    b -= lr * db

print(w, b)     # → w ≈ 2.0, b ≈ 0.0，学出了正确参数！
```

## 7. 小结

1. **梯度下降 = 沿负梯度一步步下山**：`x -= lr·∇f`
2. **学习率**：太小慢、太大震荡，是最关键超参
3. **学习率调度**：warmup + cosine（后期降 lr → 精细收敛）
4. **梯度问题**：消失（ReLU/残差）/ 爆炸（**裁剪**）
5. **三种变体**：BGD（全量）/ SGD（单样本）/ Mini-batch（折中，最常用）
6. **训练 = 梯度下降**：算损失梯度 → 更新参数 → 循环
