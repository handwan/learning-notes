# 进阶优化算法

梯度下降的改进版：Momentum（动量）、Adam（最常用）。牛顿法了解即可。

## 1. Momentum（动量）

**问题**：普通梯度下降在"峡谷"里来回震荡（左右摆，前进慢），且容易卡在局部最优。

**解决**：加"惯性"——保留之前的方向，像滚下坡的球：

```python
v = β·v + ∇f(x)          # 速度 = 旧速度的 β 倍 + 当前梯度
x = x - lr·v             # 沿速度走，而不是直接沿梯度
# β 通常取 0.9
```

**效果**：

- 震荡方向互相抵消（左右摆的梯度在 v 里抵消）
- 前进方向持续积累（往下的梯度一直累加）→ 更快滚向碗底
- 惯性帮助**冲过小的局部最优**（球滚得快，小坑拦不住）

```python
# numpy 演示（简版）：
v = 0.0
beta = 0.9
for step in range(100):
    v = beta * v + grad(f, x)
    x -= lr * v
```

## 2. Adagrad / RMSProp（Adam 的前身）

### Adagrad：给每个参数"自己的"学习率

**想法**：梯度一直很大的参数（震荡）→ **减小**它的步长；梯度小的 → 相对放大。

```python
G = G + g * g                        # 累积历史梯度平方（每个参数一份）
w = w - lr * g / (sqrt(G) + eps)     # 用 sqrt(G) 缩放步长
```

- 优点：几乎不用调 lr；对稀疏特征友好
- **缺点**：`G` 只增不减 → 学习率**单调衰减到极小** → 后期"学不动"

### RMSProp：给累积加"遗忘"

```python
G = beta * G + (1 - beta) * g * g    # 用"滑动平均"代替累加（beta 通常 0.9）
w = w - lr * g / (sqrt(G) + eps)
```

- 解决 Adagrad"后期学不动"的问题 → 长期有效
- **它是 Adam 的另一半**：Adam = Momentum（一阶矩）+ RMSProp（二阶矩）

## 3. Adam（最常用）

**全称**：Adaptive Moment Estimation，**自适应学习率 + 动量**的结合。

**核心思想**：每个参数有**自己的学习率**——变化大的参数给小学率（防震荡），变化小的给大学习率（加速）：

```python
m = β₁·m + (1-β₁)·∇f        # 一阶矩（类似动量）
v = β₂·v + (1-β₂)·(∇f)²     # 二阶矩（梯度的平方，衡量变化幅度）
m̂ = m / (1-β₁ᵗ)             # 偏差修正
v̂ = v / (1-β₂ᵗ)
x = x - lr·m̂ / (√v̂ + ε)     # 自适应步长：m̂ 定方向，√v̂ 定大小
# 常用超参：lr=0.001, β₁=0.9, β₂=0.999
```

**为什么是默认选择**：不用细调学习率（自适应），收敛快且稳。**深度学习训练默认用 Adam**。

## 4. 牛顿法（了解）

**思想**：用二阶信息（Hessian）直接跳到最小值，比梯度下降（只用一阶）快：

```python
x_new = x - f'(x) / f''(x)     # 一元牛顿法
x_new = x - H⁻¹·∇f             # 多元（H 是 Hessian 矩阵）
```

**为什么 ML 不用**：Hessian 矩阵是 n×n（n = 参数个数），深度学习参数百万级，**算逆矩阵 H⁻¹ 根本算不动**。所以 ML 用一阶方法（梯度下降系），牛顿法只在参数少时用。

| | 梯度下降 | 牛顿法 |
|--|---------|--------|
| 用几阶信息 | 一阶（梯度） | 二阶（Hessian） |
| 收敛速度 | 慢 | 快（二次收敛） |
| 每步代价 | 低 | 高（要算/求逆 Hessian） |
| ML 适用 | ✅ 主流 | ❌ 参数太多算不动 |

## 5. 小结

1. **Momentum**：加惯性，减少震荡、冲过小坑
2. **Adagrad / RMSProp**：自适应学习率的前身（**Adam = Momentum + RMSProp**）
3. **Adam**：动量 + 自适应学习率，深度学习默认
4. **牛顿法**：用二阶信息收敛快，但 Hessian 求逆太贵，ML 不用
5. 记住：**Adam 是什么、为什么默认用它**（自适应学习率）
