# 正则化

正则化 = 给损失函数**加惩罚项**，抑制模型过拟合。L1/L2 是高频。

## 1. 过拟合（为什么要正则化）

**过拟合**：模型把训练数据的**噪声**也学了，训练集表现好，测试集差。

```
欠拟合：模型太简单，没学到规律
恰好：  刚好学到规律
过拟合：模型太复杂，把噪声也背下来了
```

**解决手段之一**：正则化——**惩罚参数过大**（复杂的模型往往参数大，惩罚它 = 逼模型简单）。

## 2. L2 正则化（岭回归，最常用）

**做法**：损失函数加上"参数平方和"的惩罚：

```python
L = 原始损失 + λ · Σw²
# 加号后面是惩罚项：λ 是正则化强度（越大惩罚越狠）
```

```python
# 线性回归 + L2：
L = Σ(yᵢ - ŵxᵢ)² + λ·w²
```

**效果**：

- 参数 w 被"拽向 0"，但**不会精确到 0**（连续收缩）
- 让模型更平滑、更简单 → 防过拟合

**为什么有效**：大参数意味着"模型对输入很敏感"（小变化大输出），容易过拟合。惩罚大参数 = 逼模型"温和"，学到的规律更泛化。

## 3. L1 正则化（Lasso）

**做法**：加"参数绝对值之和"的惩罚：

```python
L = 原始损失 + λ · Σ|w|
```

**关键区别**：L1 会把**部分参数精确压成 0**（L2 只是接近 0）。

```python
# 直觉：|w| 在 0 处有"尖角"，梯度下降滚到 0 就"卡住"了
# 而 w² 在 0 处平滑，只会无限接近 0
```

**用途**：**特征选择**——被压成 0 的参数对应的特征就是"没用的特征"，自动去掉。

## 4. L1 vs L2（高频）

| | L2（岭回归） | L1（Lasso） |
|--|-------------|-------------|
| 惩罚项 | λ·Σw² | λ·Σ\|w\| |
| 参数效果 | 收缩，**不归零** | **部分精确归零** |
| 用途 | 防过拟合（通用） | 防过拟合 + **特征选择** |
| 解的稀疏性 | 不稀疏 | **稀疏** |

```python
# 简单数据演示：
w = [0.5, 0.01, 0.003, 0.8]
# L2 之后：w ≈ [0.4, 0.008, 0.002, 0.7]  都变小，没归零
# L1 之后：w ≈ [0.3, 0,     0,     0.6]   小的直接变 0
```

**要点**："L2 让参数变小防过拟合；L1 能把没用的参数压成 0，顺便做特征选择。"

## 5. 权重衰减 vs L2（AdamW 的由来）

**看起来一样，其实不同**：

| | L2 正则 | 权重衰减（weight decay） |
|--|--------|------------------------|
| 做法 | 损失里**加** `λΣw²`，再一起求导 | 更新时**直接**多减一项 `λ·w` |
| SGD 下 | **等价** ✅ | **等价** ✅ |
| **Adam 下** | **不等价** ❌ | ✅ 才是真正按比例衰减 |

**为什么不等价**：L2 的惩罚是加进**梯度**里的，而 Adam 会**自适应缩放梯度**（除以 √G）→ 惩罚项也被缩放了，就不再是"均匀衰减"。

**解决：AdamW**——把权重衰减从梯度里"拿出来"，单独做：

```python
# AdamW：
w = w - lr * adam_update - lr * lambda_w * w
#                  ↑自适应部分            ↑独立的衰减项
```

**实践**：用 Adam 时优先 **AdamW**（PyTorch：`torch.optim.AdamW`），别用 `Adam(weight_decay=...)`。

## 6. 过拟合的其他手段（补全）

正则化只是抑制过拟合的手段之一，完整方案还有：

| 手段 | 一句话 |
|------|--------|
| **正则化（L1/L2）** | 惩罚大参数（重点） |
| **Dropout** | 训练时随机"关掉"一部分神经元，逼网络不依赖单个神经元（防共适应） |
| **早停（Early Stopping）** | 验证集损失开始上升就停，不继续训练 |
| **更多数据** | 最根本的办法（数据多了难背噪声） |
| **数据增强** | 人为扩大数据（翻转、裁剪、加噪） |
| **简化模型** | 模型本身别太大 |

```python
# Dropout 的直觉：
# 每轮训练随机丢弃 50% 神经元 → 每次训练的是"不同的子网络"
# 最终效果 ≈ 很多子网络的平均（集成学习的近似）
# 推理时不用 Dropout（全网络 + 权重缩放）

# 早停：
# 训练集损失持续下降，验证集损失先降后升 → 在验证集最低点停下
```

**要点**：过拟合怎么办 → "正则化 + Dropout + 早停 + 更多数据"四件套。

## 7. 小结

1. **过拟合** = 模型背噪声，训练好测试差
2. **正则化** = 损失 + λ·惩罚项，惩罚大参数
3. **L2**：λ·Σw²，参数收缩不归零（防过拟合）
4. **L1**：λ·Σ|w|，参数精确归零（+特征选择）
5. **λ 是正则化强度**：太大欠拟合，太小过拟合，要调
6. **Adam + L2 ≠ 正确做法** → 用 **AdamW**（权重衰减独立做）
