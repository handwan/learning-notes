# 最优化

核心是「梯度下降 + 凸优化」。一句话：**怎么让模型训练出来**——即"怎么找让损失最小的参数"。

## 主线

```
① 优化问题与凸优化 → 要解的是什么问题？（训练 = 最小化损失；凸的保证能训好）
② 梯度下降 → 怎么找最小值？（沿负梯度一步步走）
③ 进阶优化算法 → 怎么改进？（Momentum、Adam）
④ 正则化 → 怎么防过拟合？（L1/L2、Dropout、早停）
```
