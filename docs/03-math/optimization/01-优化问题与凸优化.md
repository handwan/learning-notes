# 优化问题与凸优化

优化 = **找一个使函数取最小（或最大）值的点**。ML 训练模型的本质就是优化。

## 1. 优化问题是什么

```python
minimize f(x)        # 找 x，使 f(x) 最小
# f = 目标函数（ML 里就是损失函数）
# x = 要调的参数（ML 里就是模型权重）
```

**ML 的对应**：

```python
# 训练 = 优化
目标函数 f  = 损失函数 L（衡量预测和真实的差距）
变量 x     = 模型参数 w、b
最优解     = 让损失最小的参数
```

所以"训练模型"= "找让损失函数最小的参数"，本质是个优化问题。

## 2. 极值点与最优

```python
f'(x) = 0  →  候选点（驻点）

f'(x) = 0 且 f''(x) > 0  →  局部最小值
f'(x) = 0 且 f''(x) < 0  →  局部最大值
```

（这是微积分 02 章讲的求极值流程，直接用于优化。）

## 3. 局部最优 vs 全局最优（ML 的核心问题）

```python
全局最优：整个定义域里最小的点（真正想要的）
局部最优：附近最小的点（但不是整体最小）
```

**函数的形状可能有多个"谷底"**：

- **全局最优** = 所有谷底里**最低**的那个
- **局部最优** = 其他谷底：在附近是最低，但不是整体最低

**梯度下降从哪出发，就滚进哪个谷底**（起点决定结果）——这就是"非凸函数难训"的原因。

**关键问题**：梯度下降只保证找到"局部最优"，怎么找到"全局最优"？

### 鞍点（saddle point）

高维空间里，比局部最优**更常见**的"卡住点"：

**鞍点** = 一个方向是上坡、另一个方向是下坡的点（像马鞍：前后上坡、左右下坡）。

- **一维**：只有"谷底 / 峰顶"
- **高维**：可以"这个方向是谷底、那个方向是峰顶" → 梯度也是 0，但**不是最小值**

**为什么重要**：

- 参数有几百万维时，**鞍点比局部最优常见得多**
- 靠近鞍点时梯度很小 → 训练变慢（像走平地）

**好消息**：鞍点通常能"溜走"（总有下坡方向）；真正难缠的是大片**平坦区域**。

## 4. 凸优化（为什么凸函数好）

**凸函数**：碗朝上，任意两点连线都在函数上方：

```python
f(x) = x²        # 凸
f(x) = -x²       # 凹（碗朝下）
f(x) = x³        # 非凸（有拐点）
```

**凸函数的黄金性质**：

```python
凸函数：局部最优 = 全局最优！
```

**为什么**：凸函数只有一个"碗底"，任何局部最低点就是整体最低点。梯度下降无论从哪出发，都能滚到同一个最优解。

**判断凸性**（连微积分）：

```python
f''(x) ≥ 0（一元）  ⇔  Hessian 矩阵半正定（多元）  ⇔  凸
```

**ML 的意义**：

| 损失函数 | 凸吗 | 梯度下降能找到全局最优吗 |
|---------|------|------------------------|
| 线性回归 MSE | ✅ 凸 | ✅ 保证 |
| 逻辑回归交叉熵 | ✅ 凸 | ✅ 保证 |
| 神经网络损失 | ❌ 非凸 | 只能找到好的局部最优 |

**这解释了**：为什么线性/逻辑回归"保证收敛"，而深度学习"不保证"——因为前者的损失函数是凸的，后者不是。

## 5. numpy 验证

```python
import numpy as np

def f(x):
    return x**4 - 4*x**2 + x      # 非凸：多个局部最优

# 从不同起点梯度下降，会落到不同"碗底"（局部最优）
def grad_descent(f, x0, lr=0.01, steps=1000):
    x = x0
    for _ in range(steps):
        h = 1e-6
        g = (f(x+h) - f(x-h)) / (2*h)   # 数值梯度
        x -= lr * g
    return x

print(grad_descent(f, 2.0))    # 从右出发 → 一个局部最优
print(grad_descent(f, -2.0))   # 从左出发 → 另一个局部最优
# 非凸函数：起点不同，结果不同！

def g(x):
    return x**2                     # 凸

print(grad_descent(g, 5.0))    # 凸函数：任何起点都到 0（全局最优）
```

## 6. 小结

1. **优化 = 最小化目标函数**（ML 里 = 最小化损失）
2. **凸函数：局部最优 = 全局最优**（黄金性质）
3. 判断凸性：`f'' ≥ 0` 或 Hessian 半正定（连线代二次型）
4. 线性/逻辑回归损失是凸的（保证收敛），神经网络损失非凸
5. 高维空间里**鞍点比局部最优更常见**（梯度为 0 但不是最小值）
