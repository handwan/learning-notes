# 数学基础

数学五门课程：线代、概率、微积分、最优化、数值计算。

## 五大模块

- **线性代数**：矩阵 = 线性变换（10 章）
- **概率论**：贝叶斯 → MLE → 交叉熵（7 章）
- **微积分**：导数 → 梯度 → 链式法则（5 章，含矩阵微积分）
- **最优化**：凸优化 → 梯度下降 → 正则化（4 章）
- **数值计算**：浮点数 → 误差 → 稳定性 → 经典数值方法 → 量化（9 章）
