# 偏导数与梯度

多元函数（多个输入）的导数：偏导数、梯度、方向导数。梯度是**梯度下降**的核心。

## 1. 偏导数

**定义**：多元函数**只对一个变量求导**，其他变量当常数。

```python
f(x, y) = x² + y²

∂f/∂x = 2x        # 对 x 求偏导（y 当常数）
∂f/∂y = 2y        # 对 y 求偏导（x 当常数）
```

**记号**：偏导用 `∂`（不是 `d`），表示"只对这一个变量求导"。

**直觉**：偏导 = 沿某一个坐标轴方向的"斜率"。`∂f/∂x` 是"固定 y，只看 x 方向的变化率"。

## 2. 梯度（Gradient）

**定义**：所有偏导数组成的**向量**。

```python
f(x, y) = x² + y²

梯度 ∇f = (∂f/∂x, ∂f/∂y) = (2x, 2y)
```

**几何意义（最重要）**：**梯度指向函数增长最快的方向**，梯度的大小 = 增长最快方向的增长率。

```python
# 在点 (1, 1) 处：
∇f(1,1) = (2, 2)
# 函数在 (1,1) 处沿 (2,2) 方向增长最快
# 所以"负梯度方向" = 下降最快 → 梯度下降！
```

## 3. 方向导数（为什么梯度是最快方向）

**问题**：沿方向 v 的"斜率"是多少？（v 取**单位向量**）

```python
方向导数 = ∇f · v = ||∇f|| · cos θ
# 这里 v 是单位向量，所以不出现 ||v||
```

- 当 v 和 ∇f **同向**（θ=0，cos=1）：方向导数最大 = ||∇f||
- 当 v 和 ∇f **反向**（θ=180°，cos=-1）：方向导数最小 = -||∇f||

**所以**：
```
梯度方向   = 增长最快
负梯度方向 = 下降最快  ← 梯度下降就是沿这个方向走！
```

这就是**梯度下降法的原理**：每一步沿 `-∇f` 走，函数值下降最快。

```python
# 梯度下降一步：
x_new = x_old - lr * ∇f(x_old)
# lr：学习率（步长）；"-∇f"：沿负梯度（下降最快）方向
```

## 4. 二阶导与凸性（连最优化）

```python
f''(x) > 0  →  凸函数（碗朝上）→ 有唯一最小值
f''(x) < 0  →  凹函数（碗朝下）
f''(x) = 0  →  拐点
```

**为什么 ML 关心**：损失函数是凸的 → 梯度下降能收敛到全局最优；不是凸的 → 可能困在局部最优。

**和线代的连接**：多元函数的凸性，看二阶导数矩阵（**Hessian 矩阵**）是否正定——这就是线代「二次型/正定」的用处：

```
f''(x) > 0（一元）  ⇔  Hessian 正定（多元）  ⇔  凸函数
```

### 求极值的完整流程

```python
1. 解 f'(x) = 0，得到候选点
2. 用二阶导判断：
   f''(x) > 0  →  极小值
   f''(x) < 0  →  极大值
   f''(x) = 0  →  无法判断（可能拐点）
```

**为什么梯度下降找 f'(x)=0 的点**：极值点必然满足"一阶导 = 0"（变化率为 0 才可能到顶/底）。梯度下降就是数值地找这个点。

## 5. numpy 验证

```python
import numpy as np

def f(x, y):
    return x**2 + y**2

def gradient(f, point, h=1e-5):
    # 数值梯度：对每个变量求偏导
    x, y = point
    dx = (f(x+h, y) - f(x-h, y)) / (2*h)
    dy = (f(x, y+h) - f(x, y-h)) / (2*h)
    return np.array([dx, dy])

gradient(f, (1.0, 1.0))   # ∇f(1,1) = (2, 2) ✓

# 梯度下降演示
p = np.array([3.0, 4.0])       # 起点
lr = 0.1                       # 学习率
for _ in range(50):
    p = p - lr * gradient(f, p)   # 沿负梯度走
print(p)      # → 接近 (0, 0)，f 的最小值点
```

## 6. 小结

1. **偏导数** = 只对一个变量求导（∂ 记号）
2. **梯度 ∇f** = 所有偏导组成的向量
3. **梯度方向 = 增长最快方向**，负梯度 = 下降最快（梯度下降的原理）
4. **方向导数 ∇f·v** 解释为什么梯度是最快方向
5. **二阶导 > 0 = 凸**（连 Hessian 正定、线代二次型）
