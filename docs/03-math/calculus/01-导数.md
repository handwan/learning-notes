# 导数

导数 = 函数在某点的**变化率**，几何意义是**切线的斜率**。它是后面梯度、梯度下降的基础。

## 1. 定义

```python
f'(x) = lim(h→0) [f(x+h) - f(x)] / h
```

**直觉**：当 x 变化一点点（h），f 变化了多少——"变化率"。

## 2. 几何意义：切线斜率

```
导数 = 曲线在该点的切线斜率

f'(x) > 0：函数在上升
f'(x) < 0：函数在下降
f'(x) = 0：平的点（可能是极值点）
```

```python
f(x) = x²
f'(x) = 2x

在 x=2：f'(2) = 4  → 曲线正以斜率 4 上升
在 x=0：f'(0) = 0  → 曲线在底部（最小值）
```

## 3. 常用函数导数（速查表）

| 函数 f(x) | 导数 f'(x) |
|-----------|-----------|
| 常数 c | 0 |
| xⁿ | n·xⁿ⁻¹ |
| eˣ | eˣ |
| ln(x) | 1/x |
| sin(x) | cos(x) |
| cos(x) | -sin(x) |
| aˣ | aˣ·ln(a) |

## 4. 求导法则

```python
# 加减：
(f ± g)' = f' ± g'

# 乘法：
(f·g)' = f'·g + f·g'

# 除法：
(f/g)' = (f'·g - f·g') / g²
```

## 5. ML 里最常用的几个

**① sigmoid 函数**（逻辑回归、神经网络激活）：

```python
σ(x) = 1 / (1 + e⁻ˣ)
σ'(x) = σ(x)·(1 - σ(x))     # 导数可以用自己表示，好算！
```

**推导**：

```python
σ = (1 + e⁻ˣ)⁻¹

# 链式法则：(u⁻¹)' = -u⁻² · u'
σ' = -(1+e⁻ˣ)⁻² · (1+e⁻ˣ)'
   = -(1+e⁻ˣ)⁻² · (-e⁻ˣ)
   = e⁻ˣ / (1+e⁻ˣ)²

# 验算 σ(1-σ)：
σ(1-σ) = [1/(1+e⁻ˣ)] · [e⁻ˣ/(1+e⁻ˣ)] = e⁻ˣ/(1+e⁻ˣ)²   ✅ 相等
```

**② tanh 函数**（RNN 等）：

```python
tanh(x) = (eˣ - e⁻ˣ) / (eˣ + e⁻ˣ)
tanh'(x) = 1 - tanh²(x)     # 同样能用自己表示
```

**推导**（记分子 u = eˣ-e⁻ˣ、分母 v = eˣ+e⁻ˣ，注意 u' = v、v' = u）：

```python
# 商法则：(u/v)' = (u'v - uv') / v²
tanh' = (v·v - u·u) / v²
      = (v² - u²) / v²
      = 1 - (u/v)²
      = 1 - tanh²       ✅
```

**③ ReLU 函数**（现代网络默认激活）：

```python
ReLU(x) = max(0, x)
ReLU'(x) = 1（x > 0），0（x ≤ 0）
# 简单粗暴：正的就原样过，负的全截断
```

推导思路：分段函数逐段求导；`x = 0` 处左右导数不等 → 不可导（实践取次梯度 0）。

**④ log 函数**（交叉熵损失）：

```python
d/dx (log x) = 1/x
d/dx (log(1-x)) = -1/(1-x)
```

推导思路：`ln(x)` 是基本导数；`ln(1-x)` 套链式法则（外层 ln、内层 1-x，再乘 -1）。

**⑤ 平方损失**（MSE）：

```python
L = (y - ŷ)²
dL/dŷ = -2(y - ŷ)           # 对预测值的导数
```

推导思路：链式法则——外层平方求导得 `2(y-ŷ)`，内层 `(y-ŷ)` 对 ŷ 求导得 `-1`，相乘即 `-2(y-ŷ)`。

**激活函数导数速查**：

| 激活 | 导数 | 特点 |
|------|------|------|
| sigmoid | σ(1-σ) | 两端梯度消失 |
| tanh | 1-tanh² | 输出零中心 |
| ReLU | x>0 是 1，否则 0 | 简单、不饱和（主流） |

## 6. 数值求导（numpy 验证）

```python
import numpy as np

def f(x):
    return x ** 2

# 数值求导：f'(x) ≈ (f(x+h) - f(x-h)) / 2h
def derivative(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)

derivative(f, 2.0)    # f'(2) = 2*2 = 4，数值结果 ≈ 4.0
derivative(f, 0.0)    # f'(0) = 0，≈ 0.0
```

## 7. 小结

1. **导数 = 变化率 = 切线斜率**
2. 正导数上升、负导数下降、零导数可能极值
3. 常用导数要背：`xⁿ→nxⁿ⁻¹`、`eˣ→eˣ`、`ln x→1/x`
4. ML 三件套：sigmoid（σ(1-σ)）、log（1/x）、平方损失
