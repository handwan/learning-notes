# 矩阵微积分

标量求导 → **对向量/矩阵求导**。ML 里算梯度（损失对参数向量求导）全靠它。

## 1. 为什么要矩阵微积分

前面学的导数都是"标量对标量"（`f(x)`，x 是一个数）。但 ML 里：

```
损失 L = 一个数（标量）      ← 要最小化的东西
参数 w = 一串数（向量）      ← 要调的东西
```

**问题**：一个数，对一串数求导，结果是什么？

**答案**：结果的**每个分量 = L 对每个参数的偏导**——这就是**梯度**：

```
∂L/∂w = [∂L/∂w₁, ∂L/∂w₂, ..., ∂L/∂wₙ]
```

**为什么需要**：训练 = 梯度下降 = "算梯度 → 每个参数往**下坡方向**挪一小步"。算梯度就是这一步。

## 2. 预备：对向量求导是什么

### 偏导数（复习）

```
f(x₁, x₂) = x₁² + x₂²

# 只关心"x₁ 变一点，f 变多少" → 把 x₂ 当常数
∂f/∂x₁ = 2x₁
∂f/∂x₂ = 2x₂        （对称地）

# 例：在 (3, 4) 处，∂f/∂x₁ = 6、∂f/∂x₂ = 8
```

### 关键一步：把偏导打包

```
∂f/∂x = [∂f/∂x₁, ∂f/∂x₂] = [2x₁, 2x₂]
```

**"标量对向量求导" = 把每个偏导排成一排**。

> 类比：对一个数求导 → 结果是一个数；对一串数求导 → 结果是一串数。

**记住这一句，下面所有公式都是它的应用。**

## 3. 核心公式（逐个推）

### ① `∂(aᵀx)/∂x = a`

先明白 `aᵀx` 是什么：两个向量"**对应相乘再相加**"，结果是**一个数**。

```
a = [2, 3]，x = [x₁, x₂]
aᵀx = 2x₁ + 3x₂

# 逐个求偏导：
∂/∂x₁ = 2        （3x₂ 是常数，导数为 0）
∂/∂x₂ = 3

# 打包：
∂(aᵀx)/∂x = [2, 3] = a     ✅
```

**白话**：`aᵀx` 里 `x₁` 的系数就是 `a₁`、`x₂` 的系数就是 `a₂`——**求导就是把系数"露出来"**，所以结果就是 a。

### ② `∂(xᵀx)/∂x = 2x`

```
xᵀx = x₁² + x₂²

∂/∂x₁ = 2x₁、∂/∂x₂ = 2x₂
∂(xᵀx)/∂x = [2x₁, 2x₂] = 2x     ✅
```

和标量 `d(x²)/dx = 2x` 完全平行。

### ③ `∂(xᵀAx)/∂x = (A+Aᵀ)x`

最复杂的一个，用 **2×2 具体矩阵**展开：

```
A = [[a, b],
     [c, d]]

xᵀAx = a·x₁² + b·x₁x₂ + c·x₂x₁ + d·x₂²
     = a·x₁² + (b+c)·x₁x₂ + d·x₂²        （中间两项合并）

# 逐个求偏导（注意 x₁x₂ 对 x₁ 求导 = x₂）：
∂/∂x₁ = 2a·x₁ + (b+c)·x₂
∂/∂x₂ = (b+c)·x₁ + 2d·x₂

# 打包成"矩阵 × 向量"：
∂(xᵀAx)/∂x = [[2a,  b+c],  · [x₁]
              [b+c, 2d ]]    [x₂]

# 这个矩阵正好是 A + Aᵀ：
A + Aᵀ = [[a,b],[c,d]] + [[a,c],[b,d]] = [[2a, b+c],[b+c, 2d]]   ✅
```

**所以**：`∂(xᵀAx)/∂x = (A+Aᵀ)x`；**A 对称时**（b=c）= `2Ax`。

### 公式总表 + 记忆法

| 矩阵版 | 标量类比 |
|--------|---------|
| `∂(aᵀx)/∂x = a` | `d(ax)/dx = a` |
| `∂(xᵀx)/∂x = 2x` | `d(x²)/dx = 2x` |
| `∂(xᵀAx)/∂x = (A+Aᵀ)x` | `d(ax²)/dx = 2ax` |

**结构完全平行**，只是多了"**转置**"要小心（矩阵乘法对维度有要求）。

> `∂(Ax)/∂x`（向量对向量）的结果**随约定不同**——按分母布局是 `Aᵀ`、按 Jacobian 定义是 `A`（互为转置）。实践中损失是标量，**记住上面三个就够**。

## 4. 数值验证（和公式对拍）

公式对不对，可以用**数值梯度**验：

```python
import numpy as np

def f(x, A, b):          # f = xᵀAx + bᵀx
    return x @ A @ x + b @ x

def num_grad(f, x):      # 数值求偏导（中心差分）
    h = 1e-6
    g = np.zeros_like(x)
    for i in range(len(x)):
        xp, xm = x.copy(), x.copy()
        xp[i] += h
        xm[i] -= h
        g[i] = (f(xp) - f(xm)) / (2 * h)
    return g

x = np.array([1.0, 2.0])
A = np.array([[2.0, 0.0], [0.0, 3.0]])   # 对称
b = np.array([1.0, 1.0])

print((A + A.T) @ x + b)                      # 解析：公式算的
print(num_grad(lambda x: f(x, A, b), x))      # 数值：差分算的
# 两者应一致 ✅
```

## 5. ML 应用：最小二乘正规方程

**目标**：解 `Ax = b`（无解时找"最接近"的解）。

**第 1 步：写损失**（一个数）

```
L = ||Ax - b||² = (Ax - b)ᵀ(Ax - b)
```

**第 2 步：展开**（用到 `(Ax)ᵀb = xᵀAᵀb`，它们是同一个数）

```
= (Ax)ᵀ(Ax) - (Ax)ᵀb - bᵀ(Ax) + bᵀb
= xᵀAᵀAx - 2xᵀAᵀb + bᵀb          （中间两项相等，合并）
```

**第 3 步：逐项求导**（套第 3 节的公式）

```
∂/∂x (xᵀAᵀAx)  = 2AᵀAx     （公式③，AᵀA 对称）
∂/∂x (-2xᵀAᵀb) = -2Aᵀb     （公式①，a = Aᵀb）
∂/∂x (bᵀb)     = 0         （常数）

→ ∂L/∂x = 2AᵀAx - 2Aᵀb
```

**第 4 步：令梯度 = 0**（找最小值）

```
2AᵀAx - 2Aᵀb = 0
AᵀAx = Aᵀb
x = (AᵀA)⁻¹Aᵀb             ← 正规方程
```

**这就是线代的最小二乘公式**——用矩阵微积分推出来了。

```python
import numpy as np

X = np.array([[1, 1], [2, 1], [3, 1], [4, 1]])   # [x, 1]
y = np.array([3, 5, 7, 9])

w = np.linalg.solve(X.T @ X, X.T @ y)   # 正规方程，一步出解
print(w)    # → [2, 1]（斜率 2、截距 1）
```

## 6. 雅可比矩阵与 Hessian 矩阵

求导结果的"形状"随输入输出维度变，两个常见矩阵：

### 雅可比矩阵（Jacobian）

**向量对向量求导**（多输入 → 多输出）：

```
y = f(x)，x 是 n 维、y 是 m 维
J[i][j] = ∂yᵢ/∂xⱼ        （第 i 个输出 对 第 j 个输入 的偏导）
形状：m×n

例：y = Ax（线性变换）→ J = A
```

**用途**：坐标变换、自动微分的链式传播。

### Hessian 矩阵

**标量函数的二阶导矩阵**：

```
f(x) 是标量、x 是 n 维
H[i][j] = ∂²f/∂xᵢ∂xⱼ
形状：n×n，对称
```

**用途**：凸性判断（正定 → 凸）、牛顿法。

### 对比

| | Jacobian | Hessian |
|--|----------|---------|
| 谁对谁 | 向量 → 向量（一阶） | 标量 → 向量（二阶） |
| 形状 | m×n | n×n（对称） |
| 作用 | 一阶导全表 | 二阶信息（曲率） |
| ML 用途 | 自动微分、层间梯度 | 凸性、牛顿法 |

## 7. 和梯度的关系

```
梯度 ∇f = 所有偏导组成的向量 = ∂f/∂x（矩阵微积分的结果）
```

整条链：

```
微积分（标量求导）
   ↓ 推广到向量
矩阵微积分（对向量求导）→ 梯度
   ↓
梯度下降（最优化）→ 训练模型
```

## 8. 小结

1. **矩阵微积分 = "把每个偏导排成一排"**——对向量求导的本质就这一句
2. **三个公式**：`∂(aᵀx)/∂x=a`、`∂(xᵀx)/∂x=2x`、`∂(xᵀAx)/∂x=(A+Aᵀ)x`（都有标量类比）
3. **核心应用**：最小二乘正规方程 `x=(AᵀA)⁻¹Aᵀb`（四步推导）
4. **Jacobian**（向量→向量，一阶）vs **Hessian**（标量→向量，二阶）
5. **实践**：公式查 [Matrix Cookbook](https://www.math.uwaterloo.ca/~hwolkowi/matrixcookbook.pdf)，不用背；但"**逐个分量求导再打包**"这个本质要理解
