# 速查与了解

微积分的基础理论：极限、积分、泰勒展开。它们是完整微积分体系的**地基**，这里只给**速查**（用到再回查）。

## 1. 极限

**定义**：当 x 无限接近 a 时，f(x) 趋近的值：

```python
lim(x→a) f(x) = L
```

**ML 用途**：几乎没有直接用。极限是"导数"的定义基础，知道"导数 = 极限的商"就够了。

```python
f'(x) = lim(h→0) [f(x+h) - f(x)] / h   # 导数就是极限
```

## 2. 积分

**定义**：导数的逆运算（反导数），几何意义是**曲线下的面积**。

```python
∫ f(x) dx = F(x) + C      # 不定积分（反导数）
∫ₐᵇ f(x) dx = F(b) - F(a)  # 定积分（面积）
```

**ML 用途**：

- 概率论里连续分布的期望/概率用积分（但都用现成公式，不手算）
- 工程里积分交给计算机（数值积分）

**记住的**：`∫ 1/x dx = ln|x|`、`∫ eˣ dx = eˣ`（概率论推导偶尔用）。

## 3. 泰勒展开

**定义**：用多项式近似一个函数：

```python
f(x) ≈ f(a) + f'(a)(x-a) + f''(a)(x-a)²/2! + f'''(a)(x-a)³/3! + ...
```

**ML 用途**：

- 损失函数的二阶近似（梯度下降的收敛性分析）
- eˣ、sin 的近似（了解即可）

```python
# 常用的：
eˣ ≈ 1 + x + x²/2! + x³/3! + ...
ln(1+x) ≈ x - x²/2 + x³/3 - ...
```

## 4. 本章要点

1. **极限**：导数的定义基础，ML 不直接用
2. **积分**：连续分布的概率计算用（现成公式），不手算
3. **泰勒**：函数多项式近似，收敛性分析偶用

三块都是"知道概念、能认出公式"就够，ML 实战几乎不碰。微积分的重点在**前 3 章**（导数、梯度、链式法则）。
