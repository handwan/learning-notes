# 链式法则与反向传播

链式法则 = 复合函数求导。深度学习的**反向传播**就是它的连环应用。

## 1. 链式法则（复合函数求导）

**定义**：

```python
若 y = f(u)，u = g(x)，则：
dy/dx = dy/du · du/dx
```

**直觉**：y 对 x 的变化率 = "y 对 u 的变化率" × "u 对 x 的变化率"，中间环节连乘。

```python
# 例子：y = (x² + 1)³
# 拆成：y = u³，u = x² + 1

dy/du = 3u²        # 外层求导
du/dx = 2x         # 内层求导
dy/dx = 3u² · 2x = 3(x²+1)² · 2x
```

## 2. 链式法则为什么是"反向传播"

神经网络是**层层复合**的函数：

```python
# 一个简单网络（两层）：
h = σ(W₁x + b₁)         # 第一层
ŷ = σ(W₂h + b₂)         # 第二层
loss = (y - ŷ)²         # 损失
```

要求 `∂loss/∂W₁`（第一层参数的梯度），按链式法则**一层层往回乘**：

```python
∂loss/∂W₁ = ∂loss/∂ŷ · ∂ŷ/∂h · ∂h/∂W₁
             └──────┘   └─────┘
             从后往前逐层求导连乘
```

**这就是反向传播**：

```
前向：x → 第1层 → 第2层 → ... → 输出 → loss
反向：∂loss ← 第2层 ← 第1层 ← ...（梯度逐层往回传）
```

**为什么叫"反向"**：计算从输出端开始，沿网络**反向**逐层求梯度，每一层只算自己的局部梯度，和传回来的梯度相乘。

## 3. 具体推导（一个简单的例子）

```python
# 模型：ŷ = wx（一个参数 w，x 是输入）
# 损失：L = (y - ŷ)²

# 拆成链：
# L = (y - ŷ)²     ← 最外层
# ŷ = w·x          ← 内层

# 反向求导（从 L 往回）：
∂L/∂ŷ = -2(y - ŷ)       # 第1步：L 对 ŷ
∂ŷ/∂w = x               # 第2步：ŷ 对 w
∂L/∂w = ∂L/∂ŷ · ∂ŷ/∂w = -2(y - ŷ) · x   # 连乘！
```

**结果**：`∂L/∂w = -2(y - ŷ)·x` —— 这就是 w 的梯度，用它更新参数：

```python
w = w - lr · (-2(y - ŷ) · x)     # 梯度下降一步
```

## 4. sigmoid 在链式法则里的应用

```python
# 网络常用 sigmoid 激活：h = σ(Wx + b)
# σ'(z) = σ(z)(1 - σ(z))    （01-导数 里背过）

# 反向传播时：
∂h/∂W = σ'(Wx+b) · x = σ(1-σ) · x
# 其中 σ(1-σ) 和 x 都是"前向时算好、存下来"的值
```

**关键**：反向传播能高效，就是因为**前向时把中间结果存下来**，反向时直接复用。

## 5. numpy 验证（数值 vs 解析梯度）

```python
import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

# 模型：ŷ = σ(wx)，损失 L = (y - ŷ)²
def loss(w, x, y):
    y_hat = sigmoid(w * x)
    return (y - y_hat) ** 2

# 解析梯度（链式法则）：
def grad(w, x, y):
    y_hat = sigmoid(w * x)
    dL_dyhat = -2 * (y - y_hat)                    # ∂L/∂ŷ
    dyhat_dw = y_hat * (1 - y_hat) * x             # ∂ŷ/∂w = σ(1-σ)·x
    return dL_dyhat * dyhat_dw

# 数值梯度（验证）：
def num_grad(w, x, y, h=1e-6):
    return (loss(w+h, x, y) - loss(w-h, x, y)) / (2*h)

w, x, y = 0.5, 1.0, 1.0
print(grad(w, x, y))       # 解析
print(num_grad(w, x, y))   # 数值，两者应接近 ✓
```

## 6. 小结

1. **链式法则**：`dy/dx = dy/du · du/dx`，复合函数逐层连乘
2. **反向传播 = 链式法则的连环应用**：从损失往回逐层求导
3. **效率关键**：前向时存中间结果，反向时复用
4. 梯度更新：`w -= lr · ∂L/∂w`
