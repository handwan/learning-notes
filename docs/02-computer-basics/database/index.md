## 重点

- **索引**：复合索引看最左前缀；`EXPLAIN (ANALYZE, BUFFERS)` 看"估算 vs 实际"和页访问数；选择性差就别指望索引
- **事务**：隔离级别现象（脏读/不可重复读/幻读/写偏斜）；MVCC = 写新版本；预防死锁靠**按固定顺序加锁**
- **存储**：IO 单位是页；UPDATE 不改原地；**WAL 先写日志再刷数据**，崩溃恢复 = redo 已提交 + undo 未提交
- **优化**：别让函数包住索引列；深分页用 keyset；批量用 `COPY`；用连接池；消灭 N+1
- **分布式**：异步复制有延迟（"写完读不到"）；同步复制每次提交多一个来回；slot 不清理会撑爆磁盘
- **2PC**：PREPARE 后不可见、COMMIT PREPARED 才可见；代价是悬挂事务与阻塞
- **向量**：余弦距离 `<=>` 最常用；HNSW 的 `ef_search` 调速度/召回；**召回率依赖数据结构**，评估别用随机向量
- **访问方式**：参数绑定防注入（`PQexecParams` / `%s`）、事务边界、连接池——C++ 与 Python 只是 API 名字不同
