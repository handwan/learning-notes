# 计算机基础

从"计算机怎么工作"到"工程里怎么用"：**离散数学**（数学侧）→ **数据结构**（结构与选型）→ **组成与体系结构**（硬件机制）→ **操作系统、计算机网络、数据库系统**（三大系统）→ **编译原理**（源码到机器码）。

这里讲**原理**与"为什么这样设计"：先解释机制，再上数据；各子章之间只在本章内部互相引用。

## 篇目

| 子章 | 一句话 |
|------|--------|
| [离散数学](discrete-mathematics/index.md) | 逻辑、集合与关系、组合、图论、布尔代数、可计算性——每篇都落到"CS 里用在哪" |
| [数据结构](data-structure/index.md) | 结构原理、手写实现、复杂度与**选型**（含并查集/布隆/LRU/跳表） |
| [组成与体系结构](computer-organization/index.md) | 硬件视角的性能课：数据表示、Cache、流水线、并行与加速器、roofline 性能模型 |
| [操作系统](operating-system/index.md) | 进程与线程、调度、同步与死锁、虚拟内存、文件系统、IO 模型 |
| [计算机网络](computer-network/index.md) | 分层 → 链路 → IP → TCP → 应用层 → 安全 → 排查工具 |
| [数据库系统](database/index.md) | SQL、索引与执行计划、事务、存储引擎、设计优化、复制分片、向量检索 |
| [编译原理](compiler/index.md) | 词法 → 语法 → 语义 → IR → 优化 → 代码生成；附 AI 编译器与推理引擎 |

## 怎么读

- **先建"为什么"的地基**：[数据结构](data-structure/index.md) 和 [组成与体系结构](computer-organization/index.md)——"这段代码为什么快/慢"全在这里
- **三大系统按需**：碰到哪块补哪块；OS 与网络有先后依赖（网络的下层是 OS 的 IO 模型）
- **编译原理独立成线**：不依赖前三块，按篇内"学习路径"走
- **离散数学当工具书**：用到（图论、模运算、布尔代数）再翻对应篇
