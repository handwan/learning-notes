# 速查与手算模板

> 这一篇把前 8 篇里"点到为止"的**形式化与手算部分**收进来——按需查，不必背。

## 1. 乔姆斯基文法体系

| 型 | 名称 | 产生式限制 | 识别器 | 用途 |
|:---:|------|-----------|--------|------|
| 0 型 | 无限制 | α → β（α 非空） | 图灵机 | 一切可计算语言 |
| 1 型 | 上下文有关 | αAβ → αγβ（\|γ\|≥1） | 线性有界自动机 | 少见 |
| **2 型** | **上下文无关** | A → γ（左部单个非终结符） | **下推自动机**（栈） | **语法分析**（本篇重点） |
| **3 型** | **正则** | A → aB / A → a（右线性） | **有限自动机（NFA/DFA）** | **词法分析** |

**记忆**：3 型管 token、2 型管结构；再往上就是"可计算性"（[离散数学 08](../discrete-mathematics/08-代数结构与可计算性.md)）。

## 2. FIRST / FOLLOW 计算模板

**FIRST(α)**：α 能推出的**首终结符**集合。

```
① 若 α 以终结符 a 开头 → a ∈ FIRST(α)
② 若 α ⇒ ε → ε ∈ FIRST(α)
③ 若 X → Y1Y2...Yk：把 FIRST(Y1)\{ε} 加进来；若 Y1 ⇒ ε，继续看 Y2……全都能 ε 才加 ε
```

**FOLLOW(A)**：A 后面**可能紧跟的终结符**。

```
① 开始符号 S：把 $（结束符）放进 FOLLOW(S)
② 对 A → αBβ：FIRST(β)\{ε} ⊆ FOLLOW(B)
③ 若 β ⇒ ε（或 B 在末尾）：FOLLOW(A) ⊆ FOLLOW(B)
```

## 3. 预测分析表（LL(1)）构造

```
对每个产生式 A → α：
  ① 把 FIRST(α)\{ε} 填进 M[A, a]（a ∈ FIRST(α)）
  ② 若 ε ∈ FIRST(α)：把 FOLLOW(A) 填进 M[A, b]（b ∈ FOLLOW(A)）
  ③ 一格两个产生式 = LL(1) 冲突（文法要改写/提左因子）
```

## 4. LR 分析表构造步骤

```
① 拓广文法：加 S' → S（用 $ 结束）
② 求 LR(0)/LR(1) 项目集规范族：closure + goto
   · SLR(1)：用 FOLLOW 集决定归约
   · LR(1)：项目带前瞻符；LALR(1)：合并同心项目集（能力≈LR(1)，状态少）
③ 画 ACTION/GOTO 表：
   · 移进项目 A → α·aβ 且 goto(I, a) = J → ACTION[I, a] = shift J
   · 归约项目 A → α· → ACTION[I, a] = reduce A→α（a ∈ FOLLOW(A)/前瞻）
   · S' → S· → ACTION[I, $] = accept
④ 冲突：
   · 移进-归约 → 用优先级/结合性消解（yacc 的 %left）
   · 归约-归约 → 一般文法有问题
```

## 5. 属性文法要点

| 概念 | 含义 |
|------|------|
| 综合属性 | 从子节点算到父节点（自底向上） |
| 继承属性 | 从父/左兄弟算到子节点（自顶向下/左到右） |
| **S 属性 SDD** | 只用综合属性 → 可以**自底向上**在 LR 里边解析边算 |
| **L 属性 SDD** | 继承属性只依赖"左边" → 可以**自顶向下/一遍**算完 |
| 语义规则 | 产生式上挂的等式/动作（bison 的 `$$ = $1 + $3`） |

## 6. 数据流方程模板

**到达定值**（正向）：

```
GEN(B)：B 里产生、且之后没被重新定值的定值
KILL(B)：B 里被杀掉的定值（同一变量被重新定值）
IN[B]  = ∪ OUT[P]（所有前驱 P）
OUT[B] = GEN ∪ (IN[B] − KILL)
初值：OUT = GEN（全部空则迭代）
```

**活跃变量**（反向）：

```
USE(B)：B 里先使用后定值的变量；DEF(B)：B 里定值（用之前没用的）
OUT[B] = ∪ IN[S]（所有后继 S）
IN[B]  = USE ∪ (OUT[B] − DEF)
```

**用途**：常量传播/死代码（到达定值）、寄存器分配（活跃变量）——[优化篇](07-代码优化.md)有实测。

## 9. 要点回顾（一句版）

1. **3 型管词法、2 型管语法**（乔姆斯基）；识别器分别是有限自动机、下推自动机
2. **LL(1)**：FIRST/FOLLOW → 预测分析表；**LR**：项目集 → ACTION/GOTO，LALR 是工程默认
3. **冲突消解**：移进-归约用优先级/结合性；归约-归约多为文法缺陷
4. **属性文法**：综合自底向上、继承自顶向下；S/L 属性决定实现方式
5. **数据流方程**：到达定值正向、活跃变量反向——优化的情报系统
6. 本篇是查漏用的；理解与实操看前 8 篇
