# 编译原理

语言怎么一步步变成程序：**词法 → 语法 → 语义 → IR → 优化 → 代码生成**，外加 AI 时代的**图编译器（推理引擎）**。

本章讲**编译器内部的原理**；相邻话题：**ISA/流水线**见[体系结构与 CPU](../computer-organization/04-指令系统与ABI.md)篇，**可计算性/图灵机**见[离散数学](../discrete-mathematics/08-代数结构与可计算性.md)篇。

> 涉及工具：clang 18（IR/汇编对照）、手写词法器/解析器、bison（LALR 解析器）。

## 学习路径

1. **先看"能看到的东西"**：第 1 篇的 `-E/-S/-c/-emit-llvm`（编译产物链）+ 第 7 篇的 `-O0 vs -O2` 对比——**先建立"编译器在干什么"的直觉**
2. **前端理论与动手**：第 2~4 篇（正则/文法/自动机 + 手写 tokenizer/解析器 + bison）
3. **IR 与后端**：第 5~8 篇（SSA、栈帧、优化、寄存器分配）
4. **结合应用方向**：第 9 篇（AI 编译器）
5. 手算部分（LR 表等）只在需要时查第 10 篇

## 重点

- **IR 是枢纽**：前端 N 个 + 后端 M 个 = N+M（LLVM 生态的基础）；三地址码 → **SSA + φ** 是现代核心
- **优化证据链**：常量折叠成 `ret i32 10`、调用被内联、出现 φ 与 `<4 x i32>` 向量类型、汇编明显变短
- **正则管词法、文法管结构**（乔姆斯基 3 型/2 型）；DFA 保证词法线性扫描、LR 比 LL 更能容忍文法的"野性"
- **手写 vs 工具**：递归下降错误信息好（主流语言编译器用它）；bison 自动生成 LALR（表达式密集场景）
- **优化 = IR 上的等价变换**；**UB 是优化的许可证**（`nsw` 标记让编译器更大胆）
- **AI 编译器**：图 IR + **算子融合**（省显存读写 = 提高算术强度）+ autotuning 选最快 kernel + 显存复用——传统编译器的同一套骨架
