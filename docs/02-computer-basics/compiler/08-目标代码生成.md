# 目标代码生成

最后一站：把 IR 变成**目标机器的指令**——三件事：**指令选择、寄存器分配、指令调度**（外加收尾的窥孔优化）。

## 1. 指令选择（Instruction Selection）

把 IR 操作映射到目标指令：**用目标机的指令模式去"覆盖"IR 树**（树覆盖）。

- 一个 IR 操作可能对应多条指令（`x = a*4 + b` → `lea (%b,%a,4), %x` 一条搞定）
- 也可能对应一条（`x = a + 1` → x86 的 `inc`）
- **ISA 的差异在这里吸收**（x86 变长/CISC vs ARM 定长/RISC 见 [ISA 篇](../computer-organization/04-指令系统与ABI.md)）

## 2. 寄存器分配（Register Allocation）

寄存器只有几十个，变量可能上千 → **把变量塞进寄存器，塞不下的放栈**。

**图着色思路**（经典算法）：

```
① 建"冲突图"：两个变量"同时活着"（活跃变量分析）→ 连一条边
② 用 k 种颜色（k = 可用寄存器数）着色：相邻不能同色
③ 度数 < k 的节点优先着色；着色失败 → 选一个"溢出"到栈上，再重来
```

**实测（`-O2` 汇编的循环）**：

```asm
cmpl	$8, %esi          ; 循环次数比较 —— 循环变量在寄存器里
jmp	.LBB2_7
pxor	%xmm1, %xmm1      ; 向量寄存器（xmm）参与计算
movdqu	(%rdi,%r8), %xmm3 ; 从内存搬到向量寄存器
```

**要点**：`-O0` 时变量都在栈上（alloca）；`-O2` 后循环变量/累加器全在寄存器 + xmm（实测）。

## 3. 指令调度（Instruction Scheduling）

目标机有**延迟**（访存 ~4 周期、除法几十周期 [流水线篇](../computer-organization/05-CPU与流水线.md)）——编译器把**不相关指令插进延迟间隙**，减少停顿：

```
a = load(...)      ; 要等 4 周期
b = a + 1          ; 依赖 a → 停顿
c = x * y          ; 不依赖 a → 调度到这里填隙
```

（现代 CPU 有乱序执行自动填，所以编译器调度的收益比过去小——但**访存密集/长延迟指令**仍有价值。）

## 4. 窥孔优化（Peephole）

生成后再"用望远镜看几条指令"，替换成更优的局部模式：

```
mov %rax, %rbx        →      （删掉）        —— 合并/删除多余搬运
mov %rbx, %rax
add $0, %rax          →      （删掉）        —— 加 0 无害
jmp L1; L1:           →      （删掉跳转）    —— 跳到下一行
```

小、快、有效——几乎所有编译器最后都跑一遍。

## 5. 实测：同一函数的两种"目标代码"

| | `-O0` | `-O2` |
|--|:---:|:---:|
| 汇编行数 | 多 | 明显更少 |
| 指令数 | 多（每步 load/store 栈） | 少（值留寄存器） |
| 向量指令（xmm/`movdqu`） | 无 | **有** |
| 栈帧 | 完整（push rbp） | 常被省略 |

**读汇编的小技巧**：`clang++ -S` 加上 `-fverbose-asm` 会有更多注释；对照 IR 看"哪一步被展开/向量化"更直观。

## 6. 和体系结构的连接

目标代码生成**直接面对 ISA/微架构**：

- 指令集（x86/ARM/RISC-V）决定可选指令
- 流水线/乱序决定调度价值
- 缓存/访存延迟决定"数据布局优先级"（[roofline](../computer-organization/07-性能模型与roofline.md)）

**这就是"编译器 + 体系结构"不可分的原因**：好的代码生成 = 对目标机了如指掌。

## 7. 要点回顾

1. **指令选择**：树覆盖把 IR 映射到目标指令（`lea` 一条顶多条）
2. **寄存器分配**：冲突图 + k 着色 + 溢出到栈；实测 `-O2` 下循环变量/累加器都在寄存器/xmm
3. **指令调度**：填补延迟间隙（现代 CPU 乱序执行分担了大部分）
4. **窥孔优化**：收尾的局部模式替换（删多余 mov/加 0/相邻跳转）
5. **对比**：-O2 的汇编明显变短，且有向量指令、帧常省略
6. **代码生成 = 编译器与体系结构的交界**：ISA 决定指令、流水线决定调度、缓存决定数据布局
