# 语义分析与中间代码

语法管"结构对不对"，语义管"意思对不对"：变量定义了没、类型匹配吗——然后把语法树变成**中间代码（IR）**。

## 1. 符号表（Symbol Table）

编译器的"字典"：**名字 → 信息**（类型、作用域、存储位置、是否函数……）。

- **作用域链**：`{ }` 嵌套时压栈/弹栈；查找从内层往外
- **重名规则**：同一作用域不能重复定义（C++ 的重载是特例，需要签名区分）
- 实现：哈希表 + 作用域栈（[数据结构章的哈希表](../data-structure/08-哈希表.md)）

**靠它抓的错**：未定义变量、重复定义、跨作用域引用。

## 2. 类型检查

| 检查 | 例子 |
|------|------|
| 类型匹配 | `"abc" + 1`（多数语言报错）/ `int*` 与 `double*` 混用 |
| 函数调用 | 参数个数/类型/返回类型 |
| 控制流 | `return` 类型、未初始化变量（部分靠数据流分析） |

**类型推导**（C++ `auto`、Rust 推断）也是语义分析阶段的工作：局部推出来的类型**填回符号表**。

## 3. 语法制导翻译（SDD/SDT）

思想：**在文法产生式上挂"动作"**，一边解析一边算值/生成代码。

- **综合属性**：从子节点算上来（`E.val = E1.val + T.val`）
- **继承属性**：从父/兄弟传下去（声明类型传给变量）
- **S 属性 / L 属性**：只用综合（自底向上好算）/ 只允许"从左到右"的继承——对应 LR / LL 的实现方式
- SDT = SDD + 动作插在产生式里（bison 的 `{ $$ = $1 + $3; }` 就是它 第 4 篇实测）

## 4. 中间代码：三地址码与 SSA

**三地址码**：每条指令最多一个运算、三个地址（两个源 + 一个目标）：

```
t1 = b * c
t2 = a + t1
x  = t2
```

教材里常写成**四元式** `(op, arg1, arg2, result)`，便于表驱动生成。

**SSA（静态单赋值）**：每个变量**只赋值一次**——分支汇合处用 **φ（phi）函数**选值：

```
if (cond) x1 = 1; else x2 = 2;
x3 = φ(x1, x2)          ; 从哪条路来就取哪个
```

**为什么 SSA 重要**：变量的"定义-使用"关系一目了然 → 优化（常量传播、死代码删除）和寄存器分配都变简单——**现代编译器（LLVM/Go/JVM）的核心 IR 都是 SSA**。

## 5. 实测：看真实 IR（同一个函数的两个版本）

**`-O0` 的 IR（栈式，未做 SSA）**：

```llvm
define dso_local noundef i32 @_Z3addii(i32 noundef %0, i32 noundef %1) #0 {
  %3 = alloca i32, align 4        ; 参数也先丢栈上
  store i32 %0, ptr %3, align 4
  %5 = load i32, ptr %3, align 4
  %7 = add nsw i32 %5, %6
```

**`-O2` 的 IR（SSA）**：同一个程序里出现 `phi` 节点（循环/分支汇合处），load/store 被寄存器值取代。

**从 IR 还能看出别的语义信息**：

- `noundef`：参数不是未定义值
- `add nsw`：**带符号溢出是未定义行为**（`nsw` = no signed wrap）——这正是"溢出被划为 UB、编译器因此敢于假设"在 IR 层的体现

## 6. 为什么 IR 要分多级

```
AST（贴近语法） → 高层 IR（贴近语言语义，如 C++ 的异常/虚表）
              → 低层 IR（贴近机器，如 LLVM IR） → 机器 IR（贴近具体芯片）
```

- 高层优化（内联、模板展开）在高层做；低层优化（寄存器分配、调度）在低层做
- AI 编译器的"计算图"也是 IR 的一种（第 9 篇）

## 7. 要点回顾

1. **符号表**：作用域栈 + 哈希；抓未定义/重复定义；类型推导的结果也回填它
2. **类型检查**：匹配/调用/控制流；SDD/SDT 把"算值"挂在产生式上（bison 的 `$$/$1` 就是）
3. **三地址码/四元式**：教材标准中间形式；**SSA + phi** 是现代编译器的核心（一眼看出定义-使用）
4. **对比**：`-O0` 的 IR 是 alloca/store/load（栈式）；`-O2` 变 SSA（出现 phi）
5. IR 里的 `nsw` 标记 = 有符号溢出是 UB —— 编译器语义和语言规则在这里对上
6. **多级 IR**：高层做语言级优化、低层做机器级优化；AI 的计算图也是 IR
