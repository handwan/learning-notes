# 语法分析（上）：文法与递归下降

词法给了 token 流，语法分析要回答："这串 token 符不符合语法？结构是什么？"——工具是**上下文无关文法**，最常用的实现是**递归下降**。

## 1. 上下文无关文法（CFG）

四元组 `G = (V_T, V_N, P, S)`：终结符、非终结符、产生式、开始符号。

```
expr   → term (('+' | '-') term)*        # 表达式
term   → factor (('*' | '/') factor)*    # 项（优先级更高）
factor → NUMBER | '(' expr ')'           # 因子：数字或括号
```

**推导**：从开始符号出发，不断用产生式替换非终结符，直到全变成终结符。
`expr ⇒ term ⇒ factor ⇒ NUMBER` —— 得到的序列叫**句子**。

**语法树**：推导的树形表示。**二义性**：同一句子有两棵不同的语法树——经典例子是"悬空 else"（`if a then if b then s1 else s2`，else 归谁），算法上靠"最近未匹配"规则消除。

## 2. 递归下降：最实用的手写方法

**每个非终结符写一个函数**，函数体就是它的产生式——自然支持优先级：

```cpp
long long expr() {                    // expr → term (('+'|'-') term)*
    long long v = term();
    for (;;) {
        if (*s == '+') { ++s; v += term(); }
        else if (*s == '-') { ++s; v -= term(); }
        else return v;
    }
}
long long term() {                    // term → factor (('*'|'/') factor)*
    long long v = factor();
    for (;;) { ... '*': v *= factor(); '/': v /= factor(); ... }
}
long long factor() {                  // factor → NUMBER | '(' expr ')'
    if (*s == '(') { ++s; long long v = expr(); ++s; return v; }
    return number();
}
```

**实测**（一个 30 行的表达式计算器）：

```
1+2*3            = 7     （优先级正确：先乘后加）
(1+2)*3          = 9
2*(3+4*(5-1))    = 38     （括号嵌套）
100/5-3*4        = 8     （同级从左到右）
1+2+3+4          = 10
```

**递归下降的优点**：代码就是文法、易读易改（真实编译器大多用它）；**缺点**：遇到**左递归**会无限递归。

## 3. 左递归：必须消除

```
expr → expr '+' term        ❌ 直接左递归：expr() 一进来又调 expr()
```

**消除方法**（改写为右递归/循环）：

```
expr → term rest
rest → ('+' term rest) | ε
```

等价于把"左递归"变成"循环"——上面的 `expr()` 用 `for(;;)` 正是消除后的写法。

## 4. 错误处理（工程视角）

- **恐慌模式（panic mode）**：发现错误就丢弃 token 直到同步点（如 `;`/`}`），然后继续——一次编译能报多个错
- 错误恢复的质量直接影响用户体验（clang 的报错好，部分就赢在这里）

**实测的一个错误提示**（解析器遇到非数字）：

```
语法错误：期望数字，遇到 ')'
```

## 5. 和下一站的关系

递归下降是 **LL 类**（自顶向下、从左到右）的手写形式；要有"自动生成"的解析器（yacc/bison），就要学 **LR 类**（自底向上）——但**思路是表驱动 + 状态机**，第 4 篇展开。

## 6. 要点回顾

1. **CFG 四元组**；推导/语法树；**二义性**（悬空 else 是经典例）
2. **递归下降**：一个非终结符一个函数、自然处理优先级——真实编译器的主流（实测 5 个表达式全对）
3. **左递归必须消除**（改写成循环/右递归），否则无限递归
4. **错误处理**：恐慌模式恢复、同步点；报错质量是编译器体验的关键
5. 递归下降 = LL 的手写形式；要"自动生成解析器"就得学 LR（下篇）
