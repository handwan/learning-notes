# 运行时存储组织

程序跑起来"变量住哪"：函数调用怎么开栈、递归怎么工作、堆怎么管——**栈帧是理解调用/递归/调试器的基础**。

## 1. 活动记录（栈帧）

每次函数调用在栈上开一块**活动记录**：

```
高地址
┌──────────────────────┐
│ 参数（第 7 个起，见 ABI 篇）│
├──────────────────────┤
│ 返回地址（call 压的）    │ ← %rbp 指到这里附近
├──────────────────────┤
│ 保存的 %rbp（上一个帧）  │ ← 典型的帧指针链
├──────────────────────┤
│ 局部变量 + 临时值       │ ← %rsp 往下长
│ （含 alloca 的空间）     │
└──────────────────────┘
低地址
```

**实测（`-O0` 汇编的 prologue 第 1 篇）**：

```asm
_Z3addii:
	pushq	%rbp            ; 保存上一个帧指针
	movq	%rsp, %rbp      ; 建立当前帧
```

**实测（IR 视角）**：`-O0` 里每个函数的局部变量都是 `alloca`（栈空间）；`-O2` 里值留在**寄存器**（帧都省了）——"栈帧"是调试构建的概念，优化构建常常没有完整的帧。

## 2. 变量分别住哪

| 类别 | 位置 | 生命周期 |
|------|------|---------|
| 局部变量（auto） | 栈帧 | 函数返回即失效 |
| 静态/全局 | 数据段（.data/.bss） | 整个进程 |
| 动态分配（new/malloc） | **堆** | 手动/GC 管理 |
| 寄存器变量 | 寄存器（优化后） | 指令级 |

**"返回局部变量指针"为什么是 bug**：它指向的栈帧已经销毁——那块内存随时会被后面的调用覆盖。

## 3. 嵌套作用域：静态链 vs display

支持嵌套函数（如 Pascal）需要访问外层函数的变量：

| 方案 | 做法 |
|------|------|
| **静态链** | 每个帧存一个指针指向上层词法作用域的帧，逐级爬 |
| **display 表** | 一个数组直接记录各层的当前帧（快、但维护成本高） |

C++ 的 lambda 捕获、闭包（closure）是"堆上的环境 + 函数指针"的现代形态——**本质也是"记住外层变量的位置"**。

## 4. 参数传递

| 方式 | 含义 | 例子 |
|------|------|------|
| 值传递 | 拷贝一份 | C 默认 |
| 引用传递 | 传地址、函数能改实参 | C++ `int&` |
| 指针传递 | 传地址（显式解引用） | C `int*` |

**工程现实**：现代 ABI 用**寄存器传参**（前 6 个整型 + 8 个浮点 见 [ABI 篇](../computer-organization/04-指令系统与ABI.md)），大结构体按值传会在栈上拷贝（所以"传 const&"）。

## 5. 堆管理（GC 之前的世界）

- **显式管理**：`malloc/free`、`new/delete`——快但易错（泄漏/悬垂/double free）
- **智能指针**：RAII 把生命周期绑到作用域
- **垃圾回收（GC）**：标记-清扫 / 引用计数 / 分代（Java/Python/Go）——编译器要在没有"作用域"概念时也能知道对象死活（保守扫描/精确栈图）

**和 AI 推理的关联**：推理引擎自己做"显存池化/复用"（arena 分配），本质是同一类问题——**生命周期管理**（第 9 篇展开）。

## 6. 实测：栈帧的"证据"

```bash
clang++ -O0 -S t.cpp -o t.s      # -O0：完整栈帧（push rbp / mov rsp,rbp 实测）
clang++ -O2 -S opt.cpp -o opt.s  # -O2：很多帧被优化掉，值直接留寄存器
clang++ -O0 -emit-llvm -S t.cpp  # IR 里的 alloca 就是栈帧里的局部空间
```

## 7. 要点回顾

1. **活动记录**：参数/返回地址/保存的 rbp/局部变量；`push rbp; mov rsp,rbp` 是标准帧建立（实测）
2. **变量住哪**：局部在栈（返回即失效）、全局在数据段、动态在堆、优化后在寄存器
3. **嵌套作用域**：静态链/display 表；现代对应物是闭包（堆上的环境）
4. **参数传递**：值/引用/指针；现代 ABI 优先寄存器传参，大对象引用传（见 ABI 篇）
5. **堆管理**：手动 → 智能指针 → GC；推理引擎的**显存池化**是同一问题的现代版本
6. **栈帧是调试构建的概念**：`-O2` 下大量帧/局部变量被寄存器取代（汇编明显变短）
