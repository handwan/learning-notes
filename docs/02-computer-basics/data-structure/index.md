## 重点

- **连续内存是一等公民**：手写数组遍历比手写链表快 **7 倍**；数组头插则被链表头插碾压（量级差距）
- **均摊 vs 平均**：动态数组扩容翻倍 → 均摊 O(1)（千万次 push 也几乎线性）；"哈希 O(1)"是平均
- **哈希表三件事**：哈希质量（坏哈希平均探测几百次）、冲突策略（开放寻址快数倍）、已知规模先分配桶
- **选型的四个信号**：有序要树、最值要堆、前缀要 Trie、纯查要哈希
- **教材经典**：KMP 的 `next` = 最长相等前后缀（最坏数据朴素 1.99 亿次比较 vs KMP 40 万次）；nextval 在重复模式上再省 29%；二叉树 n0 = n2 + 1；哈夫曼实测 3.14 bit/字符（压到 39%）
- **B 树/B+ 树**：5 阶插 2 万随机 key → 高度 8、分裂 7396 次（节点占用校验通过）；B+ 树插 5 万后叶子链表扫描有序 —— 数据库索引的同一个东西
- **图**：CSR 构建 **7.6 倍**、BFS 快 **1.8 倍**；Prim/Kruskal 实测权值一致；Dijkstra 与 Bellman-Ford 对拍一致；Floyd 300 点跑得动；关键路径工期 13
- **排序**：百万级基数最快，快排 / 归并 / 堆排同档；稳定性：插入/冒泡/归并/基数稳定；小数组用插入排序
- **工程结构五件套**：连通性→并查集（两个优化快约 500 倍）、存在性→布隆（0.64% 误判、128 KB）、缓存→LRU（纳秒级）、有序范围+并发→跳表、窗口→单调队列
- **别背结论**：列操作 → 查表 → 比代价（复杂度/内存）→ **实测确认**
