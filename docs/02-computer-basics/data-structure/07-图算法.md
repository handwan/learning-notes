# 图算法

图的经典算法：最小生成树（Prim/Kruskal）、最短路（Dijkstra/Floyd）、拓扑排序、关键路径。

> 实现都是手写；遍历与 CSR 存储在[图结构](06-图结构.md)篇。

## 1. 术语速查

| 术语 | 含义 |
|------|------|
| 无向图/有向图 | 边有无方向 |
| 度 / 入度 / 出度 | 相连边数 / 指向它的边 / 从它出去的边 |
| 连通图 / 连通分量 | 任意两点可达 / 极大的连通子图 |
| 生成树 | 连通图的极小连通子图（n 个点、n−1 条边，无环） |
| **AOV 网** | 顶点表示活动的 DAG → 拓扑排序 |
| **AOE 网** | 边表示活动（带权=时间）→ 关键路径 |

## 2. 最小生成树（MST）

**问题**：把 n 个点连起来，边权和最小（n−1 条边）。

**Prim（加点法）**：

```
从任意点开始：每次找"已选集合到外部"最近的点，连进来（距离用 dist[] 维护）
朴素 O(n²)（每轮线性找最近点）；堆优化 O(m log n)
适合：稠密图（边多）
```

**Kruskal（加边法）**：

```
所有边从小到大排序，依次尝试加入：如果两端还不连通（并查集判）就加入
复杂度 O(m log m)（排序是瓶颈）
适合：稀疏图（边少）
```

**实测（1000 点、5000 边，随机权值）**：

| 算法 | 速度 | MST 权值 |
|------|:---:|:---:|
| Prim（朴素 O(n²)） | 慢些（扫 n²） | 12956 |
| Kruskal（排序 + 并查集） | **快 7 倍** | 12956 |

**两算法结果一致**（这是正确性的最好证明）；这个规模下稀疏图 Kruskal 快（不用扫 n² 矩阵）。

**关键点**：

- Prim 的 `dist[v] = min(dist[v], w(u,v))` 是"到已选集合的最短边"——别和 Dijkstra 的"到起点的最短路径"混淆（**算法形状几乎一样，更新方式不同**）
- Kruskal 靠**并查集**判环（见工程结构篇的路径压缩 + 按秩合并）

## 3. 最短路

**Dijkstra（单源，非负权）**：

```
dist[s] = 0，其余 ∞；每轮选出未确定里 dist 最小的点，用它松弛邻居（dist[v] = min(dist[v], dist[u]+w)）
朴素 O(n²)；堆优化 O(m log n)
```

**前提**：边权**必须非负**（有负权用 Bellman-Ford/SPFA）。

**实测（1000 点 5000 边）**：

- 朴素 Dijkstra 的**结果与 Bellman-Ford 逐点一致**（Bellman-Ford 作为标准答案对拍）
- 前面的 Prim/Kruskal 与它同源套路：都是"贪心 + 松弛"

**Floyd（多源，O(n³)）**：

```
三重循环：for k, for i, for j: D[i][j] = min(D[i][j], D[i][k] + D[k][j])
思想：允许经过中转点 k —— "经过前 k 个点中转的最短路"
```

**实测（300 点）**：**结果与 Dijkstra 对拍一致**（全源抽查）。

| | Dijkstra | Floyd |
|--|---------|-------|
| 源 | 单源 | **全部点对** |
| 复杂度 | O(n²) 或 O(m log n) | **O(n³)**（固定） |
| 负权 | ❌ | ✅ 能处理（不能有负环） |
| 适合 | 稀疏 / 单源 | 稠密 / 全源（n 小） |

**无权图**：BFS 一层层扩散就是最短路（05 篇）。

## 4. 拓扑排序（AOV）

**问题**：给"先修课"式的依赖关系排出合法顺序（DAG 才有解）。

```
每次输出入度为 0 的点（入队），并把它的邻居入度减 1；减到 0 就入队
队列空时若输出数 < n → 有环（无法拓扑排序）
```

实测已经在[图结构](06-图结构.md)篇做过：产出的顺序满足所有边的方向；**顺带能检测环**（有环时有点永远不入队）。

## 5. 关键路径（AOE）

**问题**：工程最少要多久完成？哪些活动**不能拖**（拖一天工期拖一天）？

```
ve[v]：事件 v 的最早发生时间（正向拓扑递推，取最大）
vl[v]：事件 v 的最晚发生时间（逆拓扑递推，取最小）
活动 (u,v,w) 是关键活动 ⟺ ve[u] == vl[v] - w（没有机动时间）
```

**实测（8 个活动的小工程）**：

| 指标 | 结果 |
|------|:---:|
| 总工期 ve[终点] | **13** |
| 关键活动数 | **4**（路径 0→2→3→5→6，2+4+3+4 = 13） |

**要点**：

- 关键路径可能不唯一；缩短工期要缩短**关键活动**（非关键活动有"松弛时间"）
- 求 vl 需要逆拓扑序（从终点倒推）

## 6. 要点回顾

1. **MST**：Prim 加点（稠密）/ Kruskal 加边（稀疏，排序+并查集判环）——实测权值一致（12956），稀疏下 Kruskal 快 7 倍
2. **Prim vs Dijkstra**：形似神不同——Prim 更新"到集合的最近边"，Dijkstra 更新"到起点的最短距离"
3. **Dijkstra**：非负权、单源、贪心松弛（实测与 Bellman-Ford 完全一致）；**Floyd**：全源、O(n³)、能带负权
4. **拓扑排序**：AOV 排依赖；入度法顺带检测环
5. **关键路径**：ve/vl 正逆递推；`ve[u] == vl[v]-w` 判定关键活动（实测工期 13、4 个关键活动）
6. 这些算法的共同底色：**贪心（Prim/Dijkstra）+ 松弛（Dijkstra/Bellman-Ford/Floyd）+ 并查集（Kruskal）**——都是前面结构知识的组合
