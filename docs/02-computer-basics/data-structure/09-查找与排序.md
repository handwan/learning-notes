# 查找与排序

教材最后两块：**查找**（顺序/折半/分块）与**八种排序**（手写 + 复杂度 + 稳定性 + 实测）。

> 实现都是手写；散列表查找见[哈希表](08-哈希表.md)篇。

## 1. 查找

| 方法 | 前提 | 复杂度 | 备注 |
|------|------|:---:|------|
| 顺序查找 | 无 | O(n) | 无序表唯一选择；链表也只能顺序 |
| **折半查找** | **有序 + 顺序存储** | O(log n) | 判定树高度 ≈ log2(n+1) |
| 分块查找 | 块间有序、块内无序 | 索引 O(log 块数) + 块内 O(块长) | "索引表 + 块"的折中 |
| 散列查找 | 无（哈希函数） | 平均 O(1) | 见哈希表篇 |

**折半实现**（注意 `lo + (hi - lo) / 2` 防溢出）：

```cpp
int binary_search(const int* a, int n, int key, int* cnt) {
    int lo = 0, hi = n - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;   ++*cnt;
        if (a[mid] == key) return mid;
        if (key < a[mid]) hi = mid - 1; else lo = mid + 1;
    }
    return -1;
}
```

**实测（100 万元素有序表）**：

| 查找目标 | 比较次数 |
|---------|:---:|
| 最小元素（最左） | 19 次 |
| 最大元素（最右） | 20 次 |
| 不存在的元素 | 20 次 |

（对照：顺序查找平均 **50 万次**比较——log2(1e6) ≈ 20 是折半的"天花板"。）

**分块查找**：把表分块，建"每块最大值 + 起始位置"的索引表；先查索引定块，再块内顺序找。适合"频繁插入、偶尔查找"且要求不高的场景（折中的复杂度/维护成本）。

## 2. 八种排序一览

| 排序 | 思想 | 平均 | 最坏 | 空间 | 稳定 |
|------|------|:---:|:---:|:---:|:---:|
| 直接插入 | 把元素插进前面已排好的部分 | O(n²) | O(n²) | O(1) | ✅ |
| 希尔 | 按增量分组插入（增量递减） | O(n^1.3) 左右 | O(n²) | O(1) | ❌ |
| 冒泡 | 相邻两两交换，每趟冒一个极值 | O(n²) | O(n²) | O(1) | ✅ |
| 快速 | 选基准分区，左右递归 | O(n log n) | O(n²) | O(log n) 栈 | ❌ |
| 简单选择 | 每趟选最小放前面 | O(n²) | O(n²) | O(1) | ❌ |
| 堆排 | 建大顶堆，反复"换堆顶再下沉" | O(n log n) | O(n log n) | O(1) | ❌ |
| 归并 | 两半排好再合并 | O(n log n) | O(n log n) | O(n) | ✅ |
| 基数 | 按位分配-收集（LSD） | O(d(n+r)) | 同左 | O(n+r) | ✅ |

**稳定性**：值相等的元素排序后**相对顺序不变**。要稳定就选插入/冒泡/归并/基数。

## 3. 八种排序（力扣风格实现）

都是 `vector<int>&` 原地排序（力扣写法）；换成 `int* a, int n` 版本只是把 `a.size()` 换成 `n`，算法完全一样。调用方式就是「八选一」塞进 `class Solution`：

```cpp
class Solution {                       // 力扣 912：换上任意一个排序即可
public:
    vector<int> sortArray(vector<int>& nums) {
        quickSort(nums);               // 八选一
        return nums;
    }
};
```

```cpp
// ① 直接插入（稳定）：像抓扑克牌，往前找位置插
void insertSort(vector<int>& a) {
    for (int i = 1; i < (int)a.size(); ++i) {
        int cur = a[i], j = i - 1;
        while (j >= 0 && a[j] > cur) { a[j + 1] = a[j]; --j; }   // 严格大于才后移 → 稳定
        a[j + 1] = cur;
    }
}

// ② 希尔：按增量分组做插入，gap 递减到 1
void shellSort(vector<int>& a) {
    for (int gap = (int)a.size() / 2; gap > 0; gap /= 2)
        for (int i = gap; i < (int)a.size(); ++i) {
            int cur = a[i], j = i - gap;
            while (j >= 0 && a[j] > cur) { a[j + gap] = a[j]; j -= gap; }
            a[j + gap] = cur;
        }
}

// ③ 冒泡（稳定）：相邻两两交换 + 无交换即停
void bubbleSort(vector<int>& a) {
    for (int end = (int)a.size() - 1; end > 0; --end) {
        bool swapped = false;
        for (int i = 0; i < end; ++i)
            if (a[i] > a[i + 1]) { swap(a[i], a[i + 1]); swapped = true; }
        if (!swapped) break;                                     // 已有序 → 提前结束
    }
}

// ④ 简单选择：每趟选最小放前面（远距离交换 → 不稳定）
void selectSort(vector<int>& a) {
    for (int i = 0; i + 1 < (int)a.size(); ++i) {
        int minIdx = i;
        for (int j = i + 1; j < (int)a.size(); ++j)
            if (a[j] < a[minIdx]) minIdx = j;
        swap(a[i], a[minIdx]);
    }
}

// ⑤ 快速：随机基准 + 三路划分（等于基准的一坨不用再排）
void quickSort(vector<int>& a, int l, int r) {
    if (l >= r) return;
    swap(a[l + rand() % (r - l + 1)], a[l]);                     // 随机基准，防退化
    int p = a[l], lt = l, i = l + 1, gt = r;                     // [l,lt) < p；[lt,i) == p；(gt,r] > p
    while (i <= gt) {
        if (a[i] < p) swap(a[lt++], a[i++]);
        else if (a[i] > p) swap(a[i], a[gt--]);
        else ++i;
    }
    quickSort(a, l, lt - 1);
    quickSort(a, gt + 1, r);
}
void quickSort(vector<int>& a) { quickSort(a, 0, (int)a.size() - 1); }

// ⑥ 堆排：建大顶堆，反复把堆顶换到末尾再下沉
void siftDown(vector<int>& a, int n, int i) {
    while (true) {
        int m = i, l = 2 * i + 1, r = 2 * i + 2;
        if (l < n && a[l] > a[m]) m = l;
        if (r < n && a[r] > a[m]) m = r;
        if (m == i) break;
        swap(a[i], a[m]); i = m;
    }
}
void heapSort(vector<int>& a) {
    int n = (int)a.size();
    for (int i = n / 2 - 1; i >= 0; --i) siftDown(a, n, i);      // 建堆 O(n)
    for (int end = n - 1; end > 0; --end) { swap(a[0], a[end]); siftDown(a, end, 0); }
}

// ⑦ 归并（稳定）：两半排好再合并，相等取左
void mergeSort(vector<int>& a, vector<int>& tmp, int l, int r) {
    if (r - l <= 1) return;
    int mid = l + (r - l) / 2;
    mergeSort(a, tmp, l, mid);
    mergeSort(a, tmp, mid, r);
    int i = l, j = mid, k = l;
    while (i < mid && j < r) tmp[k++] = (a[j] < a[i]) ? a[j++] : a[i++];   // 相等取左
    while (i < mid) tmp[k++] = a[i++];
    while (j < r)  tmp[k++] = a[j++];
    for (int t = l; t < r; ++t) a[t] = tmp[t];
}
void mergeSort(vector<int>& a) { vector<int> tmp(a.size()); mergeSort(a, tmp, 0, (int)a.size()); }

// ⑧ 基数 LSD（稳定）：从低位到高位，4 趟 8 位计数排序
void radixSort(vector<int>& a) {
    auto key = [](int x) { return (uint32_t)x ^ 0x80000000u; };  // int → 保序的无符号数（负数排前面）
    vector<int> out(a.size());
    for (int shift = 0; shift < 32; shift += 8) {
        int cnt[256] = {};
        for (int x : a) ++cnt[(key(x) >> shift) & 255];
        for (int i = 1; i < 256; ++i) cnt[i] += cnt[i - 1];
        for (int i = (int)a.size() - 1; i >= 0; --i)             // 倒序回填 → 稳定
            out[--cnt[(key(a[i]) >> shift) & 255]] = a[i];
        a = out;
    }
}
```

**稳定性**（由写法决定，一眼能验证）：插入/冒泡只让「严格大于」的往后走；归并相等取左；基数倒序回填——这四种稳定；希尔/快排/选择/堆排有远距离交换，会打乱相等元素的顺序，不稳定。

## 4. 实测（同一份代码）

**100 万随机 int**：基数最快（无比较、4 趟计数）→ 快排 / 归并 / 堆排同档 → 希尔稍慢。

**3 万随机 int（O(n²) 组）**：直接插入最强 > 简单选择 > 冒泡（比较和交换都多，最慢）。

**读表**：

- **基数最快**：key 是固定 32 位（4 趟计数），没有比较开销；key 位数多/范围怪时优势会减弱
- **插入在小规模很强**——所以工程实现（快排/归并的底层）常在小段切回插入排序
- **冒泡最慢**（比较和交换都多），但加了「无交换即停」后：**已排序数组几乎瞬完**
- 正确性对拍：八种实现 vs `std::sort`，覆盖空数组、单元素、有序、逆序、全相同、`INT_MIN/INT_MAX` → **全部一致**

## 5. 怎么选

| 场景 | 选择 |
|------|------|
| 小数组（几十个） | 直接插入（常数最小） |
| 通用大数组 | 快排（实践最快，注意最坏 O(n²) 可用三数取中/随机基准缓解） |
| 要**稳定** | 归并（或基数） |
| 要**最坏也 O(n log n)** + O(1) 空间 | 堆排 |
| key 是范围小的整数 | 计数/基数排序 |
| 基本有序 | 插入/冒泡（冒泡加"无交换即停"优化） |
| 内存放不下 | 外部排序（见 §6） |

## 6. 外部排序（一句版）

数据太大放不进内存：**把文件分段读入、段内排好写回**，再做**多路归并**（k 路归并减少读写趟数）——核心成本是磁盘 IO 而不是比较，所以优化方向是"少读写几趟 + 增大归并路数"。

## 7. 要点回顾

1. **折半查找 O(log n) 的实测**：100 万有序表最多 20 次比较（顺序查找平均 50 万次）
2. **八种排序**：插入/希尔/冒泡/快速/选择/堆排/归并/基数——复杂度、空间、稳定性三张表要记牢
3. **稳定性**只对"多关键字/保持原序"有意义：稳定的是插入/冒泡/归并/基数
4. **实测**（同一份代码）：百万级基数最快，快速 / 归并 / 堆排同档，希尔稍慢；小规模时**插入排序**是黑马，冒泡最慢（但已排序数组几乎瞬完）
5. **选型**：小数组插入、通用快排、要稳定归并、要最坏保证堆排、整数范围小用基数
6. **外部排序** = 分段排序 + 多路归并（瓶颈在 IO）
7. 排序是"综合运用前面的结构"：快排靠栈/递归、堆排靠堆、归并靠数组、基数靠计数桶
