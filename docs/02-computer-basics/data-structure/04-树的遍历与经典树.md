# 树的遍历与经典树

二叉树的性质、四种遍历（递归/非递归）、线索二叉树、树与森林的转换、哈夫曼树与编码——教材里"树"这一章的核心内容。

## 1. 二叉树的性质

| 性质 | 内容 |
|------|------|
| 第 i 层最多 | 2^(i-1) 个节点 |
| 深度 h 的二叉树最多 | 2^h − 1 个节点（满二叉树） |
| 叶子与"度为 2 的节点" | **n0 = n2 + 1** |
| 完全二叉树的编号 | 节点 i 的左孩子 2i、右孩子 2i+1（1 起始编号） |

**举例验证 n0 = n2 + 1**：构造的树有 3 个叶子、2 个度为 2 的节点 → **3 = 2 + 1**（任意二叉树都成立，可归纳证明）。

**为什么**：设节点数 n = n0 + n1 + n2，边数 = n − 1 = n1 + 2n2 → 两式相减即得 n0 = n2 + 1。

## 2. 存储结构

**顺序存储**：只适合**完全二叉树**（用编号直接算下标，不浪费）；一般二叉树用它会浪费大量空间（要补成完全二叉树）。

**二叉链表**（工程标准）：

```cpp
struct TNode {
    int v; TNode *left, *right;
    TNode(int v_) : v(v_), left(nullptr), right(nullptr) {}
};
```

（需要频繁找父节点时再加 `parent` 指针，变成三叉链表。）

## 3. 四种遍历

遍历 = 按某种顺序把每个节点访问一次。四种遍历的区别，只在**“根”放在什么位置**：

| 遍历 | 顺序 | 一句话 | 常见用途 |
|------|------|--------|----------|
| 先序 | 根 → 左 → 右 | 先处理根 | 复制/序列化树、表达式前缀 |
| 中序 | 左 → 根 → 右 | 根在中间 | 二叉搜索树（BST）有序输出、验证 BST |
| 后序 | 左 → 右 → 根 | 根最后处理 | 释放树、表达式求值、子树统计 |
| 层序 | 一层一层，从左到右 | 用队列 | BFS、按层打印 |

### 3.1 递归写法

先序/中序/后序的递归只差“访问根”放在哪一行：

```cpp
/* 先序：根 → 左 → 右 */
void preorder(TNode* t, int* out, int* n) {
    if (!t) return;
    out[(*n)++] = t->v;          // 访问根
    preorder(t->left, out, n);   // 左
    preorder(t->right, out, n);  // 右
}

/* 中序：左 → 根 → 右 */
void inorder(TNode* t, int* out, int* n) {
    if (!t) return;
    inorder(t->left, out, n);
    out[(*n)++] = t->v;
    inorder(t->right, out, n);
}

/* 后序：左 → 右 → 根 */
void postorder(TNode* t, int* out, int* n) {
    if (!t) return;
    postorder(t->left, out, n);
    postorder(t->right, out, n);
    out[(*n)++] = t->v;
}
```

**记忆**：函数名里的“先/中/后”指**根**被访问的时机；左右子树的相对顺序永远是“先左后右”。

### 3.2 非递归中序（显式栈）

递归靠调用栈；把调用栈换成手动维护的栈，就是非递归：

```cpp
void inorder_iter(TNode* t, int* out, int* n) {
    TNode* st[64]; int sp = 0;
    while (t || sp) {
        while (t) { st[sp++] = t; t = t->left; }  // 一路向左，沿途入栈
        t = st[--sp];                              // 弹出：左子树已处理完
        out[(*n)++] = t->v;                        // 访问根
        t = t->right;                              // 转向右子树
    }
}
```

三步循环：**向左走到头 → 弹栈访问 → 转右**。

### 3.3 层序（队列）

层序不是递归，而是 BFS：

```cpp
void levelorder(TNode* t, int* out, int* n) {
    TNode* q[64]; int h = 0, tl = 0;
    if (t) q[tl++] = t;
    while (h < tl) {
        TNode* x = q[h++];                  // 出队
        out[(*n)++] = x->v;                 // 访问
        if (x->left)  q[tl++] = x->left;    // 左孩子入队
        if (x->right) q[tl++] = x->right;   // 右孩子入队
    }
}
```

### 3.4 示例

一棵 6 节点树：

```text
        1
       / \
      2   3
     / \  /
    4  5  6
```

```text
先序: 1 2 4 5 3 6
中序: 4 2 5 1 6 3
后序: 4 5 2 6 3 1
层序: 1 2 3 4 5 6
```

- **先序**：根最先；**中序**：根在中间；**后序**：根最后
- 非递归中序与递归版本结果一致
- **遍历都是 O(n)**；递归/中序非递归的空间是 O(h)，层序队列是 O(w)（w 为最大层宽，最坏 O(n)）

### 3.5 由遍历序列还原二叉树

**前序 + 中序**（或后序 + 中序）在**节点值互异**时可以唯一确定一棵二叉树：前序定根，中序用根的位置分出左右子树，再递归处理。

**前序 + 后序不行**：分不清单孩子是左还是右。

## 4. 线索二叉树

**问题**：二叉链表里 n 个节点有 **n+1 个空指针**（浪费），而且非递归遍历要自己维护栈。

**线索化**：把空指针利用起来——左空指针指"前驱"、右空指针指"后继"（按某种遍历序），用标志位区分"孩子"还是"线索"：

```cpp
struct TBNode {
    int v; TBNode *left, *right;
    int ltag, rtag;        // 0 = 指向孩子，1 = 指向线索（前驱/后继）
    TBNode(int v_) : v(v_), left(nullptr), right(nullptr), ltag(0), rtag(0) {}
};
```

**价值**：中序线索化后，**不用栈就能顺序遍历**；有线索时找前驱/后继 O(1)，否则要到子树最左/最右端，O(h)。工程里很少手写（有更好的迭代器方案），属于教材经典。

## 5. 树与森林 ↔ 二叉树

**孩子兄弟表示法**（左孩子右兄弟）把任意树/森林存成二叉树：

```
树的每个节点：第一个孩子 → 左指针；下一个兄弟 → 右指针
森林 = 各棵树的根当成"兄弟"串起来
```

于是**树的遍历**就借用了二叉树遍历：

- 树的**先根遍历** = 对应二叉树的**先序**
- 树的**后根遍历** = 对应二叉树的**中序**

（这也是"树/森林与二叉树可以相互转换"的含义——存储结构统一了，算法就能复用。）

## 6. 哈夫曼树与编码

**问题**：给字符设计变长编码，让总长度最短（频繁出现的字符用短码、低频长码）——且必须**前缀无歧义**。

**哈夫曼算法**（贪心）：

```
1. 每个字符按频率建一个叶子节点，放进"最小堆"
2. 每次弹出两个频率最小的节点，合并成新节点（频率 = 两者之和）放回堆
3. 堆里只剩一个节点时，它就是哈夫曼树；
   从根到叶子的路径（左 0 右 1）就是每个字符的编码
```

**以文本 `"abracadabra ... banana"` 为例**：

| 字符 | 编码 |
|------|------|
| `a` | `11` |
| `空格` | `1010` |
| `b` | `100` |
| `m` | `01110` |

- 平均码长约 **3.1 bit/字符**（定长 ASCII 8 bit）→ **约 39%**
- **前缀性质成立**：没有任何编码是另一个编码的前缀 → 解码无歧义
- 加权路径长度（WPL）= Σ(频率 × 码长) 最小 → 这就是"最优二叉树"的含义

**工程里**：gzip/zstd/JPEG 等压缩算法都建立在"频率 → 变长编码"上（实际用更复杂的自适应/算术编码，思想同源）。

## 7. 要点回顾

1. **性质**：n0 = n2 + 1（如 3 = 2 + 1）；深度 h 最多 2^h − 1 个节点
2. **存储**：一般二叉树用二叉链表；顺序存储只适合完全二叉树
3. **四种遍历**：先/中/后（递归 ↔ 显式栈）+ 层序（队列）；**前/后 + 中序（值互异时）能唯一还原二叉树**
4. **线索二叉树**：把 n+1 个空指针变成前驱/后继线索，换取"不用栈的中序遍历"（教材经典）
5. **孩子兄弟表示法**：树/森林 ↔ 二叉树互转，遍历算法相互复用
6. **哈夫曼树**：最小堆合并频率 → 前缀码（平均约 3.1 bit/字符、约 39%）
7. **遍历是树一切算法的骨架**（搜索、序列化、求深度、表达式树求值都靠它）
