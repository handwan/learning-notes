# 设备与磁盘

教材"设备管理"这一块：IO 软件怎么分层、为什么要缓冲、磁盘怎么调度、RAID 怎么选。

## 1. IO 软件层次

```text
用户层        read() / write() 系统调用
  ↓
设备无关层     统一抽象（设备命名、缓冲、错误处理）
  ↓
设备驱动       每种硬件的具体操作
  ↓
中断处理       响应硬件中断
  ↓
硬件（控制器 + 设备）
```

**设计要点**：**上层统一、下层各异**——换硬件只需换驱动，上层代码不动。

## 2. 缓冲（Buffer）

**为什么需要缓冲**：

1. 速度不匹配（CPU 快、磁盘慢）
2. 粒度不匹配（进程按字节写，磁盘按块读写）
3. 减少系统调用次数（攒一批再发）

| 类型 | 说明 |
|------|------|
| **单缓冲** | 一块缓冲，读写交替（不能同时） |
| **双缓冲** | 两块，一块读一块写（流水线，重叠） |
| **缓冲池** | 多个缓冲块统一管理（现代 OS 的做法） |

## 3. SPOOLing（假脱机）

**经典例子：打印机**

```text
多个进程都要打印 → 先写进磁盘上的"输出井"（排队）
                → 后台进程按顺序真正打印
```

**效果**：把**独占设备**（打印机）虚拟成**共享设备**——进程不用排队等打印机，写完就返回。

## 4. 磁盘结构

```text
盘面 → 磁道 → 扇区（常见 512B / 4KB）
```

**访问时间 = 寻道时间 + 旋转延迟 + 传输时间**

| 部分 | 说明 | 占比 |
|------|------|:---:|
| **寻道** | 磁头移到目标磁道 | **最慢** |
| 旋转延迟 | 等扇区转到磁头下 | 中 |
| 传输 | 读写数据 | 快 |

**所以磁盘调度的目标**：**减少寻道**（别让磁头来回跳）。

## 5. 磁盘调度算法

| 算法 | 做法 | 问题 |
|------|------|------|
| **FCFS** | 按请求顺序 | 简单；但磁头来回跳，慢 |
| **SSTF** | 先处理**离当前最近**的 | 平均寻道短；但**远的请求可能饿死** |
| **SCAN**（电梯算法） | 单向扫到底，再折返扫 | 公平；中间磁道"占便宜" |
| **C-SCAN** | 只单向扫，回来时不服务 | 更公平 |

**SCAN 为什么叫电梯**：像电梯一路向上、到顶再向下。

## 6. RAID（磁盘冗余阵列）

| 级别 | 做法 | 速度 | 安全 | 空间利用率 |
|------|------|:---:|:---:|:---:|
| **RAID 0** | 条带化（数据分散到多盘） | 快 | ❌ **坏一块全完** | 100% |
| **RAID 1** | 镜像（写两份） | 读快 | ✅ | **50%** |
| **RAID 5** | 条带 + **分布式校验** | 快 | ✅ 容错 1 块 | (n-1)/n |
| RAID 10 | 先镜像再条带（1+0） | 快 | ✅ | 50% |

**怎么选**：

- 要性能不要安全 → RAID 0
- 要安全不惜空间 → RAID 1
- **兼顾（最常用）** → RAID 5
- 又要快又要安全（不惜成本）→ RAID 10

（RAID = 用多盘换带宽/可靠性；硬件 RAID 卡与软 RAID `mdadm` 都常见。）

## 7. 要点回顾

1. **IO 分层**：用户层 → 设备无关 → 驱动 → 中断 → 硬件（上层统一、下层各异）
2. **缓冲**：解决速度/粒度不匹配；单缓冲 → 双缓冲 → 缓冲池
3. **SPOOLing**：独占设备虚拟成共享（打印机）
4. **磁盘调度**：**目标是减少寻道**；FCFS / SSTF（会饿死）/ **SCAN（电梯）** / C-SCAN
5. **RAID**：0（快无冗余）/ 1（镜像）/ **5（条带+校验，最常用）** / 10
