# 概述与系统调用

## 1. 操作系统是什么

**OS = 管理硬件资源 + 给程序提供抽象和服务。**

| 职责 | 说明 |
|------|------|
| **管理** | CPU、内存、磁盘、外设——谁用、用多少、怎么分配 |
| **抽象** | 把硬件包装成好用的接口 |

三个最重要的抽象：

| 硬件 | OS 抽象 |
|------|--------|
| CPU | 进程 / 线程 |
| 内存 | 虚拟地址空间 |
| 磁盘 | 文件系统 |

## 2. 内核态与用户态

CPU 有特权级（x86 有 ring0~ring3，实际只用两级）：

| | 用户态（ring3） | 内核态（ring0） |
|--|---------------|---------------|
| 能执行 | 普通指令 | **特权指令**（改页表、开关中断、IO） |
| 能访问 | 自己的地址空间 | 全部内存 + 硬件 |
| 谁在跑 | 应用程序 | 内核代码 |

**为什么要分**：**安全 + 稳定**——用户程序不能直接动硬件或别的进程的内存。

## 3. 系统调用

**用户程序请求内核服务的唯一入口。**

```
用户程序 → 系统调用（read/write/fork...）→ 陷入内核 → 内核执行 → 返回用户态
```

| 概念 | 例子 | 关系 |
|------|------|------|
| 库函数 | `printf` | 内部调 `write` |
| 库函数 | `malloc` | 内部调 `brk`/`mmap` |
| 系统调用 | `write`、`fork`、`mmap` | 真正进内核 |

**开销在哪**：

1. **模式切换**（用户态 ↔ 内核态）
2. 参数/数据拷贝
3. 缓存/TLB 受影响

> 所以高频小 IO 要**批量/缓冲**（如 `write` 大块、用户态缓冲），减少系统调用次数。

## 4. 中断与异常

| | 中断（Interrupt） | 异常（Exception） |
|--|-----------------|-----------------|
| 来源 | **外部**（键盘、网卡、时钟） | **内部**（除零、缺页、非法指令） |
| 时机 | **异步**（随时可能来） | **同步**（执行到才触发） |
| 作用 | 通知内核处理外设 | 处理错误 / 请求内核服务 |

**中断处理流程**：

```
保存上下文（寄存器）→ 查中断向量表 → 跳处理程序 → 处理 → 恢复上下文返回
```

**时钟中断很关键**：它是**抢占式调度的基础**（时间片用完靠它把进程踢下来）。

**缺页异常**：访问的页不在内存 → 触发异常 → 内核加载页 → 重新执行指令（详见内存管理）。

## 5. OS 结构

| 结构 | 特点 | 例子 |
|------|------|------|
| 宏内核 | 内核功能都在一起，性能好、耦合高 | **Linux** |
| 微内核 | 内核只留最少功能，其余在用户态，安全但切换多 | QNX |
| 混合 | 折中 | Windows、macOS |

## 6. 虚拟化：虚拟机 vs 容器

两种"一台机器跑多个环境"的方案：

| | 虚拟机（VM） | 容器 |
|--|-------------|------|
| 隔离靠 | **Hypervisor**（虚拟硬件） | **内核**（namespace + cgroup） |
| 每个实例带 | **完整的 Guest OS** | 只有应用 + 依赖 |
| 启动 | 分钟级（要启动 OS） | **秒级 / 毫秒级** |
| 开销 | 大（多套 OS） | 小（**共享宿主内核**） |
| 隔离强度 | **强**（硬件级） | 弱一些（内核共享） |

**容器 = namespace + cgroup**：

| 机制 | 作用 |
|------|------|
| **namespace** | 隔离"**看得到什么**"（PID、网络、文件系统、用户…） |
| **cgroup** | 限制"**能用多少**"（CPU、内存、IO） |

> **一句话**：VM 虚拟的是**硬件**，容器虚拟的是**操作系统**。

## 7. 启动过程

```text
通电 → BIOS/UEFI（自检 + 找到启动盘）
     → Bootloader（GRUB：把内核加载进内存）
     → 内核初始化（内存管理、驱动、调度器）
     → init / systemd（PID 1：启动各种用户态服务）
```

| 阶段 | 干什么 |
|------|--------|
| BIOS / UEFI | 硬件自检，找到可启动设备 |
| Bootloader（GRUB） | 加载内核 |
| 内核初始化 | 建立内存管理、加载驱动、启动调度器 |
| init / systemd | **PID 1**，启动用户态服务 |

## 8. 要点回顾

1. **用户态 vs 内核态**：特权指令、为什么要分
2. **系统调用过程**：陷入 → 内核 → 返回；**开销在哪**
3. **中断 vs 异常**：来源、异步/同步；时钟中断的作用
4. **库函数 vs 系统调用**：`printf` vs `write`、`malloc` vs `brk`
5. **虚拟机 vs 容器**：Hypervisor vs namespace+cgroup；隔离强度与开销
