# 文件系统

## 1. 文件系统做什么

把磁盘"一堆块"的硬件，抽象成**目录树 + 文件**。

职责：

- **组织**：数据块怎么分配、回收
- **命名**：路径 → 文件
- **元数据**：权限、大小、时间、属主

## 2. inode

**inode = 文件的"身份证"**：存**元数据 + 数据块位置**。

| 存什么 | 不存什么 |
|--------|---------|
| 类型、权限、属主 | **文件名**（在目录项里！） |
| 大小、时间戳 | |
| 数据块指针（多级索引） | |

**数据块指针**：直接块 → 一级间接 → 二级间接 → 三级间接（文件越大，用越高层）

> **核心理解**：`文件名 → inode → 数据块`
> 目录的本质 = 一张"**文件名 → inode 号**"的表。

## 3. 硬链接 vs 软链接

```bash
ln a.txt b.txt        # 硬链接
ln -s a.txt c.txt     # 软链接（符号链接）
```

| | 硬链接 | 软链接 |
|--|-------|-------|
| 本质 | **指向同一个 inode** | 新文件，**内容是目标路径** |
| inode | 相同 | 不同 |
| 跨分区 | ❌ 不行 | ✅ 可以 |
| 指向目录 | ❌ 不允许 | ✅ 允许 |
| 目标删除后 | 数据还在（链接计数减 1） | **悬空**（指向不存在的路径） |
| `ls -l` | 计数 +1 | 显示 `c.txt -> a.txt` |

## 4. 文件描述符（fd）

**fd 是一个小整数**（0=stdin、1=stdout、2=stderr 是默认占用的）。

**打开文件的三张表**（经典考点）：

```
fd（进程私有）──→ 打开文件表项（全局共享：偏移量、状态标志）──→ inode（全局：元数据 + 数据块位置）
```

| 表 | 作用域 | 内容 |
|----|--------|------|
| 进程 fd 表 | 每进程私有 | fd → 表项指针 |
| 系统打开文件表 | **全局共享** | 读写偏移、打开模式 |
| inode 表 | 全局 | 文件元数据 |

**由此推出的行为**：

- `fork()` 后父子**共享文件偏移**（指向同一表项）
- `dup()` 复制的 fd 也共享偏移
- 想独立偏移 → 重新 `open()`

## 5. 磁盘布局与块分配

**简化布局**：

```
引导块 | 超级块 | inode 区 | 数据区
```

**块分配方式**：

| 方式 | 说明 | 问题 |
|------|------|------|
| 连续分配 | 文件占连续块 | **外部碎片**，扩展难 |
| 链式分配 | 每块存下一块指针 | 随机访问慢（要顺着链走） |
| **索引分配** | inode 存块指针（ext4：多级索引 + extent） | 元数据开销 |

**日志（Journaling）**：
ext4/xfs 等都支持——**先写日志，再改数据**，崩溃后可恢复，保证一致性。

## 6. 页缓存（Page Cache）

**读文件不是每次都读磁盘**——内核把读过的页**缓存在内存里**：

```
读文件 → 先查页缓存
  · 命中 → 直接返回（不碰磁盘）
  · 未命中 → 从磁盘读进缓存 → 返回
```

**由此理解几件事**：

- "**第二次读同一文件快**" = 页缓存命中
- `write` 默认是**写缓存**（write-back），攒够了才刷盘；`fsync` 可强制刷
- `free` 里的 `buff/cache` 就是它——**不是"浪费的内存"**（缺内存时会被回收）

> 页缓存也是[零拷贝](09-IO系统.md)和"文件读写快"的基础。

## 7. VFS 与挂载

**VFS（虚拟文件系统）**：一层抽象，让 `open/read/write` 对**所有文件系统**（ext4/xfs/NFS/proc…）用**同一套接口**。

- 向上：给应用统一 API
- 向下：各文件系统自己实现操作

> 这就是 `/proc`、`/sys` 也能当"文件"读的原因。

**挂载（mount）**：把一个文件系统"接到"目录树的某个点上。

```bash
mount /dev/sdb1 /mnt/data      # 把 sdb1 挂到 /mnt/data
umount /mnt/data
```

3. **fd 三张表**（进程表 → 系统表 → inode）
4. **`ls -l` 的链接数是几**（硬链接计数）
5. **文件系统为什么要日志**（崩溃一致性）
6. **页缓存**：为什么"第二次读同一文件快"
