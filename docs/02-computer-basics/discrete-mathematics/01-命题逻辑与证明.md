# 命题逻辑与证明

命题逻辑：真假、联结词、等值演算、推理规则与证明方法——它们是"代码正确性"的语言。

## 1. 命题与联结词

**命题**：能判断真假的陈述句。"今天下雨"是命题；"请关门"不是（没有真假）。

| 联结词 | 符号 | 读法 | 真值规则 |
|--------|:---:|------|---------|
| 否定 | ¬p | 非 p | p 真则为假，反之为真 |
| 合取 | p ∧ q | p 且 q | 都真才真 |
| 析取 | p ∨ q | p 或 q | 有一个真就真（**可兼或**，不排斥两者都真） |
| 蕴含 | p → q | 若 p 则 q | **只有 p 真且 q 假时为假** |
| 等价 | p ↔ q | p 当且仅当 q | 同真同假为真 |

**前件假，则蕴含式为真**（最容易反直觉的一条；前件 = 条件 p，后件 = 结论 q）：

> "如果明天下雨，我就带伞"——只有"下雨了但没带伞"才算食言；**没下雨时**，带不带伞都不算违背承诺。

**优先级**：¬ > ∧ > ∨ > → > ↔；记不住就加括号。

## 2. 真值表与等值演算

| p | q | ¬p | p∧q | p∨q | p→q | p↔q |
|:-:|:-:|:--:|:---:|:---:|:---:|:---:|
| T | T | F | T | T | T | T |
| T | F | F | F | T | **F** | F |
| F | T | T | F | T | T | F |
| F | F | T | F | F | T | T |

**常用等值定律**：

| 定律 | 形式 |
|------|------|
| 双重否定 | ¬¬p ≡ p |
| **德摩根** | ¬(p∧q) ≡ ¬p∨¬q；¬(p∨q) ≡ ¬p∧¬q |
| **蕴含等价** | p→q ≡ ¬p∨q |
| **逆否** | p→q ≡ ¬q→¬p |
| 分配律 | p∧(q∨r) ≡ (p∧q)∨(p∧r)；p∨(q∧r) ≡ (p∨q)∧(p∨r) |
| 吸收律 | p∨(p∧q) ≡ p；p∧(p∨q) ≡ p |
| 幂等 | p∨p ≡ p；p∧p ≡ p |
| 排中 / 矛盾 | p∨¬p ≡ T；p∧¬p ≡ F |

**怎么做等值演算**：从一边出发，逐条套用定律，变形成另一边（像代数化简）。

例：证明 p→q ≡ ¬q→¬p（逆否）

```
¬q→¬p
≡ ¬(¬q) ∨ ¬p      （蕴含等价）
≡ q ∨ ¬p          （双重否定）
≡ ¬p ∨ q          （交换律）
≡ p→q             （蕴含等价，反向用）
```

## 3. 范式：标准形式

| 形式 | 结构 | 读法 |
|------|------|------|
| **析取范式（DNF）** | (p∧q) ∨ (¬p∧r) | 若干个"且"的"或" |
| **合取范式（CNF）** | (p∨q) ∧ (¬p∨r) | 若干个"或"的"且" |
| **主析取范式** | 每个 ∧ 子句包含**全部**变量 | 唯一对应真值表的"成真行" |
| **主合取范式** | 每个 ∨ 子句包含**全部**变量 | 唯一对应真值表的"成假行" |

**从真值表机械转换**：

- 取结果为 **T** 的行：每行写一个 ∧（变量为 T 写自身、为 F 写 ¬），再把各行 ∨ 起来 → 主析取范式
- 取结果为 **F** 的行：每行写一个 ∨（变量为 T 写 ¬、为 F 写自身），再把各行 ∧ 起来 → 主合取范式

**为什么重要**：**SAT/SMT 求解器、电路综合、自动定理证明的输入都是 CNF**；把公式转成 CNF 是标准预处理。

## 4. 推理规则

| 规则 | 形式 | 例子 |
|------|------|------|
| 假言推理 | p→q, p ⊢ q | 下雨→带伞；下雨了 ⇒ 带伞 |
| **拒取式** | p→q, ¬q ⊢ ¬p | 没带伞 ⇒ 没下雨（逆否） |
| 假言三段论 | p→q, q→r ⊢ p→r | 传递性 |
| 析取三段论 | p∨q, ¬p ⊢ q | 排除法 |
| 附加 | p ⊢ p∨q | 弱化（加条件） |
| 化简 | p∧q ⊢ p | 取一部分 |

**⊢ 读作"推出"**：左边是前提，右边是必然得出的结论（前提全真时结论必真）。

**证明的写法**：两种手段交替——

1. **等值演算**（≡）：保持真值不变，用于"把式子变形"
2. **推理规则**（⊢）：从已知真推出新真，用于"往前走"

## 5. 证明方法

1. **直接证明**：假设前提，一步步推到结论
2. **反证法（归谬）**：假设结论为假，推出矛盾——如 √2 不是有理数、素数有无穷多个
3. **逆否证明**：证明 ¬q → ¬p（比 p→q 更好推时用）
4. **构造性证明**：把要证明"存在"的对象**构造出来**（存在性证明的最强形式）
5. **分情况证明**：把域拆成几块分别证明
6. **数学归纳法**：

   - 基础：n = 0（或 1）时成立
   - 归纳：假设 n = k 成立，证明 n = k+1 成立
   - 结论：对所有 n ≥ 0 成立

7. **强归纳**：假设**所有** n < k 都成立，推出 k 成立（整数分解、斐波那契性质常用）
8. **良序原理**：非空自然数集必有最小元（反证的常用工具）

**归纳法例子**（求和公式）：

> 证明 1 + 2 + ... + n = n(n+1)/2
>
> 基础：n = 1 时，左边 1，右边 1×2/2 = 1
> 归纳：假设 n = k 成立（1+...+k = k(k+1)/2），则
> 1+...+k+(k+1) = k(k+1)/2 + (k+1) = (k+1)(k+2)/2（正是 n = k+1 的形式）

## 6. 逻辑 × 编程

| 逻辑 | 代码 | 注意 |
|------|------|------|
| p ∧ q | `p && q` | **短路**：p 为假就不求值 q |
| p ∨ q | `p \|\| q` | **短路**：p 为真就不求值 q |
| ¬p | `!p` | |
| p→q | `!p \|\| q` | |
| p↔q | `p == q` | |
| 德摩根 | `!(a && b)` ≡ `!a \|\| !b` | 化简条件、避免重复求值 |

**实用点**：

- **短路求值是有序的**：`if (p != nullptr && p->ok())` 必须先判空——和 ∧ 的语义一致，**顺序有语义**
- **德摩根化简条件**：`!(x > 0 && y > 0)` → `x <= 0 || y <= 0`（少一层括号，清晰）
- **循环不变式**：循环开始前和每轮结束后都成立的性质——用归纳法证明循环正确性（二分查找、快排分区都是这么证的）
- **位运算就是按位的布尔代数**：`x & (x-1)` 清掉最低位的 1（判断 2 的幂）、`x ^ x = 0`、`x | 0 = x` —— 和 ∧∨¬ 一一对应
- **条件化简**：`if (!(a || b))` ≡ `if (!a && !b)`（德摩根），编译器和人读都更清楚

## 7. 要点回顾

1. **蕴含 p→q**：只有"p 真 q 假"为假；前件假时整体为真
2. **三条关键定律**：德摩根、蕴含等价（p→q ≡ ¬p∨q）、逆否（p→q ≡ ¬q→¬p）
3. **范式**：DNF = 若干"且"的"或"；CNF = 若干"或"的"且"；主范式与真值表一一对应；**SAT 求解器吃 CNF**
4. **推理规则**：假言推理、拒取式、假言三段论、析取三段论
5. **证明方法**：直接、反证、逆否、构造、分情况、**归纳（含强归纳）**、良序
6. **代码对应**：短路求值（顺序有语义）、德摩根化简条件、循环不变式、位运算 = 逐位布尔代数
