# 组合计数

"有多少种可能"——复杂度分析、概率、哈希、动态规划的计数都从这里来。

## 1. 两个基本原理

| 原理 | 什么时候用 | 公式 |
|------|-----------|------|
| **加法原理** | 分类（互斥的几类） | 方式数相加 |
| **乘法原理** | 分步（每一步都要做） | 方式数相乘 |

**例子**：

- 密码 6 位、每位数 0–9：10⁶（分步 × 每位；允许重复）
- IPv4 地址数：2³²（每段 8 位相乘）
- 从 A 到 B 有 3 条路、B 到 C 有 4 条：共 3×4 = 12 条（分步）

**判断口诀**：**分类用加、分步用乘**（"或"则加、"且"则乘，和逻辑 ∨∧ 对应）。

## 2. 排列与组合

| 类型 | 公式 | 含义 | 例子 |
|------|------|------|------|
| **排列** P(n,r) | n! / (n−r)! | 从 n 个里取 r 个**排成一列**（有序） | 3 人排队：3×2×1 = 6 |
| **组合** C(n,r) | n! / (r!(n−r)!) | 从 n 个里取 r 个（无序） | 从 5 人选 3 人：10 |
| 可重复排列 | nʳ | 取 r 次、每次可重复（有序） | 密码 10⁶ |
| 可重复组合 | C(n+r−1, r) | 可重复、无序（**隔板法**） | 3 个糖果分给 2 人：C(4,1)=4 |
| 圆排列 | (n−1)! | 围成圈的排列（旋转视为相同） | 5 人围桌：4! = 24 |

**换算关系**：P(n,r) = C(n,r) × r!（先选再排）。

**隔板法**（可重复组合的直觉）：把 r 个相同物品分给 n 类 = 在 r 个物品之间的 r−1 个"缝"里插 n−1 块板：C(r+n−1, n−1) = C(r+n−1, r)。

**常用小值**（心里有个数）：C(5,2)=10、C(6,3)=20、C(10,3)=120、C(52,5)=2,598,960（扑克同花顺的底数）。

## 3. 二项式与组合恒等式

**二项式定理**：`(a + b)ⁿ = Σₖ C(n,k) aⁿ⁻ᵏ bᵏ`（k 从 0 到 n）。

| 恒等式 | 含义 |
|--------|------|
| C(n,k) = C(n−1,k−1) + C(n−1,k) | **帕斯卡恒等式**（杨辉三角的递推） |
| Σₖ C(n,k) = 2ⁿ | **n 元集合的子集总数 = 2ⁿ**（每个元素选/不选） |
| Σₖ (−1)ᵏ C(n,k) = 0 | 奇偶子集个数相等 |
| C(n,0) = C(n,n) = 1 | 边界 |

**为什么有用**：

- `2ⁿ` 是"子集枚举"的复杂度（n ≤ 20 时还能暴力枚举位掩码）
- 帕斯卡恒等式是**动态规划算组合数**的基础（`dp[i][j] = dp[i-1][j-1] + dp[i-1][j]`）
- 杨辉三角第 n 行就是 (a+b)ⁿ 的系数

## 4. 容斥原理

**两个集合**：`|A ∪ B| = |A| + |B| − |A ∩ B|`（重复算的交集减掉一次）。

**三个集合**：`|A∪B∪C| = |A|+|B|+|C| − |A∩B|−|A∩C|−|B∩C| + |A∩B∩C|`（奇加偶减）。

**一般形式**：`|∪Aᵢ| = Σ|Aᵢ| − Σ|Aᵢ∩Aⱼ| + Σ|Aᵢ∩Aⱼ∩Aₖ| − ...`

**例子**：1 到 100 里能被 2 **或** 3 整除的个数

```
|A∪B| = 50（被 2 整除） + 33（被 3 整除） − 16（被 6 整除） = 67
```

**经典应用**：

- **错排问题**（1..n 的排列中"每个元素都不在自己位置"）：`n! · Σ(−1)ᵏ/k!`，n 大时趋近 n!/e
- **欧拉函数 φ(n)**：1..n 中与 n 互素的个数（用容斥推）
- **"至少满足一个条件"的计数**——正向难数就反过来用容斥

## 5. 鸽巢原理

**基本形式**：n+1 个物品放进 n 个盒子 → **至少有一个盒子装了 ≥ 2 个**。

**推广**：n 个物品放进 m 个盒子 → **至少有一个盒子装了 ⌈n/m⌉ 个**。

**例子（都能"纯逻辑"证明，但计数给下界）**：

- 13 个人里至少两人生日同月（13 > 12）
- 5 个点放进 2×2 的正方形：至少两个点距离 ≤ √2/2（把正方形四分）
- **哈希冲突**：key 比桶多时必冲突——所以哈希表要处理冲突（链地址/开放寻址）
- **压缩的极限**：任意无损压缩算法都"有的文件变小、必然有的文件变大"（单射约束 + 鸽巢）

**用法**：证明"存在性"（不用构造出那个例子）；要算具体概率用下一节。

## 6. 计数 × 编程

**① 复杂度分析就是计数**：

```cpp
for (int i = 0; i < n; ++i)        // 外层 n 次
    for (int j = i + 1; j < n; ++j) // 内层平均 n/2 次
        ...                          // 总次数 = C(n,2) = n(n-1)/2 = O(n²)
```

**② 哈希冲突概率（生日悖论）**：n 个 key、m 个桶，**无冲突**的概率是

```
m/m × (m−1)/m × ... × (m−n+1)/m  ≈  e^(−n(n−1)/(2m))
```

所以**冲突概率 ≈ 1 − e^(−n²/(2m))**：**n ≈ 1.177√m 时到 50%**（m = 2³² 时约 7.7 万；n = √m 时约 39%）——哈希表设计必须考虑。

**③ 组合数会爆炸**：

```python
import math
math.comb(100, 50)      # 100891344545564193334812497256（100 位十进制）→ 必须大整数
math.comb(1000, 500)    # 300 位数字 → 工程上用取模/对数（log C(n,k) ≈ n·H(k/n)）
```

C++ 里算组合数要**取模**（逆元）或用 `long double` 取对数（对数阶乘表）。

**④ 子集枚举 = 位掩码**：

```cpp
for (uint32_t mask = 0; mask < (1u << n); ++mask) {   // 2^n 个子集
    // mask 的第 i 位 = 第 i 个元素在不在这个子集里
    // 判断元素 i：mask >> i & 1
}
```

n ≤ 20 左右能暴力枚举（2³⁰ ≈ 10⁹ 就太慢了）。

**⑤ 路径计数 / 卡特兰数**（动态规划的计数版）：

- 网格从左上到右下（只能右下走）：C(m+n, n) 条路径
- 卡特兰数 Cₙ = C(2n,n)/(n+1)：合法括号串数、二叉树形状数、出栈序列数——满足 `Cₙ = Σ CᵢCₙ₋₁₋ᵢ`（区间 DP 的经典形状）

## 7. 递推关系与求解

**递推关系**：数列的第 n 项由前面几项决定（`aₙ = f(aₙ₋₁, aₙ₋₂, ...)`）。

| 递推 | 通项 / 量级 |
|------|------------|
| aₙ = aₙ₋₁ + aₙ₋₂（斐波那契） | Binet 公式（见下） |
| aₙ = 3aₙ₋₁ − 2aₙ₋₂，a₀=1, a₁=3 | 2ⁿ⁺¹ − 1 |
| Cₙ = Σᵢ CᵢCₙ₋₁₋ᵢ（卡特兰） | C(2n,n)/(n+1) |
| T(n) = 2T(n/2) + n（归并排序） | Θ(n log n) |

**特征方程法**（二阶线性递推 `aₙ = p·aₙ₋₁ + q·aₙ₋₂`）：

```text
1. 写特征方程：r² = p·r + q
2. 两个不同根 r₁、r₂：aₙ = A·r₁ⁿ + B·r₂ⁿ（A、B 用初始项解）
3. 重根：aₙ = (A + B·n)·rⁿ
```

**斐波那契**：r² = r + 1 → r = (1±√5)/2 = φ、ψ → `aₙ = (φⁿ − ψⁿ)/√5`（**Binet 公式**：用无理数算出整数）。

**主定理**（分治递推 `T(n) = a·T(n/b) + f(n)`）：

| 情况 | 条件 | 结果 |
|------|------|------|
| 1 | f(n) 比 n^(log_b a) 小 | Θ(n^(log_b a)) |
| 2 | 同量级 | Θ(n^(log_b a) · log n) |
| 3 | f(n) 更大（且满足正则条件） | Θ(f(n)) |

例：归并排序 a = b = 2、f(n) = n → 情况 2 → Θ(n log n)。

**生成函数**：把数列 a₀, a₁, … 装进形式幂级数 `A(x) = Σ aₙxⁿ`，用代数运算求通项——卡特兰数满足 `C(x) = 1 + x·C(x)²`，解得 `C(x) = (1 − √(1−4x)) / (2x)`，展开系数正是 C(2n,n)/(n+1)。

**和动态规划的关系**：DP 的"转移方程"就是递推；**自底向上**按 n 从小到大填表 = 迭代算递推，记忆化搜索 = 自顶向下 + 缓存。

## 8. 要点回顾

1. **分类用加、分步用乘**（∨ / ∧）
2. **排列有序、组合无序**：P(n,r) = C(n,r)·r!；可重复组合用**隔板法** C(n+r−1, r)
3. **子集总数 2ⁿ**；帕斯卡恒等式是 DP 算组合数的递推；杨辉三角 = 二项式系数
4. **容斥**：奇加偶减，用来算"至少满足一个"；错排/φ(n) 是经典应用
5. **鸽巢**：n 个进 m 个盒，必有 ⌈n/m⌉ 个——证明存在性、哈希必冲突、压缩有极限
6. **哈希冲突概率 ≈ 1 − e^(−n²/2m)**：n 到 √m 量级就大概率冲突
7. **组合数会爆炸**：工程上取模或取对数；**子集枚举 = 位掩码（2ⁿ）**
8. **递推关系**：二阶线性用**特征方程**（斐波那契 → Binet）；分治递推用**主定理**（归并 → n log n）；**DP 转移方程就是递推**
