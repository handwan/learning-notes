## 重点

- **逻辑 → 代码**：短路求值、德摩根化简条件、循环不变式（归纳法）
- **关系 → 数据库**：关系代数 = SQL 的底层；等价关系 = 并查集/连通分量
- **计数 → 复杂度/哈希**：组合数、容斥、鸽巢；哈希冲突概率 ≈ 1 − e^(−n²/2m)
- **图论**：BFS/DFS、拓扑排序、Dijkstra/Bellman-Ford/Floyd、MST、匹配与网络流
- **欧拉 ⇔ 多项式、哈密顿 ⇔ NP 完全**——问题差一个词，难度差一个量级
- **布尔代数 → 电路/位运算**：卡诺图化简、加法器；`x&(x-1)`、XOR 技巧
- **代数 → 密码学**：ℤₚ 有限域、费马/欧拉定理、扩展欧几里得 → RSA
- **可计算性**：停机问题不可判定 → 静态分析只能近似（有误报/漏报）
