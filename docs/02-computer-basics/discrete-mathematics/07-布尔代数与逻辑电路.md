# 布尔代数与逻辑电路

布尔代数 = 只有 0 和 1 的代数：它是**数字电路的语言**，也是**位运算和条件化简**的理论基础。

## 1. 布尔代数

**定义**：集合 B = {0, 1} + 三个运算 ∧（与）、∨（或）、¬（非）。

**运算律**（和命题逻辑逐一对应——换了个名字而已）：

| 定律 | 形式 |
|------|------|
| 交换 | a∧b = b∧a；a∨b = b∨a |
| 结合 | (a∧b)∧c = a∧(b∧c) |
| **分配** | a∧(b∨c) = (a∧b)∨(a∧c)；a∨(b∧c) = (a∨b)∧(a∨c) |
| **德摩根** | ¬(a∧b) = ¬a∨¬b；¬(a∨b) = ¬a∧¬b |
| 同一律 | a∧1 = a；a∨0 = a |
| 零一律 | a∧0 = 0；a∨1 = 1 |
| 幂等 | a∧a = a；a∨a = a |
| **互补** | a∧¬a = 0；a∨¬a = 1 |
| 吸收 | a∨(a∧b) = a；a∧(a∨b) = a |

**关键区别**：布尔代数里 `∨` 对 `∧` **也满足分配律**（普通算术里 `+` 不分配于 `×`）——这是它适合做"逻辑化简"的原因。

**特殊运算：异或 XOR**

```
a ⊕ b = (a∧¬b) ∨ (¬a∧b)         其中 a⊕a = 0（自己和自己异或为 0）
```

## 2. 表达式与范式

- **布尔表达式**：用 ∧∨¬ 连接的式子（对应逻辑的公式）
- **析取范式 DNF**：若干个"与项"的"或"（`ab + a'c` 这种写法，`'` 表示非）
- **合取范式 CNF**：若干个"或项"的"与"
- **最小项**：包含全部变量的与项（每个变量出现一次）；每行真值表对应一个最小项
- **主析取范式** = 所有"输出为 1"的最小项之和

**从真值表到电路**（机械流程）：

```
真值表 → 主析取范式 → 化简 → 门电路
```

## 3. 化简：让电路更小

**目标**：减少门的数量、层级（面积/延迟/功耗）。

**代数化简**（用上面的定律）：

```
ab + ab'  = a(b + b') = a·1 = a        （合并"只有 b 不同"的两项）
a + a'b   = a + b                       （吸收/常用恒等式）
```

**卡诺图（K-map）**：把真值表排成"格雷码"网格，**圈相邻的 1**（圈越大人越少项）：

```
     bc
a     00  01  11  10
0      1   1   1   0
1      0   1   1   0
```

- 圈 2 格 → 消掉 1 个变量；圈 4 格 → 消掉 2 个；圈 8 格 → 消掉 3 个
- **格雷码相邻**保证"圈里的项只差一个变量"

上例的化简：`{0,1,3,5,7}` 这 5 个格子中，`{1,3,5,7}` 四个圈成 **c**（4 格消 2 变量），剩下的 `{0}` 单独写成 **a'b'c'** → 结果 **`c + a'b'c'`**。

- **无关项（don't care）**：输出不在乎的情况（记 X）可以当 1 也可以当 0，用来把圈画得更大

**现代做法**：K-map 适合人做（≤6 变量）；更多变量用 **Quine-McCluskey** 或 EDA 工具（Espresso 等）——本质都是"找最小覆盖"。

## 4. 逻辑门与电路

**基本门**：AND、OR、NOT、XOR（还有 NAND、NOR、XNOR）。

**通用门**：**NAND 和 NOR 各自能搭出所有其他门**（芯片制造上只用一种门最省事）：

```
NOT a  = a NAND a
a AND b = NOT(a NAND b)
a OR b = (NOT a) NAND (NOT b)
```

**组合电路**（输出只取决于当前输入）：

| 电路 | 功能 | 用到的运算 |
|------|------|-----------|
| **半加器** | 两个 1 位相加：和 s = a⊕b、进位 c = a∧b | XOR + AND |
| **全加器** | 三个 1 位（含低位进位）相加 | 两个半加器 + OR |
| n 位加法器 | n 个全加器串联（或超前进位加速） | — |
| 多路选择器 MUX | 按 sel 选一路输入 | 与或（或三目） |
| 译码器 | n 位输入 → 2ⁿ 个输出中选一个 | 与门 + 非门 |

**ALU**（算术逻辑单元）= 这些组合电路的集合 + 选择器（按指令选运算）——这就是"组成原理"里 CPU 的计算部件。

**时序电路**（输出依赖历史，需要**时钟**）：触发器/寄存器/计数器——存储状态的基础（SR 锁存器 → D 触发器 → 寄存器堆）。

## 5. 布尔代数 × 编程

**位运算就是"并行的布尔代数"**（32/64 个布尔值一次算完）：

| 逻辑 | 位运算 | 用途 |
|------|--------|------|
| ∧ | `&` | **掩码**取位：`x & 0xFF` |
| ∨ | `\|` | 置位：`x \| (1 << k)` |
| ¬ | `~` | 取反（配合掩码：`x & ~mask`） |
| ⊕ | `^` | 翻转位；**不借助临时变量交换**；找"只出现一次的数" |
| 复合 | `x & (x-1)` | **清掉最低位的 1**（几次就清几个 1 = 数 1 的个数） |
| 复合 | `x & -x` | 取出最低位的 1（lowbit，树状数组用） |
| 复合 | `x & (x-1) == 0` | 判断 2 的幂 |

```cpp
// 数二进制里 1 的个数（Brian Kernighan）
int popcount(unsigned x) { int c = 0; while (x) { x &= x - 1; ++c; } return c; }

// 异或找单独出现的数：成对的都抵消，剩下就是它
int single = 0; for (int v : nums) single ^= v;

// 交换两个数（同一位置会清零，注意 a != b）
a ^= b; b ^= a; a ^= b;
```

**其他对应**：

- **条件化简**：`if (!(a && b))` → 德摩根 → `if (!a || !b)`
- **短路求值**：`&&`/`||` 和 ∧/∨ 语义一致（顺序有副作用时要注意）
- **位图/位集合**：用整数的位表示集合（并= `|`、交= `&`、差= `& ~`）——对接"集合"篇
- **SAT 求解**：布尔表达式（CNF）找可满足赋值——硬件验证、规划、约束求解的核心
- **布隆过滤器**：多个哈希位"或"起来判断"可能存在"（误判率与位数/哈希数有关）

## 6. 与组成原理的桥

| 布尔代数 | 组成原理 |
|---------|---------|
| 表达式化简（K-map） | 门级电路优化 |
| 半加器/全加器 | ALU 的加法器（超前进位/进位保留） |
| 多路选择器/译码器 | 指令选择、寄存器堆读写、地址译码 |
| 组合逻辑 | ALU、控制器的一部分 |
| 时序逻辑（触发器） | 寄存器、计数器、流水线寄存器、状态机 |

**一句话**：CPU = 一堆布尔函数 + 时钟 + 存储。布尔代数给的是"用最少的门实现函数"的方法论。

## 7. 要点回顾

1. **布尔代数 = 只有 0/1 的代数**，运算律和命题逻辑一一对应；**∨ 对 ∧ 也分配**（和算术不同）
2. **主析取范式**：所有"输出 1"的最小项之和——真值表 → 电路的机械流程
3. **化简**：代数定律；小规模用**卡诺图**（圈相邻的 1，圈越大消变量越多），大规模用 EDA 工具
4. **NAND/NOR 是通用门**；组合电路（加法器/MUX/译码器）+ 时序电路（触发器）= CPU 的积木
5. **位运算 = 并行的布尔代数**：掩码/置位/翻转、`x&(x-1)` 清最低位、XOR 找单独出现的数、位图表示集合
6. **SAT** 是"布尔可满足性"，是自动化验证/求解的基础
7. 与组成原理的接口：**ALU/控制器就是布尔函数；寄存器需要时钟**
