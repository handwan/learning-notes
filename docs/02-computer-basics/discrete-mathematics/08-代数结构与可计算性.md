# 代数结构与可计算性

群/环/域是"运算的抽象"，模运算 + 数论是**密码学的地基**；可计算性回答"什么问题根本解不了"。

## 1. 代数结构：集合 + 运算 + 公理

一个代数结构 = **一个集合** + **若干个运算** + **满足的公理**（封闭性是基本要求）。

| 结构 | 要求 | 例子 |
|------|------|------|
| 半群 | 封闭 + **结合** | (ℕ, +)、(字符串, 拼接) |
| 幺半群 | 半群 + **单位元** | (ℕ, +, 0)、(字符串, 拼接, "") |
| **群** | 幺半群 + **每个元素有逆元** | (ℤ, +, 0)、(ℤₙ, + mod n, 0) |
| 阿贝尔群 | 群 + 交换 | 上面两个都是 |
| **环** | 两个运算（+ 成阿贝尔群、× 结合、× 对 + 分配） | (ℤ, +, ×)、(ℤₙ, +, ×) |
| **域** | 环 + **非零元素对 × 成群**（能除） | ℚ、ℝ、ℂ、**ℤₚ（p 为素数）** |

**怎么读这张表**（编程视角）：

- 群 = "有一个可逆运算"（加法的逆是减法、乘法的逆是除法）
- 环 = "能加能乘但除不了"（整数除法会剩）
- 域 = "四则运算都行"——所以密码学喜欢在**有限域**上工作（有除法、元素有限、可编程）

## 2. 模运算与数论基础

```python
# 基本工具（写代码时都在 math 里）
pow(a, b, m)           # 快速幂取模：a^b mod m，O(log b)
math.gcd(a, b)         # 最大公约数
```

**同余**：`a ≡ b (mod n)` 表示 a、b 除以 n 余数相同（这是等价关系——对接"集合与关系"篇）。

| 概念 | 说明 |
|------|------|
| **逆元** | a 的逆 x 满足 `a·x ≡ 1 (mod n)`；**存在当且仅当 gcd(a,n)=1**；用**扩展欧几里得**求 |
| 快速幂 | 把指数按二进制拆：a^13 = a^8·a^4·a^1，O(log n) 次乘法 |
| **费马小定理** | p 为素数、p∤a 时：`a^(p-1) ≡ 1 (mod p)` |
| **欧拉定理** | gcd(a,n)=1 时：`a^φ(n) ≡ 1 (mod n)`（费马小定理的推广） |
| 中国剩余定理 | 一组同余式 `x ≡ aᵢ (mod nᵢ)`（nᵢ 两两互素）有唯一解 mod ∏nᵢ |

```python
# 快速幂手写（理解原理）
def power(a, e, m):
    r = 1; a %= m
    while e:
        if e & 1: r = r * a % m
        a = a * a % m; e >>= 1
    return r
```

**为什么这些在密码学里重要**：

- **模幂**便宜（O(log e)），但**模对数**（已知 a^x ≡ b 求 x，即离散对数）很难——这个不对称性就是 Diffie-Hellman/ECC 的基础
- 费马/欧拉定理让"求逆元/化简指数"变得可算

## 3. 密码学应用：RSA（离散数学的直接应用）

**构造**：

```
1. 选两个大素数 p、q（几百位）
2. n = p·q，φ(n) = (p−1)(q−1)
3. 选公钥指数 e（与 φ(n) 互素，常取 65537）
4. 求私钥 d = e⁻¹ mod φ(n)（扩展欧几里得）
5. 公钥 (n, e)，私钥 d
```

**加解密**：

```
加密：c = m^e mod n
解密：m = c^d mod n        （因为 e·d ≡ 1 mod φ(n)，配合欧拉定理）
```

**为什么安全**：公开 (n, e) 求 d 需要 φ(n) = (p−1)(q−1)，而**已知 n 求 p、q = 大整数分解**——目前没有多项式算法。**RSA 的安全性 = 分解难题**。

| 系统 | 依赖的难题 |
|------|-----------|
| RSA | 大整数分解 |
| Diffie-Hellman / ElGamal | 离散对数（有限域） |
| ECC（椭圆曲线） | 椭圆曲线离散对数（同等安全下密钥更短） |

**工程注意**（对接 [网络安全](../computer-network/09-网络安全.md)）：

- **密钥长度**：RSA 2048 位起步；曲线 256 位 ≈ RSA 3072 位
- **不能直接加密大消息**（比 n 小块才行）→ 实际是"混合加密"：RSA 传对称密钥，AES 传数据
- **实现要防旁路攻击**（时间/功耗）→ 用标准库，别自己造
- **别用教科书 RSA**（上面是简化版，没有填充）：实际要 OAEP 填充，否则可被选择明文攻击

## 4. 可计算性：哪些问题"根本解不了"

**计算模型**：图灵机、λ 演算、寄存器机、细胞自动机……它们**能力等价**（能算的函数集合相同）——这叫**邱奇-图灵论题**（"可计算 = 图灵可计算"）。

**图灵机的直觉**：一条无限纸带 + 读写头 + 状态转移规则。它简单到能形式化证明性质，又强大到能表达一切"算法"。

**可判定 vs 不可判定**：

| 问题 | 结论 |
|------|------|
| 一个数是不是素数 | 可判定（AKS 算法） |
| 程序会不会输出 42 | 不可判定 |
| **停机问题**：程序 P 在输入 x 上会不会停 | **不可判定** |
| 两个上下文无关文法是否等价 | 不可判定 |

**停机问题的对角线证明思路**（反证）：

```
假设存在判定器 H(P, x) 能判断"程序 P 在 x 上是否停机"
构造程序 D(P)：
    如果 H(P, P) 说"会停" → D 故意死循环
    如果 H(P, P) 说"不会停" → D 直接返回
问：D(D) 会停吗？
    H 说"会停" → D(D) 死循环（与 H 矛盾）
    H 说"不会停" → D(D) 停（与 H 矛盾）
⇒ H 不存在
```

**为什么值得知道**：它给"静态分析/自动验证"划了边界——**完美的"程序行为检查器"不存在**（只能近似：要么漏报、要么误报）。所以静态分析工具接受误报/漏报，而不是追求"全对"。

**Rice 定理**（推广）：程序的**任何非平凡语义性质**都不可判定（"这个程序会不会崩溃"、"它等价于那个程序吗"……都不行）。

## 5. 复杂度：可计算 ≠ 能算得动

| 类 | 含义 |
|----|------|
| **P** | 多项式时间可解（排序/最短路/匹配/线性规划） |
| **NP** | 给一个解，多项式时间能**验证**（SAT、TSP 的判定版、图着色） |
| **NP-完全** | NP 里"最难"的一类：任何 NP 问题都能多项式归约到它；**解决一个 = 解决全部** |
| **NP-hard** | 至少和 NP-完全一样难（不一定属于 NP，如优化版的 TSP） |

**SAT 是第一个 NP 完全问题**（Cook-Levin 定理）：任何 NP 问题的"验证过程"本身能被写成一个布尔公式——所以 SAT 是 NP 的"代表"。（对接布尔代数篇：现代 SAT 求解器非常强，能啃几万变量的工业实例。）

**常见的 NP 完全问题**：SAT、3-SAT、旅行商（判定版）、哈密顿回路、最大团、独立集、顶点覆盖（一般图）、子集和、装箱、课程表……

**P = NP 吗**：未解（千禧年问题）。若相等，加密（依赖"难题"）和大量优化问题都会崩塌；目前共识是 P ≠ NP。

**遇到 NP-hard 的工程策略**（对接图论篇）：

1. 看结构：树/二分/平面/小参数（FPT）常有多项式算法
2. 小规模：状压 DP（n ≤ 20）、分支限界
3. 近似/启发式：贪心、局部搜索、模拟退火
4. 直接上求解器：SAT/SMT/整数规划（OR-Tools、Gurobi）、约束编程
5. 重新建模：换目标（近似、松弛、在线）或换问题

## 6. 要点回顾

1. **代数结构 = 集合 + 运算 + 公理**：半群 → 幺半群 → 群（有逆）；环（两个运算）→ 域（非零可除）
2. **ℤₚ（p 素数）是有限域**——密码学的工作场所
3. **逆元存在 ⇔ gcd(a,n)=1**（扩展欧几里得求）；**费马/欧拉定理**是模幂化简的关键
4. **RSA = 模幂 + 大整数分解难题**；DH/ECC 依赖离散对数；实际用混合加密 + 填充
5. **邱奇-图灵论题**：一切"算法"等价于图灵机；**停机问题不可判定**（对角线法）
6. **Rice 定理**：程序的非平凡语义性质都不可判定 → 静态分析只能近似（有误报/漏报）
7. **P/NP/NP-完全**：SAT 是 NP 完全的代表；面对 NP-hard 靠结构/近似/求解器，而不是硬算
