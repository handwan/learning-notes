## 重点

- **延迟层次**（实测）：L1 ~1 ns → L2 ~4 ns → L3 ~26 ns → 内存 ~100 ns（80 倍）——一切"C++ 为什么快/慢"的物理依据
- **分支预测失败极贵**：随机分支比有序慢 **10.9 倍**（指令数相同）；依赖链拆开也有 1.6 倍
- **算术强度决定优化方向**：矩阵乘 170.7 FLOP/Byte（算力型）vs 向量加法 0.083（带宽型）——**先定位再优化**
- **量化是"数据表示"的工程化**：FP16 准但范围小（65504 上限，实测溢出）、BF16 范围大、INT8 要 per-channel（否则小值归零）
- **Amdahl**：串行部分定天花板（p=0.95 → 最多 20 倍）
- **GPU 的定位**：高算术强度负载 + 高带宽显存 + SIMT；传输（PCIe）常是喂数据的瓶颈
- **实测深入**：浮点误差累积（朴素 float 求和误差可观，Kahan 几乎为零）；冲突缺失（4KB 步长最差）；预取器（顺序 vs 随机差一个数量级）
- **同步有价**：原子自增比普通自增贵约一个数量级，争抢再翻倍——减少共享写 > 换锁
- **IO 手感**：块大小 4KB 与 64KB 带宽差一个数量级；fsync 中位几百微秒；页缓存比裸盘快几十倍；网络回环亚毫秒、公网几十毫秒
- **别背结论**：延迟 vs 吞吐、顺序 vs 随机——**先分清要解决哪个问题**
