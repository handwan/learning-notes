# 组成原理速查

> 这篇是"**考试向 / 查漏**"的压缩版：把教材里工程不常用、但"知识要全"的部分用表格与一句话收进来。**实战看前 8 篇**（那里都是实测）。
## 1. 数制与编码

| 概念 | 要点 |
|------|------|
| 进制转换 | 整数：除基取余（倒序）；小数：乘基取整（顺序） |
| BCD | 每 4 位二进制存 1 位十进制（8421 码等） |
| ASCII | 7 位编码，数字/大写/小写连续排列 |

**机器数（8 位为例）**：

| 表示 | 正数 | 负数 | 范围 |
|------|------|------|------|
| 原码 | 符号位 0 + 绝对值 | 符号位 1 + 绝对值 | −127 ~ +127（有 ±0） |
| 反码 | 同原码 | 符号位不变，数值位取反 | −127 ~ +127 |
| **补码** | 同原码 | 反码 + 1 | **−128 ~ +127**（唯一 0） |
| 移码 | 补码符号位取反 | 同 | 用于**浮点阶码**（比较大小方便） |

## 2. 定点运算

| 主题 | 要点 |
|------|------|
| 移位 | 算术移位（补码右移补符号位）、逻辑移位（补 0） |
| 溢出判断 | 双符号位：`01` 正溢、`10` 负溢；单符号位：进位异或 |
| 原码乘法 | 符号单独处理，数值位"移位相加"（一位乘） |
| **Booth（补码乘法）** | 看乘数最低位与附加位：`01` 加被乘数、`10` 减、`00/11` 不动，再算术右移 |
| 除法 | 恢复余数法（试减为负就加回来）、加减交替法（不恢复余数，更快） |
| 加法器 | 串行进位（延迟 = 位数×门延迟）→ **先行进位 CLA**（生成 G、传播 P 信号并行算进位） |

## 3. 浮点运算步骤

```
对阶（小阶向大阶看齐，尾数右移）→ 尾数加减 → 规格化（左规/右规）→ 舍入 → 溢出判断（看阶码）
```

- **左规**：尾数溢出（1x.xxx）→ 尾数右移、阶码 +1？反了：**尾数求和出现 0.0xxx 要左规（阶码减 1）**，出现 1x.xxx 要右规（阶码加 1）
- **舍入**：0 舍 1 入 / 恒置 1 / 就近舍入（IEEE 754）
- **溢出**：阶码上溢 → inf、下溢 → denormal/0（见[数据表示篇](02-数据表示与运算.md)）

## 4. 存储器细节

| 主题 | 要点 |
|------|------|
| SRAM vs DRAM | SRAM 触发器（快、贵、不刷新）；DRAM 电容（慢、便宜、**要刷新**） |
| 刷新方式 | 集中刷新（有"死区"）、分散刷新（无死区但周期长）、异步刷新（折中） |
| ROM 家族 | 掩膜 ROM → PROM（一次性）→ EPROM（紫外擦）→ EEPROM → **Flash** |
| 主存扩展 | 位扩展（补数据位）、字扩展（补地址空间）、字位同时扩展；片选用地址译码 |
| 多模块存储器 | 高位交叉（按地址分段，不能并行）；**低位交叉**（地址低位选模块 → 流水线式并行访问） |
| RAID | 0 条带 / 1 镜像 / 5 分布式校验 / 10；选型见 [设备与磁盘](../operating-system/08-设备与磁盘.md) |
| Cache 位置 | L1（分指令/数据）、L2、L3（共享）——容量 4~8 倍递增、速度递减 |

**Cache 的地址划分**（考试手算题）：`| 标记 tag | 组号/行号 | 块内偏移 |`；组相联时组号位数 = log2(组数)。工程上不用手算（见[存储篇](03-存储系统与Cache.md)）。

## 5. 指令与 CPU 微结构

| 主题 | 要点 |
|------|------|
| 扩展操作码 | 常用指令用短操作码，牺牲少数长码换平均长度更短 |
| 数据通路 | 单总线（一次一个数据）、多总线（更快）；微操作序列按节拍写 |
| 控制器 | **硬布线**（组合逻辑，快、难改）vs **微程序**（控存里的微指令，灵活、慢） |
| 微指令编码 | 水平型（并行强、字长）、垂直型（编码紧凑、并行弱）、混合型 |
| 微地址形成 | 下地址字段、增量、分支 |
| 中断响应 | 条件（指令执行完 + 有请求 + 允许中断）；**中断隐指令**：关中断、保存断点、取入口 |

## 6. 总线与 IO

| 主题 | 要点 |
|------|------|
| 总线仲裁 | 集中式：链式查询（近者优先）、计数器定时查询、独立请求（最快、线多）；分布式 |
| 总线定时 | **同步**（统一时钟，快、近距）；**异步**（握手：不互锁/半互锁/全互锁） |
| IO 编址 | 统一编址（内存映射，用普通访存指令）vs 独立编址（专用 IO 指令） |
| 多重中断 | 用**中断屏蔽字**实现优先级嵌套 |
| 中断 vs 异常 | 外中断（异步：时钟/IO）；内中断/异常（同步：缺页/除零/系统调用）；异常分**故障（重执行）/ 陷阱（下一条）/ 终止** |
| **DMA 三种方式** | 停止 CPU 访存、**周期挪用**（最常见）、交替访问 |
| **DMA vs 中断** | DMA：数据块为单位、**不经过 CPU**、优先级更高、直接访存；中断：以"程序"为单位、要保存现场 |

## 7. 手算例题（三个典型）

**① 补码与溢出**：8 位补码算 `-5 + 7`

```
-5  补码：0000 0101 取反 → 1111 1010，加 1 → 1111 1011
 7  补码：0000 0111
相加： 1111 1011 + 0000 0111 = 1 0000 0010 → 丢进位 → 0000 0010 = +2
溢出判断：符号位分别是 1、0 → 不会溢出（只有"同号相加得异号"才溢出）
```

**② 浮点转 IEEE 754**：`-12.5` 写成单精度

```
12.5 = 1100.1b = 1.1001 × 2³
符号 1 | 阶码 3 + 127 = 130 = 1000 0010 | 尾数 100 1000 ... 0
→ 1 10000010 10010000000000000000000 = 0xC1480000
```

**③ Cache 命中率手算**：直接映射，Cache 4 行、行长 16B；访问序列 `0, 16, 32, 0`

```
行号 = 块地址 mod 4：0→0、16→1、32→2、0→0
0：缺失（冷启动）；16：缺失（不同块）；32：缺失（不同块）
第二次 0：行 0 里还是 0（没被顶掉）→ 命中
→ 命中率 1/4 = 25%（换序列 0,64,0 就会冲突缺失）
```

## 8. 要点回顾（一句版）

1. 补码 = 取反加一（唯一 0、能多表示一个负数）；**移码用于阶码**
2. Booth = 看乘数尾部"01/10"决定加/减，再算术右移
3. 加法器：串行进位慢 → **CLA 用 G/P 信号并行求进位**
4. DRAM 要刷新、SRAM 不用；**低位交叉**才能流水并行访问
5. 硬布线快而"死"、微程序灵活而慢；中断隐指令 = 关中断/保存断点/取入口
6. **DMA 是块传输、不经过 CPU**；中断是程序级、要保存现场
