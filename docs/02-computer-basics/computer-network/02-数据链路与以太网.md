# 数据链路与以太网

## 1. 数据链路层干什么

管**相邻设备之间**传数据（不是端到端）。要解决三件事：

| 问题 | 办法 |
|------|------|
| 怎么划出一个个"帧" | 帧头帧尾（封装成帧） |
| 传错了怎么办 | **CRC 校验**（错了就丢，让上层重传） |
| 谁先发（共享介质） | 介质访问控制（CSMA/CD） |

## 2. MAC 地址

- **48 位**（6 字节），网卡出厂烧录（理论上全球唯一）
- 前 24 位是**厂商编号**（OUI）
- 作用：**同一局域网内**标识网卡

```text
aa:bb:cc:dd:ee:ff
└──┬──┘ └────┬────┘
 厂商编号   设备编号
```

## 3. 以太网帧格式

| 字段 | 长度 | 说明 |
|------|:---:|------|
| 目的 MAC | 6 | 发给谁 |
| 源 MAC | 6 | 谁发的 |
| 类型 | 2 | 上层协议（IPv4 / ARP） |
| 数据 | 46~1500 | 载荷 |
| **FCS** | 4 | 校验（CRC） |

**MTU = 1500**（数据部分最大长度）——IP 包超过它就要**分片**。

## 4. 差错检测（CRC）

- 帧尾 **FCS** 用 **CRC**（循环冗余校验）算出来
- **只检错、不纠错**：错了就丢，让上层（TCP）重传

## 5. 介质访问控制（谁先发）

- **CSMA/CD**（有线以太网）：先听后发；冲突了就停下、随机退避再重试
- **CSMA/CA**（无线）：避免冲突（无线难检测冲突，只能预防）
- 现在交换机组网是**全双工**（点对点，无冲突），CSMA/CD 基本"退休"了

## 6. 交换机 vs 路由器

| | 交换机（二层） | 路由器（三层） |
|--|--------------|--------------|
| 工作层 | 数据链路层 | 网络层 |
| 看什么地址 | **MAC** | **IP** |
| 作用范围 | **局域网内**转发 | **不同网络之间**转发 |
| 广播域 | 不隔离（VLAN 才能隔离） | **隔离** |
| 转发依据 | MAC 地址表（**自学习**） | 路由表 |

**一句话**：**交换机管"楼内送信"（MAC），路由器管"跨城送信"（IP）**。

## 7. VLAN

- 一台物理交换机，**逻辑上切成多个虚拟局域网**
- 好处：隔离广播域（少干扰）、安全、组网灵活

## 8. 要点回顾

1. 数据链路层 = **相邻设备**之间传"帧"（CRC 检错）
2. **MAC = 48 位**，局域网内标识网卡；**MTU = 1500**
3. **交换机看 MAC（局域网内），路由器看 IP（跨网络）**
4. **VLAN**：物理一台，逻辑多个局域网
