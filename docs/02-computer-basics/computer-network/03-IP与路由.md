# IP 与路由

## 1. IP 地址

- **IPv4**：32 位，点分十进制（如 `192.168.1.10`）
- 地址分两部分：**网络号 + 主机号**（靠子网掩码划分）
- **IPv6**：128 位（地址够用、不用 NAT），但过渡慢

## 2. 子网掩码与 CIDR

**子网掩码**标出"哪几位是网络号"：

```text
IP:       192.168.1.10
掩码:     255.255.255.0
CIDR 写法: 192.168.1.10/24      ← 前 24 位是网络号
```

**同一子网内的机器可以直接通信**（不用路由器）；不同子网要靠路由。

```text
192.168.1.0/24 → 网络号 192.168.1，主机号 0~255（可用 1~254）
```

### 子网划分怎么算

```text
题目：192.168.1.200/26，求网络号、广播地址、可用主机范围

① /26 → 掩码 255.255.255.192（最后一段 11000000）
   → 每个子网 2^(32-26) = 64 个地址

② 主机号 200 落在哪个 64 的块里？
   块0: 0~63   块1: 64~127   块2: 128~191   块3: 192~255 ← 200 在这

③ 结论：
   网络号   = 192.168.1.192   （块的开头）
   广播地址 = 192.168.1.255   （块的结尾）
   可用主机 = 192.168.1.193 ~ 192.168.1.254
```

## 3. 私有地址与 NAT

**私有地址**（内网用，不能直接上公网）：

| 网段 | 说明 |
|------|------|
| `10.0.0.0/8` | 大内网 |
| `172.16.0.0/12` | 中等 |
| `192.168.0.0/16` | 家用最常见 |

**NAT（网络地址转换）**：路由器把内网地址换成公网地址：

```text
内网 192.168.1.10:5000  ←→  公网 1.2.3.4:60001（映射表）
内网 192.168.1.11:5000  ←→  公网 1.2.3.4:60002
```

- **好处**：多台内网机器共享一个公网 IP；内网对外不可见（安全）
- **代价**：外部**无法主动连内网**（要做端口映射/内网穿透）

## 4. ARP：IP → MAC

**问题**：同一局域网里知道对方 IP，但发数据需要 **MAC 地址**。

**ARP**：广播问，单播答：

```text
广播："谁是 192.168.1.5？"
回复："我是，MAC = aa:bb:cc:dd:ee:ff"
```

结果缓存进 **ARP 表**（`arp -a` 查看）。

## 5. ICMP：ping 用的

- 用于**报错和探测**（如"目标不可达"）
- **ping** = ICMP 的 Echo Request / Reply
- **traceroute** = 利用 TTL 逐跳递减来探测路径

## 6. IP 数据报的关键字段

| 字段 | 说明 |
|------|------|
| 版本 | IPv4 |
| **TTL** | 还能经过几个路由器（**每跳 -1**，减到 0 就丢弃） |
| 协议 | 上层是 TCP / UDP / ICMP |
| 源 / 目的 IP | 地址 |
| 标识 / 标志 / 片偏移 | 分片用 |

**TTL 的作用**：防止包在网络里**无限打转**（出环）。traceroute 就是靠它逐跳探测的。

**IP 分片**：包超过 **MTU（1500）** 就切成多片，到目的地重组。

- 问题：**丢一片，整个包都要重传**
- 所以 TCP 会主动按 MTU 切：**MSS = 1500 - 20(IP头) - 20(TCP头) = 1460**

## 7. 路由：包怎么找到路

每台机器都有一张**路由表**（目的地 → 走哪个网卡 / 下一跳）：

```text
目标在同一网段 → 直接 ARP 找到对方，直接发
目标不在同网段 → 发给「默认网关」（路由器），由它转发
```

**默认网关**：路由表里匹配不上的，全部丢给网关。

路由器之间靠路由协议（OSPF / BGP）交换路由信息。

### 常见路由协议

| 协议 | 类型 | 说明 |
|------|------|------|
| **RIP** | 距离向量 | 按"**跳数**"选路（最多 15 跳）——简单，只适合小网络 |
| **OSPF** | 链路状态 | 按"**链路开销**"算最短路（Dijkstra）——企业内网常用 |
| **BGP** | 路径向量 | **自治系统（AS）之间**的路由——互联网主干 |

**记忆**：RIP 看跳数（小网络）、OSPF 看开销（内网）、BGP 管运营商之间（外网）。

## 8. IPv6

| | IPv4 | IPv6 |
|--|------|------|
| 长度 | 32 位 | **128 位** |
| 写法 | 点分十进制 | 冒号十六进制（可省略 0） |
| 地址量 | 约 43 亿（不够用） | 多到用不完 |
| NAT | 普遍需要 | **基本不需要**（每台设备都能有公网地址） |
| 头部 | 复杂（含可选字段） | **简化**（固定 40 字节） |

```text
2001:0db8:0000:0000:0000:ff00:0042:8329
缩写：2001:db8::ff00:42:8329     （:: 代替一串 0，只能用一次）
```

**过渡方式**：双栈、隧道、NAT64——过程很慢（兼容性是最大障碍）。

## 9. 要点回顾

1. **IP = 网络号 + 主机号**（靠子网掩码/CIDR 划分）；**子网划分**按"块大小"算
2. **私有地址 + NAT**：内网共享公网 IP；代价是外部无法主动连内网
3. **ARP**：同网段里"IP → MAC"（广播问、单播答）
4. **ICMP**：ping / traceroute 靠它
5. **TTL** 每跳 -1 防环路；**MTU 1500**，超了要分片（TCP 用 MSS 规避）
6. **路由**：同网段直发，跨网段交默认网关；**RIP（跳数）/ OSPF（开销）/ BGP（AS 间）**
7. **IPv6**：128 位、地址够用、头更简单、不依赖 NAT
