# DNS 与 CDN

## 1. DNS 是什么

**域名 → IP 的"电话簿"**：人记域名（`www.example.com`），机器只认 IP。

## 2. 域名的层级

```text
www.example.com.
 │     │      │
子域   二级域  顶级域（TLD）
```

对应的 DNS 服务器也有层级：

```text
根 DNS  →  TLD DNS（管理 .com/.cn…）  →  权威 DNS（管理 example.com）
```

## 3. 解析过程（递归 + 迭代）

```text
1. 先查本地缓存（浏览器 / 操作系统）
2. 没有 → 问「本地 DNS 服务器」（运营商/公共 DNS，如 8.8.8.8）
3. 本地 DNS 问「根 DNS」    → 得到 .com 的地址
4. 问「TLD DNS（.com）」    → 得到 example.com 的「权威 DNS」地址
5. 问「权威 DNS」           → 得到 IP
6. 本地 DNS 缓存结果并返回
```

**递归**（客户端 → 本地 DNS：你帮我查完）；**迭代**（本地 DNS ↔ 各层服务器：给我下一跳）。

## 4. 常见记录类型

| 类型 | 含义 |
|------|------|
| **A** | 域名 → **IPv4** 地址 |
| **AAAA** | 域名 → IPv6 地址 |
| **CNAME** | **别名**（域名 → 另一个域名） |
| **MX** | 邮件服务器记录 |
| **NS** | 该域的权威 DNS 服务器 |

## 5. DNS 用 UDP 还是 TCP

| 场景 | 用哪个 | 为什么 |
|------|--------|--------|
| **普通查询** | **UDP 53** | 一问一答、包小，握手不划算 |
| 响应 > 512 字节 / 区域传送 | TCP 53 | 要可靠性 / 数据大 |

（现在还有 DoH / DoT：把 DNS 查询加密，防窃听和劫持。）

## 6. DNS 的安全问题

| 问题 | 说明 |
|------|------|
| **DNS 劫持** | 本地 DNS / 路由器被改 → 返回**假 IP**（广告、钓鱼） |
| **DNS 污染** | 中间设备对查询**返回假结果** |

**解决**：

- **DoH**（DNS over HTTPS）：查询走 HTTPS（加密 + 防篡改）
- **DoT**（DNS over TLS）：查询走 TLS
- 用可信的公共 DNS（`8.8.8.8`、`1.1.1.1`、`223.5.5.5`）

## 7. CDN 原理

**目标**：让用户从**最近的节点**拿资源（不都挤源站）。

```text
用户 → DNS 智能解析（按位置返回最近的 CDN 节点 IP）
     → 访问就近 CDN 节点
     → 节点有缓存？直接返回
     → 没有？回源站拉取，缓存后返回（回源）
```

**用途**：静态资源（图片、JS、CSS、视频）加速、抗流量。

## 8. 负载均衡

**目标**：把流量分到多台服务器上。

| 层级 | 做法 | 例子 |
|------|------|------|
| **DNS 层** | 一个域名返回多个 IP（轮询 / 按地域） | 最简单，但**故障切换慢**（受 DNS 缓存 TTL 影响） |
| **四层**（传输层） | 按 IP + 端口转发，**不改内容**（快） | LVS |
| **七层**（应用层） | 按 URL / Header 转发（灵活，能做灰度发布） | Nginx、HAProxy |

**常见算法**：轮询、加权轮询、最少连接、**一致性哈希**（同一用户固定到同一台 → 提高缓存命中）。

## 9. 综合：从输入 URL 到页面显示

把整章串起来：

```text
1. DNS 解析：域名 → IP
2. TCP 三次握手（建立连接）
3. HTTPS 再加 TLS 握手（交换密钥）
4. 发 HTTP 请求
5. 服务端处理 → 返回响应（可能经过 CDN）
6. 浏览器渲染页面
7. 关闭连接（四次挥手）或复用（keep-alive）
```

## 10. 要点回顾

1. **DNS = 域名 → IP**，层级：根 → TLD → 权威
2. **解析过程**：本地缓存 → 本地 DNS（递归）→ 根/TLD/权威（迭代）
3. **A 记录**（IPv4）、**CNAME**（别名）最常用
4. **查询用 UDP 53**（快），大了才用 TCP；**DoH/DoT** 防劫持/污染
5. **CDN**：DNS 智能解析 + 就近缓存 + 回源
6. **负载均衡**：DNS（简单、切换慢）/ 四层（LVS）/ 七层（Nginx、能灰度）
7. **综合题**：DNS → TCP 握手 → TLS → HTTP → 渲染
