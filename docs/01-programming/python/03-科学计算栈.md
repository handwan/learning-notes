# 科学计算栈

Python 做数据/科学计算的**日常三件套**：**NumPy**（数组计算）、**pandas**（表格）、**matplotlib**（画图）——环境与装包见[环境与工程](02-环境与工程.md)。

## 1. NumPy：为什么快

**因为它在 C 层循环，而不是 Python 层。**

|          | list                        | ndarray                   |
|----------|-----------------------------|---------------------------|
| 元素类型 | 什么都能装（PyObject 指针） | **同类型**（如 float64）  |
| 内存     | 指针数组，对象散落          | **连续内存**              |
| 运算     | 每个元素走一遍解释器        | 整块交给 C 循环（向量化） |

```python
import numpy as np

a = np.arange(1_000_000)

# 差：Python 循环（慢两个数量级——10⁶ 元素实测 ≈230×）
total = 0
for x in a:
    total += x

# 好：向量化（一次 C 循环）
total = a.sum()
```

**结论：凡是能用数组整体表达的计算，就别写 Python 循环。**

## 2. ndarray 基础

`ndarray` 是 NumPy 的数组类名（`np.ndarray`），口语也叫 array；类型注解里写作 `NDArray`（`numpy.typing`）。

```python
a = np.array([1, 2, 3])              # 一维
b = np.array([[1, 2, 3], [4, 5, 6]]) # 二维（2 行 3 列）

np.zeros((2, 3))        # 全 0
np.ones((2, 3))         # 全 1
np.full((2, 2), 7.0)    # 全 7
np.arange(0, 10, 2)     # [0 2 4 6 8]        类似 range
np.linspace(0, 1, 5)    # [0. 0.25 0.5 0.75 1.]  等分
np.eye(3)               # 单位矩阵
```

**三个属性**：

```python
b.shape      # (2, 3)   形状
b.dtype      # dtype('int64')  元素类型
b.ndim       # 2        维度数
```

**指定类型**（省内存，对接 C++ 需要）：

```python
np.array([1, 2], dtype=np.float32)   # 4 字节，C++ 的 float
```

## 3. 切片是视图，不是拷贝

**Python list 切片 = 新列表；NumPy 切片 = 视图（共享同一块内存）。**

```python
a = np.arange(6)          # [0 1 2 3 4 5]
s = a[1:4]                # 视图！
s[0] = 99
print(a)                  # [ 0 99  2  3  4  5]  ← 原数组也变了

b = a[1:4].copy()         # 要独立就显式 copy
```

| 操作                                            | 结果             |
|-------------------------------------------------|------------------|
| 基本切片（`a[1:4]`）、`a.T`、`reshape`          | **视图**（尽量） |
| 花式索引（`a[[0, 2]]`）、布尔索引（`a[a > 2]`） | **拷贝**         |

## 4. 广播（broadcasting）

**不同形状的数组怎么算术运算**——小的自动"铺开"对齐。

```python
a = np.array([[1, 2, 3],
              [4, 5, 6]])       # shape (2, 3)
b = np.array([10, 20, 30])      # shape (3,)

a + b
# [[11 22 33]
#  [14 25 36]]    ← b 被广播到两行
```

**规则**（从最后一维往前对齐）：

1.  维度相等
2.  其中一个维度是 **1**（**缺的维度也按 1 算**）→ 可以广播
3.  都没有 → 报错 ❌

```python
col = np.array([[1], [2]])      # (2, 1)
a + col
# [[ 2  3  4]
#  [ 6  7  8]]    ← 每行加自己的数

a + np.array([1, 2])            # ❌ 报错：(2,3) 与 (2,) 末维 3 vs 2
```

**用途**：不用写循环就能"每个样本减均值""每列乘权重"。

## 5. axis 到底怎么理解

**记忆法：`axis=i` = 沿第 i 维操作，结果少一维。**

```python
a = np.array([[1, 2, 3],
              [4, 5, 6]])       # shape (2, 3)

a.sum()            # 21              全加起来
a.sum(axis=0)      # [5 7 9]         消掉维度 0 → 每列的和
a.sum(axis=1)      # [6 15]          消掉维度 1 → 每行的和
a.mean(axis=0, keepdims=True)   # shape (1, 3)，保留维度便于广播回去
```

**反向：加维度**——减维用 `axis`，加维用切片里的 `None`：

```python
row[:, None]                 # (3,) → (3,1)
row[None, :]                 # (3,) → (1,3)
row[:, None] * row[None, :]  # (3,3)：外积
```

**一句话**：`axis=0` 是"往下压扁"（列方向），`axis=1` 是"往右压扁"（行方向）。

## 6. 常用操作

```python
a.reshape(3, 2)                # 改形状（视图）
a.T                            # 转置
a.ravel()                      # 拉平
np.concatenate([a, b], axis=0) # 拼接
np.stack([a, b], axis=0)       # 堆成更高维

a.sum() / a.mean() / a.std() / a.max() / a.min()
a.argmax()                     # 最大值的下标
a.argmax(axis=1)               # 每行最大值的下标

np.where(a > 3, a, 0)          # 条件选择（类似三目）
a @ b                          # 矩阵乘（* 是逐元素；np.dot 也行）

# 线性代数
np.linalg.inv(m)
np.linalg.solve(A, b); np.linalg.norm(v)
```

**随机数**（用新 API，别用老的 `np.random.seed`）：

```python
rng = np.random.default_rng(42)     # 固定种子可复现
rng.random((2, 3))                  # [0, 1) 均匀
rng.normal(0, 1, size=1000)         # 标准正态
rng.integers(0, 10, size=5)         # 整数 [0, 10)
```

**读写**：

```python
np.save("a.npy", a)                  # 单个数组（二进制 .npy，快）
b = np.load("a.npy")

np.savetxt("a.csv", a, delimiter=",")    # 文本（可读、可给别的工具）
c = np.loadtxt("a.csv", delimiter=",")
```

## 7. pandas：表格数据

**底层就是 NumPy**，多了"带标签的表格"操作。

```python
import pandas as pd

df = pd.read_csv("data.csv")
df.head()          # 看前 5 行
df.info()          # 列类型 / 缺失情况
df.describe()      # 数值列统计

df["score"]                  # 取一列（Series）
df[["name", "score"]]        # 取多列（DataFrame）

df.loc[df["score"] > 60, ["name"]]   # 按条件筛 + 选列
df.iloc[0:5, 0:2]                    # 按位置取

df.isna().sum()             # 每列缺几个
df.dropna()                 # 丢缺失行
df["score"] = df["score"].fillna(0)

df.groupby("cls")["score"].mean()      # 分组统计
df["cls"].value_counts()               # 每个值出现次数
df["score"].apply(lambda s: s * 2)     # 逐元素处理（慢，能用内置方法就用内置）
df.sort_values("score", ascending=False)

pd.merge(left, right, on="id", how="left")   # 类似 SQL join

df.to_csv("out.csv", index=False)
```

**坑：链式赋值**——`df[mask]["col"] = v` 改不上（pandas 3 直接抛 `ChainedAssignmentError`，旧版只是警告），必须一步到位：

```python
df.loc[df["score"] > 60, "grade"] = "pass"
```

**Series vs DataFrame**：Series 是带索引的一维数组，DataFrame 是多列 Series 的集合。

## 8. matplotlib：画图

**用面向对象写法**（`fig, ax`），比 `plt.xxx` 状态机清晰：

```python
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(6, 4))
ax.plot(epochs, train_loss, label="train")
ax.plot(epochs, val_loss, label="val")
ax.set_xlabel("epoch")
ax.set_ylabel("loss")
ax.set_title("training curve")
ax.legend()
ax.grid(True)
fig.savefig("loss.png", dpi=150)     # 保存
plt.show()                           # 交互显示
```

**多个子图**：`fig, axes = plt.subplots(1, 2)`，然后 `axes[0].plot(...)` / `axes[1].plot(...)`。

**常用图**：

| 函数         | 用途                      |
|--------------|---------------------------|
| `ax.plot`    | 折线（训练曲线）          |
| `ax.scatter` | 散点（分布/相关性）       |
| `ax.bar`     | 柱状                      |
| `ax.hist`    | 直方图                    |
| `ax.imshow`  | 显示矩阵/图像（混淆矩阵） |

**中文乱码**：

```python
plt.rcParams["font.sans-serif"] = ["SimHei"]     # Windows
plt.rcParams["axes.unicode_minus"] = False       # 负号正常显示
# Linux 没有 SimHei，需装中文字体（如 Noto Sans CJK）后换成对应名字
```

## 9. 和 C++ 的分工

- **NumPy/pandas/matplotlib = 实验和验证**：原型、看数据、画曲线、算指标
- **生产重活还是 C++**：Python 循环再向量化也快不过原生实现，真正的推理/计算内核用 C++（见[与 C++ 互操作](04-与C++互操作.md)）

## 10. 要点回顾

1.  **NumPy 快在向量化**（C 循环 + 连续内存），能整体算就别写循环
2.  **切片是视图**：`a[1:4]` 会改原数组；要独立用 `.copy()`；花式/布尔索引才是拷贝
3.  **广播**：从末维对齐，维度相等或为 1 才能算
4.  **axis=i = 消掉第 i 维**（2D 里 `axis=0` 是列方向）；**加维度用 `None`**
5.  **随机数**用 `np.random.default_rng(seed)`
6.  **pandas**：`loc`（标签）/ `iloc`（位置）、`isna`/`fillna`、`groupby`、`merge`；赋值一步到位（`.loc[mask, "col"] = v`，链式会报错）
7.  **matplotlib** 用 `fig, ax` 写法；中文要设 `font.sans-serif`
8.  这套是**实验工具**，生产内核交给 C++
