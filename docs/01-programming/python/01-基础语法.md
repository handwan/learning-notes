# 基础语法

从 C++ 程序员视角写：只讲**差异**和**坑**，不重复两边都一样的东西（if/for/while 略）。

## 1. 运行模型：和 C++ 的差别

|        | C++                      | Python（CPython）                        |
|--------|--------------------------|------------------------------------------|
| 执行   | 编译成机器码，运行前查错 | 编译成**字节码**，逐行解释执行           |
| 类型   | 静态、编译期确定         | 动态、运行时才查 → 类型错误运行时才暴露  |
| 变量   | 有类型，存值（或地址）   | **名字绑定对象**，名字本身没有类型       |
| 代码块 | `{}`                     | **缩进**（空格，通常 4 个）              |
| 内存   | 手动 / RAII              | 引用计数 + 垃圾回收                      |
| 速度   | 快                       | 慢 1~2 个数量级（所以重活交给 C++ / NumPy） |

**两个直接后果**：

- 没有"编译期检查"——靠**类型注解 + mypy**（见[环境与工程](02-环境与工程.md)）和测试来兜底
- 没有"未定义行为"——代价是运行时开销

## 2. 名字是引用，不是盒子

C++ 里变量是"装值的盒子"；Python 里**变量只是贴在对象上的名字**。

```python
a = [1, 2, 3]
b = a            # 不是拷贝！b 和 a 是同一个列表的两个名字
b.append(4)
print(a)         # [1, 2, 3, 4]
```

### `is` vs `==`

```python
a = [1, 2]
b = [1, 2]
a == b     # True：值相等
a is b     # False：不是同一个对象
a is a     # True：同一对象
```

**`is` 只用来和 `None` / `True` / `False` 比较**（判断"是不是同一个对象"），别用来比值。

### 可变 vs 不可变对象

| 不可变（immutable）                         | 可变（mutable）                   |
|---------------------------------------------|-----------------------------------|
| `int`、`float`、`str`、`tuple`、`frozenset` | `list`、`dict`、`set`、自定义对象 |

```python
s = "abc"
s2 = s.upper()    # 不是"改 s"，而是产生新字符串
print(s)          # 还是 abc（str 不可变）

t = (1, [2, 3])   # tuple 本身不可变，但里面的 list 可以改
t[1].append(4)    # 合法
```

### 浅拷贝 vs 深拷贝

```python
import copy

a = [[1, 2], [3, 4]]
b = a.copy()          # 浅拷贝：外层新列表，内层还是共享的
b[0][0] = 99
print(a)              # [[99, 2], [3, 4]] ← 原列表也被改了

c = copy.deepcopy(a)  # 深拷贝：整棵树复制
c[0][0] = 0
print(a)              # 不受影响
```

### 可变默认参数

```python
def add(item, lst=[]):      # ❌ 默认值只在定义时创建一次
    lst.append(item)
    return lst

add(1)      # [1]
add(2)      # [1, 2]  ← 不是 [2]！两处调用共享同一个 list
```

**正确写法**：

```python
def add(item, lst=None):
    if lst is None:
        lst = []
    lst.append(item)
    return lst
```

**口诀：默认参数只放不可变对象。**

## 3. 容器对照

| 用途     | C++                    | Python                          | 备注                       |
|----------|------------------------|---------------------------------|----------------------------|
| 动态数组 | `std::vector<T>`       | `list`                          | 可以装不同类型（但不建议） |
| 哈希表   | `std::unordered_map`   | `dict`                          | 插入有序（3.7+ 语言保证）  |
| 有序表   | `std::map`             | 无内置（用 `sortedcontainers`） | 想按序就 `sorted()`        |
| 集合     | `std::unordered_set`   | `set`                           |                            |
| 定长异构 | `std::pair` / `struct` | `tuple`                         | 不可变                     |
| 定长同质 | `std::array`           | `tuple`（或 NumPy）             |                            |

**创建**：

```python
lst = [1, 2, 3]
d = {"a": 1, "b": 2}
s = {1, 2, 3}
t = (1, 2)
empty = []          # 空 list
empty_dict = {}     # 空 dict（不是 set）
empty_set = set()   # 空 set 得这么写
```

**常用差异**：

```python
len(lst)           # 长度（不是 lst.size()）
1 in lst           # 成员检查（不是 std::find）
d.get("k", 0)      # 取不到返回默认值（不抛异常）
d.setdefault("k", [])  # 取不到就插入默认值
```

**标准库补充容器**（`collections`）：

```python
from collections import Counter, defaultdict, deque

Counter("abracadabra")                 # 计数：{'a': 5, 'b': 2, ...}
Counter("abracadabra").most_common(2)  # 出现最多的两个

d = defaultdict(list)                  # 访问不存在的键 → 自动建 []
d["k"].append(1)

q = deque([1, 2, 3])
q.appendleft(0)                        # 两端 O(1)（list 头部插入是 O(n)）
q.pop()
```

**排序**（对应 `std::sort` + 比较器）：

```python
nums = [3, 1, 2]
nums.sort()                              # 原地排序
sorted(nums, reverse=True)               # 返回新列表
sorted(people, key=lambda p: p.age)      # 按字段
sorted(words, key=len)                   # 按长度
```

## 4. 切片、推导式与常用句式

### 切片

```python
a = [0, 1, 2, 3, 4, 5]
a[1:4]      # [1, 2, 3]      左闭右开
a[:3]       # [0, 1, 2]
a[3:]       # [3, 4, 5]
a[-1]       # 5              负数从末尾数
a[::2]      # [0, 2, 4]      步长
a[::-1]     # [5, 4, 3, 2, 1, 0]  反转
```

**注意**：`list` 切片**产生新列表**；**NumPy 切片是视图**（改会改原数组，见[科学计算栈](03-科学计算栈.md)）。

### 推导式（comprehension）

```python
squares = [x * x for x in range(5)]          # [0, 1, 4, 9, 16]
evens = [x for x in range(10) if x % 2 == 0] # 带条件
pairs = {x: x * x for x in range(3)}         # 字典推导
uniq = {x % 3 for x in range(10)}            # 集合推导
```

比手写 `for` + `append` 更快也更地道；但**别嵌套超过两层**（可读性差）。

**日常句式**（写脚本常用）：

```python
# f-string：格式化首选（C++ 没有对应物）
f"{loss:.4f}"             # 保留 4 位小数
f"{name} = {value}"       # 插值
f"{x=}"                   # 3.8+：连变量名一起打印（调试）

# enumerate / zip：少写索引
for i, v in enumerate(items):
    ...
for a, b in zip(xs, ys):  # 默认按最短截断；3.10+ 可加 strict=True 改成"长度不等就报错"
    ...

# dict 遍历
for k, v in d.items():
    ...

# 字符串常用（命名和 C++ 不同）
s.split(",")              # 切分 → list
",".join(lst)             # 拼接（比 += 循环快）
s.strip()                 # 去首尾空白
```

## 5. 函数

### 参数

```python
def f(a, b=1, *args, **kwargs):
    print(a, b, args, kwargs)

f(1, 2, 3, 4, x=5)
# a=1, b=2, args=(3, 4), kwargs={'x': 5}
```

- `*args`：多出来的位置参数，收成 **tuple**
- `**kwargs`：多出来的关键字参数，收成 **dict**
- 调用时反过来用就是**拆包**：`f(*lst, **d)`

**关键字参数**：`f(b=2, a=1)` 顺序随意——C++ 没有，API 里很常见。

### 函数是一等对象

```python
words = ["bbb", "a", "cc"]
sorted(words, key=len)          # 按长度排：'a', 'cc', 'bbb'
sorted(words, key=lambda w: -len(w))  # 从长到短
```

`lambda` 只能写单个表达式；复杂逻辑就用普通 `def`。

### 闭包

```python
def make_adder(n):
    def add(x):
        return x + n        # 捕获外层变量 n
    return add

add5 = make_adder(5)
add5(3)     # 8
```

### 作用域：LEGB、global、nonlocal

查找顺序 **LEGB**：Local → Enclosing → Global → Built-in。

```python
count = 0

def bump():
    global count          # 要改模块级变量，得声明
    count += 1

def make_counter():
    n = 0
    def inc():
        nonlocal n        # 要改闭包外层变量，得声明
        n += 1
        return n
    return inc
```

不声明就**只能读**：`n += 1` 会被当成"新建局部变量"，报 `UnboundLocalError`。

### 闭包的延迟绑定

循环里创建函数，变量取的是**最后的值**：

```python
funcs = [lambda: i for i in range(3)]
[f() for f in funcs]                          # [2, 2, 2] ← 不是 [0, 1, 2]

funcs = [lambda i=i: i for i in range(3)]     # 用默认参数把值固定住
[f() for f in funcs]                          # [0, 1, 2]
```

### 传参：传的是"对象引用的副本"

```python
def add_item(lst):        # 改对象 → 外面也跟着变
    lst.append(1)

def rebind(lst):          # 重新绑定名字 → 外面不变
    lst = [99]

a = []
add_item(a)               # a == [1]
rebind(a)                 # a 还是 [1]
```

C++ 对照：Python 没有"按值 / 按引用"之分——**能不能影响外面，取决于你是"改对象"还是"重新绑定名字"**。

### 返回值与解包

```python
def min_max(nums):
    return min(nums), max(nums)     # 实际返回一个 tuple

lo, hi = min_max([3, 1, 2])         # 解包
a, b = b, a                         # 交换（也是 tuple 解包）
```

位置专用 `/`、关键字专用 `*`（API 里常见）：

```python
def f(a, /, b, *, c):     # a 只能位置传，c 只能关键字传
    ...

f(1, 2, c=3)              #
# f(a=1, b=2, c=3)        # ❌ a 不能关键字传
# f(1, 2, 3)              # ❌ c 必须关键字传
```

### 装饰器

**本质**：接收函数、返回新函数的高阶函数。

```python
import functools

def log(func):
    @functools.wraps(func)      # 保留原函数的名字/文档
    def wrapper(*args, **kwargs):
        print("calling", func.__name__)
        return func(*args, **kwargs)
    return wrapper

@log
def work():
    pass

work()      # 打印 calling work
```

`@log` 等价于 `work = log(work)`。常见用途：日志、计时、缓存（`functools.lru_cache`）、注册。

## 6. 类与继承

属性不用声明、`self` 显式、多态靠鸭子类型——写法比 C++ 简单，机制不同。

### 6.1 最小骨架

```python
class Model:
    count = 0                     # 类属性：所有实例共享（≈ C++ static 成员）

    def __init__(self, name):     # 初始化器（不是构造器）
        self.name = name          # 实例属性：赋值即存在，不用声明
        self.layers = []
        Model.count += 1

    def forward(self, x):
        return x
```

**类属性是所有实例共享的**，可变的类属性不能当"每个实例的默认值"：

```python
class A:
    items = []            # ❌ 所有实例共用同一个 list
a, b = A(), A()
a.items.append(1)
print(b.items)            # [1]
```

要按实例隔离，在 `__init__` 里赋值：`self.items = []`。

### 6.2 三种方法

| 写法                      | 第一个参数 | 用途（C++ 类比）              |
|---------------------------|------------|-------------------------------|
| `def f(self)`             | 实例       | 普通成员函数                  |
| `@classmethod def f(cls)` | 类         | 备用构造器（`from_xxx` 工厂） |
| `@staticmethod def f()`   | 无         | 工具函数，放类里只是归组      |

```python
class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y

    @classmethod
    def origin(cls):              # 备用构造器：cls 是类本身（子类也适用）
        return cls(0, 0)

    @staticmethod
    def dist(a, b):               # 不需要实例/类状态
        return abs(a - b)
```

### 6.3 继承与 super

```python
class MyModel(Model):
    def __init__(self):
        super().__init__("my")    # 必须显式调用父类 __init__
        self.extra = 1

    def forward(self, x):         # 覆写
        return super().forward(x) * 2   # 也能调父类实现（≈ Base::forward(x)）
```

**和 C++ 最大的差别**：C++ 的基类构造在派生类构造体之前**自动执行**；Python **不自动**——不写 `super().__init__()`，父类状态就是空的。

**访问控制**：没有 `private`，靠约定——`_x` 表示"内部用"；`__x` 会被改写成 `_类名__x`（防子类意外覆盖）。

### 6.4 多重继承与 MRO

`super()` 不是"找父类"，而是**沿 MRO（方法解析顺序）往下走**：

```python
class A: ...
class B(A): ...
class C(A): ...
class D(B, C): ...

D.__mro__    # (D, B, C, A, object)
```

**Mixin 模式**：把一小块能力写成类混进来（日志、序列化、重试），比 C++ 的多重继承轻。

### 6.5 多态：鸭子类型（不是虚函数）

```python
def save(sink, data):
    sink.write(data)      # 只要有 write() 就能传，不要求继承

class FileSink:
    def write(self, data): ...

save(FileSink(), "x")     # 不需要继承任何"接口"
```

C++ 靠**继承 + 虚函数**；Python 靠**运行时查找**（有这个方法就行）。代价是拼错方法名要到运行时才炸。

想要明确接口，有两种写法：

```python
from abc import ABC, abstractmethod

class Sink(ABC):
    @abstractmethod
    def write(self, data): ...    # 子类不实现就实例化报错
```

```python
from typing import Protocol

class Writer(Protocol):           # 结构化类型（≈ C++ concepts）
    def write(self, data: str) -> None: ...
```

### 6.6 常用魔术方法

| 方法                                   | 作用                                 | C++ 类比                         |
|----------------------------------------|--------------------------------------|----------------------------------|
| `__init__` / `__new__`                 | 初始化 / 真正造对象                  | 构造函数（`__del__` 不保证时机） |
| `__repr__` / `__str__`                 | 调试表示 / 用户表示                  | `operator<<`                     |
| `__eq__` / `__hash__`                  | 相等 / 哈希（改了 eq 要一起改 hash） | `operator==` / `std::hash`       |
| `__len__` / `__getitem__` / `__iter__` | `len()` / `obj[i]` / `for`           | `size()` / `operator[]` / 迭代器 |
| `__call__`                             | 实例当函数调                         | `operator()`                     |
| `__add__` 等                           | 运算符重载                           | `operator+`                      |
| `__enter__` / `__exit__`               | `with`                               | RAII                             |

### 6.7 property / dataclass / **slots**

```python
class Cfg:
    def __init__(self, lr):
        self._lr = lr

    @property                      # getter；要写检查就再加 @lr.setter
    def lr(self):
        return self._lr
```

```python
from dataclasses import dataclass, field

@dataclass                         # 自动生成 __init__ / __repr__ / __eq__
class Point:
    x: float
    y: float = 0.0
    tags: list = field(default_factory=list)   # 可变默认值用 default_factory
```

`__slots__ = ("x", "y")` 固定属性集合、省内存（≈ 固定布局）。

### 6.8 和 C++ 的关键差异

|          | C++                        | Python                            |
|----------|----------------------------|-----------------------------------|
| `this`   | 隐式                       | **`self` 显式写**（第一个参数）   |
| 属性声明 | 必须声明                   | 赋值即存在，还能动态加            |
| 访问控制 | `public/private/protected` | 无（约定 `_x` / `__x` 名字改写）  |
| 基类构造 | 自动调用                   | **必须手动 `super().__init__()`** |
| 多态     | 虚函数 + 继承              | **鸭子类型**：有方法就能调        |
| 多继承   | 复杂，少用                 | 支持，`super()` 按 MRO 走         |

### 6.9 nn.Module 用到的机制

```python
import torch.nn as nn

class Net(nn.Module):
    def __init__(self):
        super().__init__()                    # ① 必须先初始化基类
        self.fc = nn.Linear(4, 1)             # ② 赋值触发 __setattr__ → 自动注册子模块
        self.blocks = nn.ModuleList([...])    # ③ 普通 list 不会被注册，必须用 ModuleList

    def forward(self, x):                     # ④ 只覆写 forward
        return self.fc(x)

net = Net()
net(torch.randn(2, 4))    # ⑤ net(...) 走 __call__ → hooks → forward
```

| 机制                                                      | 依赖的 Python 特性                    |
|-----------------------------------------------------------|---------------------------------------|
| `self.fc = nn.Linear(...)` 自动登记参数/子模块            | `__setattr__` 拦截                    |
| `net(x)` 而不是 `net.forward(x)`                          | `__call__`（hooks、梯度追踪挂在上面） |
| `parameters()` / `state_dict()` / `eval()` 递归找到所有层 | 注册树遍历                            |
| 自定义数据集 / 损失函数 / 调度器                          | 继承 + 覆写 + `@property`             |

PyTorch 用到的就是这一组：继承、覆写、`__init__` + `super()`、`__call__`、少量 `@property`。

## 7. 异常与 with

```python
try:
    n = int("abc")
except ValueError as e:
    print("转换失败:", e)
except (TypeError, KeyError):
    pass
else:
    print("没出错才走这里")
finally:
    print("一定执行")
```

- 异常是**类**，可以自定义：`class MyError(Exception): pass`
- **不检查异常**（不像 Java 的 checked exception）——靠文档和测试
- `raise ValueError("xxx") from e` 保留原始异常链

**`with` ≈ RAII**：

```python
with open("a.txt", encoding="utf-8") as f:   # 退出时自动 close（即使抛异常）
    data = f.read()
```

`open` 的默认编码：**3.15 起统一 UTF-8**（PEP 686）；更早版本跟平台走（Windows 是 GBK）——跨版本代码一律显式写 `encoding="utf-8"` 最稳。

原理是上下文管理器协议（`__enter__` / `__exit__`）——和 RAII 的"析构保证释放"是同一个目标。

## 8. 迭代器与生成器

**可迭代对象**：能 `for x in obj` 的东西（实现了 `__iter__`）。

**生成器**：用 `yield` 的函数，**惰性**产出值，不占内存。

```python
def count_up(n):
    for i in range(n):
        yield i

g = count_up(3)
next(g)      # 0
next(g)      # 1
for x in g:  # 继续从 2 开始
    print(x)
```

**生成器表达式**（把推导式的 `[]` 换成 `()`）：

```python
gen = (x * x for x in range(10**8))   # 不占内存，用到才算
sum(gen)
```

**`yield from`**：把另一个可迭代对象直接"接力"产出：

```python
def chain(*iterables):
    for it in iterables:
        yield from it

list(chain([1, 2], "ab"))     # [1, 2, 'a', 'b']
```

**生成器只能遍历一次**（消费掉就空了）：

```python
g = (x for x in range(3))
sum(g)      # 3
sum(g)      # 0  ← 已经空了
```

**用途**：读大文件、数据流、无限序列——"一次一个"而不是"全造出来"。

## 9. GIL 与并发

**GIL（全局解释器锁）**：CPython 里**同一时刻只有一个线程执行 Python 字节码**。

- 等待 IO 时 GIL 会释放 → **IO 密集**用多线程有收益
- 纯 Python 计算时 GIL 不释放 → **CPU 密集**多线程反而更慢
- Python 3.13 起提供 free-threaded（无 GIL）构建，生态仍在过渡

| 场景                  | 用什么                                                                                                   |
|-----------------------|----------------------------------------------------------------------------------------------------------|
| IO 密集（网络、文件） | `threading` 或 `asyncio`                                                                                 |
| CPU 密集              | `multiprocessing`（多进程绕开 GIL）                                                                      |
| CPU 密集且要极致性能  | **写 C++ 扩展**，计算时释放 GIL（见[与 C++ 互操作](04-与C++互操作.md)） |

```python
# asyncio：单线程 + 事件循环，用 async/await 写并发 IO
import asyncio

async def fetch(name):
    await asyncio.sleep(1)
    return name

async def main():
    results = await asyncio.gather(fetch("a"), fetch("b"))
    print(results)

asyncio.run(main())     # 1 秒完成两个（不是 2 秒）
```

**线程池 / 进程池**（`concurrent.futures`，两边接口一样）：

```python
from concurrent.futures import ThreadPoolExecutor, ProcessPoolExecutor

def work(x):
    return x * x

with ThreadPoolExecutor(max_workers=4) as ex:      # IO 密集
    results = list(ex.map(work, range(100)))

with ProcessPoolExecutor() as ex:                  # CPU 密集（绕开 GIL）
    results = list(ex.map(work, range(100)))
```

多进程的参数和返回值要能 **pickle**（普通对象可以，lambda、打开的文件不行）。

**注意**：`x += 1` 这种复合操作**不是原子的**——多线程共享可变状态要加锁（`threading.Lock`）。

## 10. 要点回顾

1.  **名字是引用**：赋值 = 绑名字；`b = a` 不是拷贝；传参传的是"对象引用的副本"
2.  **`is` 比值用 `==`**、比值别用 `is`（只和 `None` 比）
3.  **可变默认参数是坑** → 用 `None` 占位；**可变的类属性同样共享**
4.  **浅拷贝共享内层**，要独立用 `deepcopy`
5.  **切片**：list 是拷贝、NumPy 是视图
6.  **参数**：`*args` / `**kwargs` 收参数 = tuple / dict；调用时 `*` / `**` 拆包；`/` 和 `*` 限定位置/关键字
7.  **闭包要改外层变量用 `nonlocal`**；循环里建闭包要固定变量值
8.  **装饰器 = 高阶函数**，`@log` 等价 `f = log(f)`
9.  **类与继承**：类属性共享、`super().__init__()` 必须手动、三种方法、多态靠鸭子类型、`__call__` 让实例可调用——PyTorch 全靠这套
10. **`with` ≈ RAII**（`__enter__` / `__exit__`）
11. **生成器惰性、只能遍历一次**；`yield from` 接力
12. **GIL**：IO 密集用线程/协程或线程池，CPU 密集用多进程或 C++ 扩展
