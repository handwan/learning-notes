## 重点

- **名字是引用不是盒子**——默认参数、浅/深拷贝这些坑的根源
- **NumPy**：能整体算就别写循环；切片是**视图**不是拷贝
- **GIL**：IO 密集用线程/协程，CPU 密集用多进程或 C++ 扩展
- **部署结构**：Python 胶水 + C++ 内核（pybind11）
