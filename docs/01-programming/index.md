# 语言基础

**C++**：系统编程与性能；**Python**：实验、数据处理与 AI 生态接口；**Rust**：内存与并发安全的系统级路线。

语言无关的公共基础——编译链接、内存、并发、调试——见 [C++ 篇](cpp/index.md)和[计算机基础](../02-computer-basics/index.md)。

## 语言

- **C++**：语言基础 → 对象模型与泛型 → 标准版本（C++11/14/17/20/23）→ STL → 并发 → 工程与构建 → 系统与性能 → 设计模式
- **Python**：语法差异与常用坑 → 环境与工程 → 科学计算栈（NumPy / pandas / matplotlib）→ 与 C++ 互操作（pybind11）
- **Rust**：基础语法 → 所有权与借用 → 类型系统 → 内存与并发 → 迭代器与闭包 → 集合与字符串 → 工程与互操作 → async 与生态

## 主线

- **C++ 的四块地基**：RAII / 智能指针、移动语义、UB 清单、模板与编译期计算
- **Python 的三个坑**：名字是引用（可变默认参数）、GIL（CPU 密集要靠多进程 / 扩展）、NumPy 向量化（别写 Python 循环）
- **Rust 的一个核心**：所有权与借用——由此推出"数据竞争是编译错误"（`Send` / `Sync`）
- **跨语言接口层**：C ABI（`extern "C"`）、pybind11——"用别人的库 / 让别人用你的库"都靠它
