# 集合与字符串

`Vec` 之外的常用容器（`HashMap`/`HashSet`/`BTreeMap`）、字符串的 UTF-8 语义、数值溢出与转换、格式化。

## 1. Vec 与切片

```rust
let mut v = Vec::new();
v.push(3);                       // 尾部追加
v.push(1);
v.push(2);

v.sort();                        // [1, 2, 3]
v.insert(0, 0);                  // 指定位置插入（O(n)）
v.remove(0);                     // 指定位置删除（O(n)）
v.retain(|&x| x != 2);           // 保留满足条件的：[1, 3]
v.pop();                         // 弹尾部：Some(3)

v.contains(&1);                  // true
v.len(); v.is_empty();
v.first(); v.last();             // Option<&T>
```

**索引 vs `get`**（C++ 里 `[]` 越界是 UB）：

```rust
let v = vec![10, 20, 30];
let x = v[1];                    // 越界 → panic（安全）
let y = v.get(99);               // Option<&T>：Some/None，不 panic
assert_eq!(y, None);
```

**预分配**（避免反复扩容拷贝）：

```rust
let mut v = Vec::with_capacity(1000);   // 容量至少 1000，长度 0
v.push(1);
assert_eq!(v.len(), 1);
assert!(v.capacity() >= 1000);
```

**切片 `&[T]`**：参数优先用切片，`Vec` 和数组都能传（deref coercion）：

```rust
fn total(nums: &[i32]) -> i32 {
    nums.iter().sum()
}

total(&[1, 2, 3]);                 // 数组
total(&vec![1, 2, 3]);             // Vec
```

## 2. HashMap / HashSet

### 基本操作

```rust
use std::collections::HashMap;

let mut scores: HashMap<String, i32> = HashMap::new();

scores.insert("amy".to_string(), 90);     // 插入（覆盖旧值）
scores.get("amy");                        // Option<&V>
scores.get_mut("amy");                    // Option<&mut V>，可改
scores.contains_key("amy");               // true
scores.remove("amy");                     // Option<V>
scores.len();
```

### entry API：一次查找搞定"有则改、无则建"

```rust
let mut counts: HashMap<&str, i32> = HashMap::new();

// 计数惯用法
for word in ["a", "b", "a"] {
    *counts.entry(word).or_insert(0) += 1;
}
assert_eq!(counts["a"], 2);

// 更完整的形式
counts.entry("c")
    .and_modify(|v| *v += 10)      // 已存在：改
    .or_insert(1);                 // 不存在：插
assert_eq!(counts["c"], 1);
```

`entry` 的价值：**只哈希/查找一次**，比"get 一次 + insert 一次"少一遍（也少一次借用冲突的机会）。

### 顺序、键的要求、默认哈希

| 问题 | 说明 |
|------|------|
| 遍历顺序 | `HashMap` **无序**（每次运行可能不同）；要按 key 有序用 `BTreeMap` |
| 能不能当 key | 必须实现 `Hash + Eq`——`f64` 不行（没有 `Eq`），字符串/整数/`Vec` 可以 |
| 哈希算法 | 默认 `RandomState`（带随机种子，防 HashDoS 攻击）；要确定性/更快可换 `ahash` 等 |

```rust
// 按 key 排序输出（HashMap 本身无序）
let mut items: Vec<_> = counts.iter().collect();
items.sort_by_key(|(k, _)| *k);
```

### HashSet

```rust
use std::collections::HashSet;

let a: HashSet<i32> = [1, 2, 3].into_iter().collect();
let b: HashSet<i32> = [3, 4].into_iter().collect();

a.contains(&2);                                    // true（平均 O(1)）
a.union(&b); a.intersection(&b); a.difference(&b); // 并 / 交 / 差（返回惰性迭代器）
```

**和 `Vec` 的区别**：`Vec::contains` 是 O(n)，`HashSet::contains` 平均 O(1)——"去重/判重"用 set。

## 3. BTreeMap / BTreeSet（有序）

```rust
use std::collections::BTreeMap;

let mut m = BTreeMap::new();
m.insert(3, "c");
m.insert(1, "a");
m.insert(2, "b");

let keys: Vec<_> = m.keys().copied().collect();
assert_eq!(keys, vec![1, 2, 3]);          // 始终按 key 有序

// 范围查询（HashMap 做不到）
let between: Vec<_> = m.range(1..=2).map(|(k, v)| (*k, *v)).collect();
assert_eq!(between, vec![(1, "a"), (2, "b")]);
```

| | `HashMap` | `BTreeMap` |
|--|-----------|-----------|
| 底层 | 哈希表 | 平衡树（≈ `std::map`） |
| 单点查询 | 平均 O(1) | O(log n) |
| 有序遍历 / range | ❌ | ✅ |
| 什么时候用 | 默认选它 | 需要按 key 排序或范围查询 |

## 4. 字符串与 Unicode

**核心事实：Rust 的 `String` 是 UTF-8 字节序列**——`len()` 是**字节数**，不是字符数。

```rust
let s = "héllo";
assert_eq!(s.len(), 6);                 // 字节数（é 占 2 字节）
assert_eq!(s.chars().count(), 5);       // 字符数（O(n)）

let cn = "中文";
assert_eq!(cn.len(), 6);                // 每个汉字 3 字节
assert_eq!(cn.chars().count(), 2);
```

### 不能按整数索引

```rust
let s = String::from("hello");
// let c = s[0];                        // ❌ 编译错误：str 不支持按整数索引
let c = s.chars().nth(0);               // Option<char>
let b = s.as_bytes()[0];                // u8（字节视角）
```

**切片也可能 panic**：`&s[0..2]` 要求落在**字符边界**上：

```rust
let s = "中文";
// let bad = &s[0..1];                  // ❌ panic：byte index 1 is not a char boundary
let ok = &s[0..3];                      // 正好一个汉字
assert_eq!(ok, "中");
assert!(!s.is_char_boundary(1));
```

**C++ 对照**：C++ 的 `std::string` 是字节数组，`s[0]` 拿 `char`；Rust 的 `char` 是 **Unicode 标量值（4 字节）**，和字节不是一回事——所有"按下标访问字符"的直觉都要换成 `chars()`。

### 常用方法

```rust
let s = "  Hello, Rust  ";

s.trim();                             // "Hello, Rust"
"a  b   c".split_whitespace().count();          // 3（自动跳过连续空白）
"line1\nline2".lines().count();                // 2
"42".parse::<i32>();                  // Ok(42)；失败返回 Err
```

`replace` / `starts_with` / `to_lowercase` 这些和别的语言差不多，按需查文档。

### 拼接

```rust
let mut s = String::from("hello");
s.push_str(" world");              // 追加 &str
s.push('!');                       // 追加 char
assert_eq!(s, "hello world!");

let a = String::from("foo");
let b = "bar";
let c = a + b;                     // ⚠️ `+` 会移动左侧的 a（等价于 a.push_str(b) 再返回 a）
let d = format!("{c}-{b}");        // 推荐：不移动任何东西
```

**函数参数**优先 `&str`（`String`、字面量、切片都能传）；要返回新字符串就返回 `String`。

## 5. 数值：溢出与转换

### 溢出：编译期报错 / debug panic / release 回绕

```rust
// ① 编译期能算出来的 → 直接编译失败（两种构建都是）
// let y: u8 = 255 + 1;         // ❌ error: this arithmetic operation will overflow

// ② 运行时才知道的值 → 行为随构建变化
fn inc(x: u8) -> u8 { x + 1 }

let n: u8 = "255".parse().unwrap();
// inc(n);                      // debug：panic "attempt to add with overflow"
//                              // release：回绕成 0
```

C++ 的溢出是 UB（编译器可以乱来）；Rust 是**明确定义**的行为，但**debug 和 release 不一样**——发布版的静默回绕同样要小心。

要明确语义，用这四个方法：

| 方法 | 溢出的行为 |
|------|-----------|
| `checked_add` | 返回 `Option`（`None`） |
| `wrapping_add` | 回绕（和 release 默认一样） |
| `saturating_add` | 卡在边界（`255`） |
| `overflowing_add` | 返回 `(值, 是否溢出)` |

```rust
assert_eq!(255u8.checked_add(1), None);
assert_eq!(255u8.wrapping_add(1), 0);
assert_eq!(255u8.saturating_add(1), 255);
assert_eq!(255u8.overflowing_add(1), (0, true));
```

**"数字来自用户/文件/网络"就别用 `+`**——用 `checked_*` 或 `TryFrom`。

### 转换：`as` vs `From`/`TryFrom`

**`as`**：C 风格转换，**截断/按位重解释**，不做检查：

```rust
assert_eq!(300u32 as u8, 44);             // 截断（300 - 256）
assert_eq!((-1i32) as u32, 4294967295);   // 按位重解释
assert_eq!((3.9f64) as i32, 3);           // 截断小数
```

**`From` / `Into`**：无损才实现，编译期保证安全：

```rust
let x: i64 = i64::from(5u8);              // u8 → i64 永远装得下
let y: i64 = 5u8.into();                  // 等价写法（目标类型明确时）
```

**`TryFrom` / `TryInto`**：可能失败，返回 `Result`：

```rust
assert!(u8::try_from(300u32).is_err());
assert_eq!(u8::try_from(255u32), Ok(255));

let n: i32 = "77".parse()?;               // 字符串解析（配合 ? 见[类型系统](03-类型系统.md)）
```

**选择原则**：能 `From` 就别 `as`；可能失败用 `TryFrom`；`as` 只留给"明确知道要截断/重解释"的场合（如底层位操作）。

## 6. 格式化

```rust
let (name, score) = ("amy", 95.5);

format!("{name}: {score}");        // "amy: 95.5"（内联变量）
format!("{:08}", 42);              // "00000042"
format!("{:.2}", 3.14159);         // "3.14"
format!("{:>8}|", 42);             // "      42|"（对齐）
format!("{:?}", vec![1, 2]);       // "[1, 2]"（Debug）
format!("{:#?}", vec![1, 2]);      // 多行美化版
```

进制（`{:x}`/`{:b}`）、科学计数（`{:e}`）、按位置/命名参数等，按需查文档。

**两套 trait**：`{}` 要 `Display`（面向用户）、`{:?}` 要 `Debug`（调试用，`#[derive(Debug)]` 就能有）。

```rust
use std::fmt;

struct Point { x: f64, y: f64 }

impl fmt::Display for Point {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        write!(f, "({}, {})", self.x, self.y)
    }
}

println!("{}", Point { x: 1.0, y: 2.0 });    // (1, 2)
```

输出到别的目标（文件/字符串）用 `write!`（返回 `Result`，要 `?` 或 `unwrap`）。

## 7. 要点回顾

1. **`Vec`**：索引越界 panic、`get` 返回 `Option`；参数用 `&[T]`；`with_capacity` 预分配
2. **`HashMap`**：`entry(...).or_insert(...)` 是计数/累加的标准写法；无序、key 要 `Hash + Eq`（`f64` 不行）
3. **要按 key 有序或 range 查询 → `BTreeMap`**；判重/去重用 `HashSet`（O(1)）
4. **`String` 是 UTF-8 字节序列**：`len()` 是字节数，`chars().count()` 才是字符数
5. **不能 `s[0]`**；切片要在**字符边界**上（否则 panic）；用 `chars()`/`bytes()`
6. **溢出**：debug panic、release 回绕；要明确语义用 `checked_add`/`wrapping_add`/`saturating_add`
7. **转换**：优先 `From`/`Into`，可能失败用 `TryFrom`；`as` 会截断/重解释
8. **格式化**：`{}`（Display）/ `{:?}`（Debug）/ `{:#?}` / `{:.2}` / `{:>8}` / `{:08}`；`format!` 返回 `String`
