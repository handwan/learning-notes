# 基础语法

Rust 的语法地基：变量、类型、函数、控制流、模块、宏。**与 C++ 明显不同的地方会单独标出**（少踩坑），一样的（`+ - * /`、`if` 形状、`for` 循环）一句带过。

> 含 3 个**故意写错**的反例（错误码照抄编译器输出；rustc 1.98）。

## 1. 变量：默认不可变

```rust
let a = 1;            // 默认不可变（和 C++ 正好相反）
let mut b = 2;        // 要改就加 mut
b += 1;
a = 3;                // ❌ error[E0384]: cannot assign twice to immutable variable
```

- **对比 C++**：C++ 默认可变、`const` 才不可变；Rust 反过来
- 类型推断：`let n = 5;`（推断成 `i32`）；要标注写 `let n: u32 = 5;`
- 常量：`const MAX: u32 = 100;`（**必须标类型**、编译期求值）、`static NAME: &str = "rust";`
- 命名规范（编译器会**警告**）：变量/函数 `snake_case`、类型 `CamelCase`、常量 `SCREAMING_SNAKE_CASE`

**遮蔽（shadowing）**：允许用同名新变量，甚至换类型：

```rust
let a = a + 10;          // 新变量，覆盖旧的
let a = a as f64 / 2.0;  // 再换成 f64（实测 a = 5.5）
```

- 和 C++ 的"内层作用域同名变量"不同：遮蔽在**同一作用域**也合法
- 用途：类型转换链、把 `mut` 用完之后丢掉可变性

## 2. 类型：没有隐式转换

| 类别 | Rust | C++ 对照 |
|------|------|---------|
| 整数 | `i8`~`i128` / `u8`~`u128`（定长） | `short/int/long`（平台相关） |
| 指针宽度 | `isize` / `usize`（索引、长度用它） | `ptrdiff_t` / `size_t` |
| 浮点 | `f32` / `f64` | `float` / `double` |
| 字符 | `char` = **4 字节 Unicode 标量**（实测） | `char` = 1 字节（完全不是一回事） |
| 元组 | `(i32, f64)`，解构 `let (a, b) = t;` | `std::tuple` + `std::get`（Rust 是内建） |
| 数组 | `[i32; 3]`（定长、栈上）；切片 `&arr[1..]` | `std::array` + `std::span` |

**没有隐式数值转换**：

```rust
let a: i32 = 3;
let b: i64 = a;          // ❌ error[E0308]: mismatched types
let b = a as i64;        // 显式 as（窄化会截断）
let b: i64 = a.into();   // 更安全：From/Into
```

- **索引必须是 `usize`**：`v[i]` 里 `i` 是 `i32` 会直接编译不过（最常撞的一处）
- 溢出行为：**debug 构建 panic**（`attempt to add with overflow`）、**release 构建回绕**；要明确语义就用 `wrapping_add` / `checked_add` / `saturating_add`
- 浮点比较同样不能用 `==`（`f64::EPSILON` / `approx`）

## 3. 函数与"表达式返回"

```rust
fn add(a: i32, b: i32) -> i32 { a + b }                     // 最后一个表达式就是返回值
fn early(x: i32) -> i32 { if x < 0 { return 0; } x * 2 }    // 提前返回用 return
```

- **分号的区别**：`a + b` 是表达式（有值）；`a + b;` 是语句（值被丢弃）→ 实测报 `error[E0308]: mismatched types`
- 块也是表达式：`let y = { let t = 3; t * t };`（y = 9）
- 参数**必须标类型**；**没有默认参数**（用 `Option<T>` 或 builder 模式）
- **没有函数重载**（用泛型 + trait，或不同函数名）

## 4. 控制流：都是表达式

```rust
let z = if b > 2 { "big" } else { "small" };                // if 是表达式（两分支类型必须一致）
let found = loop { i += 1; if i == 5 { break i * 10; } };   // loop 能 break 出值
for k in 0..3 { print!("{k} "); }                           // 0..3 左闭右开；0..=3 是闭区间
'outer: loop { loop { break 'outer; } }                     // 标签跳转（多层循环）
```

- `if` 要当表达式用就必须写完整的 `if/else`
- `while` / `for` 的值是 `()`（不能 `let x = while ...`）
- `match` 也是表达式，而且**必须穷尽所有情况**（见[类型系统](03-类型系统.md)）
- 没有 `switch`、没有 `goto`；`for` 只遍历"可迭代的东西"（`0..n`、`&v`、`v.iter()`）

## 5. 字符串与打印（细节见[集合与字符串](06-集合与字符串.md)）

```rust
let s1: &str = "字面量";                     // 借用：不可变视图
let s2: String = String::from("可增长");     // 拥有所有权
println!("{s1} {s2}");                       // 宏：{} = Display
println!("{:?}", (1, 2.5));                  // {:?} = Debug（调试友好）
```

- 打印用宏：`println!` / `print!` / `format!`（`!` 是宏标记）
- `{}` 要求类型实现 `Display`；`{:?}` 要求 `Debug`（`#[derive(Debug)]` 自动生成）
- 变量捕获简写：`println!("{name}")`；也可以位置参数 `{0}` / 命名参数

## 6. 模块：文件即模块

```
crate（一个编译单元）
 └── mod foo        → src/foo.rs 或 src/foo/mod.rs
      └── mod bar   → src/foo/bar.rs
```

- `pub` 控制可见性（**默认私有**，和 C++ 的 `class` 默认私有类似）
- 路径前缀：`crate::`（本 crate 根）、`super::`（父模块）、`self::`（当前）
- `use` 引入名字：`use std::collections::HashMap;`
- 组织惯例：`lib.rs` 是库入口、`main.rs` 是二进制入口（详见[工程与互操作](07-工程与互操作.md)）

## 7. 宏与注释

| 用途 | Rust | C++ |
|------|------|-----|
| 打印 | `println!`（宏） | `printf` / `iostream` |
| 调试打印 | `dbg!(x)`（打印**并返回**值） | `printf` / gdb |
| 未实现 | `todo!()` / `unimplemented!()` | 抛异常 / abort |
| 断言 | `assert!` / `assert_eq!`（**release 下也生效**） | `assert`（`NDEBUG` 下失效） |
| 文档注释 | `///`（项）、`//!`（模块） | `/** */`（Doxygen） |
| 属性 | `#[derive(Debug)]`、`#[test]` | `[[nodiscard]]`、宏 |

- `/* */` 块注释在 Rust 里**可以嵌套**
- 宏 = "带 `!` 的调用"：`println!`、`vec!`、`format!`、`matches!`

## 8. C++ ↔ Rust 速查

| 场景 | C++ | Rust |
|------|-----|------|
| 变量 | `int x = 1;`（可改） | `let x = 1;`（不可改）/ `let mut x = 1;` |
| 常量 | `constexpr int N = 5;` | `const N: i32 = 5;` |
| 类型别名 | `using T = ...` / `typedef` | `type T = ...;` |
| 函数返回 | `return x;` | 最后一个表达式（`x` 不带分号） |
| 条件表达式 | `c ? a : b` | `if c { a } else { b }` |
| 循环 | `for (int i = 0; i < n; ++i)` | `for i in 0..n` |
| 可空 | 指针 / `std::optional` | `Option<T>` + `match` |
| 错误处理 | 异常 / 错误码 | `Result<T, E>` + `?` |
| 打印 | `printf` / `cout` | `println!("{x}")` |
| 引入代码 | `#include "a.h"` | `mod a;` + `pub` |
| 类型转换 | 隐式转换 + 四种 cast | **只能显式**：`as` / `into()` / `try_into()` |

## 9. 要点回顾

1. **默认不可变**（`let` / `let mut`），和 C++ 相反；**遮蔽**允许同名换类型
2. **没有隐式数值转换**：用 `as` / `into()`；索引和长度必须是 `usize`
3. **表达式语言**：块的值 = 最后一个不带分号的表达式；`if` / `loop` / `match` 都能返回值
4. **`char` 是 4 字节 Unicode 标量**，和 C++ 的 `char` 完全不是一回事
5. **没有重载、没有默认参数、没有 goto**；宏带 `!`（`println!` / `vec!`）
6. **模块用 `mod` / `pub` / `use`**，文件即模块，默认私有
7. 溢出：debug panic / release 回绕；`assert!` 在 release 下也生效
