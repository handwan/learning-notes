# C++11-14

## C++11 语言特性

### 1. auto 类型推导

```cpp
auto i = 42;                       // int
auto d = 3.14;                     // double
auto s = std::string("hi");        // std::string
auto it = m.begin();               // 迭代器类型（写不出来但推导得出）

// 引用必须显式写
auto x = v[0];                     // int（拷贝！）
auto& y = v[0];                    // int&（引用）
const auto& z = v[0];              // const int&（只读、零拷贝）

// 范围 for 里的惯用法
for (const auto& item : container) { /* 只读遍历，不拷贝 */ }
for (auto& item : container) { item.update(); }
```

**推导规则**（记住两条就够）：

- `auto` 会**丢掉引用和顶层 const**（像按值传参）
- 想要引用/const，自己写：`auto&`、`const auto&`、`auto&&`（转发引用）

**坑**：

- `auto` 从代理类型推导时容易踩坑：`std::vector<bool>` 的 `v[0]` 是**代理对象**（不是 `bool&`），`auto b = v[0];` 拿到的是代理——要 `bool b = v[0];`
- `auto` 推导出的类型不好读时，用 `static_assert` / `decltype` 打印出来看

### 2. decltype

```cpp
int x = 0;
decltype(x) a = 1;              // int（带 const/引用信息，和 auto 不同）

// decltype 的规则：
// 表达式是"名字/成员访问" → 取声明类型
// 表达式是"其它左值"       → 引用类型（T&）
int& r = x;
decltype(r) b = x;              // int&（b 是引用）
decltype((x)) c = x;            // int&（加括号变左值表达式！）

// C++14：decltype(auto)——按 decltype 的规则推导返回值
template <typename F, typename... Args>
decltype(auto) call(F&& f, Args&&... args) {
    return std::forward<F>(f)(std::forward<Args>(args)...);   // 完美转发返回值
}
```

**auto vs decltype**：`auto` 保守（去引用去 const），`decltype` 精确（保留引用/const，还区分左值右值）——写库/转发时用 `decltype(auto)`。

### 3. nullptr

```cpp
void f(int);
void f(char*);

f(NULL);        // ❌ 有歧义或错误地调 f(int)（NULL 往往是 0）
f(nullptr);     // 明确调 f(char*)

int* p = nullptr;               // 类型是 std::nullptr_t，能隐式转成任意指针
if (p) { }                      // 能当 bool 用
```

**为什么需要它**：`NULL` 是整数 0 的宏（或 `0L`），在重载解析里会挑 `int` 版本；`nullptr` 有独立类型 `std::nullptr_t`，语义清楚。

### 4. 范围 for 循环

```cpp
std::vector<int> v{1, 2, 3};

for (int x : v) { }              // 拷贝每个元素
for (int& x : v) { x *= 2; }     // 引用，可修改
for (const auto& x : v) { }      // 只读、零拷贝（默认选择）

// 展开规则：
// for (auto&& x : range)  →  用 begin(range) / end(range)
```

**注意**：

- **遍历时不能改容器大小**（push_back / erase 会让迭代器失效）
- C++17 起允许 `begin`/`end` 返回**不同类型**（以前必须相同）
- 想同时要下标，用 `std::views::enumerate`（C++23）或自己计数——范围 for 不提供下标

### 5. 统一初始化 + 初始化列表

```cpp
int a{5};                        // 统一用 {}
std::vector<int> v{1, 2, 3};
struct P { int x, y; };
P p{1, 2};

int b(5.9);                      // 5（括号允许窄化）
// int c{5.9};                   // ❌ 大括号禁止"窄化转换"（更安全）
```

**坑：`{}` 会优先选 `initializer_list` 构造函数**——这是最容易踩的地方：

```cpp
std::vector<int> v1(5, 2);       // 5 个元素，每个都是 2 → {2,2,2,2,2}
std::vector<int> v2{5, 2};       // 两个元素：5 和 2 → {5, 2}

// 空 {} 的含义：
std::vector<int> v3{};           // 空 vector（调默认构造）
std::vector<int> v4();           // ⚠️ 这是个函数声明（most vexing parse）！
```

**建议**：容器用 `{}` 明确列元素、用 `()` 明确传大小/参数；空初始化用 `{}` 而不是 `()`。

### 6. 右值引用与移动语义

```cpp
std::string a = "hello";
std::string b = std::move(a);    // 移动：a 的资源被"掏走"，a 变空
// a 现在状态未指定，只能赋值/销毁，别再用它的值

// 移动构造 / 移动赋值
class Buffer {
public:
    Buffer(Buffer&& other) noexcept              // 移动构造
        : data_(other.data_), size_(other.size_) {
        other.data_ = nullptr;                   // 把源置空
        other.size_ = 0;
    }
    Buffer& operator=(Buffer&& other) noexcept;  // 移动赋值（记得处理自赋值、释放自身资源）
private:
    int* data_ = nullptr;
    size_t size_ = 0;
};
```

**要点**：

- `std::move` 本身**不移动**，只是把左值转成右值引用（一个 cast）；真正的移动发生在移动构造/赋值
- 移动后源对象"有效但未指定"——只能重新赋值或销毁
- **返回值别写 `return std::move(x);`**（阻止 RVO，详见 [C++17](C++17.md)）
- 移动构造尽量标 `noexcept`——否则容器扩容会退化成拷贝（见下面第 17 节）

> 完整版（值类别、forward、引用折叠、RVO）见 [右值引用与移动语义](右值引用与移动语义.md)。

### 7. lambda 表达式

```cpp
// 完整语法：[捕获](参数) mutable -> 返回类型 { 体 }
auto add = [](int a, int b) { return a + b; };
auto counter = [n = 0]() mutable { return ++n; };      // 初始化捕获（C++14）

int x = 10;
auto by_value = [x] { return x; };            // 按值捕获（拷贝一份）
auto by_ref = [&x] { x++; };                  // 按引用捕获（注意生命周期）
auto all_val = [=] { return x; };             // 按值捕获所有用到的
auto all_ref = [&] { x++; };                  // 按引用捕获所有用到的

// 捕获 this（成员函数里）
struct S {
    int v = 1;
    auto f() { return [this] { return v; }; }        // 捕获指针（对象没了就悬垂）
};
```

**要点**：

- lambda 本质是**匿名的函数对象**（编译器生成一个带 `operator()` 的类）
- `mutable` 让按值捕获的变量在 lambda 体内可改（改的是副本）
- 按引用捕获的变量**生命周期要长于 lambda**（异步/存起来的 lambda 用值捕获）
- 捕获列表里可以"移动"大对象：`[p = std::move(ptr)] { }`

**和 `std::function` 对比**：lambda 本身是具体类型、可内联、零开销；存进 `std::function` 后是类型擦除 + 可能堆分配（见第 21 节）。

### 8. 智能指针

```cpp
#include <memory>

std::unique_ptr<Widget> p = std::make_unique<Widget>();   // 独占（C++14 才有 make_unique）
std::shared_ptr<Widget> sp = std::make_shared<Widget>();  // 共享引用计数
std::weak_ptr<Widget> wp = sp;                            // 不增加计数（打破循环引用）

sp.use_count();                // 当前引用计数
wp.lock();                     // 尝试提升为 shared_ptr（可能返回空）
```

**要点**：

- `unique_ptr`：零开销（和裸指针一样大）、不可拷贝只能移动——**默认首选**
- `shared_ptr`：有原子计数开销；**别用同一个裸指针构造两个 shared_ptr**（会双重释放），要 `std::make_shared`
- 循环引用（A 持有 B 的 shared_ptr、B 持有 A 的）永远不会释放 → 一方用 `weak_ptr`
- 自定义删除器（文件、socket）：`std::unique_ptr<FILE, decltype(&fclose)> fp{fopen(...), &fclose};`

> 深入（内存布局、循环引用案例、enable_shared_from_this）见 [内存管理](内存管理.md)。

### 9. enum class（强类型枚举）

```cpp
enum class Color { Red, Green, Blue };       // 强类型、有作用域
enum OldColor { Red2, Green2 };              // 老式：作用域泄漏、能隐式转 int

Color c = Color::Red;                        // 必须带作用域
// int i = c;                                // ❌ 不隐式转整数（要 static_cast）
if (c == Color::Red) { }

enum class Status : std::uint8_t { Ok, Fail };   // 指定底层类型（省内存/协议对齐）
```

**为什么用它**：老 enum 的名字会"泄漏"到外层作用域（两个 enum 都有 `Red` 就冲突），还能隐式转 int（和整数乱比）。`enum class` 两个问题都没有。

### 10. override / final

```cpp
class Base {
public:
    virtual void run() const;
    virtual ~Base() = default;
};

class Derived : public Base {
public:
    void run() const override;      // 显式声明"我在覆写"——签名写错会编译报错
    // void run() override;         // ❌ 少个 const，编译器会告诉你没覆写到
};

class Sealed final : public Base { };   // 不能再被继承
class D2 : public Base {
    void run() const final;             // 这个虚函数不能再被覆写
};
```

**要点**：写虚函数覆写时**永远加 `override`**——不然签名稍微不一致（const、参数）就变成"新函数"，运行时才发现没调用到。

### 11. constexpr

```cpp
constexpr int square(int x) { return x * x; }    // 编译期可求值

constexpr int n = square(5);                     // 编译期算好（也是常量表达式）
int runtime = 7;
int m = square(runtime);                         // 运行期调用也行（constexpr = "可以"编译期）

constexpr int fib(int n) {                       // C++11 的限制：只能一条 return（递归写法）
    return n <= 1 ? n : fib(n - 1) + fib(n - 2);
}
static_assert(fib(10) == 55);
```

**要点**：

- `constexpr` 表示"**可以**在编译期求值"（不是"必须"）；`consteval`（C++20）才是必须
- 用途：编译期常量、数组大小、模板参数、`static_assert`、把计算从运行期挪到编译期
- C++11 的 constexpr 函数限制很严（单条 return、不能有循环/局部变量）——C++14 放宽（见第 30 节）

### 12. 变参模板

```cpp
// 递归展开（C++11 的经典写法）
void print() { std::cout << '\n'; }                  // 递归终点

template <typename T, typename... Rest>
void print(T first, Rest... rest) {
    std::cout << first << ' ';
    print(rest...);                                  // 用掉一个，剩下的递归
}

print(1, 2.5, "three");       // 1 2.5 three

// 取参数个数
template <typename... Args>
constexpr size_t count(Args...) { return sizeof...(Args); }

// C++17 后可以用折叠表达式代替递归（见 [C++17](C++17.md)）
```

**用途**：写"参数个数不定 + 类型不限"的模板（`make_shared`、`emplace_back`、日志、`std::tuple` 内部都靠它）。

### 13. default / delete

```cpp
class Widget {
public:
    Widget() = default;                          // 显式要求"生成默认实现"
    Widget(const Widget&) = delete;              // 禁止拷贝
    Widget& operator=(const Widget&) = delete;   // 禁止拷贝赋值
    virtual ~Widget() = default;                 // 多态基类要有虚析构
};
```

**要点**：

- 一旦你自己写了析构/拷贝构造等，编译器就不再隐式生成其它的——用 `= default` 明确要回来
- `= delete` 比"声明成 private 不实现"（老写法）清楚得多，且报错在编译期调用处

### 14. 委托构造 / 继承构造

```cpp
class Config {
    int a_, b_;
public:
    Config(int a, int b) : a_(a), b_(b) { }
    Config() : Config(0, 0) { }                  // 委托构造：复用另一个构造函数
    Config(int a) : Config(a, a) { }
};

class Derived : public Base {
public:
    using Base::Base;                            // 继承构造：把基类构造函数都拿过来
};
```

**要点**：委托构造避免"多个构造函数重复初始化"；继承构造省掉"转发一遍参数"的样板（注意：继承来的构造函数只初始化基类部分）。

### 15. using 类型别名

```cpp
using IntVec = std::vector<int>;                 // 和 typedef 等价（但顺序更好读）

// typedef 做不到的：模板别名
template <typename T>
using Vec = std::vector<T>;                      //

// template <typename T>
// typedef std::vector<T> Vec2;                  // ❌ 编译错误

Vec<int> v;
```

**要点**：新代码优先 `using`；需要"带模板参数的别名"时只能用 `using`。

### 16. static_assert（编译期断言）

```cpp
static_assert(sizeof(int) == 4, "int 必须是 4 字节");
static_assert(std::is_integral_v<int>);           // C++17 起消息可省

template <typename T>
void process(T t) {
    static_assert(std::is_copy_constructible_v<T>,
                  "T 必须可拷贝构造");
}
```

**用途**：把"假设"写进代码——类型大小、平台、模板约束；不满足直接编译失败（比运行期 assert 更早）。

### 17. noexcept

```cpp
void f() noexcept;                 // 承诺不抛异常
void g() noexcept(false);          // 明确可能抛（少见）

// 条件 noexcept（模板库里常见）
template <typename T>
void wrapper(T&& x) noexcept(noexcept(inner(std::forward<T>(x)))) {
    inner(std::forward<T>(x));
}

static_assert(noexcept(std::declval<std::vector<int>&>().size()));   // 检测用
```

**为什么重要（性能相关）**：**只有移动构造标了 `noexcept`，`std::vector` 扩容时才会用"移动"而不是"拷贝"**。

```cpp
struct A {
    A(A&&) noexcept { }              // 标了 noexcept → vector 扩容用移动（快）
};
struct B {
    B(B&&) { }                       // 没标 → vector 用拷贝（慢，但保证强异常安全）
};
```

原因：vector 扩容时若移动中途抛异常，原数据已被破坏、没法回滚——所以标准库用 `move_if_noexcept`：**能拷贝且移动可能抛 → 用拷贝**。
（例外：类型**不可拷贝**时没有退路，只能用移动，哪怕移动没标 noexcept。）

**经验**：自己写的移动构造/移动赋值**都加 `noexcept`**（除非真会抛）。

### 18. alignas / alignof（对齐控制）

```cpp
alignof(int);                              // 4（查询类型的对齐）

struct alignas(16) Vec4 { float x, y, z, w; };       // 强制 16 字节对齐（SIMD 友好）

struct alignas(64) Counter {              // 按 cache line 对齐（避免伪共享）
    std::atomic<long> value{0};
};

alignas(32) float buf[8];                 // 对齐的数组（AVX 操作更快）
```

**用途**：SIMD 指令要求对齐、避免多线程伪共享、和硬件/协议的数据结构对齐。

### 19. 用户定义字面量

```cpp
constexpr long double operator""_km(long double x) { return x * 1000; }
constexpr unsigned long long operator""_KB(unsigned long long x) { return x * 1024; }

auto d = 5.0_km;          // 5000.0
auto n = 4_KB;            // 4096
```

**用途**：给单位加类型/语义（时间、长度、字节数）；标准库就用了不少（`1s`、`100ms`、`"str"s`、`"x"sv`）。

## C++11 标准库特性

### 20. std::thread / mutex / atomic

```cpp
#include <thread>
#include <mutex>
#include <atomic>

std::thread t([]{ do_work(); });
t.join();                                  // 等它结束（或 detach，但很少用）

std::mutex mtx;
{
    std::lock_guard<std::mutex> lk{mtx};   // RAII 加锁
    // 临界区
}                                          // 自动解锁

std::atomic<int> counter{0};
counter.fetch_add(1);                      // 原子自增（无锁）
++counter;                                 // 也原子（但语义是"读-改-写"）
```

**要点**：

- `thread` 析构前必须 `join()` 或 `detach()`，否则程序终止
- `lock_guard` 最小够用；要"手动解锁/条件变量"用 `unique_lock`；多锁用 `scoped_lock`（C++17）
- `atomic` 只对"单变量、单目运算"省心；多步操作用 `mutex`
- 线程间同步、内存序、线程池 → 见 [并发编程](并发编程.md)、[内存模型与内存序](内存模型与内存序.md)

**`std::call_once` / `once_flag`**（单次初始化）：

```cpp
std::once_flag flag;
std::call_once(flag, []{ init_shared_resource(); });   // 多线程也只执行一次
```

### 21. std::function / std::bind

```cpp
#include <functional>

// function：能装"任何可调用对象"（函数指针、lambda、函数对象）
std::function<int(int, int)> f = [](int a, int b) { return a + b; };
f(1, 2);

// 用途：回调、存进容器、当类成员
class Button {
public:
    std::function<void()> onClick;
};

// bind：绑定部分参数（旧写法）
auto add = [](int a, int b) { return a + b; };
auto add10 = std::bind(add, 10, std::placeholders::_1);   // 等价于 lambda
// C++11 后推荐直接写 lambda：auto add10 = [](int x) { return add(10, x); };

// std::ref：按引用传参（bind/thread 默认按值拷贝）
void inc(int& x) { ++x; }
int v = 0;
auto t = std::thread(inc, std::ref(v));   // 不包 ref 就是拷贝，改不到外面
t.join();
```

**要点**：

- `std::function` 有**类型擦除开销**（可能堆分配 + 间接调用）——性能敏感路径用模板参数或 lambda 类型
- `bind` 基本被 lambda 取代（可读性好、能内联）；只有极少数转发场景还用
- **默认按值拷贝**：要改外部变量得 `std::ref`

### 22. std::array / std::tuple / std::unordered_map

```cpp
#include <array>
#include <tuple>
#include <unordered_map>

// array：定长数组，但有 size()/begin()/end()，能当值传递
std::array<int, 3> a{1, 2, 3};
a.size();                     // 3（编译期常量）
a[0];                         // 不检查越界
a.at(0);                      // 检查（抛 std::out_of_range）

// tuple：不同类型打包
std::tuple<int, std::string, double> t{1, "hi", 3.14};
std::get<0>(t);               // 1（按下标）
std::get<std::string>(t);     // 按类型（类型必须唯一）
std::tie(x, s, d) = t;        // 解包到已有变量
auto [i2, s2, d2] = t;        // C++17 结构化绑定（更好用）

// unordered_map：哈希表（平均 O(1)）
std::unordered_map<std::string, int> m{{"a", 1}};
m["b"] = 2;
m.find("a");
```

**要点**：

- `array` 传参不退化（区别于 C 数组）、可赋值、可比较
- 自定义类型当 `unordered_map` 的 key：**要提供哈希函数和 `operator==`**（或特化 `std::hash`）
- 要**稳定顺序**用 `std::map`（红黑树），只查得快用 `unordered_map`

### 23. std::chrono（时间库）

```cpp
#include <chrono>
using namespace std::chrono;

// 三种时钟
steady_clock::now();      // 单调递增（计时用这个）
system_clock::now();      // 墙上时间（能转 time_t，可能被 NTP 调整）
high_resolution_clock::now();   // 通常是上面之一的别名

// 计时惯用法
auto t0 = steady_clock::now();
do_work();
auto t1 = steady_clock::now();
auto us = duration_cast<microseconds>(t1 - t0).count();

// 时长（字面量：C++14 起）
seconds s = 2s;
milliseconds ms = 150ms;
```

**要点**：**计时永远用 `steady_clock`**（`system_clock` 会被系统时间调整影响）；比较时间点/求差值都是类型安全的（不同单位不会混）。

### 24. `<random>`（随机数）

```cpp
#include <random>

std::random_device rd;                       // 真随机种子（慢，只用一次）
std::mt19937 gen(rd());                      // 梅森旋转引擎
// 可复现实验：固定种子
std::mt19937 gen2(42);

std::uniform_int_distribution<int> dice(1, 6);       // [1, 6] 均匀
std::uniform_real_distribution<double> uni(0.0, 1.0);
std::normal_distribution<double> normal(0.0, 1.0);   // 正态

dice(gen);       // 掷骰子
normal(gen2);    // 取正态分布样本
```

**要点**：

- **别用 `rand()`**（质量差、范围小、线程不安全）
- **分布对象不该共用**：同一个分布对象跨引擎用可能得到相关结果，一般"一个引擎 + 局部分布"或每个线程一套
- **要复现**（实验/测试）就固定种子（`mt19937 gen(42)`）；要不可预测用 `random_device`

## C++14 特性

### 25. 泛型 lambda

```cpp
auto add = [](auto a, auto b) { return a + b; };     // 参数用 auto → 模板化 operator()
add(1, 2);          // int
add(1.5, 2.5);      // double
add(std::string("a"), std::string("b"));             // string
```

**本质**：lambda 的 `operator()` 变成模板；等价于 `[]<typename T>(T a, T b)`（C++20 的显式模板 lambda）。

### 26. 返回类型推导

```cpp
auto add(int a, int b) { return a + b; }             // 推导成 int

// 想推成引用用 decltype(auto)
template <typename T>
decltype(auto) front(T& c) { return c[0]; }          // 返回引用而不是拷贝

auto f() { return 42; }                              // 普通函数也能 auto 返回
// auto g() { return {1, 2}; }                       // ❌ 没法从 braced-init-list 推
```

**注意**：`auto` 返回值和 `auto` 变量一样**会丢掉引用**——要引用必须 `decltype(auto)` 或显式 `auto&`。

### 27. std::make_unique

```cpp
auto p = std::make_unique<Widget>(arg1, arg2);       // C++14 才有（C++11 只能 new）

// 为什么用 make 函数：
// ① 异常安全：f(std::unique_ptr<A>(new A), g()) 里 g() 抛异常可能漏资源
// ② 不用重复写类型
// ③ shared 版还能把控制块和对象一次分配（make_shared）
```

### 28. 变量模板

```cpp
template <typename T>
constexpr T pi = T(3.1415926535897932385);

pi<float>;      // float 精度
pi<double>;     // double 精度

// 标准库也用了：std::numbers::pi_v<T>（C++20）
```

### 29. 数字分隔符 / 二进制字面量

```cpp
int million = 1'000'000;             // 分隔符（纯可读性，值不变）
int hex_mask = 0xFF'FF'00'00;
int bin = 0b1010'0101;               // 二进制字面量（C++14）
int bin2 = 0b1010'0101'0000'1111;
```

### 30. 放宽的 constexpr

C++14 起 `constexpr` 函数里可以有**局部变量、循环、if、多语句**（C++11 只能单条 `return`）：

```cpp
// C++11 风格：递归 + 三元表达式
constexpr int sum11(int n) { return n <= 0 ? 0 : n + sum11(n - 1); }

// C++14 风格：正常写循环
constexpr int sum14(int n) {
    int total = 0;
    for (int i = 1; i <= n; ++i) total += i;
    return total;
}
static_assert(sum14(100) == 5050);
```

**意义**：编译期计算能像普通代码一样写（配置校验、查表生成、字符串处理），不用再写递归体操。

### 31. std::exchange

```cpp
#include <utility>

// 移动赋值/移动构造里的经典用法：取出旧值、换成新值
struct Buffer {
    int* data = nullptr;
    Buffer& operator=(Buffer&& other) noexcept {
        data = std::exchange(other.data, nullptr);   // 拿过来 + 把对方置空，一步完成
        return *this;
    }
};

// 其他用途：把"当前值"取出来，同时设置新值
int current = std::exchange(value, 0);    // current = 旧值，value 变成 0
```

### 32. [[deprecated]]

```cpp
[[deprecated("改用 new_api()")]]
void old_api();

[[deprecated]]
void older_api();
```

**用途**：标记"还能用但不建议"的接口——调用处会出编译警告，方便渐进式迁移（比直接删掉温和）。
