# 异常处理

C++ 错误处理机制：`throw` 抛出、`try/catch` 捕获。重点是**异常安全**和 **noexcept**。

## 1. 基本语法

```cpp
int divide(int a, int b) {
    if (b == 0) throw std::runtime_error("除零");   // 抛出异常
    return a / b;
}

int main() {
    try {
        divide(1, 0);
    } catch (const std::runtime_error& e) {
        std::cout << e.what();     // 捕获：打印 "除零"
    } catch (...) {
        // 兜底：捕获所有异常
    }
}
```

**机制**：`throw` 后函数立即退出，控制流沿调用栈**往回找** `catch`（栈展开）。找到匹配的 catch 就处理，找不到程序终止（terminate）。

**栈展开**：异常抛出后，从 throw 到 catch 之间的所有局部对象都会被**析构**（这也是 RAII 安全的来源）。

## 2. 异常安全

异常安全分三个等级：

| 等级 | 保证 | 说明 |
|------|------|------|
| 基本保证 | 不泄漏、对象仍可用 | 状态可能改变，但不崩溃不泄漏 |
| 强保证 | 失败像没发生一样 | 操作要么成功，要么完全不变 |
| 不抛保证 | 绝不抛异常 | `noexcept` 函数 |

```cpp
// 基本保证 vs 强保证 的例子：vector 插入
// 强保证实现：先拷贝一份，成功再替换（copy-and-swap）
```

## 3. noexcept

**含义**：声明函数不抛异常。

```cpp
void f() noexcept;        // noexcept 说明符：承诺不抛
// 如果 noexcept 函数里真的抛了异常 → 直接调用 std::terminate 终止程序
```

**noexcept 运算符**（容易漏）：`noexcept(表达式)` 编译期判断"表达式会不会抛异常"：

```cpp
void f() noexcept;
void g() { /* 可能抛 */ }

static_assert(noexcept(f()), "f 不抛");    // true
noexcept(g());                              // → false

// 常用于"条件性 noexcept"：
template <typename T>
void swap(T& a, T& b) noexcept(noexcept(a.swap(b)));   // 取决于 T 的 swap 是否 noexcept
```

**为什么移动构造要加 noexcept**（和前面移动语义呼应）：

```cpp
// vector 扩容时要搬移元素：
// - 移动构造 noexcept → vector 放心用移动（快）
// - 移动构造没 noexcept → vector 不敢用移动（怕抛异常后无法恢复），退化用拷贝（慢）
class String {
    String(String&& other) noexcept { /* ... */ }   // ⚠️ 必须加 noexcept
};
```

**何时用**：

- 移动构造/移动赋值 → **必须加** noexcept
- 析构函数 → 默认 noexcept，别改
- 确定不抛的函数（如 swap）→ 加

## 4. 析构函数不能抛异常

```cpp
class A {
    ~A() {
        throw std::runtime_error("error");   // ❌ 大忌！
    }
};
```

**为什么**：

1. 析构抛出异常 → 如果正在**栈展开**（处理另一个异常）→ 两个异常并存 → 直接 terminate
2. 析构里资源释放不该失败，失败也没人处理

**规则**：**析构函数默认 noexcept，绝不能抛异常**。析构里可能失败的操作（如 close 文件）要吞掉错误或记录日志。

## 5. RAII 与异常（配合）

```cpp
// 手动管理：异常抛出会泄漏
void f() {
    int* p = new int(5);
    risky_operation();        // 抛异常 → delete 不执行 → 泄漏
    delete p;
}

// RAII：异常抛出自动释放
void g() {
    std::unique_ptr<int> p = std::make_unique<int>(5);
    risky_operation();        // 抛异常 → unique_ptr 析构 → 自动释放 ✓
}
```

**这就是 RAII 和异常安全的联动**：异常 + RAII = 不用写一堆 try/catch 也能保证资源释放。

## 6. 要点回顾

1. **try/catch/throw 机制**：栈展开、找 catch
2. **异常安全三等级**：基本保证 / 强保证 / 不抛保证
3. **noexcept**：移动构造必须加（vector 扩容敢用移动）
4. **析构不能抛异常**：栈展开时两异常并存 → terminate
5. **RAII 保证异常安全**：异常下资源自动释放
6. **按引用捕获**：`catch (const std::exception& e)`，不要按值（避免切片）——按值捕获会把派生类异常**拷贝成基类对象**（切片），丢失派生类信息，多态失效；按引用保留完整对象
