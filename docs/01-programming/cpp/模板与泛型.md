# 模板与泛型

模板 = **类型参数化**：写一份代码，适用于多种类型。C++ 泛型编程的核心。

## 1. 为什么需要模板

```cpp
// 没有模板：每种类型写一份（代码重复）
int add(int a, int b) { return a + b; }
double add(double a, double b) { return a + b; }

// 模板：一份代码，所有类型通用
template <typename T>
T add(T a, T b) { return a + b; }

add(1, 2);        // T 推导为 int
add(1.5, 2.5);    // T 推导为 double
```

## 2. 函数模板

```cpp
template <typename T>          // 模板参数列表
T max(T a, T b) {
    return a > b ? a : b;
}

// 显式指定类型 / 自动推导
max<int>(1, 2);     // 显式
max(1, 2);          // 自动推导
```

**编译机制**：模板是"编译期展开"——每次用不同类型调用，编译器生成一份对应的实际代码（**实例化**）。所以模板不会降低运行性能，但会增加编译时间和二进制体积。

## 3. 类模板

```cpp
template <typename T>
class Box {
    T value_;
public:
    Box(T v) : value_(v) { /* ... */ }
    T get() const { return value_; }
};

Box<int> b1(5);
Box<std::string> b2("hello");
// 注意：类模板必须显式指定类型（C++17 前），函数模板能自动推导
```

STL 容器全是类模板：`std::vector<int>`、`std::map<std::string, int>`。

## 4. 模板特化（全特化）

**目的**：对某个特定类型，用特殊实现：

```cpp
template <typename T>
class Printer {
public:
    void print(T v) { std::cout << v << "\n"; }
};

// 全特化：针对 bool 的特殊版本
template <>
class Printer<bool> {
public:
    void print(bool v) { std::cout << (v ? "true" : "false") << "\n"; }
};

Printer<int> p1;
p1.print(1);          // 用通用版
Printer<bool> p2;
p2.print(true);       // 用特化版 → "true"
```

## 5. 偏特化（Partial Specialization）

只特化一部分模板参数（只针对类模板，函数模板不能偏特化）：

```cpp
template <typename T, typename U>
class Pair { /* 通用版 */ };

// 偏特化：两个类型相同时，用这个版本
template <typename T>
class Pair<T, T> { /* T 和 T 相同类型的特殊版 */ };

// 偏特化：第二个是指针时
template <typename T, typename U>
class Pair<T*, U> { /* 指针版 */ };
```

**典型应用**：`std::vector<bool>` 是 `vector` 的偏特化（位压缩存储，节省空间）。

## 6. 变参模板（Variadic Templates）

模板参数个数不定：

```cpp
template <typename... Args>          // 参数包
void print(Args... args) {           // 展开参数包
    (std::cout << ... << args);      // C++17 折叠表达式
}

print(1, 2, "hello", 3.14);          // 任意个数、任意类型
```

**递归展开**（C++11 风格）：

```cpp
void print() { /* 递归终止 */ }
template <typename T, typename... Args>
void print(T first, Args... rest) {
    std::cout << first << " ";
    print(rest...);                  // 递归处理剩下的
}
```

## 7. 类型萃取（type traits）

编译期判断/修改类型：

```cpp
#include <type_traits>

std::is_same<int, int>::value;         // true（类型是否相同）
std::is_pointer<int*>::value;          // true（是否指针）
std::is_integral<int>::value;          // true（是否整型）

// 配合 if constexpr（C++17）：
template <typename T>
auto get_value(T t) {
    if constexpr (std::is_pointer_v<T>) return *t;   // 指针就解引用
    else return t;
}
```

## 8. SFINAE 与 enable_if

**SFINAE**（Substitution Failure Is Not An Error）：模板替换失败不算错误，只是把该重载剔除：

```cpp
// enable_if：条件为真时才启用这个模板
// 只有 T 是整型时，这个函数才存在
template <typename T>
std::enable_if_t<std::is_integral_v<T>, T>
f(T x) { return x * 2; }

f(5);        // int 是整型，启用
f(5.5);      // ❌ double 不是整型，这个重载被剔除
```

**用途**：根据类型条件，选择不同的模板重载。

### 标签分发（Tag Dispatch）

**思路**：用"空标签类型"做重载选择，比 enable_if 更直观：

```cpp
// 用标签表示类型类别
struct input_tag {};
struct random_access_tag {};

// 不同迭代器类型，不同实现
template <typename Iter>
void advance_impl(Iter& it, int n, input_tag) { /* 一步步走 */ }

template <typename Iter>
void advance_impl(Iter& it, int n, random_access_tag) { it += n; }   // 直接跳

// 入口：根据迭代器类别选标签
template <typename Iter>
void advance(Iter& it, int n) {
    advance_impl(it, n, typename std::iterator_traits<Iter>::iterator_category{});
}
```

**用途**：STL 内部大量使用（根据迭代器能力给不同实现）。

### enable_if 实战（按条件启用重载）

```cpp
// 例：只接受"可调用对象"的接口
template <typename F,
          typename = std::enable_if_t<std::is_invocable_v<F>>>
void run(F f) { f(); }

// 例：整型走 A 版，浮点走 B 版
template <typename T>
std::enable_if_t<std::is_integral_v<T>> process(T x) { /* 整型 */ }

template <typename T>
std::enable_if_t<std::is_floating_point_v<T>> process(T x) { /* 浮点 */ }
```

### CRTP（奇异递归模板模式）

**定义**：派生类把自己作为模板参数传给基类——实现**静态多态**：

```cpp
template <typename Derived>
class Base {
public:
    void interface() {
        static_cast<Derived*>(this)->impl();   // 编译期确定调用哪个 impl
    }
};

class Derived : public Base<Derived> {
public:
    void impl() { /* ... */ }
};
```

**对比虚函数（动态多态）**：

| | 虚函数 | CRTP |
|--|--------|------|
| 多态时机 | 运行期（vtable） | **编译期** |
| 开销 | 虚函数调用 | **零开销**（直接调用展开） |
| 能否运行时切换 | ✅ | ❌ |

**用途**：

- **静态多态**（性能敏感处替代虚函数）
- **混入（Mixin）**：给类加通用功能（如计数、比较）
- Eigen（矩阵库）大量用 CRTP 做表达式模板

## 9. 模板定义放哪（头文件 vs .cpp）

**规则**：模板定义必须让**实例化它的地方看得见**——实例化发生在编译期，编译器要看到定义才能生成代码。

**反例实测**（声明在 `.h`、定义藏在 `.cpp`）：

```cpp
// util.h
template <class T> T addOne(T x);              // 只有声明

// util.cpp
#include "util.h"
template <class T> T addOne(T x) { return x + 1; }
```

链接结果：

```
undefined reference to `int addOne<int>(int)'   ❌
```

**两种修法**：

1. **定义写进头文件**（最常见）——所以模板库大多是 header-only
2. **显式实例化**（已知会用哪些类型时）：

```cpp
// util.cpp 末尾
template int addOne<int>(int);    // 在这里就把 int 版生成好
```

**为什么普通函数没这个问题**：普通函数由链接器按名字找定义 ✅；模板是"按类型现生成"，链接器找不到"还没生成的那份代码" ❌。

## 10. 别名模板与变量模板

**别名模板（C++11）**：给"带参数的复杂类型"起短名字 ✅（`typedef` 做不到，它不能带参数 ❌）：

```cpp
template <class T>
using Matrix = std::vector<std::vector<T>>;    // 别名模板

Matrix<int> m{{1, 2}, {3, 4}};                 // = vector<vector<int>>，不用再写两层
```

典型用途还有"把分配器/比较器固定在别名里"：`template <class T> using Vec = std::vector<T, MyAlloc<T>>;`。

**变量模板（C++14）**：把常量也模板化，按类型给精度：

```cpp
template <class T>
constexpr T pi = T(3.1415926535897932385);

double a = pi<double>;   // 3.141592653589793
float  b = pi<float>;    // 3.1415927（float 精度）
```

实测：`pi<float>` 确实是 `float`。标准库里 `std::numbers::pi_v<T>`（C++20）就是变量模板。

## 11. 模板的缺点

1. **编译慢**：每次实例化都要重新编译一份
2. **二进制膨胀**：每种类型一份代码
3. **错误信息难读**：深层模板错误报一大堆（C++20 Concepts 改善）
4. **必须放头文件**：模板定义要可见才能实例化

## 12. 要点回顾

1. **模板 = 编译期多态**（vs 虚函数的运行期多态）
2. **实例化**：用不同类型就生成一份代码
3. **全特化 vs 偏特化**：全特化固定所有参数，偏特化固定部分（函数模板不能偏特化）
4. **变参模板 + 折叠表达式**：参数包展开
5. **CRTP**：静态多态（编译期，零开销），Eigen 等库常用
6. **类型萃取**：编译期判断类型（`is_pointer` 等）
7. **SFINAE / enable_if / 标签分发**：按类型条件启用或剔除重载
8. **模板 vs 宏**：模板有类型检查，宏是文本替换
9. **模板定义要可见**：放头文件（或显式实例化）——否则 `undefined reference` ❌
10. **别名模板 / 变量模板**：`template <class T> using Vec = ...`、`template <class T> constexpr T pi = ...`
