# 字符串

std::string 的底层（SSO）、常用操作、string_view，以及几个真会踩的坑（生命周期、编码、性能）。

## 1. SSO（短字符串优化）

**问题**：`std::string` 对象本身有多大？如果它总是"指针 + 长度 + 容量"，那每个 string 都要堆分配，短字符串开销大。

**SSO 答案**：短字符串**直接存在对象内部**（栈上），超过阈值才堆分配：

```cpp
// std::string 对象内部（简化）：
// union {
//     char buf[16];          // 短字符串：直接放这（栈上）
//     char* ptr;             // 长字符串：指向堆
// };
// size_t size, capacity;

std::string s1 = "hi";          // 短：存在对象内部，无堆分配
std::string s2(1000, 'a');      // 长：堆分配

sizeof(std::string);            // 常见是 32（GCC/libstdc++），不管多长都一样
```

**关键**：`sizeof(std::string)` 是固定的（对象本身大小），和字符串多长无关；数据要么在对象内（短），要么在堆上（长）。

**常见问题**："string 有多长时开始堆分配？"——答：超过 SSO 缓冲区（libstdc++ 是 15 字节）。

## 2. 常用操作

```cpp
std::string s = "hello";
s.size();                    // 长度（字节数，不是字符数！）
s += " world";               // 拼接
s.substr(0, 5);              // 子串（返回新 string，拷贝！）
s.find("ll");                // 查找，返回位置或 npos
s.contains("ll");            // C++20，判断包含
s.starts_with("he");         // C++20
s == "hello";                // 比较
s.c_str();                   // 转 C 风格字符串（给 C 接口用）
```

**注意**：`s.size()` 返回**字节数**，中文字符一个占 3 字节（UTF-8），不是字符个数。

## 3. std::string_view（零拷贝视图）

```cpp
std::string s = "hello world";
std::string_view sv = s;      // 不拷贝，只记录指针+长度

sv.substr(0, 5);              // 视图切片，零拷贝（string 的 substr 是拷贝！）
sv == "hello";                // 直接比较

// ⚠️ 注意：sv 不拥有数据，源字符串销毁后 sv 悬垂！
```

**对比**：

| | string::substr | string_view::substr |
|--|---------------|--------------------|
| 拷贝 | ✅ 拷贝新字符串 | ❌ 零拷贝 |
| 用途 | 需要独立字符串 | 只读、传递参数 |

## 4. 生命周期：两个真会 UB 的坑

**① `c_str()` / `data()` 的指针会失效** ❌——之后只要发生"可能重新分配"的操作（`+=`、`append`、`insert`、`resize`…），指针就悬垂：

```cpp
std::string s(100, 'a');
const char* p = s.c_str();
s += std::string(1000, 'b');   // 重新分配 → p 悬垂
printf("%c", p[0]);            // UB
```

实测（ASan）：`heap-use-after-free` ❌。**规则**：`c_str()` 的结果只"立刻用"（马上传给 C 接口 ✅），不要存下来 ❌。

**② `string_view` 不拥有数据**——三种禁区 ❌：

- 返回**局部 string** 的 view（函数一返回就悬垂）
- 存成成员变量 / 跨语句长期持有 ❌
- 指向临时对象（如 `string_view sv = s + "x";` ❌）

实测（ASan）：同样 `heap-use-after-free` ❌。**安全用法**：只在"源串还活着"的作用域里当只读参数 ✅。

## 5. 编码：`size()` 是字节，不是字符

```cpp
std::string zh = "中文ab";
zh.size();          // 8 —— 2 个中文 × 3 字节 + 2
zh[0];              // 0xE4 —— 只是"中"的第一个字节，不是字符 ❌
zh.substr(0, 1);    // 切出半个"中"（坏掉的 UTF-8 ❌）
```

- ASCII 下"字节 = 字符"，UTF-8 下**必须区分**
- 按字符处理要自己解析 UTF-8（看首字节判长度）或用库；C++20 有 `char8_t`/`u8string`（但它仍是**字节序列**）
- 常见翻车：`size()` 当字数、`substr` 按字节截断中文 ❌

## 6. 拷贝与拼接的性能

实测（追加 5 万字符）：

| 写法 | 耗时 |
|------|:---:|
| `s = s + c` | **16.1 ms** ❌（每次造临时串 + O(n²)） |
| `s += c` | **0.027 ms**（摊还） |
| `s.reserve(n)` + `s += c` | **0.021 ms** |

- `a + b + c` 会产生临时对象；循环里拼接一律 `+=`/`append`，知道最终长度就 `reserve`
- **函数参数**：传值会整串拷贝——实测传 1 MB 字符串 200 次：**传值 4.4 ms vs `const&` 0.000 ms** → 只读用 `const string&`
- **返回**：直接 `return local;`（RVO/NRVO 不拷贝 ✅），别写 `return std::move(local);` ❌（具体见[右值引用与移动语义](右值引用与移动语义.md) ✅）

## 7. 查找：用 `npos`，不要用 `-1`

```cpp
if (s.find(x) >= 0) { }        // ❌ 恒真（无符号），编译器还会警告 -Wtype-limits
if (s.find(x) != std::string::npos) { }   // 正确写法
```

`npos` 就是 `SIZE_MAX`（实测 = 18446744073709551615 ✅）。另外 `int pos = s.find(x);` 会把 `npos` 截断 ⚠️（开 `-Wconversion` 才会警告 ✅）。

## 8. 字符分类函数：必须先转 `unsigned char`

`isalpha` / `isdigit` / `toupper` 的标准要求：参数要么是 `EOF`，要么**能表示成 `unsigned char`** ❌——直接传负的 `char`（中文/非 ASCII 字节）是 UB：

```cpp
char c = (char)0xE9;              // 实测 = -23（负数 ⚠️）
isalpha(c);                       // ⚠️ UB（标准不允许传负数）
isalpha((unsigned char)c);        // 正确写法
```

而且这些函数是**按字节、按 locale** 的——处理 UTF-8 中文别指望它们。

## 9. 数值转换

```cpp
std::stoi("12abc");        // 12 —— 只解析前缀，不报错 ⚠️
std::stoi("abc");          // 抛 std::invalid_argument（实测）
std::stoi("999999999999"); // 抛 std::out_of_range（实测）
```

要"不抛异常 + 更快"就用 C++17 的 `from_chars`（实测：不抛异常，返回"停在第 2 个字符"）——见 [C++17](C++17.md)。输出方向：`to_string` / `to_chars`。

## 10. 要点回顾

1. **SSO**：短字符串存对象内（栈），超过阈值（libstdc++ 15 字节）才堆分配
2. **sizeof(string) 固定**：和内容长度无关（约 32）
3. **size() 是字节数**：UTF-8 中文一个 3 字节
4. **substr 是拷贝**：频繁子串用 string_view（零拷贝）
5. **string_view 不拥有数据**：源销毁后悬垂——别返回局部串的 view、别长期持有
6. **`c_str()` 的指针会失效**：之后任何"可能重新分配"的操作都会让它悬垂（ASan 实测 use-after-free）
7. **`size()` 是字节**：UTF-8 中文一个 3 字节；`s[i]`/`substr` 都按字节，别当字符用
8. **拼接用 `+=`（可 `reserve`）**：`s = s + c` 是 O(n²)（实测差 600 倍）；参数只读用 `const&`
9. **查找用 `npos`**：`find(...) >= 0` 恒真 ❌；`isalpha` 类函数要传 `(unsigned char)` ✅
10. **转换会抛异常**：`stoi` 抛 `invalid_argument`/`out_of_range`；不抛用 `from_chars`
