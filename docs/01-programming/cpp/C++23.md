# C++23

## 语言特性

### 1. if consteval

```cpp
constexpr int f(int x) {
    if consteval {                 // 现在是编译期求值吗？
        return compile_time_path(x);   // 编译期走这条
    } else {
        return runtime_path(x);        // 运行期走这条
    }
}
```

**和 `if constexpr` 的区别**：`if constexpr` 判的是"类型/常量表达式"，`if consteval` 判的是"**当前这次调用是不是在常量求值中**"。

**用途**：同一个 `constexpr` 函数里，编译期用一套实现（比如查表、简单算法）、运行期用另一套（比如用 SIMD、调库）——以前要靠 `std::is_constant_evaluated()` 惯用法，容易写错。

**注意**：`if consteval` 的否定分支写 `else` 或 `if !consteval`（C++23 起支持 `!consteval` 写法）；它必须在**立即函数上下文**里用（简单说：写在 `constexpr` 函数内）。

### 2. deducing this（显式对象参数）

```cpp
struct Widget {
    // 老写法：成员函数；this 是隐式的
    int value() const { return v_; }

    // 新写法：显式写出对象参数（类型可以推）
    int value2(this const Widget& self) { return self.v_; }

    int v_ = 0;
};
```

**能解决什么**（以前要写一堆重载/CRTP）：

```cpp
// ① 按值类别限定：左值/右值各一套实现，不用写两个重载
struct Buffer {
    void work(this Buffer&)       { /* 左值：可以复用内部资源 */ }
    void work(this Buffer&&)      { /* 右值：可以偷资源 */ }
};

// ② 替代 CRTP（静态多态）：派生类行为直接在基类里拿到 self 的真实类型
struct Base {
    template <typename Self>
    auto name(this Self&& self) {
        return self.get_name();          // self 是真实类型，不是 Base
    }
};

// ③ 递归 lambda（lambda 调用自己）
auto factorial = [](this auto&& self, int n) -> int {
    return n <= 1 ? 1 : n * self(n - 1);   // self 就是 lambda 自己
};
factorial(5);      // 120
```

**要点**：`this T` 的形式让"对象参数"变成普通参数——**按值/按引用/按 const、左值/右值限定**都能用一套模板表达，代码风格更统一。

### 3. 多维下标运算符

```cpp
struct Matrix {
    int rows = 2, cols = 3;
    int data[6] = {1, 2, 3, 4, 5, 6};

    int& operator[](int r, int c) { return data[r * cols + c]; }   // 直接多参数
};

Matrix m;
m[1, 1];          // 以前只能写 m(1, 1) 或 m[1][1]（返回代理对象）
```

**以前怎么绕**：`operator()`（调用语法）或返回"行代理"再重载一次 `[]`——都有别扭之处。C++23 直接支持 `operator[]` 多个参数。

**用途**：矩阵/张量/图像库（`img[y, x]`、`tensor[i, j, k]`）——`std::mdspan` 也用了这个特性。

### 4. auto(x)（衰减拷贝）

```cpp
void f(const Widget& w) {
    auto copy = auto(w);       // 显式拷贝一份（去掉引用和 const）
    // 等价于：auto copy = Widget(w);
}
```

**它是什么**：`auto(x)` 是"**按值传递那样的拷贝**"（decay-copy）——在泛型代码里想明确"我要一份副本"时用：

```cpp
// 泛型代码里，参数可能是引用、可能是 const，也可能是 proxy 类型
template <typename T>
void store(T&& value) {
    // 想把值拷贝进容器，但 value 可能是引用/const/代理：
    vec.push_back(auto(std::forward<T>(value)));   // 明确产生一个"值"
}
```

**注意**：会把代理类型"物化"成真实类型（如 `vector<bool>` 的代理 → `bool`），这正是想要的。

### 5. std::print / std::println（直接打印）

```cpp
#include <print>

std::print("{} + {} = {}\n", 1, 2, 3);
std::println("{} + {} = {}", 1, 2, 3);        // 自动换行
std::println("{:.2f}", 3.14159);               // 支持 format 的全部格式
std::println("{}", std::vector{1, 2, 3});      // 直接打印 range：支持

std::println(stderr, "错误: {}", "原因");       // 输出到文件流
```

**为什么不用 iostream/printf**：

- 比 `std::cout <<` 短、无状态（不用管 `<<` 链和 endl）
- 比 `printf` 安全（格式串编译期检查）
- 直接支持 range（不用手写循环）

**坑**：编译器支持较晚（GCC 14+ 才有 `<print>`）；输出走 stdout，和 iostream 混用时注意**刷新顺序**（C++23 起 `std::print` 与 `std::cout` 是同步的，但混着用容易乱）。

### 6. std::expected（期望值或错误）

```cpp
#include <expected>

std::expected<int, std::string> parse_int(const std::string& s) {
    try {
        return std::stoi(s);
    } catch (...) {
        return std::unexpected("不是合法整数");       // 错误路径：带错误信息
    }
}

auto r = parse_int("42");
if (r) {
    std::cout << *r << '\n';        // 取值
} else {
    std::cout << r.error() << '\n'; // 取错误
}
r.value_or(-1);                     // 出错时的默认值
```

**和 `optional` / 异常的分工**：

| 方案 | 失败时带信息 | 开销 | 适合 |
|------|-------------|------|------|
| `optional<T>` | ❌（只有"没有"） | 最小 | 失败原因不重要 |
| `expected<T, E>` |（错误值） | 小 | **可预期失败 + 要原因**（解析、IO、配置） |
| 异常 | ✅ | 抛出路径较贵 | 不可恢复/不该由调用方处理的错误 |

**monadic 操作**（和 optional 一样，C++23 都给加了）：

```cpp
auto r = parse_int("42")
    .and_then([](int x) -> std::expected<int, std::string> { return x * 2; })  // 成功才继续
    .transform([](int x) { return x + 1; })                                    // 变换成功值
    .or_else([](const std::string& e) -> std::expected<int, std::string> {     // 失败时兜底
        return 0;
    });
```

### 7. std::mdspan（多维视图）

```cpp
#include <mdspan>

std::vector<double> buf(2 * 3, 1.0);            // 一维存储
std::mdspan<double, std::dextents<size_t, 2>> mat{buf.data(), 2, 3};

mat[1, 1] = 9.0;                                // 用 C++23 的多维下标访问
mat.extent(0);                                  // 2（行数）
mat.rank();                                     // 2（维数）
```

**它是什么**：**多维数组的"视图"**——不拥有数据，只是"指针 + 维度 + 布局"，**零拷贝**。

| 组成 | 含义 |
|------|------|
| 元素类型 | `double` |
| Extents | 各维长度（`dextents` = 运行期长度；也可以固定长度） |
| Layout | `layout_right`（行优先，默认）/ `layout_left`（列优先） |
| Accessor | 怎么读写元素（一般默认） |

**用途**：科学计算/ML 里把一维 buffer 当矩阵/张量用，替代"手动算下标"（`buf[i * cols + j]`）和一堆自定义矩阵类。

### 8. std::generator（生成器）

```cpp
#include <generator>

std::generator<int> range(int n) {
    for (int i = 0; i < n; ++i) {
        co_yield i;                 // 协程：每次产出后挂起
    }
}

for (int x : range(3)) {
    std::cout << x << ' ';          // 0 1 2
}

// 也能递归产出（树的遍历）
std::generator<int> walk(const Node* n) {
    if (!n) co_return;
    co_yield n->value;
    co_yield std::ranges::elements_of(walk(n->left));    // 把子生成器接进来
    co_yield std::ranges::elements_of(walk(n->right));
}
```

**意义**：C++20 有协程机制但**没有现成的生成器类型**（要手写 30 行 `promise_type`，见 [C++20](C++20.md)）；C++23 的 `std::generator` 填上了这个坑，可直接当 range 用。

**注意**：GCC 14+ / MSVC 才有；生成器是**惰性**的（不遍历就不执行）。

### 9. std::flat_map / std::flat_set

```cpp
#include <flat_map>

std::flat_map<int, std::string> fm{{2, "b"}, {1, "a"}, {3, "c"}};
fm[1];                 // "a"（查找 O(log n)，二分）
fm.contains(2);        // true
```

**和 `std::map` 的区别**：

| | `std::map` | `std::flat_map` |
|--|-----------|-----------------|
| 底层 | 红黑树（每个节点单独分配） | **排序的连续数组**（内部是 vector） |
| 查找 | O(log n) | O(log n)（二分，**缓存友好**） |
| 插入/删除 | O(log n)（不动别的元素） | **O(n)**（要挪动元素） |
| 内存 | 每节点有指针开销 | 紧凑连续 |

**什么时候用**：**构建一次、查询很多次**（配置表、静态映射）——遍历和查找都更快；频繁增删就别用。

### 10. 范围新视图

```cpp
#include <ranges>
namespace rv = std::views;

auto a = std::vector{1, 2, 3};
auto b = std::vector{4, 5, 6};

for (auto [x, y] : rv::zip(a, b)) { }            // 配对遍历（不用手写下标）
for (auto [i, x] : rv::enumerate(a)) { }         // 带下标
for (auto chunk : a | rv::chunk(2)) { }          // 每 2 个一组
for (auto win : a | rv::slide(2)) { }            // 滑动窗口（步长 1）
for (auto x : rv::iota(1) | rv::stride(2) | rv::take(3)) { }   // 步长
a | rv::as_const;                                // 转 const 视图
a | rv::as_rvalue;                               // 转右值视图（移动语义）
rv::cartesian_product(a, b);                     // 笛卡尔积
```

**要点**：这些以前都要手写循环/下标；现在 `|` 串起来，**惰性**且可组合。

**坑**：和所有 view 一样**不拥有数据**——`zip` 出来的 `tuple` 里是引用，别存下来超出源容器生命周期。

### 11. std::ranges::to（范围转容器）

```cpp
#include <ranges>

auto v = std::views::iota(1, 5) | std::ranges::to<std::vector>();     // {1,2,3,4}
auto m = v | std::views::filter([](int x) { return x % 2 == 0; })
           | std::ranges::to<std::map<int, int>>();   // 也能转 map 等（元素要能构造 key/value）
```

**它补的是什么**：C++20 的 ranges 只能"看"（view），要**物化**还得 `std::vector(v.begin(), v.end())` 或手写循环——`ranges::to` 一步收进任意容器，且能配合管道写。

## 小工具

### 12. 常用小特性

```cpp
// enum → 底层整数（不用写 static_cast）
enum class Color { Red, Green };
std::to_underlying(Color::Red);        // 0

// 标记"不可能走到这里"（比 assert 更明确，且给优化器更多信息）
switch (x) {
    case 1: return a;
    case 2: return b;
    default: std::unreachable();       // 调用它是 UB，但能表达"逻辑上不可能"
}

// 字节序翻转（网络/文件格式）
std::byteswap(0x1234u);                // 0x34120000

// 调用栈（调试/日志）
#include <stacktrace>
std::cout << std::stacktrace::current() << '\n';

// string / string_view 的 contains
std::string("abc").contains("b");      // true

// optional / expected 的 monadic 操作（不用一层层 if）
opt.and_then(f).transform(g).or_else(h);

// 只能移动的 function：可以装 move-only 的可调用对象（std::function 装不了）
#include <functional>
std::move_only_function<int()> mf = [p = std::make_unique<int>(1)] { return *p; };

// ranges 版 fold
std::ranges::fold_left(v, 0, std::plus<>{});          // 左折叠
std::ranges::fold_right(v, 0, std::plus<>{});         // 右折叠
```

## 编译器支持一览

本机实测（GCC 13.3 / Clang 18，2026 年环境）——**C++23 的坑主要在工具链**：

| 特性 | GCC 13.3 | 补充说明 |
|------|:---:|------|
| `if consteval`、多维下标、`auto(x)` | ✅ | |
| `std::expected`（含 monadic 操作） | ✅ | |
| `views::zip` / `enumerate` / `chunk` / `slide` / `stride` / `cartesian_product` / `as_const` | ✅ | |
| `to_underlying` / `byteswap` / `unreachable` / `string::contains` | ✅ | |
| `move_only_function` / `ranges::fold_left` / `fold_right` | ✅ | |
| `<stacktrace>` | ✅ | **链接要加 `-lstdc++_libbacktrace`** |
| deducing this | ❌ | 语言特性，需要新编译器（Clang 18 ✅） |
| `std::print` / `std::println` | ❌ | 需要更新的标准库 |
| `std::mdspan` | ❌ | 同上 |
| `std::generator` | ❌ | 同上 |
| `std::flat_map` / `flat_set` | ❌ | 需要更新的标准库 |
| `std::ranges::to` | ❌ | 同上（GCC 13 没有；临时用 `std::vector(v.begin(), v.end())` 收集） |

**遇到"不是 std 的成员"时先查版本**——C++23 有一半内容是新库里才有的。
